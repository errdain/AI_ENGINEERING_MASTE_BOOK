### 1. WHAT IS IT?

A digital image is a finite grid of samples of light. Each grid cell (pixel) stores one or a few numbers for intensity or colour. Everything a vision model ever sees is that array of numbers.

### 2. WHY DOES IT EXIST?

Cameras measure light with a sensor grid; computers can only store discrete values. Representation choices (resolution, bit depth, colour space, compression) decide what information survives before any model runs.

### 3. DETAILED EXPLANATION

**Sampling and quantization.** Sampling picks *where* we measure (resolution, e.g. 224x224); quantization picks *how finely* we record each measurement (8 bits = 256 levels per channel, 0-255).

**Raster vs vector.** Photos are *raster* (pixel grids); icons and charts may be *vector* (shapes + coordinates). Vision models consume rasters, so vector art is rendered first.

**Compression.** JPEG is lossy (discards high-frequency detail, creates blocky artifacts); PNG is lossless. Models trained on JPEG-decoded pixels see JPEG artifacts, so train/serve pipelines should use the same decoding.

**Colour spaces.** RGB (sensor/display), grayscale (1 channel), HSV/YCbCr (separate brightness from colour). Deep learning almost always uses RGB, floats in [0,1] or standardized.

### 4. HOW DOES IT WORK?

Light -> sensor (Bayer filter, one colour per photosite) -> demosaicing -> 8-bit RGB -> optional compression (JPEG) -> file. Loading reverses it: decode bytes into a `uint8` array of shape (H, W, 3).

### 5. SIMPLE EXAMPLE

A 3x3 grayscale image `[[0,255,0],[255,255,255],[0,255,0]]` is a white plus sign on black. Nine numbers, nothing else.

### 6. TECHNICAL EXAMPLE

A 224x224 RGB image has 224*224*3 = 150,528 numbers; stored as uint8 it is 150,528 bytes raw (about 147 KiB), regardless of whether the on-disk JPEG is 20 KB. Raw memory, not file size, is what the GPU sees.

### 8. INPUT → PROCESS → OUTPUT

Input: photons / file bytes. Process: sample -> quantize -> (compress) -> decode. Output: integer array `(H, W, C)` ready for preprocessing ([13.3 Image preprocessing](13.03-image-preprocessing.md)).

### 9. ENTERPRISE USE CASE

A claims system receives phone photos as HEIC/JPEG at 12 MP. Storing 12 MP originals for audit but running models on a 512 px derivative is a common cost/accuracy split; the pipeline must record which derivative a prediction was made on.

### 10. AI ENGINEERING CONNECTION

Every multimodal model starts here. Resolution and compression decide VLM token counts ([13.17 Patch embeddings](13.17-patch-embeddings.md), [13.22 Vision-language models (VLMs)](13.22-vision-language-models-vlms.md)) and OCR accuracy ([13.25 OCR fundamentals](13.25-ocr-fundamentals.md)).

### 11. ADVANTAGES

Simple, universal, lossless formats exist; numeric arrays plug directly into linear algebra.

### 12. LIMITATIONS

Pixels carry no semantics; the same object under different lighting yields very different numbers. Lossy compression and low resolution remove information permanently.

### 13. TRADE-OFFS

Resolution: more detail vs quadratic growth in pixels (and in ViT tokens, [13.16 Image patches](13.16-image-patches.md)). Lossy compression: storage/bandwidth vs artifacts that harm small-text OCR.

### 14. COMMON MISTAKES

Mixing up (H, W) and (W, H); assuming a 'PNG' is 8-bit RGB (it may be 16-bit or palette-based); forgetting EXIF rotation so photos arrive sideways; decoding with two libraries that differ slightly.

### 15. PERFORMANCE / COST CONSIDERATIONS

Decoding JPEG on CPU often dominates data-loading time; raw size scales with H*W. Down-sampling early cuts every downstream cost.

### 16. SECURITY CONSIDERATIONS

Image files are untrusted input: decompression bombs (tiny file, giant dimensions), malformed headers in decoders, and metadata (EXIF GPS) leaking privacy. Cap dimensions before decoding, strip metadata, use maintained decoders.

### 17. INTERVIEW EXPLANATION

An image is a sampled, quantized grid: height x width x channels of intensity numbers, typically 8-bit RGB. Models never see 'objects', only that array, so resolution, colour space, compression and decoding choices upstream directly limit what any model can learn.

### 18. RAPID-FIRE ANSWER

A grid of quantized colour/intensity samples (H x W x C).
