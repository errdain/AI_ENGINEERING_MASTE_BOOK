### 1. WHAT IS IT?

Cross-modal attention concepts: how one modality's tokens attend to another's - text queries attending to visual keys/values (cross-attention), or both modalities in one self-attention sequence (early fusion).

### 2. WHY DOES IT EXIST?

Fusing modalities inside the network lets language tokens pull exactly the image regions they need, beyond a single global vector.

### 3. DETAILED EXPLANATION

**Cross-attention.** Queries from text/LLM hidden states; keys/values from image tokens (math in [Tier 7 Attention](../tier-07-attention/)). Used in Flamingo-style designs (REVIEW_REQUIRED for details).

**Joint self-attention.** Visual tokens sit in the same sequence as text tokens (LLaVA-style): every text token can attend to every image token (causal masks apply to text).

**Q-Former / resampler.** A small set of learned query tokens cross-attends to many patch tokens and outputs a fixed, smaller number of visual tokens (compression).

**Cost.** Joint attention cost grows with (visual + text tokens)^2; cross-attention costs text x image tokens.

Reference diagram: [13.22 Vision-language models (VLMs)](13.22-vision-language-models-vlms.md) figure (visual tokens joined with prompt tokens).

### 4. HOW DOES IT WORK?

`attn = softmax(Q_text K_image^T / sqrt(d)) V_image` for cross-attention; or concatenate sequences and mask appropriately.

### 5. SIMPLE EXAMPLE

The word 'total' in the question attends strongly to the patch tokens containing the bottom of the receipt.

### 6. TECHNICAL EXAMPLE

Dimensions: text 20 tokens, image 576 tokens -> cross-attention score matrix 20 x 576 per head, vs joint self-attention of 596 x 596.

### 7. CODE

```python
import torch, torch.nn.functional as F
d = 32
q = torch.randn(20, d)          # text-side queries
k = v = torch.randn(576, d)     # image-side keys/values
out = F.softmax(q @ k.T / d ** 0.5, dim=-1) @ v
print(out.shape)                # torch.Size([20, 32]); score matrix is 20 x 576
```
Attention math is taught in [Tier 7 Attention](../tier-07-attention/); no VLM is trained in this tier's lab.

### 8. INPUT → PROCESS → OUTPUT

Input: text and image token sets. Process: attention across them. Output: text states enriched with visual information.

### 9. ENTERPRISE USE CASE

Document-QA systems cap image tokens per page so attention cost stays predictable at 10k pages/day.

### 10. AI ENGINEERING CONNECTION

Underlies how VLMs ground answers in image regions and why token counts dominate cost.

### 11. ADVANTAGES

Fine-grained grounding; flexible fusion.

### 12. LIMITATIONS

Cost with many visual tokens; attention maps are weak explanations.

### 13. TRADE-OFFS

Early fusion (richer, costlier) vs late alignment (cheap, coarse); compress with Q-Former (cheaper, may lose detail).

### 14. COMMON MISTAKES

Reading attention maps as faithful explanations; ignoring mask rules for causal text; confusing cross- and self-attention shapes.

### 15. PERFORMANCE / COST CONSIDERATIONS

Cross-attention: O(T_text * T_image); joint: O((T_text+T_image)^2).

### 16. SECURITY CONSIDERATIONS

Visual tokens can steer the LLM (injection); see [13.22 Vision-language models (VLMs)](13.22-vision-language-models-vlms.md).

### 17. INTERVIEW EXPLANATION

Cross-modal attention lets text tokens attend to image tokens, either via explicit cross-attention layers (queries from text, keys/values from image) or by putting visual tokens in the same self-attention sequence. Resamplers like Q-Former compress many patch tokens into a few. The trade-off is fidelity versus attention cost.

### 18. RAPID-FIRE ANSWER

Text queries attend to image keys/values (or share one sequence).
