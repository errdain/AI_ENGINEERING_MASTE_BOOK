### 1. WHAT IS IT?

Padding adds extra border pixels (usually zeros) around the input before convolving.

### 2. WHY DOES IT EXIST?

Without it every conv shrinks the map by k-1 and border pixels participate in fewer windows than centre pixels.

### 3. DETAILED EXPLANATION

**Modes.** `valid` (p=0, output shrinks), `same` (p=(k-1)/2 for odd k, stride 1 keeps size), `full`, plus zero / reflect / replicate content.

**Formula.** With k=3: p=1 keeps size at s=1. Padding adds 2p to n.

**Side effect.** Zero padding gives networks a weak cue about absolute position (they can detect the border).

Play: padding slider in [`conv_explorer.html`](interactive/conv_explorer.html) - the grey frame is the added border.

### 4. HOW DOES IT WORK?

Create an (n+2p) array, copy the image into the centre, convolve.

### 5. SIMPLE EXAMPLE

A 5x5 image with 3x3 kernel: valid gives 3x3, same (p=1) gives 5x5.

### 6. TECHNICAL EXAMPLE

`conv_out_size(n,3,1,1) == n` is asserted in the lab tests; `conv2d_naive` uses `np.pad` exactly like this.

### 7. CODE

```python
import sys; sys.path.insert(0, "lab")
from vision import conv_out_size
for p in (0, 1, 2): print(p, conv_out_size(16, 3, 1, p))   # 14 16 18
```

### 8. INPUT → PROCESS → OUTPUT

Input: image, p. Process: border add. Output: larger input to the conv.

### 9. ENTERPRISE USE CASE

Segmentation of satellite tiles uses reflect/overlap padding at tile borders so predictions do not show seams.

### 10. AI ENGINEERING CONNECTION

Segmentation ([13.27 Image segmentation](13.27-image-segmentation.md)) needs same-size outputs; padding style affects border quality.

### 11. ADVANTAGES

Preserves size and border information.

### 12. LIMITATIONS

Zero borders are artificial; extra compute at edges.

### 13. TRADE-OFFS

valid (no fake data, shrinking) vs same (size-preserving, synthetic border).

### 14. COMMON MISTAKES

Forgetting padding when stacking many layers (map vanishes); using even kernels with 'same' (asymmetric padding); not matching padding between framework and reimplementation.

### 15. PERFORMANCE / COST CONSIDERATIONS

Padding costs little; it increases compute slightly per layer.

### 16. SECURITY CONSIDERATIONS

Not applicable.

### 17. INTERVIEW EXPLANATION

Padding adds a border so size is preserved and edge pixels are used fully. 'Same' uses p=(k-1)/2 at stride 1; 'valid' uses none and shrinks the map by k-1.

### 18. RAPID-FIRE ANSWER

Border added before convolution to control output size and edge treatment.
