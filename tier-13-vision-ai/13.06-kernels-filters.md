### 1. WHAT IS IT?

A kernel (filter) is the small weight array a convolution slides over the image; it defines which local pattern the output channel responds to.

### 2. WHY DOES IT EXIST?

Hand-designed kernels (blur, edges) show what filters compute; CNNs *learn* kernels from data instead of designing them.

### 3. DETAILED EXPLANATION

**Classic kernels (3x3).** Identity, box blur (all 1/9), Sobel-x/y (horizontal/vertical gradients), sharpen (centre 5, neighbours -1).

**Learned kernels.** Initialized randomly and updated by backprop; the first-layer filters of trained image CNNs frequently look like oriented edges and colour blobs (a commonly reported observation).

**Properties.** Weights sum to 1 -> brightness-preserving (blur); weights sum to 0 -> responds only to change (edge); sign of output tells edge direction.

![Five kernels on the same noisy circle](figures/03_kernel_gallery.png)

*Look at: blur removes the noise, Sobel-x lights up left/right edges (colour = sign), Sobel-y top/bottom edges, sharpen amplifies noise.*

Play: [`conv_explorer.html`](interactive/conv_explorer.html) preset menu.

### 4. HOW DOES IT WORK?

Choose or learn k x k weights; convolve ([13.5 Convolution](13.05-convolution.md)); the output map is large where the local patch correlates with the kernel pattern.

### 5. SIMPLE EXAMPLE

Sobel-x on a black/white vertical boundary gives a strong response only in columns touching the boundary.

### 6. TECHNICAL EXAMPLE

Lab test `test_edge_kernel_responds_at_edge_only`: on an image with a step edge at column 4, Sobel-x output is 0 away from the edge and positive near it. `KERNELS` in `lab/vision.py` holds the presets.

### 7. CODE

```python
import sys; sys.path.insert(0, "lab")
import numpy as np
from vision import KERNELS, conv2d_single
img = np.zeros((8, 8)); img[:, 4:] = 1                 # vertical step edge
g = conv2d_single(img, KERNELS["sobel-x"])
print(g.round(0)[0])                                  # [0. 0. 4. 4. 0. 0.]
```

### 8. INPUT → PROCESS → OUTPUT

Input: image + kernel weights. Process: correlate. Output: filtered map that highlights the pattern.

### 9. ENTERPRISE USE CASE

Classical document-scanning pipelines still use blur/threshold/morphology kernels for deskewing before OCR ([13.25 OCR fundamentals](13.25-ocr-fundamentals.md)).

### 10. AI ENGINEERING CONNECTION

Learned kernels are the weights of every CNN; visualizing early-layer kernels is a basic debugging/teaching tool.

### 11. ADVANTAGES

Interpretable at layer 1; tiny; hand-tunable.

### 12. LIMITATIONS

Single kernel = single pattern; deeper filters are hard to interpret.

### 13. TRADE-OFFS

Hand-designed (transparent, no data) vs learned (accurate, opaque).

### 14. COMMON MISTAKES

Assuming learned kernels equal Sobel; ignoring the kernel's sign convention; not normalizing a blur kernel (image gets brighter).

### 15. PERFORMANCE / COST CONSIDERATIONS

Separable kernels (e.g. Gaussian) can be applied as two 1-D passes: 2k instead of k^2 multiplies.

### 16. SECURITY CONSIDERATIONS

Filter-based preprocessing can be bypassed by adversarial noise; do not rely on blur as a defence.

### 17. INTERVIEW EXPLANATION

A kernel is a small weight array that defines the pattern a conv channel detects. Blur kernels sum to one; edge kernels sum to zero and respond to gradients. In CNNs the kernel values are learned by backprop rather than designed.

### 18. RAPID-FIRE ANSWER

The small learnable weight array a convolution slides; defines the detected pattern.
