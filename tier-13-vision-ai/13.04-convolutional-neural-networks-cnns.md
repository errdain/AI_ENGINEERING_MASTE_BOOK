### 1. WHAT IS IT?

A Convolutional Neural Network is a network whose early layers apply small learnable filters at every image location (shared weights), alternate with nonlinearities and pooling, and end in a classifier or embedding head.

### 2. WHY DOES IT EXIST?

A fully connected layer on a 224x224x3 image needs 150,528 weights *per output unit* and ignores that nearby pixels are related and that a cat is a cat anywhere in the frame. CNNs bake in two priors: locality and translation equivariance, with far fewer parameters.

### 3. DETAILED EXPLANATION

**Building blocks.** conv -> nonlinearity (ReLU) -> pool, repeated; channels grow (3 -> 16 -> 32 ...) while spatial size shrinks. Final layers: global average pool + linear head.

**Weight sharing.** One 3x3x3 filter (27 weights + bias) is reused at every position; a conv layer with 16 filters has 16*(27)+16 = 448 parameters regardless of image size.

**Hierarchy.** Early layers learn edges/colour blobs, middle layers textures/parts, late layers object-level patterns (as typically visualised in the literature; our toy lab is too small to show this).

**Inductive bias vs data.** CNN priors help most with little data; ViT ([13.15 Vision Transformer (ViT)](13.15-vision-transformer-vit.md)) has weaker priors and needs more data or pretraining.

![CNN vs ResNet vs ViT on the synthetic lab](figures/11_cnn_vs_vit_lab.png)

*Look at: right panel - the CNN is ahead of the ViT at every training-set size (nearly tied at 10%, about 9 points ahead at 100%). This toy never reaches the large-data regime where ViTs overtake CNNs, so it shows only that ViT has no advantage at small scale (one seed, 1,200 images).*

### 4. HOW DOES IT WORK?

Input (B,3,H,W) -> `Conv2d` sliding filters ([13.5 Convolution](13.05-convolution.md)) -> feature maps ([13.11 Feature maps](13.11-feature-maps.md)) -> `ReLU` -> `MaxPool` ([13.9 Pooling](13.09-pooling.md)) -> ... -> global pooling -> `Linear` -> logits. Trained end-to-end by backprop (Tier 4): gradients flow to every shared filter from every position.

### 5. SIMPLE EXAMPLE

Detecting a plus sign: layer 1 finds short horizontal and vertical strokes anywhere; layer 2 notices 'horizontal stroke crossing vertical stroke'; the head says 'cross'.

### 6. TECHNICAL EXAMPLE

Lab `TinyCNN`: conv(3->16)-ReLU-pool-conv(16->32)-ReLU-pool-GAP-linear(32). 6,276 parameters reach about 0.96 test accuracy on 4 synthetic shape classes (measured in this lab; seed-dependent).

### 7. CODE

```python
import sys; sys.path.insert(0, "lab")
from vision import make_dataset
from models import TinyCNN, fit_classifier, count_params
Xtr, ytr, _ = make_dataset(600, seed=0); Xte, yte, _ = make_dataset(200, seed=1)
m = TinyCNN()
acc = fit_classifier(m, Xtr, ytr, Xte, yte, epochs=15)   # run_lab.py uses 1,200 images / 30 epochs
print(count_params(m), "params, test acc", round(acc, 2))   # chance = 0.25
```
Lab: [`lab/models.py`](lab/models.py) `TinyCNN`; end-to-end: `python lab/run_lab.py`.

### 8. INPUT → PROCESS → OUTPUT

Input: (B,3,H,W) tensor. Process: stacked conv/ReLU/pool blocks, global pool. Output: class logits or an embedding vector ([13.14 Image embeddings](13.14-image-embeddings.md)).

### 9. ENTERPRISE USE CASE

Factory visual inspection: a small CNN on 128x128 crops classifies 'ok/scratch/dent' on an edge GPU with millisecond latency, where a ViT or VLM would be overkill and slower.

### 10. AI ENGINEERING CONNECTION

CNNs remain strong, efficient backbones (edge devices, detection, segmentation); many VLM vision towers are ViTs ([13.18 Vision encoders](13.18-vision-encoders.md)) but CNN ideas (locality, hierarchy, pooling) persist in hybrids.

### 11. ADVANTAGES

Few parameters, fast, data-efficient, strong spatial priors, mature tooling.

### 12. LIMITATIONS

Limited global context per layer (receptive field, [13.10 Receptive fields](13.10-receptive-fields.md)); less natural for multimodal token fusion; priors can hurt when data is abundant and tasks are non-local.

### 13. TRADE-OFFS

Depth vs latency; width vs memory; locality prior vs flexibility (ViT).

### 14. COMMON MISTAKES

Forgetting that pooling discards position information; training without normalization/augmentation; evaluating on near-duplicate images; using a classification CNN for tasks requiring dense output without changing the head.

### 15. PERFORMANCE / COST CONSIDERATIONS

Cost ~ H*W*k^2*C_in*C_out per layer (FLOPs, [13.5 Convolution](13.05-convolution.md)); halving resolution cuts conv cost ~4x. Activations (not weights) dominate memory at high resolution.

### 16. SECURITY CONSIDERATIONS

Vulnerable to adversarial perturbations and to spurious cues (background, watermark); validate on shifted data; treat model files as code-adjacent artifacts (pickle loading risks).

### 17. INTERVIEW EXPLANATION

A CNN slides small shared filters across the image, so it uses far fewer parameters than a dense net and is translation-equivariant. Stacked conv + nonlinearity + pooling grows the receptive field and builds a feature hierarchy. Its strong locality prior makes it data-efficient; ViTs trade that prior for flexibility and need more data.

### 18. RAPID-FIRE ANSWER

Stacked shared-weight local filters + pooling: locality and translation-equivariance priors.
