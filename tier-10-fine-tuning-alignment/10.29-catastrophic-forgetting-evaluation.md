### 1. WHAT IS IT?

**Catastrophic-forgetting evaluation** is measuring what a fine-tune lost, with a regression suite run before and after every training round.

### 2. WHY DOES IT EXIST?

You cannot manage forgetting you do not measure.

### 3. DETAILED EXPLANATION

Keep a **regression suite** of capabilities you must not lose (general knowledge, safety refusals, formatting, a few earlier tasks) and run it before and after every fine-tune. Report **deltas**, not absolutes. Track both held-out plain-text loss (cheap, sensitive; what the forgetting figure plots) and task metrics (more meaningful, noisier). In production gate the release on "no more than X-point drop" per suite (thresholds are product decisions).

### 4. HOW DOES IT WORK?

Baseline run -> fine-tune -> same suite -> deltas -> pass/fail gate.

### 5. SIMPLE EXAMPLE

Re-taking last year's exam after studying new material.

### 6. TECHNICAL EXAMPLE

Lab: plain-text loss 0.59 before; 2.96 after full FT; 0.62 with replay ([methods figure](figures/05_full_vs_lora_vs_qlora.png)).

### 7. CODE

```python
def regression(model, suites):                   # suites: {name: callable(model) -> float}
    return {k: f(model) for k, f in suites.items()}
deltas = {k: after[k] - before[k] for k in before}
```

### 8. INPUT → PROCESS → OUTPUT

```
before-suite + after-suite --> deltas --> gate (ship / retrain / rollback)
```

### 9. ENTERPRISE USE CASE

CI jobs run the suite on every candidate adapter.

### 10. AI ENGINEERING CONNECTION

Feeds release gates and links to evaluation tiers (Tier 15/30).

### 11. ADVANTAGES

Early warning; objective gate.

### 12. LIMITATIONS

Suites need maintenance; metrics can be noisy.

### 13. TRADE-OFFS

Breadth versus eval cost.

### 14. COMMON MISTAKES

Only measuring the new task; absolute scores with no baseline; small noisy suites.

### 15. PERFORMANCE / COST CONSIDERATIONS

Running suites adds eval compute for each candidate.

### 16. SECURITY CONSIDERATIONS

Include safety refusals in the suite.

### 17. INTERVIEW EXPLANATION

I keep a regression suite covering general ability, safety and earlier tasks, run it before and after every fine-tune, report deltas and gate the release on allowed drops. Plain-text loss is a cheap sensitive signal; task metrics are more meaningful.

### 18. RAPID-FIRE ANSWER

Measure deltas before you ship.
