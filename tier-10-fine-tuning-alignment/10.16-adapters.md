### 1. WHAT IS IT?

**Bottleneck adapters** insert a small `down-project -> nonlinearity -> up-project (+ residual)` module inside each Transformer block and train only those.

### 2. WHY DOES IT EXIST?

An early PEFT method to adapt one model to many tasks with few parameters.

### 3. DETAILED EXPLANATION

Unlike LoRA, adapters add *layers*, hence extra inference latency unless fused; LoRA's linear form is what makes merging free. Adapter fusion/composition methods exist (`REVIEW_REQUIRED`). Colloquially "adapter" now often means a LoRA adapter file.

### 4. HOW DOES IT WORK?

`h' = h + W_up * act(W_down * h)` after attention and/or MLP; base frozen.

### 5. SIMPLE EXAMPLE

A small plug-in module between two existing pipes.

### 6. TECHNICAL EXAMPLE

Houlsby-style adapters at hidden size d with bottleneck m add about `2dm` parameters per insertion (`REVIEW_REQUIRED` for exact placement in published variants). Not implemented in the lab.

### 7. CODE

```python
class BottleneckAdapter(nn.Module):
    def __init__(self, d, m): super().__init__(); self.down, self.up = nn.Linear(d, m), nn.Linear(m, d)
    def forward(self, h): return h + self.up(torch.relu(self.down(h)))
```
(illustrative; not in `lab/`)

### 8. INPUT → PROCESS → OUTPUT

```
h --> down (d->m) --> nonlinearity --> up (m->d) --> + h
```

### 9. ENTERPRISE USE CASE

Multi-task platforms used adapters before LoRA became dominant.

### 10. AI ENGINEERING CONNECTION

Conceptual ancestor of LoRA; still used in some multi-task setups.

### 11. ADVANTAGES

Small and modular.

### 12. LIMITATIONS

Extra latency; not mergeable by simple addition.

### 13. TRADE-OFFS

Nonlinear expressiveness versus serving cost.

### 14. COMMON MISTAKES

Calling any PEFT file an adapter without noting the type.

### 15. PERFORMANCE / COST CONSIDERATIONS

Params ~2dm per insertion; added sequential compute.

### 16. SECURITY CONSIDERATIONS

Same as other adapters: treat as data-bearing artifact.

### 17. INTERVIEW EXPLANATION

Bottleneck adapters add a tiny down-project, nonlinearity, up-project block with a residual inside each layer and train only that. They add latency since they are extra layers; LoRA's linear form can be merged away, which is why LoRA took over.

### 18. RAPID-FIRE ANSWER

Adapters add layers; LoRA adds a mergeable delta.
