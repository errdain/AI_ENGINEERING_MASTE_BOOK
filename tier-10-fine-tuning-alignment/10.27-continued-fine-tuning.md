### 1. WHAT IS IT?

**Continued fine-tuning** is fine-tuning an already fine-tuned model on new data: a new domain, a new month of data, or another task.

### 2. WHY DOES IT EXIST?

Models must be updated as data and needs change without retraining from scratch.

### 3. DETAILED EXPLANATION

Sequential stages overwrite each other unless mitigated ([10.28](10.28-catastrophic-forgetting.md)). Distinguish it from *continued pretraining* ([Tier 9](../tier-09-foundation-model-pretraining/README.md)), which uses raw text and the pretraining loss.

[Explore the stage-by-stage drift](interactive/forgetting_merge.html) (learning rate, steps, replay weight).

### 4. HOW DOES IT WORK?

Load the latest checkpoint -> train on new data (optionally mixed with replay) -> evaluate new task and regression suite ([10.29](10.29-catastrophic-forgetting-evaluation.md)).

### 5. SIMPLE EXAMPLE

A nurse training on a new ward while still needing the old ward's skills.

### 6. TECHNICAL EXAMPLE

Lab: replay (30 % plain-text batches) keeps plain-text loss at 0.62 while the task is learned.

### 7. CODE

```python
mix = lambda: sft_batch(...) if rng.random() > 0.3 else base_batch(rng)   # 30 % replay
```
File: [`lab/run_lab.py`](lab/run_lab.py).

### 8. INPUT → PROCESS → OUTPUT

```
checkpoint_k --+ new data + replay --> train --> checkpoint_k+1 --> eval new + old
```

### 9. ENTERPRISE USE CASE

Monthly refreshes with a frozen regression suite and an automatic rollback.

### 10. AI ENGINEERING CONNECTION

Models in production drift; continued fine-tuning plus evaluation is the maintenance loop.

### 11. ADVANTAGES

Cheaper than retraining; keeps the model fresh.

### 12. LIMITATIONS

Forgetting; compounding errors; version sprawl.

### 13. TRADE-OFFS

Freshness versus stability.

### 14. COMMON MISTAKES

No replay; no regression check; overwriting the previous checkpoint.

### 15. PERFORMANCE / COST CONSIDERATIONS

Cost like SFT; storage for checkpoints.

### 16. SECURITY CONSIDERATIONS

Each round can erode safety; re-run safety evals each time.

### 17. INTERVIEW EXPLANATION

Continued fine-tuning updates an existing tuned model on new data. Without care later stages overwrite earlier skills, so I replay old data, use gentle learning rates, evaluate a regression suite every round and keep the prior checkpoint for rollback.

### 18. RAPID-FIRE ANSWER

Keep the old skills while adding new ones.
