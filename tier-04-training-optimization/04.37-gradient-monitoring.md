# 4.37 Gradient monitoring

**Metadata** — Tier: 4 · Phase: 1 · Priority: P0 · Difficulty: 3/5 · Interview: High · Hands-on: Very high
Prerequisites: 3.25 Vanishing gradients, 3.26 Exploding gradients, 4.4 Backward pass · Leads to: 4.38 NaN/Inf debugging, 4.39 Loss debugging

> **In plain words**
> **Gradient monitoring** means **watching the size of the gradients while you train**. The loss only tells you *that* something is wrong; the gradients tell you *where*. Log the overall gradient norm, the norm **per layer**, and the **update-to-weight ratio** (how much a step changes a weight relative to its size). A few lines of code can reveal vanishing, exploding or dead layers long before the loss does.

**You need first:** 3.25 Vanishing gradients, 3.26 Exploding gradients, 4.4 Backward pass.

> **Figure 4.37-1 — what to watch and what it means**
>
> ```mermaid
> flowchart LR
>     G["gradient statistics"] --> N["global norm<br/>→ spikes = instability"]
>     G --> L["per-layer norm<br/>→ vanishing / exploding layers"]
>     G --> Z["fraction of zero gradients<br/>→ dead ReLUs"]
>     G --> R["update / weight ratio<br/>→ is the learning rate sane?"]

>
> *How to read it:* each box is one number you can log every N steps. A healthy run has a stable global norm without large spikes, per-layer norms within a few orders of magnitude of each other, few exact zeros, and update/weight ratios around 10⁻³.

**Words you'll meet on this page**

| Word | What it means here |
|---|---|
| gradient norm | the overall size of a gradient |
| per-layer norm | norm computed layer by layer |
| update-to-weight ratio | `‖lr·update‖ / ‖weights‖` |
| dead ReLU | a unit that never activates, so its gradient is 0 |
| hook | a function PyTorch calls during forward/backward |
| `clip_grad_norm_` | clips and returns the pre-clip global norm |
| histogram | distribution of gradient values |

### 1. What is it?
Logging statistics of `parameter.grad` (and sometimes activations) during training: norms, extremes, zero fractions, ratios.

### 2. Why does it exist?
Many failures are invisible in the loss until late: a layer that receives no gradient, exploding values before a NaN, or a learning rate that is too high or too low.

### 3. Detailed explanation
- **Global norm:** `clip_grad_norm_(params, max_norm)` returns it (4.15). Plot it; a sudden jump precedes many divergences.
- **Per-layer norm:** compare first versus last layers. A ratio of 10⁻⁶ or less signals vanishing; 10⁶ or more exploding (3.25–3.26).
- **Fraction of zeros:** exactly-zero gradients across many units mean dead ReLUs or masked paths (3.12).
- **Update-to-weight ratio:** `lr × ‖update‖ / ‖w‖`; around 10⁻³ is a common healthy value (REVIEW_REQUIRED). Much smaller: learning is crawling; much larger: unstable.
- **`None` gradients:** a parameter whose `.grad` is `None` after backward is not connected to the loss (frozen, unused, or detached).
- **Hooks:** `param.register_hook(fn)` (on gradients) and `module.register_full_backward_hook` collect statistics without changing the model (code ③).
- **When to log:** every 10–100 steps; per-layer histograms every few hundred (TensorBoard/W&B).
- **Activations:** also monitor activation means/stds per layer (3.22); exploding activations precede exploding gradients.
- **Compare with the loss scale:** gradients scale with the loss; normalizing (mean reduction, 4.3) keeps values comparable across runs.
- **Mixed precision:** check gradients after unscaling (4.19).
- **Cost:** computing norms requires a reduction; sample sparsely for big models.

### 4. How does it work?
After `backward()` (and before `step()`), iterate over parameters, compute norms, log; optionally use hooks.

### 5. Simple example
A car dashboard: the speed (loss) is useful, but oil pressure and engine temperature (gradient norms) warn you before the engine fails.

**By hand.** Gradient `[3, 4]` has norm 5. If a weight vector has norm 10 and `lr = 0.01`, the update norm is `0.01 × 5 = 0.05`, the ratio `0.05 / 10 = 5×10⁻³`.

### 6. Technical example
Logging `grad_norm`, `lr`, `loss` and `tokens/s` every step in LLM runs, plus per-layer histograms every 500 steps.

### 7. Code
**① By hand (plain Python).** Norms and the update ratio.

```python
import math

grad, weights, lr = [3.0, 4.0], [6.0, 8.0], 0.01
g_norm = math.sqrt(sum(g * g for g in grad))
w_norm = math.sqrt(sum(w * w for w in weights))
print("gradient norm:", g_norm, "   weight norm:", w_norm)
print("update-to-weight ratio:", lr * g_norm / w_norm)
```

```text
gradient norm: 5.0    weight norm: 10.0
update-to-weight ratio: 0.005
```

**② With NumPy.** Per-layer gradient norms in a deep sigmoid network reveal vanishing gradients.

```python
import numpy as np

rng = np.random.default_rng(0)
width, depth = 32, 10
Ws = [rng.normal(0, np.sqrt(1 / width), (width, width)) for _ in range(depth)]
a, acts = rng.normal(size=(16, width)), []
for W in Ws:
    a = 1 / (1 + np.exp(-(a @ W.T))); acts.append(a)
grad = np.ones_like(a) / a.size
norms = []
for W, act in zip(reversed(Ws), reversed(acts)):
    dz = grad * act * (1 - act)
    norms.append(np.linalg.norm(dz))                                 # gradient reaching this layer's pre-activation
    grad = dz @ W
norms = norms[::-1]
print("per-layer gradient norms (layer 1 ... 10):")
print(" ", " ".join(f"{n:.0e}" for n in norms))
print(f"first/last ratio: {norms[0] / norms[-1]:.1e}  -> vanishing" if norms[0] / norms[-1] < 1e-3 else "ok")
```

```text
per-layer gradient norms (layer 1 ... 10):
  1e-08 8e-08 3e-07 1e-06 5e-06 2e-05 1e-04 5e-04 3e-03 1e-02
first/last ratio: 1.2e-06  -> vanishing
```

**③ With PyTorch.** A monitor with hooks: per-layer norms, zero fraction and update ratio.

```python
import torch
from torch import nn

torch.manual_seed(0)
net = nn.Sequential(nn.Linear(10, 32), nn.Sigmoid(), nn.Linear(32, 32), nn.Sigmoid(), nn.Linear(32, 32), nn.Sigmoid(), nn.Linear(32, 1))
X = torch.randn(64, 10); y = X.sum(dim=1, keepdim=True)
opt = torch.optim.SGD(net.parameters(), lr=0.1)
nn.functional.mse_loss(net(X), y).backward()

print(f"{'layer':<8}{'grad norm':>11}{'zero frac':>11}{'update/weight':>15}")
for name, p in net.named_parameters():
    if p.dim() < 2:
        continue
    update = 0.1 * p.grad.norm() / p.norm()
    print(f"{name:<8}{p.grad.norm().item():>11.2e}{(p.grad == 0).float().mean().item():>11.2f}{update.item():>15.1e}")
total = nn.utils.clip_grad_norm_(net.parameters(), max_norm=1e9).item()
print(f"global gradient norm: {total:.2e}")
```

```text
layer     grad norm  zero frac  update/weight
0.weight   2.50e-02       0.00        7.9e-04
2.weight   9.48e-02       0.00        2.8e-03
4.weight   5.55e-01       0.00        1.7e-02
6.weight   3.67e+00       0.00        6.1e-01
global gradient norm: 3.94e+00
```

### 9. Enterprise use case
Alerts on gradient-norm spikes stop runs early and save compute.

### 10. AI engineering connection
LLM training logs global norm and clip rate; fine-tuning debugging uses per-layer norms to spot frozen or dead modules.

### 11. Advantages
Early warning; pinpoints the layer; cheap.

### 12. Limitations
Norm scales depend on parameterization; thresholds are heuristic.

### 13. Trade-offs
Detailed per-layer logging costs I/O and compute.

### 14. Common mistakes
Logging after `zero_grad`; measuring scaled FP16 gradients; comparing norms across models without normalization; ignoring `None` gradients; only logging the loss.

### 15. Performance / cost
Compute norms with fused reductions every N steps.

### 16. Security
No direct issue.

### 17. Interview explanation
"I log the global gradient norm, per-layer norms, the fraction of zero gradients and the update-to-weight ratio every few steps. Spikes warn of instability, an extreme first-to-last ratio shows vanishing or exploding gradients, zeros show dead units, and `None` gradients show disconnected parameters."

### 18. Rapid-fire answer
Log global/per-layer grad norm, zero fraction, update/weight ratio (≈1e-3), `None` grads; spikes precede NaNs.

### 20. Hands-on exercise
**Goal:** find a dead layer by its gradient.

1. Build `Linear(4, 8) → ReLU → Linear(8, 1)` and set the first layer's biases to −100 (so every ReLU output is 0).
2. Run backward and print the gradient norm of each weight matrix.

<details>
<summary>Show a solution</summary>

```python
import torch
from torch import nn

torch.manual_seed(0)
net = nn.Sequential(nn.Linear(4, 8), nn.ReLU(), nn.Linear(8, 1))
nn.init.constant_(net[0].bias, -100.0)                              # every hidden unit is "off"
X = torch.randn(32, 4)
nn.functional.mse_loss(net(X), torch.randn(32, 1)).backward()
for name, p in net.named_parameters():
    print(f"{name:<9} grad norm = {p.grad.norm().item():.3g}")
print("first layer receives no gradient at all: dead units cannot recover")
```

```text
0.weight  grad norm = 0
0.bias    grad norm = 0
2.weight  grad norm = 0
2.bias    grad norm = 0.49
first layer receives no gradient at all: dead units cannot recover
```
