# 6.23 Relative positional encoding

**Metadata** — Tier: 6 · Phase: 2 · Priority: High · Difficulty: Intermediate · Interview: High · Hands-on: Low
Prerequisites: [6.20 Positional information](06.20-positional-information.md), [6.22 Sinusoidal positional encoding](06.22-sinusoidal-positional-encoding.md) · Leads to: [6.24 RoPE](06.24-rope.md), [6.25 ALiBi](06.25-alibi.md)

> **In plain words**
> **Relative positional encoding** makes attention depend on **how far apart** two tokens are (their offset `j − i`) instead of their absolute numbers. "Three tokens back" then means the same thing anywhere in the text. Several methods exist (learned relative biases, T5-style buckets, RoPE, ALiBi); the modern parameter-free ones act on the attention scores, not the input vectors.

**You need first:** [6.20 Positional information](06.20-positional-information.md), [6.22 Sinusoidal positional encoding](06.22-sinusoidal-positional-encoding.md).

### 1. What is it?

Relative positional encoding makes attention depend on the *offset* between two tokens (j - i) instead of their absolute indices.

### 2. Why does it exist?

Language is largely about nearby relationships, and relative schemes generalize better to sequence lengths unseen in training than absolute tables.

### 3. Detailed explanation

Implementations: learned relative key/value terms (Shaw et al., 2018), Transformer-XL style relative terms, T5-style learned **relative bias** (scalar per bucketed offset per head), and two parameter-free modern methods: **RoPE** ([6.24 RoPE](06.24-rope.md), rotates Q and K) and **ALiBi** ([6.25 ALiBi](06.25-alibi.md), linear bias on logits). All inject relative information into attention scores rather than the input embedding (`REVIEW_REQUIRED` for citations and bucket details).

### 4. How does it work?

Score `s_ij = f(q_i, k_j, j - i)`; the position dependence is only through the offset.

### 5. Simple example

'The word two places back' instead of 'word number 57'.

**By hand.** Offsets: token 4 looking at token 2 has offset 2; token 7 looking at token 5 also has offset 2. With a relative bias table `b[offset]` both get the same bias `b[2]`, e.g. −1.0 with slope 0.5. With absolute vectors the two cases look different (positions 4, 2 vs 7, 5) and the model must learn that they are alike.

### 6. Technical example

T5 buckets offsets (exact for near, logarithmic for far) and adds a learned scalar per head to each logit.

### 7. Code

**① By hand (plain Python).** A relative bias depends only on the offset.

```python
slope = 0.5
def bias(i, j):
    return -slope * (i - j) if j <= i else float("-inf")

print("token 4 → token 2 :", bias(4, 2))
print("token 7 → token 5 :", bias(7, 5), "  (same offset 2, same bias)")
print("token 3 → token 0 :", bias(3, 0), "  (offset 3)")
print("future token      :", bias(1, 3))
```

```text
token 4 → token 2 : -1.0
token 7 → token 5 : -1.0   (same offset 2, same bias)
token 3 → token 0 : -1.5   (offset 3)
future token      : -inf
```

**② With NumPy.** The whole bias matrix is Toeplitz: constant along diagonals.

```python
import numpy as np

n, slope = 5, 0.5
i, j = np.indices((n, n))
b = np.where(j <= i, -slope * (i - j), -np.inf)
print(b)
print("diagonal offset 2 values:", [float(b[k + 2, k]) for k in range(n - 2)])
```

```text
[[-0.  -inf -inf -inf -inf]
 [-0.5 -0.  -inf -inf -inf]
 [-1.  -0.5 -0.  -inf -inf]
 [-1.5 -1.  -0.5 -0.  -inf]
 [-2.  -1.5 -1.  -0.5 -0. ]]
diagonal offset 2 values: [-1.0, -1.0, -1.0]
```

### 20. Hands-on exercise

Verify in the snippet that equal offsets give equal ALiBi biases.

<details>
<summary>Show a solution</summary>

```python
import numpy as np

n = 6
rng = np.random.default_rng(0)
table = rng.normal(size=n)                                        # a learned bias per offset 0..5
i, j = np.indices((n, n))
bias = np.where(j <= i, table[np.clip(i - j, 0, n - 1)], -np.inf)
same = [bias[k + 2, k] for k in range(n - 2)]
print("all pairs at offset 2 share one bias:", len(set(same)) == 1, f"({same[0]:.2f})")
print("learned parameters:", table.size, "(versus", n * n, "for a free bias per pair)")
```

```text
all pairs at offset 2 share one bias: True (0.64)
learned parameters: 6 (versus 36 for a free bias per pair)
```
