# 6.17 Token embedding

**Metadata** — Tier: 6 · Phase: 2 · Priority: Critical · Difficulty: Beginner · Interview: Very high · Hands-on: High
Prerequisites: [6.7 Token IDs](06.07-token-ids.md); Tier 3 (learned layers) · Leads to: [6.18 Embedding matrix](06.18-embedding-matrix.md), [6.20 Positional information](06.20-positional-information.md), [Tier 8](../tier-08-transformer-architecture/README.md)

> **In plain words**
> A **token embedding** is the learnable vector that belongs to one token id: the model's first picture of that token. At the input layer the vector depends **only on the id**, so "bank" has the same vector in "river bank" and "bank loan"; later layers add the context. The vectors are learned by ordinary backpropagation, and only the rows of tokens that appear in a batch receive gradient.

**You need first:** [6.7 Token IDs](06.07-token-ids.md); Tier 3 (learned layers).

**Words you'll meet on this page**

| Word | What it means here |
|---|---|
| embedding | a learned vector standing for a token |
| static | depends only on the id, not on the context |
| gradient row | only rows used in the batch get a gradient |
| d (embedding dimension) | the length of each vector |
| scaling by √d | the original Transformer multiplies embeddings by √d_model |
| contextual embedding | a vector computed by later layers using the context |

### 1. What is it?

A token embedding is the learnable vector associated with one token ID: the model's first representation of that token.

### 2. Why does it exist?

Integer IDs have no geometry; vectors let the network express similarity and let gradient descent shape each token's meaning.

### 3. Detailed explanation

At the input layer the vector depends **only on the ID** (static): the word 'bank' gets the same vector in 'river bank' and 'bank loan'. Context is added by later layers ([Tier 8](../tier-08-transformer-architecture/README.md)). Embeddings are learned by backpropagation like any weight; only rows for tokens that appear in the batch receive gradient.

Original-Transformer convention: embeddings are scaled by `sqrt(d_model)` before adding position encodings (`REVIEW_REQUIRED`: practice varies by model).

### 5. Simple example

A name badge with a long number written on it that follows each token around.

**By hand.** Embedding table with 3 rows `[[1, 0], [0, 1], [2, 2]]`. The sequence of ids `[2, 0, 2]` becomes `[[2,2], [1,0], [2,2]]`: the first and third vectors are identical although they sit at different positions. After a backward pass only rows 0 and 2 have non-zero gradients; row 1 is untouched.

### 6. Technical example

Repeated IDs share a row, so repeated tokens in a sentence produce identical input vectors until positions are added.

### 7. Code

**① By hand (plain Python).** Lookup and a hand-computed gradient: gradients land only on the used rows.

```python
table = [[1.0, 0.0], [0.0, 1.0], [2.0, 2.0]]
ids = [2, 0, 2]
vectors = [table[i] for i in ids]
print("vectors:", vectors)
grad = [[0.0, 0.0] for _ in table]
for i in ids:                                     # loss = sum of all entries, so d loss / d row = 1 for each use
    grad[i] = [g + 1.0 for g in grad[i]]
print("gradient per row:", grad)
```

```text
vectors: [[2.0, 2.0], [1.0, 0.0], [2.0, 2.0]]
gradient per row: [[1.0, 1.0], [0.0, 0.0], [2.0, 2.0]]
```

**② With NumPy.** The same with arrays, including the sqrt(d) scale of the original Transformer.

```python
import numpy as np

rng = np.random.default_rng(0)
V, d = 8, 4
E = rng.normal(0, 1 / np.sqrt(d), (V, d))
ids = np.array([2, 5, 2])
x = E[ids]
print("same id -> same vector:", np.array_equal(x[0], x[2]))
print("norm of a row before / after scaling by sqrt(d):", round(float(np.linalg.norm(E[2])), 2), round(float(np.linalg.norm(E[2] * np.sqrt(d))), 2))
```

```text
same id -> same vector: True
norm of a row before / after scaling by sqrt(d): 0.79 1.58
```

**③ With PyTorch.** A real nn.Embedding: sparse gradients.

```python
import torch

torch.manual_seed(0)
emb = torch.nn.Embedding(num_embeddings=8, embedding_dim=4)
ids = torch.tensor([2, 5, 2])
x = emb(ids)
x.sum().backward()
rows = (emb.weight.grad.abs().sum(1) > 0).nonzero().flatten().tolist()
print("rows that received gradient:", rows)
print("row 2 was used twice, its gradient is twice row 5's:", torch.allclose(emb.weight.grad[2], 2 * emb.weight.grad[5]))
```

```text
rows that received gradient: [2, 5]
row 2 was used twice, its gradient is twice row 5's: True
```

### 9. Enterprise use case

Fine-tuning that adds domain tokens must initialize the new rows sensibly (e.g. mean of constituent sub-token embeddings), a standard engineering practice.

### 10. AI engineering connection

First layer of every LLM; the output layer is often tied to it (see [6.18 Embedding matrix](06.18-embedding-matrix.md)).

### 11. Advantages

Learned, dense, cheap lookup; sparse gradients.

### 12. Limitations

Static (context-free) at input; rare tokens are undertrained; table size scales with V.

### 13. Trade-offs

Higher d = more capacity and memory.

### 14. Common mistakes

- Confusing token embeddings with sentence embeddings ([6.26 Token vs semantic embeddings](06.26-token-vs-semantic-embeddings.md)).
- Treating a newly added token's random row as meaningful.

### 15. Performance / cost

Lookup is memory-bound and cheap; the table is `V*d` parameters.

### 16. Security

Embedding rows of rarely-seen tokens may leak memorized training strings via nearest-neighbour inspection; do not publish raw embeddings of private-data-trained models without review (`REVIEW_REQUIRED`).

### 20. Hands-on exercise

Run the snippet; then print the gradient rows for ids [1, 1, 3].

<details>
<summary>Show a solution</summary>

```python
import torch

torch.manual_seed(0)
emb = torch.nn.Embedding(5, 3)
target = torch.tensor([[1.0, 0.0, 0.0]])
opt = torch.optim.SGD(emb.parameters(), lr=0.5)
before = emb.weight.detach().clone()
for _ in range(20):
    opt.zero_grad()
    loss = ((emb(torch.tensor([3])) - target) ** 2).sum()
    loss.backward(); opt.step()
changed = (emb.weight.detach() != before).any(dim=1).nonzero().flatten().tolist()
print("rows that changed:", changed, "  row 3 is now", emb.weight[3].detach().numpy().round(2))
```

```text
rows that changed: [3]   row 3 is now [1. 0. 0.]
```
