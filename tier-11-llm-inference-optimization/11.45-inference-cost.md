### 1. WHAT IS IT?

**Inference cost** is the money spent to produce tokens: for self-hosting, GPU-hours divided by tokens produced; for hosted APIs, per-token prices for input and output.

### 2. WHY DOES IT EXIST?

Cost per token determines product margins and make-vs-buy decisions.

### 3. DETAILED EXPLANATION

`cost per 1M output tokens ≈ GPU_$/hour ÷ (system tokens/s × 3600) × 10⁶`. With an **assumed** $2.00/GPU-hour (not a quote): 1,000 tok/s → $0.56 per 1M tokens; at 20% utilization it is 5x that. Hosted APIs price input and output separately; output costs more because decode is the bottleneck (prices `REVIEW_REQUIRED`).
Levers: quantization, batching/utilization, prefix caching, shorter prompts, smaller/routed models, response caching, output caps.

### 4. HOW DOES IT WORK?

Measure tokens in/out and utilization → compute $/1M tokens → apply levers → re-measure.

### 5. SIMPLE EXAMPLE

Taxi fare: the meter runs whether or not seats are full.

### 6. TECHNICAL EXAMPLE

Compare "hosted at $X/1M tokens" against "2 reserved GPUs at 60% utilization".

### 7. CODE

```python
def cost_per_million(gpu_usd_hour: float, tokens_per_s: float, utilization: float = 1.0, n_gpus: int = 1) -> float:
    return gpu_usd_hour * n_gpus / (tokens_per_s * utilization * 3600) * 1e6

print(round(cost_per_million(2.0, 1000), 2))         # 0.56
print(round(cost_per_million(2.0, 1000, 0.2), 2))    # 2.78
```

### 8. INPUT → PROCESS → OUTPUT

```
GPU $/hour ÷ (tokens/s × utilization × 3600) ─► $/token
```

### 9. ENTERPRISE USE CASE

Finance teams re-check build-vs-buy quarterly.

### 10. AI ENGINEERING CONNECTION

Drives model routing, caching, and quantization decisions.

### 11. ADVANTAGES

- Clear formula; many levers.

### 12. LIMITATIONS

- Needs real utilization data; prices change.

### 13. TRADE-OFFS

Cost vs quality vs latency.

### 14. COMMON MISTAKES

- Costing only input tokens. - Ignoring idle time. - List price comparisons without quality parity.

### 15. PERFORMANCE / COST CONSIDERATIONS

Utilization is the main self-hosting lever.

### 16. SECURITY CONSIDERATIONS

Budget caps and rate limits protect against abuse driving cost.

### 17. INTERVIEW EXPLANATION

"Cost per million tokens is GPU dollars per hour over tokens per hour. Utilization dominates, so I'd measure, then quantize, batch, prefix-cache, route easy requests to smaller models and cap outputs."

### 18. RAPID-FIRE ANSWER

Cost = $/hour ÷ tokens/hour; utilization is the lever.
