### 1. WHAT IS IT?

**Temperature** `T` rescales logits before softmax: `p_i = softmax(z_i / T)`. Low `T` sharpens the distribution, high `T` flattens it.

### 2. WHY DOES IT EXIST?

A single knob to trade determinism for diversity without retraining.

### 3. DETAILED EXPLANATION

- `T < 1` sharpens (more greedy-like); `T = 1` is the model's own distribution; `T > 1` flattens.
- `T -> 0` approaches greedy; `T -> infinity` approaches uniform.
- It rescales **all** tokens, including the junk tail, so high `T` alone can yield incoherent text; pair it with top-p or min-p ([11.7 Top-p sampling](11.07-top-p-sampling.md)).

### 4. HOW DOES IT WORK?

Divide every logit by `T`, then softmax. Because softmax is exponential, dividing by a smaller `T` widens the gaps between logits and concentrates mass on the top token.

### 5. SIMPLE EXAMPLE

A volume knob for creativity: turn it down and the model repeats the safest answer; turn it up and it tries stranger words.

### 6. TECHNICAL EXAMPLE

Marketing copy at `T` about 0.8-1.0; deterministic extraction at `T` = 0 (illustrative starting points).

### 7. CODE

```python
import torch
from decoding import apply_temperature

z = torch.tensor([2.0, 1.0, 0.1])
for T in (0.5, 1.0, 2.0):
    print(T, apply_temperature(z, T).softmax(-1))
```

### 8. INPUT → PROCESS → OUTPUT

```
logits --(/T)--> scaled logits --softmax--> probs  (T<1 peaked, T>1 flat)
```

### 9. ENTERPRISE USE CASE

Product teams expose temperature presets per feature (extraction vs brainstorming).

### 10. AI ENGINEERING CONNECTION

Self-consistency and best-of-N need `T > 0` to produce diverse candidates.

### 11. ADVANTAGES

Simple, one scalar, continuous control.

### 12. LIMITATIONS

Reshapes the tail too, so large values admit nonsense; interacts with other filters.

### 13. TRADE-OFFS

Diversity vs coherence.

### 14. COMMON MISTAKES

Applying it to probabilities rather than logits; `T = 0` division by zero in custom code (special-case it as greedy); changing `T` and top-p together.

### 15. PERFORMANCE / COST CONSIDERATIONS

No measurable cost; the cost of high-temperature output is indirect (more retries, worse quality).

### 16. SECURITY CONSIDERATIONS

Not a security control; clamp user-supplied values to a safe range.

### 17. INTERVIEW EXPLANATION

"Temperature divides the logits before softmax. Below 1 it makes the model more confident and repetitive, above 1 it flattens the distribution and adds variety, and it affects the whole vocabulary including the unlikely tail, which is why I usually pair it with top-p."

### 18. RAPID-FIRE ANSWER

Divide logits by T; low T sharpens, high T flattens, T=0 is greedy.

### 19. INTERVIEW QUESTIONS

**Basic.** What does T=0 do? **Intermediate.** Why does high T give nonsense? (Tail tokens gain mass.) **Advanced.** Show T scales entropy monotonically. **Scenario.** Outputs are too samey; what do you tune and what do you risk?
