PagedAttention: block table vs contiguous reservation

Each row is a sequence. Contiguous allocators reserve the max context up front (grey = wasted). Paged allocators hand out fixed blocks on demand; only the last block of each sequence is partly empty (red hatch = internal fragmentation).
