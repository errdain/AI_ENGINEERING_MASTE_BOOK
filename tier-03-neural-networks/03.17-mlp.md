# 3.17 Multi-layer perceptron (MLP)

**Metadata** — Tier: 3 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: Very high · Hands-on: Very high
Prerequisites: 3.4, 3.9, 3.16 · Leads to: 3.18 Forward propagation, 3.20 Backpropagation, Tier 8 FFN

### 1. What is it?
A **feed-forward network of Dense layers with nonlinear activations between them**: `f(x) = W_L φ(… φ(W₁x + b₁) …) + b_L`. Information flows one way, input to output.

### 2. Why does it exist?
It is the simplest neural network able to represent nonlinear functions, and the template for every larger architecture's feed-forward parts.

### 3. Detailed explanation
- **XOR solved by hand:** hidden units `h₁ = ReLU(x₁ + x₂)`, `h₂ = ReLU(x₁ + x₂ − 1)`, output `h₁ − 2h₂` gives `[0, 1, 1, 0]` exactly for inputs `(0,0),(0,1),(1,0),(1,1)` (tested). A single neuron cannot (3.2).
- **Training it:** a 2-4-2 tanh MLP reaches 100% on XOR with backprop (tested); with no hidden layer accuracy stays below 100%.
- **Nonlinear boundaries:** points labelled by "outside the unit circle": linear classifier 60.1% vs 16-unit tanh MLP 99.4%.
- **Universal approximation theorem:** a feed-forward network with one hidden layer and a suitable nonlinear activation can approximate any continuous function on a compact set arbitrarily well *given enough hidden units*. It is an existence result: it says nothing about how many units, whether gradient descent finds the weights, or generalization.
- **Width in practice** (fit `sin(x)` on [−3,3], tanh MLP, full-batch GD): final MSE 0.046 (1 unit), 0.0154 (2), 0.0094 (4), 0.0028 (16), 0.0096 (64: not better because the same fixed training budget was too short for the larger net: an optimization effect, not a capacity limit).
- **Counting parameters:** 784→128→64→10 has 109,386 (matches `torch.nn.Sequential`).
- **Implementation here:** `nn.MLP` stores a list of `Dense` and `Activation` objects, with manual backpropagation verified by finite differences and PyTorch autograd for five activations (tested).
- **Where MLPs appear:** tabular models, classification heads, embedding projections, and the **feed-forward sublayer of every Transformer block** (typically hidden width ≈ 4×`d_model`, Tier 8).
- **Limits:** no built-in structure (translation invariance, sequence order), so images/sequences usually need convolutions/attention for efficiency; MLPs on raw pixels are parameter-heavy.

### 4. How does it work?
`h₀ = x; hₗ = φ(Wₗhₗ₋₁ + bₗ)`; final layer gives logits/values; a loss and backprop train all weights (3.18, 3.20).

### 6. Technical example
Credit-scoring model: 40 standardized features → 64 → 32 → 1 logit with dropout, trained with BCE.

### 7. Code
```python
import numpy as np, nn as N
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], float); y = np.array([0, 1, 1, 0])
m = N.MLP([2, 4, 2], activation='tanh', seed=1).fit(X, y, lr=0.5, epochs=2000)
print(m.predict_classes(X), m.history_[0], m.history_[-1])       # [0 1 1 0]  loss falls by >10×
```

### 8. Input → Process → Output
`x → Dense → φ → … → Dense → logits → loss`

### 9. Enterprise use case
Strong tabular baselines after gradient-boosted trees; easy to serve (small matmuls).

### 10. AI engineering connection
Transformer FFNs, adapters, projection heads, router networks, reward-model heads.

### 11. Advantages
Simple, general, trainable end to end.

### 12. Limitations
Many parameters for structured data; needs scaling and tuning; can overfit small data.

### 13. Trade-offs
Depth/width vs data and compute (2.30).

### 14. Common mistakes
No activations between layers; unscaled inputs; too large for the dataset; ignoring init; using MLPs on raw images/sequences without considering better inductive biases.

### 15. Performance / cost
Compute ≈ 2·parameters per sample; batch for efficiency.

### 16. Security
Same as other models: memorization and adversarial vulnerability.

### 17. Interview explanation
"An MLP is stacked dense layers with nonlinearities. One hidden layer is enough in theory to approximate any continuous function, but the theorem gives no size or trainability guarantee. I can show XOR needs a hidden layer, count parameters layer by layer, and point out that the Transformer's feed-forward sublayer is just an MLP."

### 18. Rapid-fire
Stacked Dense+activation layers; universal approximator in theory; XOR needs a hidden layer; basis of Transformer FFN.
