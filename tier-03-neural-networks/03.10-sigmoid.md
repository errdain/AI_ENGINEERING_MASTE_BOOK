# 3.10 Sigmoid

**Metadata** — Tier: 3 · Phase: 1 · Priority: P0 · Difficulty: 1/5 · Interview: High · Hands-on: High
Prerequisites: 3.9, 1.42 · Leads to: logistic regression (2.14), gates in recurrent nets (Tier 5), binary outputs

> **In plain words**
> The **sigmoid** is an **S-shaped squashing function**: any number, however large or small, becomes a number between 0 and 1. Big negative → near 0, zero → exactly 0.5, big positive → near 1.
> It turns a score into a probability-like number, which makes it natural for **yes/no outputs** and **gates** ("how much of this signal to let through"). Its weakness: it is **flat at both ends**, so gradients vanish if you stack many.

**You need first:** 3.9 Activation functions, 1.42 Exponentials.

> *How to read it:* the curve is steepest in the middle (slope 0.25) and almost flat at both ends. A flat curve means a tiny gradient, which is why a neuron that has pushed `z` far from 0 learns slowly. See the sigmoid curves in Figure 3.9-1.

### 1. What is it?
`σ(x) = 1/(1 + e⁻ˣ)`, an S-shaped function mapping any real number into `(0, 1)`.

### 2. Why does it exist?
It turns a score into a probability-like number and is the inverse of the log-odds (logit): `σ(logit(p)) = p`.

### 3. Detailed explanation
- **Derivative:** `σ′(x) = σ(x)(1 − σ(x))`, largest at `x = 0` with the value **0.25**, and tiny in the tails (at `x = 8`, below `4 × 10⁻⁴`).
- **Vanishing gradients:** each sigmoid layer scales the backward signal by at most 0.25; ten of them: at most `9.5 × 10⁻⁷` (3.25). Hence sigmoid is avoided in deep hidden stacks.
- **Not zero-centred:** the outputs are always positive, which makes the gradient updates for the next layer's weights share one sign (slower, zig-zag optimisation).
- **Uses today:** binary classification outputs (with BCE from logits, 1.43), multilabel outputs, gating (LSTM and GRU gates, Tier 5), attention-like gating, and `σ(x)·x` inside SiLU (3.14).
- **Relation to softmax:** `σ(a − b)` equals the first component of a two-class softmax over `(a, b)` (3.15). Also `tanh(x) = 2σ(2x) − 1` (3.11).
- **Numerical stability:** compute with `exp(−|x|)` so that large `|x|` neither overflows nor gives NaN.
- **Probability caveat:** a sigmoid output is a probability only if the model is calibrated (2.43).

### 4. How does it work?
Squash the pre-activation into (0, 1); in backpropagation multiply by `σ(1 − σ)`.

### 5. Simple example
A dimmer switch that saturates fully off and fully on.

| −1 | 0.269 | 0.197 |
| 0 | 0.500 | 0.250 |
| 1 | 0.731 | 0.197 |

### 6. Technical example
A binary spam classifier: one logit → sigmoid → `p(spam)`; an LSTM's forget gate is a sigmoid.

### 7. Code
**① By hand (plain Python).** A stable sigmoid and its slope.

```python
import math

def sigmoid(z):
    if z >= 0:
        return 1 / (1 + math.exp(-z))
    e = math.exp(z)                      # never exponentiate a large positive number
    return e / (1 + e)

for z in (-1000, -4, 0, 4, 1000):
    s = sigmoid(z)
    print(f"z = {z:>5}: sigmoid {s:.4f}   slope {s * (1 - s):.6f}")
print("ten layers shrink the gradient by at most", 0.25 ** 10)
```

```text
z = -1000: sigmoid 0.0000   slope 0.000000
z =    -4: sigmoid 0.0180   slope 0.017663
z =     0: sigmoid 0.5000   slope 0.250000
z =     4: sigmoid 0.9820   slope 0.017663
z =  1000: sigmoid 1.0000   slope 0.000000
ten layers shrink the gradient by at most 9.5367431640625e-07
```

**② With NumPy.** The two-class softmax identity and the logit inverse.

```python
import numpy as np

sigmoid = lambda z: 1 / (1 + np.exp(-z))
a, b = 1.3, -0.4
softmax_first = np.exp(a) / (np.exp(a) + np.exp(b))
print("sigmoid(a - b) =", round(float(sigmoid(a - b)), 6), "  first softmax component =", round(float(softmax_first), 6))
p = 0.8
print("logit then sigmoid gives p back:", round(float(sigmoid(np.log(p / (1 - p)))), 6))
```

```text
sigmoid(a - b) = 0.845535   first softmax component = 0.845535
logit then sigmoid gives p back: 0.8
```

**③ With PyTorch.** The gradient vanishes in the tails; BCE from logits.

```python
import torch

z = torch.tensor([-8.0, 0.0, 8.0], requires_grad=True)
torch.sigmoid(z).sum().backward()
print("sigmoid gradients at z = -8, 0, 8:", [round(v, 6) for v in z.grad.tolist()])

logit = torch.tensor([2.0])
print("BCE from the logit (stable):", round(torch.nn.functional.binary_cross_entropy_with_logits(logit, torch.tensor([1.0])).item(), 4))
print("extreme logit 1000 is still finite:", torch.sigmoid(torch.tensor([1000.0])).item())
```

```text
sigmoid gradients at z = -8, 0, 8: [0.000335, 0.25, 0.000335]
BCE from the logit (stable): 0.1269
extreme logit 1000 is still finite: 1.0
```

### 9. Enterprise use case
Used for scores that downstream systems threshold; thresholds need calibration monitoring.

### 10. AI engineering connection
Binary and multilabel heads, gating mechanisms, reward-model probabilities, and the gate in SwiGLU-style feed-forward blocks (via SiLU).

### 11. Advantages
Interpretable as the inverse of log-odds; smooth; bounded.

### 12. Limitations
Saturates; not zero-centred; costs an `exp`.

### 13. Trade-offs
Bounded outputs versus vanishing gradients.

### 14. Common mistakes
Hidden sigmoids in deep networks; the naive `1/(1 + exp(−x))` overflowing; applying sigmoid and then BCE (use logits); mixing up softmax and sigmoid for multiclass.

### 15. Performance / cost
Fused sigmoid + BCE kernels avoid intermediate tensors.

### 16. Security
Saturated outputs hide uncertainty and can be exploited with adversarial inputs.

</details>

### 17. Interview explanation
"Sigmoid squashes a score to (0, 1); its derivative is σ(1 − σ), at most 0.25, which is why stacking many of them kills gradients. I keep it for binary outputs and gates, compute it in a numerically stable form, and feed logits to a fused BCE loss."

### 18. Rapid-fire answer
`σ(x) = 1/(1 + e⁻ˣ)`; range (0, 1); `σ′ = σ(1 − σ) ≤ 0.25`; saturates; use for binary outputs and gates.

### 19. Interview questions

### 20. Hands-on exercise
**Goal:** watch the gradient shrink through a stack of sigmoids.

1. Build a PyTorch network of 10 `Linear(8, 8) → Sigmoid` layers.
2. Backpropagate from the sum of the output.
3. Print the gradient norm of the first and the last layer's weights.

<details>
<summary>Show a solution</summary>

```python
import torch

torch.manual_seed(0)
layers = []
for _ in range(10):
    layers += [torch.nn.Linear(8, 8), torch.nn.Sigmoid()]
net = torch.nn.Sequential(*layers)
net(torch.randn(16, 8)).sum().backward()
first, last = net[0].weight.grad.norm().item(), net[-2].weight.grad.norm().item()
print(f"gradient norm, last layer : {last:.2e}")
print(f"gradient norm, first layer: {first:.2e}   ({last / first:,.0f} times smaller)")
```

```text
gradient norm, last layer : 1.59e+01
gradient norm, first layer: 6.60e-08   (240,960,796 times smaller)
```
