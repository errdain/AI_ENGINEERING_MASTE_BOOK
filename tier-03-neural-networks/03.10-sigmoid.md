# 3.10 Sigmoid

**Metadata** — Tier: 3 · Phase: 1 · Priority: P0 · Difficulty: 1/5 · Interview: High · Hands-on: High
Prerequisites: 3.9, 1.42 · Leads to: logistic regression (2.14), gates in recurrent nets (Tier 5), binary outputs

### 1. What is it?
`σ(x) = 1/(1 + e⁻ˣ)`, an S-shaped function mapping any real number into `(0, 1)`.

### 2. Why does it exist?
It turns a score into a probability-like number and is the inverse of the log-odds (logit): `σ(logit(p)) = p`.

### 3. Detailed explanation
- **Derivative:** `σ′(x) = σ(x)(1 − σ(x))`, maximal at `x = 0` with value **0.25**, and tiny in the tails: at `x = 8`, `σ′ < 4×10⁻⁴`. On [−6, 6] 23.6% of inputs have `σ′ < 0.01`.
- **Vanishing gradients:** each sigmoid layer scales the backward signal by ≤ 0.25; ten of them: ≤ `9.5×10⁻⁷` (3.25). Hence sigmoid is avoided in deep hidden stacks.
- **Not zero-centered:** outputs are always positive, which makes gradient updates for the next layer's weights share a sign (slower, zig-zag optimization).
- **Uses today:** binary classification outputs (with BCE from logits, 1.43), multilabel outputs, gating (LSTM/GRU gates, 3.x/Tier 5), attention-like gating, `σ(x)·x` inside SiLU (3.14).
- **Relation to softmax:** `σ(a − b)` equals the first component of a two-class softmax over `(a, b)` (tested, 3.15). `tanh(x) = 2σ(2x) − 1` (3.11).
- **Numerical stability:** compute with `exp(−|x|)` so large |x| neither overflows nor produces NaN; our implementation is finite at ±1000 (tested).
- **Probability caveat:** a sigmoid output is a probability only if the model is calibrated (2.43).

### 4. How does it work?
Squash the pre-activation into (0,1); backprop multiplies by `σ(1−σ)`.

### 5. Simple example
A dimmer switch that saturates fully off and fully on.

### 6. Technical example
Binary spam classifier: single logit → sigmoid → p(spam); LSTM forget gate = sigmoid.

### 8. Input → Process → Output
`logit → σ → p ∈ (0,1)`

### 9. Enterprise use case
Used for scores that downstream systems threshold; thresholds need calibration monitoring.

### 10. AI engineering connection
Binary/multilabel heads, gating mechanisms, reward-model probabilities, the gate in SwiGLU-style FFNs (via SiLU).

### 11. Advantages
Interpretable as log-odds inverse; smooth; bounded.

### 12. Limitations
Saturates; not zero-centered; exp cost.

### 13. Trade-offs
Bounded outputs vs vanishing gradients.

### 14. Common mistakes
Hidden sigmoids in deep nets; naive `1/(1+exp(−x))` overflow; applying sigmoid then BCE (use logits); softmax/sigmoid confusion for multiclass.

### 15. Performance / cost
Fused sigmoid+BCE kernels avoid intermediate tensors.

### 16. Security
Saturated outputs hide uncertainty and can be exploited with adversarial inputs.

### 17. Interview explanation
"Sigmoid squashes a score to (0,1); its derivative is σ(1−σ), at most 0.25, which is why stacking many of them kills gradients. I keep it for binary outputs and gates, compute it in a numerically stable form, and feed logits to a fused BCE loss."

### 18. Rapid-fire
σ(x)=1/(1+e⁻ˣ); range (0,1); σ′=σ(1−σ) ≤ 0.25; saturates; use for binary outputs and gates.
