# 3.23 Xavier (Glorot) initialization

**Metadata** — Tier: 3 · Phase: 1 · Priority: P1 · Difficulty: 3/5 · Interview: Medium-High · Hands-on: High
Prerequisites: 3.22, 1.30 · Leads to: 3.24 He initialization, Transformer init choices

### 1. What is it?
An initialization that sets weight variance to `Var(W) = 2/(fan_in + fan_out)` (normal) or draws `W ~ U(−a, a)` with `a = √(6/(fan_in + fan_out))` (uniform), designed to keep activation and gradient variances similar across layers for linear or symmetric (tanh-like) activations. Proposed by Glorot & Bengio (2010).

### 2. Why does it exist?
It compromises between preserving forward variance (needs `1/fan_in`) and backward variance (needs `1/fan_out`).

### 3. Detailed explanation
- **Derivation sketch (linear units, independent zero-mean weights and inputs):** `Var(z) = fan_in · Var(W) · Var(x)`. Forward stability requires `Var(W) = 1/fan_in`; backward stability requires `Var(W) = 1/fan_out`. Taking the harmonic compromise gives `2/(fan_in+fan_out)`.
- **Uniform version:** a uniform on `[−a, a]` has variance `a²/3`; setting that equal to `2/(fan_in+fan_out)` gives `a = √(6/(fan_in+fan_out))`. The library's sampled maximum is within 1e-3 of this bound and the sample std of `xavier_normal_` matches `√(2/(fan_in+fan_out))` to 2%.
- **Intended activations:** tanh/sigmoid in their near-linear regime, or linear layers.
- **Behaviour on deep tanh stacks (30 layers, width 256):** activation std declines slowly from 0.63 to 0.13 but stays alive, whereas N(0, 0.01²) collapses to ≈0 and N(0,1) saturates. He's larger scale keeps tanh at ≈0.55; PyTorch's recommended `gain` for tanh is 5/3 (`calculate_gain('tanh') = 1.667`), which rescales Xavier for tanh's compressive effect.
- **With ReLU it under-scales:** 30 ReLU layers with Xavier shrink activations to 2×10⁻⁵ (≈ `0.5^(30/2) = 3×10⁻⁵`), motivating He (3.24).
- **Transformers** often use small fixed-std normal init (e.g., 0.02) with residual-branch scaling instead; the principle (control variance) is the same (REVIEW_REQUIRED per model).
- **Assumptions:** independence and zero mean; they hold approximately at initialization only.

### 4. How does it work?
Compute fan_in and fan_out from the weight shape and sample from the scaled normal or uniform distribution.

### 5. Simple example
Split the difference between 'keep the forward signal steady' and 'keep the backward signal steady'.

### 6. Technical example
`torch.nn.init.xavier_uniform_(w, gain=nn.init.calculate_gain('tanh'))`.

### 7. Code
```python
import nn as N, numpy as np
rng = np.random.default_rng(0); W = N.init_weights(512, 256, 'xavier_normal', rng); print(W.std(), np.sqrt(2 / (256 + 512)))     # ≈0.051  0.0510
U = N.init_weights(512, 256, 'xavier_uniform', rng); print(np.abs(U).max() <= np.sqrt(6 / (256 + 512)))                         # True
```

### 8. Input → Process → Output
`fan_in, fan_out → Var(W)=2/(fan_in+fan_out) → sample`

### 9. Enterprise use case
Framework defaults vary; document the initializer in model cards for reproducibility.

### 10. AI engineering connection
Used in embeddings/projections of many models; knowledge of the variance principle is needed to modify architectures safely.

### 11. Advantages
Principled; works well for symmetric activations and shallow-to-moderate depth.

### 12. Limitations
Not tuned for ReLU; assumptions are approximate; deep nets still need normalization/residuals.

### 13. Trade-offs
Uniform vs normal variants are equivalent in variance; differences are minor.

### 14. Common mistakes
Using Xavier with ReLU; forgetting gain for tanh; computing fan_in/out incorrectly for convolutions; mixing PyTorch `(out,in)` with Keras `(in,out)` when computing fans.

### 15. Performance / cost
Negligible.

### 17. Interview explanation
"Xavier initialization sets weight variance to 2 over fan-in plus fan-out, balancing forward and backward variance preservation for symmetric activations like tanh. For ReLU I switch to He, which doubles the variance because ReLU zeroes half the units."

### 18. Rapid-fire
