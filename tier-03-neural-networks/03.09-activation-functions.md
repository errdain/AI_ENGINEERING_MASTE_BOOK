# 3.9 Activation functions

**Metadata** — Tier: 3 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: Very high · Hands-on: Very high
Prerequisites: 3.8, 1.20, 1.21, 1.42 · Leads to: 3.10–3.15, 3.25 Vanishing gradients, 3.22–3.24 Initialization

### 1. What is it?
Nonlinear functions `φ` applied elementwise to the weighted sum: `a = φ(z)`. They give networks the ability to represent nonlinear relationships.

### 2. Why does it exist?
Stacking linear layers gives only a linear map (two Dense layers collapse into one; tested). The activation breaks that collapse and sets how gradients flow.

### 3. Detailed explanation
- **Collapse demonstration:** `W₂(W₁x) = (W₂W₁)x`: a 8→6→3 network of two linear layers has 54 + 21 = 75 parameters but computes exactly what a 27-parameter linear map does. With ReLU in between the equality fails.
- **Properties to compare:** nonlinearity, differentiability (a.e. is enough), output range, monotonicity, zero-centering, **saturation** (flat regions where gradient ≈ 0), cost, and behaviour on negative inputs.
- **Measured on x ∈ [−6, 6] (lab):**
  | activation | range | max derivative | fraction with \|f′\| < 0.01 |
  |---|---|---|---|
  | sigmoid | (0, 1) | 0.25 | 23.6% |
  | tanh | (−1, 1) | 1.0 | 50.1% |
  | ReLU | [0, ∞) | 1 | 50.0% (all negative inputs) |
  | Leaky ReLU | (−∞, ∞) | 1 | 0% |
  | GELU | ≈[−0.17, ∞) | 1.129 | 24.9% |
  | SiLU | ≈[−0.278, ∞) | 1.10 | 0.7% |
- **Where used:** hidden layers → ReLU family / GELU / SiLU; recurrent gates → sigmoid/tanh; outputs → identity (regression), sigmoid (binary), softmax (multiclass) (3.5).
- **Gradient flow:** backprop multiplies by `φ′(z)` at every layer (1.25). If `φ′ ≤ 0.25` (sigmoid) ten layers give at most `0.25¹⁰ ≈ 9.5×10⁻⁷` (3.25).
- **Interaction with initialization:** He init is derived for ReLU, Xavier for tanh/sigmoid-like (3.23–3.24).
- **Choosing:** default to GELU/SiLU in Transformers, ReLU in CNNs/MLPs; test alternatives empirically; the differences are usually modest compared with data, architecture and optimization.
- **Implementation:** vectorized, numerically stable (sigmoid via `exp(−|x|)`), with analytic derivatives verified against PyTorch autograd (tested for sigmoid, tanh, ReLU, Leaky ReLU, GELU, SiLU).

### 4. How does it work?
Apply `φ` elementwise to `Z`; in backprop multiply the upstream gradient by `φ′(Z)`.

### 5. Simple example
A gate that bends the straight-line response so combinations of lines can draw curves.

### 6. Technical example
FFN(x) = W₂ φ(W₁x + b₁) + b₂ with φ = GELU/SiLU in Transformers.

### 8. Input → Process → Output
`z → φ(z) → a; backward: dz = da · φ′(z)`

### 9. Enterprise use case
Export/compilation tools must support the chosen activation; approximations (e.g., tanh-GELU) can change numerics slightly.

### 10. AI engineering connection
Activation choice affects trainability, quantization sensitivity and kernel fusion in LLMs (Tier 11).

### 11. Advantages
Provide expressiveness; cheap.

### 12. Limitations
Saturating ones cause vanishing gradients; dying ReLUs; non-monotone ones are slightly pricier.

### 13. Trade-offs
Smoothness (GELU/SiLU) vs simplicity and sparsity (ReLU).

### 14. Common mistakes
Omitting activations between layers; sigmoid hidden units in deep nets; mismatched init; using softmax as a hidden activation; forgetting the output activation belongs in the loss.

### 15. Performance / cost
Elementwise ops are memory-bound; fuse with the preceding matmul (kernel fusion).

### 17. Interview explanation
"Without a nonlinearity a stack of linear layers is just one linear map. I choose activations by gradient behaviour: ReLU/GELU/SiLU for hidden layers, sigmoid/softmax at outputs, and I pair the choice with the right initialization. Saturating activations multiply gradients by small numbers, which is why they vanish in deep networks."

### 18. Rapid-fire
