# 3.21 Automatic differentiation

**Metadata** — Tier: 3 · Phase: 1 · Priority: P0 · Difficulty: 3/5 · Interview: High · Hands-on: High
Prerequisites: 3.19, 3.20, 1.21 · Leads to: Tier 4 PyTorch autograd, JAX-style transformations

### 1. What is it?
Systematic computation of exact derivatives of programs by applying the chain rule to each elementary operation. Two modes: **forward mode** (propagate derivatives with the values) and **reverse mode** (record, then propagate backward). Backpropagation is reverse mode applied to neural networks.

### 2. Why does it exist?
Writing gradients by hand is error-prone; numerical differences are slow and inaccurate. Autodiff gives exact gradients for arbitrary code at a small constant overhead.

### 3. Detailed explanation
- **Three ways to get derivatives:** symbolic (algebra, can explode in size), numerical (finite differences: approximate, one function evaluation per input), automatic (exact up to floating point).
- **Numerical differentiation error** (central difference of `x³` at 0.7): h = 0.1 → 1.0×10⁻²; 10⁻³ → 1.0×10⁻⁶; 10⁻⁵ → 9.2×10⁻¹¹; 10⁻⁸ → 7.8×10⁻⁹; 10⁻¹² → 3.7×10⁻⁵. Truncation error shrinks with h, round-off grows: there is a sweet spot (1.21). Autodiff has neither problem.
- **Forward mode (dual numbers):** carry `(value, derivative w.r.t. one chosen input)`. One pass per input. Cheap for functions with few inputs and many outputs. Implemented as `Dual`.
- **Reverse mode:** one forward pass to record, one backward pass for **all** input gradients of a scalar output. For 1,000 inputs, forward mode needs 1,000 passes; reverse mode 1 (both equal exactly in the tests). This asymmetry is why deep learning uses reverse mode: one scalar loss, billions of parameters.
- **Handles control flow:** the derivative is of the executed path. `relu(x)` or `0.1x` selected by a Python `if` gives gradients 1.0 and 0.1 (tested).
- **Limits:** derivatives of non-smooth or discrete operations are 0 or undefined (`round` gives gradient 0); gradients of iterative/numerical routines may be inaccurate unless the algorithm is differentiated carefully; in-place mutation breaks recording.
- **Higher-order derivatives** (Hessian-vector products) come from differentiating the gradient program (used in curvature analysis, 1.46).
- **Frameworks:** PyTorch `autograd` (dynamic tape), JAX `grad/jit/vmap` (function transformations), TensorFlow `GradientTape`. Concepts are shared.
- **Our minimal engine** (`Value`) is about 100 lines, handles `+ − × ÷ ** exp log tanh relu sigmoid`, and agrees with PyTorch to 1e-12 on a composite function.
- **Deep chains:** a recursive topological sort overflows Python's stack at ~1,000 nested operations; our implementation is iterative for that reason.

### 4. How does it work?
Overload operations so each records its local derivative rule; reverse mode then runs recorded rules in reverse order, accumulating gradients.

### 5. Simple example
A calculator that keeps a ledger of each step so it can tell you how the final answer reacts to any input.

### 6. Technical example
`loss.backward()` in PyTorch; `jax.grad(loss)(params)` in JAX.

### 7. Code
```python
from autodiff import Value, Dual
x, y = Value(0.7), Value(-1.3); out = (x * y + x.tanh()) ** 2 + (y * y + 1).log(); out.backward(); print(x.grad, y.grad)     # matches torch autograd
d = (Dual(0.4, 1.0) * Dual(0.4, 1.0)).d; print(d)      # forward mode: d/dx x^2 at 0.4 = 0.8
```

### 8. Input → Process → Output
`program → record ops → backward sweep → exact gradients`

### 9. Enterprise use case
Autodiff frameworks make custom losses and architectures cheap to build and verify.

### 10. AI engineering connection
Custom layers, loss functions, differentiable retrieval or ranking components, meta-learning (differentiating through training).

### 11. Advantages
Exact, general, efficient for scalar objectives.

### 12. Limitations
Memory of recorded graph; non-differentiable operations; subtle in-place/numerical issues.

### 13. Trade-offs
Reverse mode: memory heavy but efficient for many inputs. Forward mode: low memory but one pass per input.

### 14. Common mistakes
Using numerical gradients in training; detaching accidentally; differentiating through `argmax`; relying on autodiff through unstable numerics (fuse log-softmax).

### 15. Performance / cost
Tape memory ≈ activations; checkpointing and fusion reduce it.

### 16. Security
Gradient access can enable model inversion and adversarial examples; control it in deployed APIs.

### 17. Interview explanation
"Autodiff applies the chain rule mechanically to the operations a program actually executed. Reverse mode computes the gradient of a scalar with respect to all inputs in about the cost of two evaluations, which is why training uses it; forward mode needs one pass per input. Unlike finite differences it has no step-size error."

### 18. Rapid-fire
Exact derivatives by chain rule over executed ops; reverse mode = all grads of a scalar in one backward pass; forward mode = one input per pass.
