> **In plain words**
> **SiLU** (also called **Swish**) is `x · sigmoid(x)`: **the input multiplied by how "on" it is**. Large positive inputs pass almost unchanged; large negative inputs are squashed to about 0; in between there's a smooth, slightly negative dip.
> It looks very much like GELU. Its big modern job: it is the **gate** inside **SwiGLU** feed-forward blocks, used by many recent large language models.

**You need first:** 3.10 Sigmoid and 3.12 ReLU.

### 1. What is it?
`SiLU(x) = x·σ(x)` (Sigmoid Linear Unit; also called **Swish** with `β = 1`): a smooth, non-monotone activation that gates the input by its own sigmoid.

### 2. Why does it exist?
It combines ReLU-like behaviour for large inputs with smoothness, and it is the gate in the SwiGLU feed-forward blocks of many modern language models.

### 3. Detailed explanation
- **Shape:** minimum ≈ **−0.278** at `x ≈ −1.28`; approaches 0 for very negative `x`; approaches `x` for large positive `x`.
- **Derivative:** `σ(x)(1 + x(1 − σ(x)))`; its maximum is about **1.10**. It has almost no flat region on [−6, 6].
- **Swish with a parameter:** `x·σ(βx)`; `β → ∞` recovers ReLU; `β = 1` is SiLU.
- **Gated linear units:** `SwiGLU(x) = (SiLU(xW) ⊙ xV)W₂` uses SiLU as the gate; used in several recent LLM families (REVIEW_REQUIRED: cite specific models before publishing). Gated FFNs have **three** weight matrices instead of two, so the hidden width is reduced to keep the parameter count comparable (Tiers 8, 12).
- **Relation to GELU:** a very similar shape; SiLU uses the logistic CDF, GELU the Gaussian CDF.
- **Numerics:** use a stable sigmoid (3.10).
- **Cost:** one sigmoid and one multiplication per element.

### 4. How does it work?
`a = z·σ(z)`; in backpropagation multiply by `σ(z)(1 + z(1 − σ(z)))`.

### 5. Simple example
An input that multiplies itself by how "on" it is.

**By hand.**

| `x` | `σ(x)` | `SiLU = x·σ(x)` |
|---|---|---|
| −4 | 0.018 | −0.072 |
| −1.28 | 0.217 | −0.278 (the minimum) |
| 0 | 0.5 | 0 |
| 2 | 0.881 | 1.762 |
| 6 | 0.9975 | 5.985 |

### 6. Technical example
A LLaMA-style feed-forward block: `down(SiLU(gate(x)) * up(x))`.

### 7. Code
**① By hand (plain Python).**

```python
import math

sigmoid = lambda x: 1 / (1 + math.exp(-x))
silu = lambda x: x * sigmoid(x)
for x in (-4, -1.28, 0, 2, 6):
    print(f"x = {x:>5}: sigmoid {sigmoid(x):.3f}   SiLU {silu(x):+.3f}")
print("minimum on a grid:", round(min(silu(i / 100) for i in range(-800, 801)), 3))
```

```text
x =    -4: sigmoid 0.018   SiLU -0.072
x = -1.28: sigmoid 0.218   SiLU -0.278
x =     0: sigmoid 0.500   SiLU +0.000
x =     2: sigmoid 0.881   SiLU +1.762
x =     6: sigmoid 0.998   SiLU +5.985
minimum on a grid: -0.278
```

**② With NumPy.** The derivative, and Swish with large `β` becoming ReLU.

```python
import numpy as np

sigmoid = lambda z: 1 / (1 + np.exp(-z))
x = np.linspace(-8, 8, 1601)
d = sigmoid(x) * (1 + x * (1 - sigmoid(x)))
print("derivative maximum:", round(float(d.max()), 3))
for beta in (1, 5, 50):
    swish = x * sigmoid(beta * x)
    print(f"beta = {beta:>2}: max |swish - relu| = {np.abs(swish - np.maximum(x, 0)).max():.3f}")
```

```text
derivative maximum: 1.1
beta =  1: max |swish - relu| = 0.278
beta =  5: max |swish - relu| = 0.056
beta = 50: max |swish - relu| = 0.005
```

**③ With PyTorch.** A SwiGLU block and its parameter count against a plain GELU feed-forward.

```python
import torch

d, hidden = 512, 2048
plain = torch.nn.Sequential(torch.nn.Linear(d, hidden), torch.nn.GELU(), torch.nn.Linear(hidden, d))

class SwiGLU(torch.nn.Module):
    def __init__(self, d, hidden):
        super().__init__()
        self.gate, self.up, self.down = torch.nn.Linear(d, hidden), torch.nn.Linear(d, hidden), torch.nn.Linear(hidden, d)
    def forward(self, x):
        return self.down(torch.nn.functional.silu(self.gate(x)) * self.up(x))            # SiLU gates the other projection

swiglu = SwiGLU(d, hidden * 2 // 3)                                                       # shrink the width to keep parameters comparable
count = lambda m: sum(p.numel() for p in m.parameters())
print("plain GELU feed-forward parameters:", count(plain))
print("SwiGLU with hidden width 2/3       :", count(swiglu), "(about the same: three matrices of smaller width)")
print("output shape:", tuple(swiglu(torch.randn(4, d)).shape))
```

```text
plain GELU feed-forward parameters: 2099712
SwiGLU with hidden width 2/3       : 2099882 (about the same: three matrices of smaller width)
output shape: (4, 512)
```

The gate non-linearity in the SwiGLU feed-forward blocks of recent LLMs (Tiers 8, 12).

Smooth, no hard dead zone, strong empirical performance.

Costlier than ReLU; non-monotone.

Smoothness versus cost; gated variants add parameters and compute.

### 14. Common mistakes
Confusing SiLU with sigmoid or with GELU; forgetting that SwiGLU needs an extra projection; mismatched hidden sizes when porting.

### 17. Interview explanation
"SiLU, or Swish, is x times sigmoid of x: smooth, slightly negative for small negatives, almost linear for large positives. In modern LLMs it's the gate in SwiGLU feed-forward blocks, where one projection is passed through SiLU and multiplied element-wise by another."

### 20. Hands-on exercise
**Goal:** work out the right hidden width for a SwiGLU block.

1. A plain feed-forward block `d = 4096 → 16384 → 4096` has `2·d·16384 (+ biases)` parameters.
2. A SwiGLU block has three matrices of size `d × h`. Find `h` so that the weights (ignoring biases) match.

<details>
<summary>Show a solution</summary>

```python
d, plain_hidden = 4096, 16384
plain_weights = 2 * d * plain_hidden
h = plain_weights / (3 * d)
print("plain FFN weights :", plain_weights)
print("SwiGLU hidden size to match:", round(h), "  = 2/3 of", plain_hidden, "=", round(plain_hidden * 2 / 3))
print("SwiGLU weights    :", 3 * d * round(h))
```

SwiGLU hidden size to match: 10923   = 2/3 of 16384 = 10923
SwiGLU weights    : 134221824
