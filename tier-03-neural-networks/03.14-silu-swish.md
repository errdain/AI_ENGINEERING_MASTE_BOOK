# 3.14 SiLU / Swish

**Metadata** — Tier: 3 · Phase: 1 · Priority: P0 · Difficulty: 1/5 · Interview: Medium-High · Hands-on: Medium
Prerequisites: 3.10, 3.12 · Leads to: Tier 8 gated FFNs (SwiGLU), Tier 12 modern architectures

### 1. What is it?
`SiLU(x) = x·σ(x)` (Sigmoid Linear Unit; also called **Swish** with β=1): a smooth, non-monotone activation that gates the input by its own sigmoid.

### 2. Why does it exist?
It combines ReLU-like behaviour for large inputs with smoothness, and it is the gate in the SwiGLU feed-forward blocks of many modern language models.

### 3. Detailed explanation
- **Shape:** minimum ≈ **−0.278** at x ≈ −1.28; approaches 0 for very negative x; approaches x for large positive x.
- **Derivative:** `σ(x)(1 + x(1 − σ(x)))`; maximum ≈ **1.10**; on [−6, 6] only 0.7% of inputs have |derivative| < 0.01, so it has almost no flat region there (lab).
- **Swish with parameter β:** `x·σ(βx)`; β → ∞ recovers ReLU, β = 1 is SiLU.
- **Gated linear units:** `SwiGLU(x) = (SiLU(xW) ⊙ xV)W₂` uses SiLU as the gate; used in several recent LLM families (REVIEW_REQUIRED: cite specific models before publishing). Gated FFNs have three weight matrices instead of two, so hidden width is reduced to keep parameters comparable (Tier 8, 12).
- **Relation to GELU:** very similar shape; SiLU uses the logistic CDF, GELU the Gaussian CDF.
- **Numerics:** use a stable sigmoid (3.10); derivative checked against PyTorch autograd.
- **Cost:** one sigmoid and one multiply per element.

### 4. How does it work?
`a = z·σ(z)`; backprop multiplies by `σ(z)(1 + z(1−σ(z)))`.

### 5. Simple example
An input that multiplies itself by how 'on' it is.

### 6. Technical example
LLaMA-style FFN: `down(SiLU(gate(x)) * up(x))`.

### 8. Input → Process → Output
`z → z·σ(z)`

### 9. Enterprise use case
Supported natively in major runtimes; fused kernels are standard.

### 10. AI engineering connection
Gate nonlinearity in SwiGLU FFNs of recent LLMs (Tier 8, 12).

### 11. Advantages
Smooth, no hard dead zone, strong empirical performance.

### 12. Limitations
Costlier than ReLU; non-monotone.

### 13. Trade-offs
Smoothness vs cost; gated variants add parameters/compute.

### 14. Common mistakes
Confusing SiLU with sigmoid or with GELU; forgetting that SwiGLU needs an extra projection; mismatched hidden sizes when porting.

### 15. Performance / cost
Fused with the elementwise multiply in gated FFNs.

### 17. Interview explanation
"SiLU, or Swish, is x times sigmoid of x: smooth, slightly negative for small negatives, almost linear for large positives. In modern LLMs it's the gate in SwiGLU feed-forward blocks, where one projection is passed through SiLU and multiplied elementwise by another."
