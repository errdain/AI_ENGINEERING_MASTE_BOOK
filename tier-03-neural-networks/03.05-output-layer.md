# 3.5 Output layer

**Metadata** — Tier: 3 · Phase: 1 · Priority: P0 · Difficulty: 1/5 · Interview: High · Hands-on: High
Prerequisites: 3.4, 2.14, 2.15 · Leads to: 3.15 Softmax, 2.17 Loss functions, Tier 16 LLM heads

### 1. What is it?
The **final layer** that produces the prediction in the form the task needs: its size, activation and paired loss depend on the problem.

### 2. Why does it exist?
A mismatch between output layer and loss (e.g., softmax twice, wrong size) is a common source of silent errors.

### 3. Detailed explanation
| Task | Output units | Activation (on logits) | Loss |
|---|---|---|---|
| Regression (1 value) | 1 | none (identity) | MSE / MAE / Huber |
| Binary classification | 1 (a logit) | sigmoid | binary cross-entropy |
| Multiclass (one label) | K | softmax | categorical cross-entropy |
| Multilabel (several labels) | K | K independent sigmoids | BCE per label |
| Language model (next token) | vocabulary size V | softmax over V | cross-entropy |

- **Output logits, not probabilities, to the loss:** compute softmax/sigmoid inside the loss (2.17, 1.43) for numerical stability. In our library the output layer returns raw logits and `softmax_cross_entropy` handles the rest (checked against PyTorch).
- **Output size drives parameters:** an LM head projecting `d_model = 768` onto a 50,000-token vocabulary has `768·50,000 + 50,000 = 38.45M` parameters, a large share of a small model's total. Weight tying with the input embedding is a common saving (Tier 8).
- **Output range matters:** a final ReLU forbids negative regression outputs; a sigmoid bounds outputs to (0,1); choose accordingly.
- **Calibration:** softmax outputs are not guaranteed to be calibrated (2.43).
- **Multiple heads:** one backbone with several output layers for multi-task learning.
- **Structured outputs:** JSON/tool calls (Tier 19) are produced by the LM head token by token, constrained by decoding; they are not separate output layers.

### 4. How does it work?
Final Dense layer maps the last hidden representation to task-sized logits; the loss (or inference step) applies the right activation.

### 5. Simple example
The form on which the network writes its answer: one number, a yes/no, or a score per category.

### 6. Technical example
10-class digit classifier: Dense(64→10) producing logits for softmax cross-entropy.

### 7. Code
```python
import nn as N, numpy as np
logits = N.MLP([784, 128, 64, 10]).forward(np.zeros((32, 784)))          # raw logits, shape (32, 10)
loss, dlogits = N.softmax_cross_entropy(logits, np.zeros(32, int))        # activation lives inside the loss
```

### 8. Input → Process → Output
`last hidden state → Dense → logits → (softmax/sigmoid) → prediction + loss`

### 9. Enterprise use case
Output specifications (classes, ranges, thresholds) are part of the model contract with consumers.

### 10. AI engineering connection
LM heads, reward-model scalar heads, classification heads on embeddings, multiple heads in multimodal models.

### 11. Advantages
Task-specific interface with standard loss pairings.

### 12. Limitations
Fixed number of classes; changing the label set needs a new head or retraining.

### 13. Trade-offs
Large vocabularies increase compute and memory in the output projection.

### 14. Common mistakes
Applying softmax before a loss that applies it again; sigmoid for mutually exclusive classes; wrong number of units; ReLU on regression output.

### 15. Performance / cost
Vocabulary-size softmax is a notable cost at inference (sampling) and in memory for the logit tensor.

### 16. Security
Output filtering/validation is a safety layer: never trust raw model outputs for actions.

### 17. Interview explanation
"The output layer matches the task: one linear unit for regression, one logit for binary classification, K logits with softmax for multiclass, K independent sigmoids for multilabel. I feed logits to a loss that includes the activation for stability, and I watch the size: an LM head over a 50k vocabulary is tens of millions of parameters."

### 18. Rapid-fire
Regression: 1 linear unit; binary: 1 logit+sigmoid; multiclass: K logits+softmax; multilabel: K sigmoids; pass logits to the loss.
