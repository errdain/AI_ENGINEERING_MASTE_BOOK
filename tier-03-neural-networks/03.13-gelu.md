> **In plain words**
> **GELU** is **ReLU with the corner sanded off**: instead of a hard on/off switch at zero, it **fades** between "block" and "pass". Small negative inputs are *partly* let through instead of being cut to exactly 0.
> The formula is `x · Φ(x)`, where `Φ(x)` is the chance that a standard bell-curve random number is below `x`: "multiply the input by how likely it is to be kept". It is the standard activation inside the feed-forward blocks of BERT-style and GPT-2-style Transformers.

**You need first:** 3.12 ReLU and 1.28 Distributions (the bell curve).

### 1. What is it?
The **Gaussian Error Linear Unit** `GELU(x) = x·Φ(x)`, where `Φ` is the standard normal CDF: a smooth ReLU-like function that weights each input by the probability that a standard Gaussian variable is below it.

### 2. Why does it exist?
A smooth, non-monotone alternative to ReLU that works well in Transformers and avoids a hard kink.

### 3. Detailed explanation
- **Exact form:** `0.5·x·(1 + erf(x/√2))`. A common **tanh approximation** is `0.5x(1 + tanh(√(2/π)(x + 0.044715x³)))`. The difference (about `10⁻³`) matters for exactly reproducing released checkpoints.
- **Shape:** about 0 for very negative `x` (`GELU(−10) ≈ 0` within `10⁻⁶`), approaches `x` for large positive `x`; a slight negative dip with minimum ≈ **−0.17** near `x ≈ −0.75`.
- **Derivative:** `Φ(x) + x·φ(x)` (`φ` = the bell-curve density); its maximum is about **1.13**, slightly above 1.
- **Versus ReLU:** the two never differ by more than about 0.17. GELU is smooth, so gradients pass through small negative inputs instead of being blocked.
- **Usage:** BERT, GPT-2 and many later Transformers use GELU in the feed-forward sub-layer; newer LLMs often use gated variants with SiLU (SwiGLU, 3.14). REVIEW_REQUIRED: verify per-model statements before publishing.
- **Intuition (stochastic view):** keep the input with probability `Φ(x)`; the expected result of that gating is GELU.
- **Cost:** slightly higher than ReLU (an `erf` or a `tanh`).

### 4. How does it work?
Compute `x·Φ(x)` element-wise (the `erf` or `tanh` form); in backpropagation use `Φ(x) + xφ(x)`.

### 5. Simple example
A soft ReLU: small negatives are partly let through rather than fully blocked.

**By hand.**

| 0 | 0.5 | 0 | 0 |

### 6. Technical example
The feed-forward block in BERT: `GELU(xW₁ + b₁)W₂ + b₂` with hidden width 4 × `d_model`.

### 7. Code
**① By hand (plain Python).**

```python
import math

def gelu(x):
    return 0.5 * x * (1 + math.erf(x / math.sqrt(2)))                # x * Phi(x)

for x in (-3, -1, 0, 1, 3):
    print(f"x = {x:>2}: GELU {gelu(x):+.3f}   ReLU {max(0, x):.1f}")
print("minimum on a grid:", round(min(gelu(i / 100) for i in range(-800, 801)), 3))
```

```text
x = -3: GELU -0.004   ReLU 0.0
x = -1: GELU -0.159   ReLU 0.0
x =  0: GELU +0.000   ReLU 0.0
x =  1: GELU +0.841   ReLU 1.0
x =  3: GELU +2.996   ReLU 3.0
minimum on a grid: -0.17
```

**② With NumPy.** The tanh approximation and how far it is from the exact function.

```python
import numpy as np
from math import erf, sqrt, pi

x = np.linspace(-8, 8, 1601)
exact = np.array([0.5 * v * (1 + erf(v / sqrt(2))) for v in x])
approx = 0.5 * x * (1 + np.tanh(sqrt(2 / pi) * (x + 0.044715 * x ** 3)))
print("max |exact - tanh approximation|:", f"{np.abs(exact - approx).max():.1e}")
print("max |GELU - ReLU|               :", round(float(np.abs(exact - np.maximum(x, 0)).max()), 3))
print("derivative maximum              :", round(float((np.gradient(exact, x)).max()), 3))
```

```text
max |exact - tanh approximation|: 4.7e-04
max |GELU - ReLU|               : 0.17
derivative maximum              : 1.129
```

**③ With PyTorch.** Both variants, side by side.

```python
import torch
import torch.nn.functional as F

x = torch.linspace(-6, 6, 1201)
diff = (F.gelu(x) - F.gelu(x, approximate="tanh")).abs().max().item()
print("exact vs tanh variant in PyTorch, max difference:", f"{diff:.1e}", "(matters when reproducing checkpoints)")
z = torch.tensor([-1.0, 0.0, 1.0], requires_grad=True)
F.gelu(z).sum().backward()
print("GELU gradient at -1, 0, 1:", [round(v, 3) for v in z.grad.tolist()])
```

```text
exact vs tanh variant in PyTorch, max difference: 4.7e-04 (matters when reproducing checkpoints)
GELU gradient at -1, 0, 1: [-0.083, 0.5, 1.083]
```

### 10. AI engineering connection
The standard feed-forward activation in many Transformer encoders and decoders (Tier 8).

### 11. Advantages
Smooth, good empirical performance, non-saturating for positive inputs.

### 12. Limitations
More expensive than ReLU; non-monotone; approximation variants differ.

### 13. Trade-offs
Smoothness and accuracy versus speed.

### 14. Common mistakes
Mixing the exact and tanh GELU between training and inference; assuming it is monotone; using it without checking quantisation effects.
