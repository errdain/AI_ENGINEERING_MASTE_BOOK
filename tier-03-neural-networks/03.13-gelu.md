# 3.13 GELU

**Metadata** — Tier: 3 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: High · Hands-on: Medium
Prerequisites: 3.12, 1.28 · Leads to: Tier 8 Transformer FFN

### 1. What is it?
The **Gaussian Error Linear Unit** `GELU(x) = x·Φ(x)`, where `Φ` is the standard normal CDF: a smooth ReLU-like function that weights each input by the probability that a standard Gaussian variable is below it.

### 2. Why does it exist?
A smooth, non-monotone alternative to ReLU that empirically works well in Transformers and avoids a hard kink.

### 3. Detailed explanation
- **Exact form:** `0.5·x·(1 + erf(x/√2))`; a common **tanh approximation** is `0.5x(1 + tanh(√(2/π)(x + 0.044715x³)))` (differences of ~10⁻³ matter for exact reproducibility of released checkpoints).
- **Shape:** near 0 for very negative x (e.g., GELU(−10) ≈ 0 to within 10⁻⁶), approaches `x` for large positive x; slight negative dip, minimum ≈ **−0.17** near x ≈ −0.75.
- **Derivative:** `Φ(x) + xφ(x)` (φ = normal pdf); maximum ≈ **1.129** (slightly above 1), checked against PyTorch autograd.
- **Difference from ReLU:** at most 0.17 in absolute value on [−8, 8] (lab). It is smooth, so gradients pass through small negative inputs instead of being blocked.
- **Usage:** BERT, GPT-2 and many later Transformers use GELU in the feed-forward sublayer; newer LLMs often use gated variants with SiLU (SwiGLU, 3.14). REVIEW_REQUIRED: verify per-model statements before publishing.
- **Intuition (stochastic regularizer view):** input is kept with probability `Φ(x)`; the expectation of that gating is GELU.
- **Cost:** slightly higher than ReLU (erf or tanh).

### 4. How does it work?
Compute `x·Φ(x)` elementwise (erf or tanh form); backprop uses `Φ(x) + xφ(x)`.

### 5. Simple example
A soft ReLU: small negatives are partly let through instead of fully blocked.

### 6. Technical example
FFN in BERT: `GELU(xW₁ + b₁)W₂ + b₂` with hidden width 4×d_model.

### 8. Input → Process → Output
`z → z·Φ(z)`

### 9. Enterprise use case
Pinning the exact vs tanh variant matters when converting models between frameworks.

### 10. AI engineering connection
Standard FFN activation in many Transformer encoders/decoders (Tier 8).

### 11. Advantages
Smooth, good empirical performance, non-saturating for positive inputs.

### 12. Limitations
More expensive than ReLU; non-monotone; approximation variants differ.

### 13. Trade-offs
Smoothness and accuracy vs speed.

### 14. Common mistakes
Mixing exact and tanh GELU between training and inference; assuming it is monotone; using it without checking quantization effects.

### 15. Performance / cost
Fused kernels make the extra cost small.
