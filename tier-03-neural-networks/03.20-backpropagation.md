# 3.20 Backpropagation

**Metadata** — Tier: 3 · Phase: 1 · Priority: P0 · Difficulty: 3/5 · Interview: Very high · Hands-on: Very high
Prerequisites: 1.24, 1.25, 3.18, 3.19 · Leads to: Tier 4 Training loop, 3.25–3.26 gradient problems

### 1. What is it?
The algorithm that computes the **gradient of the loss with respect to every parameter** by applying the chain rule backward through the network, reusing intermediate results from the forward pass.

### 2. Why does it exist?
Training by gradient descent needs `∂L/∂θ` for millions or billions of parameters. Backprop gets all of them for roughly the cost of two forward passes.

### 3. Detailed explanation
For layer `l` with `zₗ = Wₗaₗ₋₁ + bₗ`, `aₗ = φ(zₗ)` and upstream gradient `δ_a = ∂L/∂aₗ`:
1. `δ_z = δ_a ⊙ φ′(zₗ)`
2. `∂L/∂Wₗ = δ_zᵀ aₗ₋₁`, `∂L/∂bₗ = Σ_batch δ_z`
3. `∂L/∂aₗ₋₁ = δ_z Wₗ` (passed to the previous layer)

For softmax + cross-entropy the starting signal at the logits is simply `softmax(z) − onehot(y)` divided by the batch size (1.37).
- **Verification:** the manual backward matches central finite differences to 2×10⁻¹⁰ and PyTorch autograd for five activations (tanh, ReLU, GELU, sigmoid, SiLU) in the test suite.
- **Cost:** backward ≈ **2×** forward FLOPs (one matmul for `dW`, one for the input gradient, per layer). Finite differences for the 109,386-parameter network would need `2P = 218,772` forward passes per gradient; backprop needs one forward and one backward.
- **Memory:** forward activations are cached until used; this is the training memory bottleneck (3.18).
- **Reverse mode is the right direction:** one scalar loss, many parameters (3.21).
- **Depth effects:** each layer multiplies the backward signal by `Wᵀ φ′`; repeated products shrink (3.25) or blow up (3.26) the gradient.
- **Parameter sharing and reuse:** shared weights (tied embeddings, recurrence) accumulate gradient contributions from every use (3.19).
- **Non-differentiable pieces:** `argmax`, sampling, rounding block the gradient; use straight-through estimators or reinforcement learning.
- **After backprop:** an optimizer (SGD, Adam; Tier 4) turns gradients into updates; backprop itself only computes gradients.
- **History:** reverse-mode differentiation was known earlier; Rumelhart, Hinton & Williams (1986) popularized backprop for neural networks (REVIEW_REQUIRED: verify history).

### 4. How does it work?
Forward: compute and cache. Backward: start from `∂L/∂logits`, move layer by layer toward the input, computing parameter gradients and passing input gradients.

### 5. Simple example
Tracing blame backward: how much did each earlier decision contribute to the final error?

### 6. Technical example
`loss.backward()` in PyTorch; our `MLP.backward(dlogits)` is the same computation written out.

### 7. Code
```python
import numpy as np, nn as N
m = N.MLP([4, 5, 3], activation='tanh', init='xavier_normal'); loss, d = N.softmax_cross_entropy(m.forward(X), y); m.backward(d)
# m.layers[0].dW now equals the finite-difference gradient to ~1e-10; compare with N.numerical_grad
```

### 8. Input → Process → Output
`dL/dlogits → ×Wᵀ, ×φ′ → … → dL/dW for every layer`

### 9. Enterprise use case
Training cost estimates multiply forward cost by about 3 (forward + 2× backward) per token; this feeds GPU budgeting.

### 10. AI engineering connection
Fine-tuning, LoRA, RLHF all rely on backprop; gradient checkpointing, mixed precision and clipping are engineering around it.

### 11. Advantages
Exact gradients at low cost; general for any differentiable graph.

### 12. Limitations
Memory for activations; vanishing/exploding gradients; needs differentiability.

### 13. Trade-offs
Activation checkpointing: less memory, ~33% more compute.

### 14. Common mistakes
Forgetting to zero accumulated gradients; wrong order of multiplications and transposes; in-place ops breaking caches; using probabilities instead of logits at the start.

### 15. Performance / cost
Backward matmuls dominate; overlapping communication with backward is key in distributed training (Tier 4).

### 16. Security
Gradients can leak training data (federated/distributed settings); clip and noise for privacy.

### 17. Interview explanation
"Backprop applies the chain rule from the loss back to each parameter, reusing the forward activations: for each layer, dW is the upstream gradient transposed times the layer input, and the gradient passed down is upstream times W. It costs about twice a forward pass, versus a forward pass per parameter for finite differences."

### 18. Rapid-fire
Reverse chain rule: δ_z=δ_a⊙φ′; dW=δ_zᵀa_prev; da_prev=δ_z·W; cost ≈2× forward; start with softmax−onehot.
