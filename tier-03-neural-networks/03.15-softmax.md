# 3.15 Softmax

**Metadata** — Tier: 3 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: Very high · Hands-on: Very high
Prerequisites: 1.42, 1.43, 1.28 · Leads to: 2.14 Classification, 1.37 Cross-entropy, Tier 7 Attention, Tier 16 sampling

### 1. What is it?
`softmax(z)ᵢ = exp(zᵢ) / Σⱼ exp(zⱼ)`: turns a vector of scores (logits) into a probability distribution over `K` classes: positive, summing to 1.

### 2. Why does it exist?
Classification and next-token prediction need a categorical distribution; softmax provides one with a clean gradient when paired with cross-entropy.

### 3. Detailed explanation
- **Properties (all tested):** each row sums to 1; **shift invariant** (`softmax(z + c) = softmax(z)`); preserves the ordering of logits (argmax unchanged).
- **Numerically stable form:** subtract the max before exponentiating (1.43); `log_softmax` is `z − logsumexp(z)`. Naive softmax of `[1000, 0]` overflows to NaN; the stable one is finite (matches PyTorch).
- **Temperature `T`:** `softmax(z/T)`. Mean entropy on random logits: 0.051 nats at `T = 0.1` (nearly one-hot), 1.06 at `T = 1`, 1.77 at `T = 10` (near uniform). `T → 0` approaches argmax; `T → ∞` approaches uniform. Argmax is unchanged. Used in sampling (Tier 16) and distillation.
- **Sigmoid as a special case:** for two classes `softmax([a, b])₁ = σ(a − b)` (tested).
- **Gradient with cross-entropy:** `∂L/∂z = softmax(z) − onehot(y)` (1.37). Jacobian of softmax itself: `diag(p) − ppᵀ` (1.24), singular because outputs sum to 1.
- **Attention:** attention weights are a softmax over scores `QKᵀ/√d` (Tier 7), a different use of the same function.
- **Calibration:** softmax scores are *not* guaranteed probabilities of correctness (2.43); modern networks tend to be overconfident.
- **Closed-set assumption:** softmax forces probabilities to sum to 1 over known classes, so an out-of-distribution input still receives a confident class; add an 'unknown' class, thresholds, or open-set methods.
- **Cost:** `O(K)` per sample; with a 50k-token vocabulary the logits tensor `(B·T, V)` is a major memory consumer.

### 4. How does it work?
Shift by max, exponentiate, normalize.

### 5. Simple example
Turning raw scores into vote shares that add up to 100%.

### 6. Technical example
Final layer of an image classifier: 1000 logits → softmax → class probabilities.

### 7. Code
```python
import numpy as np, nn as N
z = np.array([[2.0, 1.0, 0.1]]); print(N.softmax(z), N.softmax(z, temperature=0.1), N.softmax(z + 100))
print(N.softmax(np.array([[1000.0, 0.0]])))        # [[1. 0.]] — finite
```

### 8. Input → Process → Output
`logits → exp(z − max) → normalize → probabilities`

### 9. Enterprise use case
Probabilities from softmax feed thresholds and abstention rules; those require calibration checks.

### 10. AI engineering connection
Next-token distributions, attention weights, routing in mixture-of-experts gates, classification heads.

### 11. Advantages
Differentiable, interpretable as a distribution, pairs with cross-entropy.

### 12. Limitations
Overconfident; closed-world; cost with huge vocabularies.

### 13. Trade-offs
Temperature trades determinism against diversity.

### 14. Common mistakes
Softmax over the wrong axis (1.6); applying softmax before a loss that applies it; naive unstable implementation; reading scores as calibrated probabilities.

### 15. Performance / cost
Fused/online softmax kernels reduce memory traffic (flash-attention idea).

### 16. Security
Confidence from softmax is exploitable by adversarial inputs; do not use it alone for safety gating.

### 17. Interview explanation
"Softmax exponentiates the logits and normalizes them into a distribution. I compute it stably by subtracting the max, pair it with cross-entropy for the clean softmax-minus-label gradient, use temperature to control sharpness, and remember it's overconfident and closed-set, so I check calibration."

### 18. Rapid-fire
exp(zᵢ)/Σexp(zⱼ); sums to 1, shift-invariant; stable via max-shift; temperature controls entropy; gradient softmax−onehot.
