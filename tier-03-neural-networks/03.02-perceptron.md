# 3.2 Perceptron

**Metadata** — Tier: 3 · Phase: 1 · Priority: P1 · Difficulty: 2/5 · Interview: Medium-High · Hands-on: High
Prerequisites: 3.1, 2.14 · Leads to: 3.17 MLP, 3.20 Backpropagation (why we needed it)

### 1. What is it?
The **perceptron** is a single threshold neuron `ŷ = 1 if w·x + b > 0 else 0` trained by an error-driven rule: after a wrong prediction, move the weights toward the correct answer: `w ← w + η(y − ŷ)x`, `b ← b + η(y − ŷ)`.

### 2. Why does it exist?
It is the historical first learning machine for classification and the cleanest illustration of linear separability and of why hidden layers are needed.

### 3. Detailed explanation
- **Learning rule:** updates only on mistakes. If the sample is a false negative (`y=1, ŷ=0`) add `ηx`; if a false positive subtract `ηx`.
- **Convergence theorem (Novikoff):** if the data are linearly separable with margin `γ` and all `‖x‖ ≤ R`, the perceptron makes at most `(R/γ)²` mistakes and then stops. Verified in the lab: with margins 0.5, 0.2, 0.05 the numbers of mistakes were 6, 22 and 8 versus bounds 37, 219 and 2,865. The bound is loose but it holds.
- **Linearly separable:** AND converged in 6 epochs (10 mistakes), OR in 4 epochs (4 mistakes).
- **XOR failure:** no line separates `{(0,1),(1,0)}` from `{(0,0),(1,1)}`; after 100 epochs the perceptron was still making mistakes (397 in total) and never converged. Minsky and Papert (1969) highlighted this limitation of single-layer perceptrons, which slowed neural-network research until multilayer training (backpropagation) became practical (history simplified).
- **Differences from logistic regression:** hard threshold output, no probabilities, no gradient (the step function has zero derivative almost everywhere), update only on errors. Replace the step by a sigmoid and the squared/log loss by gradient descent and you get logistic regression (2.14).
- **Non-separable data:** the perceptron oscillates and never stabilizes; use a decaying rate, averaging ('averaged perceptron') or a smooth loss.
- **Still useful:** online learning, structured prediction (the structured perceptron), and as a teaching device.

### 4. How does it work?
Loop over samples; predict; if wrong update; repeat epochs until an epoch has zero mistakes (or a limit is reached).

### 7. Code
```python
import numpy as np, nn as N
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
p = N.Perceptron().fit(X, np.array([0, 0, 0, 1])); print(p.converged_, p.mistakes_per_epoch_)         # True, AND learned
q = N.Perceptron(max_epochs=100).fit(X, np.array([0, 1, 1, 0])); print(q.converged_)                   # False: XOR
```

### 8. Input → Process → Output
`x → step(w·x+b) → compare with y → update w on mistakes`

### 9. Enterprise use case
Rarely deployed alone now; the same update idea persists in online and large-margin methods.

### 10. AI engineering connection
Conceptual root of neural classifiers; explains why depth and nonlinearity are required.

### 11. Advantages
Simple, fast, provable convergence on separable data.

### 12. Limitations
Only linear boundaries; no probabilities; unstable on non-separable data.

### 13. Trade-offs
Hard-threshold simplicity vs smooth-loss optimization with gradients.

### 14. Common mistakes
Expecting convergence on non-separable data; ignoring feature scaling; forgetting the bias; confusing the perceptron update with gradient descent on a smooth loss.

### 15. Performance / cost
`O(d)` per update.

### 16. Security
Online updates from untrusted streams can be poisoned.

### 17. Interview explanation
"The perceptron is a threshold neuron trained by adding or subtracting the input when it makes a mistake. If the data are linearly separable it converges in at most (R over margin) squared mistakes; it can't learn XOR, which is why we need hidden layers and a trainable, differentiable setup."

### 18. Rapid-fire
w += η(y−ŷ)x on mistakes; converges iff linearly separable (≤(R/γ)² mistakes); fails on XOR.
