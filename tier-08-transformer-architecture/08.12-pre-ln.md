### 1. WHAT IS IT?

**Pre-LN** puts the normalisation *inside* the residual branch: `x <- x + F(Norm(x))`. The residual path from input to output stays a clean identity. Most modern LLMs use it, with a **final norm** before the output head.

### 2. WHY DOES IT EXIST?

In Post-LN, gradients must pass through a normalisation at every layer and deep stacks need careful warm-up. Pre-LN removes norms from the skip path so gradients flow undamped and training is far more forgiving.

### 3. DETAILED EXPLANATION

| | Post-LN (2017) | Pre-LN (most modern LLMs) |
|---|---|---|
| Formula | `x <- Norm(x + F(x))` | `x <- x + F(Norm(x))` |
| Residual path | passes through a norm every sub-layer | clean identity input to output |
| Stream scale | held near 1 after each norm | grows with depth |
| Final norm needed | no | **yes** |
| Deep-stack training | needs warm-up; can diverge | much more stable |
| Final quality if both train | some reports slightly better | some reports slightly worse |

*(Quality remarks are from the literature and task dependent: `REVIEW_REQUIRED`.)*

Intuition: in Post-LN every gradient crosses `L` normalisation Jacobians on the way back; at initialisation these can shrink or amplify it layer after layer. In Pre-LN the identity path bypasses all norms. See Xiong et al. 2020 for the analysis (`REVIEW_REQUIRED` for exact claims).

### 4. HOW DOES IT WORK?

1. Norm the stream.
2. Apply the sub-layer (attention or FFN).
3. Add the output to the *un-normalised* stream.
4. After the last block apply a **final norm**, then the output head.

### 5. SIMPLE EXAMPLE

Keep the master copy of the document untouched (the road) and edit a normalised photocopy (the branch); then staple the edit onto the master.

### 6. TECHNICAL EXAMPLE

The lab MiniGPT uses Pre-LN (`prenorm=True`) with `final_norm`; GPT-2 is Pre-LN style; the original Transformer and the original BERT are Post-LN (`REVIEW_REQUIRED` per model).

### 7. CODE

```python
import torch
from mini_gpt import GPTConfig, MiniGPT

def final_rms(prenorm, L=24, d=64, seed=0):
    torch.manual_seed(seed)
    m = MiniGPT(GPTConfig(vocab_size=64, block_size=32, n_layer=L, n_head=4, d_model=d, prenorm=prenorm)).eval()
    for n, p in m.named_parameters():                       # same init regime as Figure 4: sub-layers matter at init
        if p.dim() == 2 and n.startswith("blocks"): torch.nn.init.normal_(p, 0, 0.25)
    torch.nn.init.normal_(m.tok.weight, 0, 1.0)
    x = m.tok(torch.randint(0, 64, (16, 32))) + m.pos(torch.arange(32))
    for b in m.blocks: x = b(x)
    return x.pow(2).mean().sqrt().item()

pre, post = final_rms(True), final_rms(False)
print(f"stream RMS after 24 blocks: Pre-LN {pre:.1f}   Post-LN {post:.2f}")
assert post < 1.5 and pre > 5 * post       # Post-LN pinned near 1, Pre-LN grew
```

Code: `Block.forward` (Pre-LN branch) and `final_norm` in [`lab/mini_gpt.py`](lab/mini_gpt.py).

### 8. INPUT → PROCESS → OUTPUT

```
x --> Norm --> F --> (+) --> next      with x also going straight into (+)
final: x_L --> Norm --> output head
```

### 9. ENTERPRISE USE CASE

Loading Pre-LN weights into Post-LN code (or the reverse) produces no error and garbage output; verify the architecture config in conversion pipelines.

### 10. AI ENGINEERING CONNECTION

Training recipes for large LLMs assume Pre-LN stability; norm placement affects learning-rate choice, warm-up, and the position of loss spikes ([Tier 9 — Pre-training](../tier-09-foundation-model-pretraining/README.md)).

### 11. ADVANTAGES

Stable deep training; warm-up less critical; clean gradient path.

### 12. LIMITATIONS

Stream scale grows with depth; needs final norm; some reports of slightly lower final quality.

### 13. TRADE-OFFS

Training stability versus potential quality edge of Post-LN.

### 14. COMMON MISTAKES

Forgetting the final norm; mixing the two layouts in one model; assuming the same learning-rate schedule works for both.

### 15. PERFORMANCE / COST CONSIDERATIONS

No extra cost per se; stability reduces wasted training runs (a big cost saver).

### 16. SECURITY CONSIDERATIONS

Silent checkpoint mismatch; do not accept untrusted checkpoints without verifying config and weights format.

### 17. INTERVIEW EXPLANATION

*"Post-LN puts the norm after the residual add, so the skip path is normalised at every layer and deep stacks are hard to train without warm-up. Pre-LN puts the norm inside the branch, leaving a clean identity path for gradients, which is why almost all modern LLMs use it - at the price of a growing residual-stream scale and a required final norm."*

### 18. RAPID-FIRE ANSWER

Pre-LN: `x + F(Norm(x))`, norm the branch not the road.
