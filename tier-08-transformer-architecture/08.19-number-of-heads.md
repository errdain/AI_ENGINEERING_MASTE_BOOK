### 1. WHAT IS IT?

The **number of heads** `h` splits the hidden dimension into `h` subspaces of width `d_k = d/h`, each with its own attention pattern.

### 2. WHY DOES IT EXIST?

Different heads can attend to different relationships in parallel; a single head would average them.

### 3. DETAILED EXPLANATION

- **Changing `h` at fixed `d` does not change the parameter count** (QKV and O stay `4 d^2`).
- It changes how capacity is partitioned, the score-tensor shape `(B,h,T,T)` (memory ~ `h T^2`), and arithmetic intensity.
- Typical `d_k` is 64-128 (`REVIEW_REQUIRED`); too many heads leaves each too narrow.
- KV-sharing variants (MQA/GQA) reduce inference memory: Tier 12.6-12.7; the KV cache itself: Tier 11.

### 4. HOW DOES IT WORK?

1. Split `d` into `h` slices. 2. Run attention per slice. 3. Concatenate and project with `W_O`.

### 5. SIMPLE EXAMPLE

A panel of experts each reading the same document with a different question in mind.

### 6. TECHNICAL EXAMPLE

For `d=768`: `h=12 -> d_k=64`; `h=6 -> d_k=128`; `h=1 -> d_k=768`; parameters identical.

### 7. CODE

```python
from mini_gpt import GPTConfig, MiniGPT, count_params

counts = {h: count_params(MiniGPT(GPTConfig(vocab_size=41, block_size=32, n_layer=2, n_head=h, d_model=96)))
          for h in (1, 2, 4, 8, 16)}
print(counts)
assert len(set(counts.values())) == 1          # head count does not change parameters
try:
    GPTConfig(vocab_size=41, d_model=96, n_head=5)
except AssertionError as e:
    print("rejected:", e)
```

### 8. INPUT → PROCESS → OUTPUT

```
d -> h heads x d_k -> h attention maps (T,T) -> concat -> W_O -> d
```

### 9. ENTERPRISE USE CASE

Head count interacts with tensor-parallel sharding (heads are split across GPUs).

### 10. AI ENGINEERING CONNECTION

MQA/GQA change how many KV heads exist (Tier 12) to shrink the KV cache.

### 11. ADVANTAGES

Diverse patterns in parallel; parameter-free to change.

### 12. LIMITATIONS

Narrow heads limit per-head expressiveness; score memory grows with `h`.

### 13. TRADE-OFFS

Number of heads versus head width.

### 14. COMMON MISTAKES

Choosing `h` that does not divide `d`; assuming more heads = bigger model.

### 15. PERFORMANCE / COST CONSIDERATIONS

Score memory ~`h T^2` without flash kernels.

### 16. SECURITY CONSIDERATIONS

None specific.

### 17. INTERVIEW EXPLANATION

*"Heads split the model dimension into subspaces so attention can look for several relations at once. Changing the head count at fixed width does not change the parameter count; it changes head width and attention memory."*

### 18. RAPID-FIRE ANSWER

`h` heads of width `d/h`; parameters unchanged.
