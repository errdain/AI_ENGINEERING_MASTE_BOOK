Pre-LN vs Post-LN: activation and gradient scale vs depth

A small, real forward + backward pass through a random residual stack. Change depth, width and the sublayer gain; see how norm placement changes what the first layers receive.

What this is. A toy single-token residual stack: each layer is f(u)=W₂·GELU(W₁u) with random Gaussian weights of std g/√d. Pre-LN: x←x+f(LN(x)) (plus a final LN). Post-LN: x←LN(x+f(x)). We run forward and then a real manual backward pass and plot the RMS of the activation and of the gradient dL/dx at each layer input. No attention, no training: it isolates the norm placement effect at initialisation.

Read-out (try g = 0.5, 1, 2.5 with L = 48): Pre-LN activations grow with depth (the stream accumulates every layer's write), but the gradient reaching layer 0 stays about O(1) for any depth, because the identity path carries it. Post-LN renormalises the stream after every add, so activation scale is constant, but the gradient at layer 0 is multiplied by one LN Jacobian per sublayer and drifts geometrically: with a large gain it collapses (compare the “gradient RMS at layer 0” column as L grows). This is a toy at initialisation with one token and no attention; the real-model measurement of per-layer parameter-gradient norms is Figure 2 in the README.
