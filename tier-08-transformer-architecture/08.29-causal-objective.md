### 1. WHAT IS IT?

The **causal objective** (causal language modelling) trains the model to predict token `t+1` from tokens `<= t`, with a lower-triangular attention mask that prevents any position from reading the future.

### 2. WHY DOES IT EXIST?

It turns raw text into supervised data with no labels: each token is the label for the prefix before it, and one forward pass trains `T-1` predictions at once.

### 3. DETAILED EXPLANATION

| | Causal LM | Masked LM ([8.30 Masked objective](08.30-masked-objective.md)) |
|---|---|---|
| Task | predict token t+1 from tokens <= t | predict hidden tokens from both sides |
| Attention mask | lower-triangular | full |
| Supervised positions per sequence | all (T-1) | only masked (~15 %) |
| Gives | a generator | a representation |
| Pitfall | a mask bug leaks the future | `[MASK]` never appears at inference |

The causal guarantee is testable: `test_causal_mask_no_future_leak` changes only positions >= 6 and asserts logits at positions < 6 are unchanged for Pre-LN and Post-LN. If the mask leaks, training loss collapses toward 0 while the model learns nothing usable. Tier 9 owns objectives at scale (9.17-9.19).

### 4. HOW DOES IT WORK?

1. Inputs `x = tokens[:-1]`, targets `y = tokens[1:]`. 2. Forward with causal mask. 3. Cross-entropy over all positions. 4. Average.

### 5. SIMPLE EXAMPLE

Covering the next word of a sentence and guessing it, for every word.

### 6. TECHNICAL EXAMPLE

The lab's `get_batch` returns `(x, y)` with `y` shifted by one; training loss starts near `ln 41 = 3.71` and ends near 0.7 (train) / 0.41 (validation).

### 7. CODE

```python
import torch
from mini_gpt import GPTConfig, MiniGPT

torch.manual_seed(0)
m = MiniGPT(GPTConfig(vocab_size=23, block_size=16, n_layer=2, n_head=2, d_model=32)).eval()
tokens = torch.randint(0, 23, (1, 13))
x, y = tokens[:, :-1], tokens[:, 1:]                   # shift by one
logits, loss = m(x, y)
print(loss.item())                                      # about ln(23) = 3.14 at init
# leakage test: change only the future
x2 = x.clone(); x2[0, 8:] = torch.randint(0, 23, (4,))
assert torch.allclose(m(x)[0][:, :8], m(x2)[0][:, :8], atol=1e-5)
```

### 8. INPUT → PROCESS → OUTPUT

```
tokens -> x = t[:-1], y = t[1:] -> causal model -> logits (B,T,V) -> CE(logits, y)
```

### 9. ENTERPRISE USE CASE

Training data pipelines are built around shifting and packing sequences.

### 10. AI ENGINEERING CONNECTION

Used for LLM pre-training ([Tier 9 — Pre-training](../tier-09-foundation-model-pretraining/README.md)); the loss is perplexity's log.

### 11. ADVANTAGES

Dense supervision; no labels; simple.

### 12. LIMITATIONS

Unidirectional context; exposure bias between teacher forcing and sampling.

### 13. TRADE-OFFS

Dense signal versus no right context.

### 14. COMMON MISTAKES

Forgetting to shift; leaking the future through a mask bug; averaging loss over padding.

### 15. PERFORMANCE / COST CONSIDERATIONS

One pass trains `T-1` predictions.

### 16. SECURITY CONSIDERATIONS

A leaking mask invalidates evaluation and hides model failure.

### 17. INTERVIEW EXPLANATION

*"Causal language modelling predicts the next token from the prefix. With a lower-triangular mask one forward pass supervises every position, which is why decoder-only models train efficiently. The main risk is a mask bug that leaks the future and makes training loss deceptively low."*

### 18. RAPID-FIRE ANSWER

Predict the next token from the past; the mask makes it fair.
