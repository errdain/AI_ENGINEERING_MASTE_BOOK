### 1. WHAT IS IT?

**GELU** (Gaussian Error Linear Unit) is a smooth activation `GELU(x) = x * Phi(x)`, where `Phi` is the standard normal CDF (Hendrycks & Gimpel, 2016). It is the default FFN activation of BERT and GPT-2/3-era models.

### 2. WHY DOES IT EXIST?

ReLU has a hard zero-gradient region and a kink at 0. GELU weights each input by the probability that a unit Gaussian is below it, giving a smooth, slightly non-monotonic gate.

### 3. DETAILED EXPLANATION

- Exact form: `x * 0.5 * (1 + erf(x/sqrt(2)))`; common approximation: `0.5x(1 + tanh(sqrt(2/pi)(x + 0.044715 x^3)))`.
- Mixing exact and tanh-approximate GELU between training and inference causes small but real numerical drift.
- SiLU/Swish (`x*sigmoid(x)`) is similar and is the gate in SwiGLU ([8.16 SwiGLU](08.16-swiglu.md)).

### 4. HOW DOES IT WORK?

1. Compute `Phi(x)` (or the tanh approximation). 2. Multiply by `x`. 3. Use as the nonlinearity between `W_up` and `W_down`.

### 5. SIMPLE EXAMPLE

A dimmer switch rather than an on/off switch: large positive inputs pass, large negatives are suppressed, small values are softly scaled.

### 6. TECHNICAL EXAMPLE

`GELU(1) = 0.841`, `GELU(-1) = -0.159`, `GELU(0) = 0` (computed from the formula).

### 7. CODE

```python
import math, torch, torch.nn.functional as F

x = torch.linspace(-4, 4, 9)
exact = x * 0.5 * (1 + torch.erf(x / math.sqrt(2)))
tanh = 0.5 * x * (1 + torch.tanh(math.sqrt(2 / math.pi) * (x + 0.044715 * x ** 3)))
assert torch.allclose(exact, F.gelu(x), atol=1e-6)
assert torch.allclose(tanh, F.gelu(x, approximate="tanh"), atol=1e-6)
print((exact - tanh).abs().max().item())           # tiny but non-zero
print(F.gelu(torch.tensor([1.0, -1.0, 0.0])))      # 0.8413, -0.1587, 0
```

### 8. INPUT → PROCESS → OUTPUT

```
pre-activation u -> x * Phi(x) -> smooth gated output
```

### 9. ENTERPRISE USE CASE

Converting models between frameworks that default to different GELU variants silently changes outputs by small amounts.

### 10. AI ENGINEERING CONNECTION

Used in BERT and GPT-2; the baseline against which SwiGLU is measured.

### 11. ADVANTAGES

Smooth; no dead-gradient zone; works well in practice.

### 12. LIMITATIONS

More expensive than ReLU; two variants to keep consistent.

### 13. TRADE-OFFS

Quality and smoothness versus speed.

### 14. COMMON MISTAKES

Mixing exact and tanh GELU; confusing GELU with SiLU.

### 15. PERFORMANCE / COST CONSIDERATIONS

Slightly more expensive than ReLU but a minor part of FFN cost (the matmuls dominate).

### 16. SECURITY CONSIDERATIONS

Numerical-parity tests are cheap; do them when porting weights.

### 17. INTERVIEW EXPLANATION

*"GELU is a smooth ReLU-like activation that multiplies the input by the Gaussian CDF of the input. It is the standard FFN activation in BERT and GPT-2; modern LLMs often use the gated SwiGLU instead."*

### 18. RAPID-FIRE ANSWER

GELU: a soft, smooth ReLU, `x * Phi(x)`.
