### 1. WHAT IS IT?

**Parameter counting** is computing a model's number of learnable weights from its architecture hyper-parameters, on paper, and predicting where they live.

### 2. WHY DOES IT EXIST?

It tells you memory, compute, cost and whether a model fits on your hardware before you download it, and lets you sanity-check a model card.

### 3. DETAILED EXPLANATION

For a GPT-style model with learned positions, biases, LayerNorm, GELU, `d_ff = 4d`:

```
per block   = attention (4d^2 + 4d) + FFN (8d^2 + 5d) + 2 LayerNorms (4d) = 12d^2 + 13d
embeddings  = V*d (tokens) + T*d (positions)
total       = V*d + T*d + L*(12d^2 + 13d) + 2d (final LN)   [+ V*d if the head is untied]
```

The general version (any `d_ff`, SwiGLU, RMSNorm, no biases, Pre/Post-LN) is `count_params_formula` in the lab; the tests build all 32 combinations of {norm, Pre/Post, act, tied, bias} and assert it equals `sum(p.numel())` of the real model.

**Worked checks (TESTED by the calculator and the lab).** GPT-2-small-shaped config `V=50257, T=1024, d=768, L=12`, tied: **124,439,808** (the widely quoted "124 M"; published figure `REVIEW_REQUIRED`). The Mini-GPT of this lab (`V=41, T=64, d=96, L=3`): **345,792**.

| Quantity | Rule of thumb | Note |
|---|---|---|
| Weights in memory | `2N` bytes (fp16/bf16), `N` bytes (int8) | activations and KV cache extra |
| Training state, Adam, mixed precision | about `16N` bytes before activations | `REVIEW_REQUIRED`: depends on optimiser/sharding |
| Forward FLOPs per token | about `2N` plus attention term | |
| Training FLOPs per token | about `6N` | scaling-law convention ([Tier 9 — Pre-training](../tier-09-foundation-model-pretraining/README.md)) |

### 4. HOW DOES IT WORK?

1. Count each weight matrix and bias: QKV `3d^2+3d`, `W_O` `d^2+d`, FFN `2*d*d_ff + d_ff + d`. 2. Add norms (`2d` or `d`). 3. Multiply by `L`. 4. Add embeddings, final norm, untied head.

### 5. SIMPLE EXAMPLE

Counting the bricks in a building from the floor plan: rooms per floor times floors plus the lobby.

### 6. TECHNICAL EXAMPLE

Mini-GPT: block `= 12*96^2 + 13*96 = 111,840`; times 3 = 335,520; plus `41*96 + 64*96 = 10,080`; plus final LN `192` = **345,792**.

### 7. CODE

```python
from mini_gpt import GPTConfig, MiniGPT, count_params, count_params_formula

cfg = GPTConfig(vocab_size=50257, block_size=1024, n_layer=12, n_head=12, d_model=768)
print(f"{count_params_formula(cfg):,}")                      # 124,439,808
assert count_params_formula(cfg) == 124_439_808

small = GPTConfig(vocab_size=41, block_size=64, n_layer=3, n_head=4, d_model=96)
assert count_params(MiniGPT(small)) == count_params_formula(small) == 345_792
```

### 8. INPUT → PROCESS → OUTPUT

```
hyper-parameters (V,T,d,L,d_ff,h) -> formula -> N parameters -> bytes (2N) , FLOPs (2N fwd, 6N train)
```

### 9. ENTERPRISE USE CASE

Capacity planning, GPU sizing, cost estimates and licence/MoE comparisons start from this number.

### 10. AI ENGINEERING CONNECTION

Scaling laws ([Tier 9 — Pre-training](../tier-09-foundation-model-pretraining/README.md)) are stated in `N`; serving memory ([Tier 11 — Inference](../tier-11-llm-inference-optimization/README.md)) in `2N` bytes.

### 11. ADVANTAGES

Fast, exact, catches model-card inconsistencies.

### 12. LIMITATIONS

Ignores activations, KV cache and optimiser state; MoE total vs active parameters differ ([Tier 12 — Modern architectures](../tier-12-modern-architectures/)).

### 13. TRADE-OFFS

Parameters versus the other budgets (data, FLOPs, memory).

### 14. COMMON MISTAKES

Counting embeddings twice (or not at all); forgetting position embeddings; comparing MoE total to dense.

### 15. PERFORMANCE / COST CONSIDERATIONS

`2N` bytes fp16 weights; `~6N` training FLOPs per token; `~16N` bytes training state.

### 16. SECURITY CONSIDERATIONS

Pickle checkpoints execute code when loaded: use `weights_only=True` or `safetensors` for untrusted weights.

### 17. INTERVIEW EXPLANATION

*"Per block it's about 12 d-squared - 4d-squared for attention, 8d-squared for a 4x-wide FFN - times L layers, plus V times d for the embedding table, plus T times d if positions are learned; tying the head removes another V times d. I use 2N bytes for fp16 weights and about 6N FLOPs per token to train."*

### 18. RAPID-FIRE ANSWER

`N ~ 12 L d^2 + V d` (plus positions); fp16 memory `2N` bytes.

### 19. INTERVIEW QUESTIONS

**Basic.** Where are most parameters? **Intermediate.** Derive 12 L d^2. **Advanced.** What do you ignore? **Scenario.** A '7 B' model does not fit your GPU: arithmetic?
