### 1. WHAT IS IT?

A **cross-attention layer** has the same computation as self-attention, but **queries come from one sequence (the decoder stream) and keys/values from another (the encoder output)**. It is the only channel from encoder to decoder in an encoder-decoder model.

### 2. WHY DOES IT EXIST?

A decoder generating a translation or a summary must condition on the source. Self-attention only sees the target prefix; cross-attention lets each target position retrieve source information.

### 3. DETAILED EXPLANATION

- Scores are `(B,h,T_tgt,S_src)`: a **rectangle**, with no causal mask (only padding over the source).
- Parameters: another `Q,K,V,O` set, `4d^2` per decoder layer. The K/V projections are applied to the encoder output once and can be cached across decode steps.
- Decoder-only models have no cross-attention: they condition by putting the context in the prompt, where it is read by ordinary self-attention.

### 4. HOW DOES IT WORK?

1. `Q = W_Q * decoder_stream`; `K = W_K * memory`; `V = W_V * memory`.
2. `scores = Q K^T / sqrt(d_k)` with shape `(B,h,T,S)`; mask padding of the source.
3. `softmax` over the source axis; weight `V`; concatenate heads; `W_O`.
4. Add to the decoder stream (residual).

### 5. SIMPLE EXAMPLE

A translator writing French: at each word they look back at the English sentence to see which source words matter now.

### 6. TECHNICAL EXAMPLE

In machine translation, cross-attention weights often show a soft alignment between target and source words (an interpretation, not a guarantee).

### 7. CODE

```python
import math, torch, torch.nn as nn

class CrossAttention(nn.Module):
    def __init__(self, d, h):
        super().__init__()
        self.h, self.dk = h, d // h
        self.q, self.kv, self.o = nn.Linear(d, d), nn.Linear(d, 2 * d), nn.Linear(d, d)

    def forward(self, x, memory, pad=None):             # x: (B,T,d)  memory: (B,S,d)
        B, T, D = x.shape; S = memory.size(1)
        q = self.q(x).view(B, T, self.h, self.dk).transpose(1, 2)
        k, v = self.kv(memory).split(D, dim=2)
        k, v = (t.view(B, S, self.h, self.dk).transpose(1, 2) for t in (k, v))
        att = q @ k.transpose(-2, -1) / math.sqrt(self.dk)          # (B,h,T,S)
        if pad is not None:                                        # pad: (B,S) True = padding
            att = att.masked_fill(pad[:, None, None, :], float("-inf"))
        w = att.softmax(-1)
        return self.o((w @ v).transpose(1, 2).reshape(B, T, D)), w

ca = CrossAttention(32, 4)
out, w = ca(torch.randn(2, 5, 32), torch.randn(2, 9, 32))
print(out.shape, w.shape)                 # (2,5,32)  (2,4,5,9): a rectangle
assert sum(p.numel() for p in ca.parameters()) == 4 * 32 * 32 + 4 * 32
```

### 8. INPUT → PROCESS → OUTPUT

```
decoder stream (B,T,d) --Q--+
                             +--> scores (B,h,T,S) -> softmax -> @V -> (B,T,d)
encoder memory (B,S,d) --K,V-+
```

### 9. ENTERPRISE USE CASE

Document summarisation or translation service: encode the source once, decode many tokens, each attending to the cached encoder K/V.

### 10. AI ENGINEERING CONNECTION

Conceptually the template for any "query a memory" mechanism, including RAG and multimodal fusion in later tiers; in decoder-only LLMs the same effect is achieved by self-attention over prompt tokens.

### 11. ADVANTAGES

Explicit, direct conditioning on a second sequence; source processed once.

### 12. LIMITATIONS

Adds `4d^2` parameters per decoder layer; cost per step grows with source length `S`.

### 13. TRADE-OFFS

Explicit conditioning channel versus the simplicity of one stack.

### 14. COMMON MISTAKES

Applying a causal mask over the source; taking K/V from the decoder stream by mistake; forgetting the source padding mask.

### 15. PERFORMANCE / COST CONSIDERATIONS

Cache the projected K/V of the encoder output; per-step cost `O(S d)` per layer.

### 16. SECURITY CONSIDERATIONS

Source content steers every output token; inputs from untrusted documents can carry injected instructions (see later tiers on prompt injection).

### 17. INTERVIEW EXPLANATION

*"Cross-attention is attention where the queries come from the decoder and the keys and values from the encoder output. It is how an encoder-decoder model reads its input while generating. The score matrix is target-by-source and not causal."*

### 18. RAPID-FIRE ANSWER

Attention whose queries come from the decoder and whose keys and values come from the encoder.
