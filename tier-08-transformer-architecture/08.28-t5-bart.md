### 1. WHAT IS IT?

**T5** (Raffel et al., 2019) and **BART** (Lewis et al., 2019) are encoder-decoder models pre-trained by corrupting text and reconstructing it. T5 frames every task as text-to-text and uses **span corruption**; BART is a denoising autoencoder.

### 2. WHY DOES IT EXIST?

Encoder-decoder pre-training needs an objective that has an input and an output; corrupting spans gives both. Text-to-text framing unifies tasks (translation, summarisation, classification as text).

### 3. DETAILED EXPLANATION

- **T5** (`REVIEW_REQUIRED` details): masked spans replaced by sentinel tokens (`<extra_id_0>`...) in the input; the decoder outputs each sentinel followed by the missing span; ~15 % corruption, mean span length 3; uses relative position biases and a simplified RMS-style layer norm without bias; original FFN ReLU.
- **BART** (`REVIEW_REQUIRED`): corruption includes token masking, deletion, text infilling and sentence permutation; reconstruct the original with a causal decoder; GELU; base 6+6 layers, large 12+12.
- Fit: translation, summarisation, structured rewriting.

### 4. HOW DOES IT WORK?

1. Choose spans to corrupt. 2. Input: text with sentinels. 3. Target: sentinels with their spans. 4. Train with teacher forcing and cross-entropy.

### 5. SIMPLE EXAMPLE

Torn-up sentences: the encoder reads the torn page; the decoder writes the missing pieces.

### 6. TECHNICAL EXAMPLE

"Thank you for inviting me to your party last week" -> input "Thank you <X> me to your party <Y> week", target "<X> for inviting <Y> last".

### 7. CODE

```python
import random

def t5_span_corrupt(tokens, noise=0.15, mean_span=3, seed=0):
    """Replace random spans with sentinels. Returns (input_tokens, target_tokens)."""
    rng = random.Random(seed); n = len(tokens)
    n_noise = max(1, round(n * noise)); n_spans = max(1, round(n_noise / mean_span))
    starts = sorted(rng.sample(range(0, n - mean_span), n_spans))
    inp, tgt, i, s = [], [], 0, 0
    while i < n:
        if s < len(starts) and i >= starts[s]:
            inp.append(f"<X{s}>"); tgt.append(f"<X{s}>"); tgt.extend(tokens[i:i + mean_span]); i += mean_span; s += 1
            while s < len(starts) and starts[s] < i: s += 1
        else:
            inp.append(tokens[i]); i += 1
    return inp, tgt

words = "thank you for inviting me to your party last week and see you soon".split()
a, b = t5_span_corrupt(words)
print(a); print(b)
assert any(w.startswith("<X") for w in a) and len(a) < len(words) + 4
```

### 8. INPUT → PROCESS → OUTPUT

```
text -> corrupt spans -> encoder(sentinel text) -> decoder -> sentinels + missing spans
```

### 9. ENTERPRISE USE CASE

Summarisation and rewriting pipelines built on fine-tuned T5/BART-family checkpoints.

### 10. AI ENGINEERING CONNECTION

Early instruction-tuning work used text-to-text models; relevance to Tier 9/10.

### 11. ADVANTAGES

Unified text-to-text interface; strong for transformation tasks.

### 12. LIMITATIONS

Two stacks; less used for chat; objective-specific details vary.

### 13. TRADE-OFFS

Task fit versus ecosystem.

### 14. COMMON MISTAKES

Mixing sentinel vocabularies between tokenizers; ignoring that BART and T5 use different corruptions.

### 15. PERFORMANCE / COST CONSIDERATIONS

Encoder once, decoder per output token.

### 16. SECURITY CONSIDERATIONS

Corrupted-input pre-training does not make models robust to adversarial inputs.

### 17. INTERVIEW EXPLANATION

*"T5 and BART are encoder-decoder models pre-trained by corrupting text and reconstructing it. T5 replaces spans with sentinels and the decoder outputs the missing spans, framing every task as text-to-text; BART denoises with several corruption types. They suit translation and summarisation."*

### 18. RAPID-FIRE ANSWER

T5/BART: corrupt text in, reconstruct text out.
