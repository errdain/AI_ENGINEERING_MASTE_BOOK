### 1. WHAT IS IT?

A **Transformer decoder** is a stack of blocks that generate a sequence left to right. Each layer has **causal** (masked) self-attention, and in the original encoder-decoder design also **cross-attention** to the encoder output, followed by an FFN. Without cross-attention it becomes the decoder-only LLM block ([8.25 Decoder-only architecture](08.25-decoder-only-architecture.md)).

### 2. WHY DOES IT EXIST?

Generation needs a model whose prediction at position `i` can only depend on tokens before `i`, so that the same network works in training (all positions in parallel) and at inference (one new token at a time).

### 3. DETAILED EXPLANATION

**Causal self-attention.** A lower-triangular mask sets scores `j > i` to `-inf` before softmax, so position `i` reads only positions `<= i`. This single property makes one forward pass train `T` next-token predictions at once ([8.29 Causal objective](08.29-causal-objective.md)).

**Cross-attention (encoder-decoder only).** Queries come from the decoder stream, keys/values from the encoder output ([8.7 Cross-attention layer](08.07-cross-attention-layer.md)). The 2017 decoder layer therefore has three sub-layers; a decoder-only layer has two.

**Shifted input.** The decoder input is the target sequence shifted right by one (start token first), so the output at position `i` is trained to equal the token at `i+1`.

### 4. HOW DOES IT WORK?

1. Embed shifted-right target tokens + positions.
2. Masked self-attention (`+` residual) lets each position summarise earlier ones.
3. Cross-attention (`+` residual) pulls information from the encoder memory (skipped in decoder-only models).
4. FFN (`+` residual). Repeat `L` times; final norm and a linear head produce logits `(B,T,V)`.
5. Inference: append the sampled token and repeat; the KV cache avoids recomputing past keys/values ([Tier 11 — Inference](../tier-11-llm-inference-optimization/README.md)).

### 5. SIMPLE EXAMPLE

Writing a sentence one word at a time: you may reread what you have written so far and (if translating) the source text, but you may not peek at words you have not written yet.

### 6. TECHNICAL EXAMPLE

Translation decoding: at step 4 the decoder has produced three French words, self-attends over them, cross-attends over the English sentence, and predicts the fourth word. The decoder-only equivalent is GPT-style text continuation.

### 7. CODE

```python
import torch, torch.nn as nn

d, h = 64, 4
dec_layer = nn.TransformerDecoderLayer(d_model=d, nhead=h, dim_feedforward=256, dropout=0.0,
                                       batch_first=True, norm_first=True)
dec = nn.TransformerDecoder(dec_layer, num_layers=2).eval()
memory = torch.randn(2, 7, d)                      # encoder output, S = 7 source tokens
tgt = torch.randn(2, 5, d)                         # T = 5 target positions
causal = nn.Transformer.generate_square_subsequent_mask(5)    # -inf above the diagonal
y = dec(tgt, memory, tgt_mask=causal)
print(y.shape)                                     # (2, 5, 64)

# Causality: changing the last target position must not change earlier outputs
tgt2 = tgt.clone(); tgt2[:, 4] += 1.0
assert torch.allclose(dec(tgt2, memory, tgt_mask=causal)[:, :4], y[:, :4], atol=1e-5)
```

From-scratch decoder-only version (no cross-attention): `Block` + `CausalSelfAttention` in [`lab/mini_gpt.py`](lab/mini_gpt.py); its leak test is `test_causal_mask_no_future_leak` in [`lab/test_tier08.py`](lab/test_tier08.py).

### 8. INPUT → PROCESS → OUTPUT

```
shifted target (B,T) -> embed+pos -> [masked self-attn -> (cross-attn to memory) -> FFN] x L -> logits (B,T,V) -> loss vs target
```

### 9. ENTERPRISE USE CASE

Chat assistants, code completion and summarisation backends are decoders. The serving stack (batching, KV cache, sampling) is built around the decoder loop.

### 10. AI ENGINEERING CONNECTION

Decoder-only LLMs are the dominant foundation-model architecture ([8.25 Decoder-only architecture](08.25-decoder-only-architecture.md), [8.26 GPT](08.26-gpt.md)). Agents and RAG systems are built on top of decoding. See [Tier 11 — Inference](../tier-11-llm-inference-optimization/README.md) for the autoregressive loop.

### 11. ADVANTAGES

Parallel training over all positions; one objective gives a signal at every token; generation is natural; scales cleanly.

### 12. LIMITATIONS

Inference is sequential (one token per forward pass); attention to the past grows with context; a mask bug silently destroys validity.

### 13. TRADE-OFFS

Generative flexibility versus per-token latency. Adding cross-attention conditions on an encoder but doubles the stack to serve.

### 14. COMMON MISTAKES

Forgetting to shift the target; applying the causal mask in the wrong dimension; mixing the padding and causal masks; leaking the label through an unmasked path.

### 15. PERFORMANCE / COST CONSIDERATIONS

Per token: `~2N` FLOPs plus attention over the cached prefix. Memory for the KV cache grows with context length and batch size ([Tier 11 — Inference](../tier-11-llm-inference-optimization/README.md)).

### 16. SECURITY CONSIDERATIONS

A leaking causal mask gives suspiciously low training loss and a useless model - an invalid-evaluation and data-leak failure. Test it numerically (see `test_causal_mask_no_future_leak`). Generated text from untrusted prompts is also an injection surface (later tiers).

### 17. INTERVIEW EXPLANATION

*"The decoder generates left to right. Its self-attention is causal so position i only sees earlier tokens, which lets training use every position as a prediction target in one pass. In the original design each decoder layer also cross-attends to the encoder output; modern LLMs drop that and keep only masked self-attention plus the FFN."*

### 18. RAPID-FIRE ANSWER

A stack of blocks with causal self-attention (and optionally cross-attention) that predicts the next token.
