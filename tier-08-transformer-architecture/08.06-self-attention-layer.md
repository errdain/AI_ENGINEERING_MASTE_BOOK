### 1. WHAT IS IT?

The **self-attention layer** is the sub-layer in which queries, keys and values all come from the *same* sequence. Inside a block it is: fused QKV projection, split into heads, scaled dot-product scores with a mask, softmax, weighted sum of values, concatenate heads, output projection. (The mathematics is owned by [Tier 7 — Attention](../tier-07-attention/README.md); here it is a layer in the block.)

### 2. WHY DOES IT EXIST?

It is the only operation that lets position `i` read information from position `j`. Without it tokens would be processed independently.

### 3. DETAILED EXPLANATION

- **Mask choice** decides the model family: full (encoder), causal (decoder). See [8.2 Transformer encoder](08.02-transformer-encoder.md) / [8.3 Transformer decoder](08.03-transformer-decoder.md).
- **Fused QKV.** One `d -> 3d` matmul followed by a split is faster than three matmuls and has identical parameters (`3d^2 + 3d`, plus `d^2 + d` for the output projection `W_O`).
- **Cost.** `O(T^2 d)` FLOPs and `O(h T^2)` score memory per layer.

{fig('09_attention_maps_trained.png', 'Figure 9 - Learned attention weights of the trained Mini-GPT (3 layers x 4 heads). Look at: every map is lower-triangular (causal mask) and heads differ in how far back they look; interpreting single heads needs more evidence than one sentence.')}

### 4. HOW DOES IT WORK?

1. `qkv = Linear(d, 3d)(x)`, split into `q, k, v`, reshape to `(B,h,T,d_k)`.
2. `scores = q k^T / sqrt(d_k)` -> `(B,h,T,T)`.
3. Apply the mask (`-inf` where not allowed), `softmax` over the last axis.
4. `y = scores @ v`, concatenate heads to `(B,T,d)`, apply `W_O`.

### 5. SIMPLE EXAMPLE

In a meeting each person (token) asks a question (query), everyone holds up a label (key) and a note (value); you read mostly the notes whose label matches your question.

### 6. TECHNICAL EXAMPLE

In the trained Mini-GPT, layer 1 tends to attend near the diagonal (recent characters) while deeper layers spread over more of the past (see Figure 9); this is an observation on one sentence, not a general law.

### 7. CODE

```python
import math, torch, torch.nn.functional as F
from mini_gpt import GPTConfig, CausalSelfAttention

cfg = GPTConfig(vocab_size=41, block_size=16, n_layer=1, n_head=4, d_model=32, bias=True)
att = CausalSelfAttention(cfg).eval()
x = torch.randn(2, 8, 32)
y = att(x)

# reference with PyTorch's fused kernel using the SAME weights
B, T, D = x.shape
q, k, v = att.qkv(x).split(D, dim=2)
q, k, v = (t.view(B, T, 4, D // 4).transpose(1, 2) for t in (q, k, v))
ref = F.scaled_dot_product_attention(q, k, v, is_causal=True).transpose(1, 2).reshape(B, T, D)
ref = att.proj(ref)
assert torch.allclose(y, ref, atol=1e-5)
print("hand-written attention == F.scaled_dot_product_attention")
```

Code: `CausalSelfAttention` in [`lab/mini_gpt.py`](lab/mini_gpt.py).

### 8. INPUT → PROCESS → OUTPUT

```
x (B,T,d) -> qkv (B,T,3d) -> heads (B,h,T,d_k) -> scores (B,h,T,T) -> mask+softmax -> @V -> concat -> W_O -> (B,T,d)
```

### 9. ENTERPRISE USE CASE

The layer an inference team optimises hardest (FlashAttention, KV cache, paged memory); long-context pricing is driven by it.

### 10. AI ENGINEERING CONNECTION

[Tier 7 — Attention](../tier-07-attention/README.md) owns the math; here the point is where it sits. RAG context becomes keys/values this layer reads; cache and long-context engineering ([Tier 11 — Inference](../tier-11-llm-inference-optimization/README.md)) target it.

### 11. ADVANTAGES

Direct pairwise interaction between any two tokens; parallel; interpretable weights (with care).

### 12. LIMITATIONS

Quadratic in sequence length; weights are not explanations; heads can be redundant.

### 13. TRADE-OFFS

Mask type and head count trade expressiveness against compute and memory.

### 14. COMMON MISTAKES

Using `sqrt(d)` rather than `sqrt(d_k)`; masking after softmax instead of before; wrong reshape/transposes silently mixing heads.

### 15. PERFORMANCE / COST CONSIDERATIONS

`O(T^2)` memory for scores unless a fused/flash kernel is used; score memory scales with `h*T^2`.

### 16. SECURITY CONSIDERATIONS

A wrong mask leaks future or padding tokens; very long untrusted contexts are a denial-of-service and injection surface.

### 17. INTERVIEW EXPLANATION

*"Self-attention lets every token weigh every other token. Each token is projected into a query, key and value; the query-key dot products, scaled and masked, go through softmax and weight the values. In a block it is the only place information crosses positions. I use a causal mask for decoders and none for encoders."*

### 18. RAPID-FIRE ANSWER

The sub-layer where tokens read from each other through Q, K, V and a mask.

### 19. INTERVIEW QUESTIONS

**Basic.** Where do Q, K, V come from? **Intermediate.** Why fuse the three projections? **Advanced.** Why divide by `sqrt(d_k)`? **Scenario.** Outputs for position 3 change when you edit position 9 in a decoder: what is wrong?
