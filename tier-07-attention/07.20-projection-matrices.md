### 1. WHAT IS IT?

The projection matrices of an attention layer: `W_q, W_k, W_v` (in) and the **output projection** `W_o` (out) that mixes information across heads.

### 2. WHY DOES IT EXIST?

Input projections create Q/K/V per head ([7.5 Q/K/V projections](07.05-q-k-v-projections.md)); `W_o` lets the concatenated heads exchange information before the result is added back to the residual stream (Tier 8).

### 3. DETAILED EXPLANATION

`W_q, W_k, W_v ∈ ℝ^{d_model × (H·d_h)}` (fused or separate) and `W_o ∈ ℝ^{(H·d_h) × d_model}`. Parameters per MHA layer: `4·d_model²` (bias-free, `H·d_h = d_model`). Under GQA/MQA `W_k, W_v` shrink to `d_model × (H_kv·d_h)` ([7.21 MQA](07.21-mqa.md), [7.22 GQA](07.22-gqa.md)). For `d_model = 4096`: MHA = 4·4096² ≈ 67.1 M parameters; with `H = 32`, `H_kv = 8`, `d_h = 128`: `2·4096² + 2·4096·1024` = 41.9 M.

| Matrix | Shape | MHA params (d=4096) | GQA H_kv=8 |
|---|---|---|---|
| W_q | d × H·d_h | 16.8 M | 16.8 M |
| W_k | d × H_kv·d_h | 16.8 M | 4.2 M |
| W_v | d × H_kv·d_h | 16.8 M | 4.2 M |
| W_o | H·d_h × d | 16.8 M | 16.8 M |

Interactive: [multi-head / GQA explorer](interactive/multihead_gqa.html). Test: `test_mqa_gqa_parameter_and_cache_savings`.

### 4. HOW DOES IT WORK?

1. Project inputs with `W_q, W_k, W_v`.
2. Per-head attention.
3. Concatenate heads (`H·d_h`).
4. `out = concat @ W_o`.

### 8. INPUT → PROCESS → OUTPUT

```
heads (B,H,T,d_h) ─► merge (B,T,H·d_h) ─► ·W_o ─► (B,T,d_model)
```

### 9. ENTERPRISE USE CASE

LoRA-style fine-tuning commonly targets these matrices (Tier 10; `REVIEW_REQUIRED` for recipes).

### 10. AI ENGINEERING CONNECTION

Attention parameters are roughly one third of a dense Transformer block's parameters when the FFN is 4×d (ratio depends on architecture; Tier 8).

### 11. ADVANTAGES

Clean separation: per-head matching, cross-head mixing.

### 12. LIMITATIONS

`W_o` is a bottleneck mixing step; the matrices dominate attention parameters.

### 13. TRADE-OFFS

Fused QKV (fast) versus separate (flexible for GQA).

### 14. COMMON MISTAKES

Forgetting `W_o`; wrong shapes under GQA; transposed weight conventions.

### 15. PERFORMANCE / COST CONSIDERATIONS

Projection FLOPs are linear in n; parameters bytes matter for loading.

### 16. SECURITY CONSIDERATIONS

Model weights are sensitive IP; nothing attention-specific.
