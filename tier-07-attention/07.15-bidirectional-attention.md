### 1. WHAT IS IT?

Bidirectional attention: no causal mask (except padding), so every token can see every other token.

### 2. WHY DOES IT EXIST?

Understanding tasks (classification, tagging, embeddings) benefit from using both left and right context for each token.

### 3. DETAILED EXPLANATION

Used in BERT-style encoders, the encoder half of T5, vision transformers and embedding models. It cannot generate left-to-right directly because positions see the future.

| | Causal | Bidirectional |
|---|---|---|
| Mask | lower-triangular | none (except padding) |
| Pairs computed | ≈ n²/2 | n² |
| Typical models | GPT/Llama-style LLMs | BERT-style encoders, embedding models |
| Generation | natural | not natively |

Compare the masks in the figure in [7.16 Attention masks](07.16-attention-masks.md) and the "causal" switch in [the mask explorer](interactive/mask_explorer.html).

### 4. HOW DOES IT WORK?

1. Use only the padding mask.
2. Every query attends to every real key.

### 5. SIMPLE EXAMPLE

Proof-reading a whole sentence with the full page visible.

### 6. TECHNICAL EXAMPLE

Retrieval encoders (Tier 20) use bidirectional attention to build one embedding per passage.

### 7. CODE

```python
import numpy as np
from attention_np import scaled_dot_product_attention, causal_mask
rng = np.random.default_rng(0)
q, k, v = (rng.normal(size=(4, 8)) for _ in range(3))
_, w_bi = scaled_dot_product_attention(q, k, v)                 # no mask
_, w_ca = scaled_dot_product_attention(q, k, v, causal_mask(4))
print((w_bi > 0).sum(), (w_ca > 1e-12).sum())                  # 16 vs 10 non-zero weights
```

### 8. INPUT → PROCESS → OUTPUT

```
X ─► full T×T attention (padding mask only) ─► context-rich token states
```

### 9. ENTERPRISE USE CASE

Semantic search, classification and reranking pipelines.

### 10. AI ENGINEERING CONNECTION

Embedding/retrieval encoders for RAG (Tier 20).

### 11. ADVANTAGES

Full context per token.

### 12. LIMITATIONS

Not natively generative; n² pairs.

### 13. TRADE-OFFS

Richer per-token context versus cheap training signal and caching ([7.14 Causal attention](07.14-causal-attention.md)).

### 14. COMMON MISTAKES

Using a bidirectional encoder for left-to-right generation; leaking labels via future tokens when fine-tuning generatively.

### 15. PERFORMANCE / COST CONSIDERATIONS

n² pairs (about 2× causal).

### 16. SECURITY CONSIDERATIONS

None specific beyond padding masks ([7.17 Padding masks](07.17-padding-masks.md)).

### 17. INTERVIEW EXPLANATION

*"Bidirectional attention has no causal mask, so encoders get full context for each token but cannot generate autoregressively."*

### 18. RAPID-FIRE ANSWER

No causal mask: everyone sees everyone.
