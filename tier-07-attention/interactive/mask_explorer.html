Mask explorer: causal, padding, window, sinks

Combine masks and see exactly which query/key pairs survive. Set S different from T to see cross-attention shapes (T x S need not be square).

Green = the (query i, key j) score is computed and kept. White/grey = set to -inf before softmax, so its weight is exactly 0.
Rows can end up with zero allowed keys (e.g. a padded query row or window that excludes everything) — in naive code softmax gives NaN; real kernels special-case this.
