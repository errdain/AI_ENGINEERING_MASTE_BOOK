### 1. WHAT IS IT?

Causal attention restricts each position *i* to keys *j ≤ i* by setting masked scores to −∞ before softmax.

### 2. WHY DOES IT EXIST?

For next-token prediction the model must not see the answer. Masking the future lets one forward pass train all T next-token predictions in parallel (teacher forcing) while keeping inference consistent with training.

### 3. DETAILED EXPLANATION

Mask `M_ij = −∞` for `j > i` so those weights are exactly 0 (`exp(−∞) = 0`). Decoder-only LLMs are causal. Roughly half the pairs (≈ n²/2) are needed. Causality also means earlier tokens' K and V never change as new tokens arrive, which is what makes the KV cache valid ([7.24 Attention memory requirements](07.24-attention-memory-requirements.md); Tier 11).

![Decoding GIF](figures/10_decode_kv_cache.gif)

*Animation — autoregressive decoding. Each step adds one new query row (red); keys/values of earlier tokens are reused from the cache (green).*

See the causal panel of the mask figure in [7.16 Attention masks](07.16-attention-masks.md) and toggle "causal" in [the mask explorer](interactive/mask_explorer.html).

### 4. HOW DOES IT WORK?

1. Build `mask = tril(ones(T,T))` (True = allowed).
2. Apply before softmax.
3. Train on all positions at once; at inference generate one token at a time using the cache.

### 5. SIMPLE EXAMPLE

Reading a book with your hand covering everything after the current word.

### 6. TECHNICAL EXAMPLE

`test_causal_matches_torch_and_no_future_leak` perturbs the **last** token's value and checks earlier outputs are unchanged.

### 7. CODE

```python
import numpy as np
from attention_np import causal_mask, scaled_dot_product_attention
T = 5
rng = np.random.default_rng(0)
q, k, v = (rng.normal(size=(T, 4)) for _ in range(3))
out, w = scaled_dot_product_attention(q, k, v, causal_mask(T))
print(np.triu(w, 1).max())            # 0.0  -> no weight on the future
v2 = v.copy(); v2[-1] += 10            # change the last token
out2, _ = scaled_dot_product_attention(q, k, v2, causal_mask(T))
print(np.allclose(out[:-1], out2[:-1]))   # True: earlier outputs unaffected
```
Source: `causal_mask` in [`lab/attention_np.py`](lab/attention_np.py).

### 8. INPUT → PROCESS → OUTPUT

```
scores (T×T) ─► upper triangle := −∞ ─► softmax ─► lower-triangular weights ─► ·V
```

### 9. ENTERPRISE USE CASE

All chat/completion LLM serving relies on it (KV caching, streaming).

### 10. AI ENGINEERING CONNECTION

Foundation of GPT/Llama-style LLMs (Tier 11 covers serving).

### 11. ADVANTAGES

Parallel training on all positions; cacheable inference; no leakage.

### 12. LIMITATIONS

Tokens cannot use right context; weaker for pure understanding tasks than bidirectional.

### 13. TRADE-OFFS

Causal gives cheap training signal and caching; bidirectional gives richer context ([7.15 Bidirectional attention](07.15-bidirectional-attention.md)).

### 14. COMMON MISTAKES

Missing causal mask in training (model cheats and fails at generation); off-by-one (diagonal must be allowed); mask applied after softmax.

### 15. PERFORMANCE / COST CONSIDERATIONS

≈ n²/2 pairs; one new query row per decode step.

### 16. SECURITY CONSIDERATIONS

A missing causal mask silently produces a model that "cheats"; test for future leakage.

### 17. INTERVIEW EXPLANATION

*"Causal attention masks the upper triangle with −∞ before softmax so each token only sees the past; that makes next-token training parallel and inference cacheable."*

### 18. RAPID-FIRE ANSWER

Mask j>i with −∞ so no token sees the future.
