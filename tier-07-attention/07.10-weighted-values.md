### 1. WHAT IS IT?

Weighted values: the output is `out_i = Σ_j w_ij v_j`, i.e. `Out = W V`.

### 2. WHY DOES IT EXIST?

This is the step that actually moves information: after weights decide *how much* of each token to read, this step *reads* it.

### 3. DETAILED EXPLANATION

Each output row is a convex combination of value rows, so it lies in their convex hull. Sparse weights mean "copy that token's value"; flat weights mean "average the context". Shape: `(T×S)·(S×d_v) = T×d_v`; output length equals the **query** length, even in cross-attention ([7.13 Cross-attention](07.13-cross-attention.md)). The output is later mixed by `W_o` ([7.20 Projection matrices](07.20-projection-matrices.md)).

![Pipeline panel 4](figures/01_attention_pipeline.png)

*Figure — panel 4 shows `W V`.*

### 4. HOW DOES IT WORK?

1. Take row `i` of the weight matrix.
2. Multiply by `V` (S×d_v).
3. Result: one d_v vector for token *i*.

### 5. SIMPLE EXAMPLE

Mixing paint: 70% of one colour, 20% of another, 10% of a third.

### 6. TECHNICAL EXAMPLE

With a one-hot weight row on position 3, output equals `V[3]` exactly (copy behaviour).

### 7. CODE

```python
import numpy as np
rng = np.random.default_rng(0)
V = rng.normal(size=(5, 3))
w = np.array([[0, 0, 1., 0, 0], [.2, .2, .2, .2, .2]])
print(w @ V)                 # row 0 = V[2]; row 1 = mean of V
```

### 8. INPUT → PROCESS → OUTPUT

```
weights (T×S) ─► @ V (S×d_v) ─► output (T×d_v)
```

### 9. ENTERPRISE USE CASE

Second GEMM of attention; together with QKᵀ it makes ≈ 4·B·H·n²·d_h FLOPs per layer ([7.23 Attention complexity](07.23-attention-complexity.md)).

### 10. AI ENGINEERING CONNECTION

Together with `W_o` this writes into the residual stream (Tier 8).

### 11. ADVANTAGES

Simple, parallel, differentiable.

### 12. LIMITATIONS

Blending can blur information when weights are flat.

### 13. TRADE-OFFS

Few sharp weights (copy) versus broad (aggregate).

### 14. COMMON MISTAKES

Multiplying `V W` instead of `W V`; using the wrong sequence length for the output.

### 15. PERFORMANCE / COST CONSIDERATIONS

T·S·d_v multiply-adds per head.

### 16. SECURITY CONSIDERATIONS

Injected content in values is blended like any other.

### 17. INTERVIEW EXPLANATION

*"After softmax gives weights, the output for each token is the weighted sum of the value vectors, one matrix multiply."*

### 18. RAPID-FIRE ANSWER

Out = W·V: weighted average of value rows.
