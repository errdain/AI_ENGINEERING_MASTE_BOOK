### 1. WHAT IS IT?

Self-attention: queries, keys and values all come from the **same sequence** `X`. Each token updates itself using the others (including itself).

### 2. WHY DOES IT EXIST?

To build context-aware token representations (e.g. resolving "it" or "bank") a model must let tokens exchange information inside one sequence.

### 3. DETAILED EXPLANATION

Score matrix `T×T`. **Without position information, self-attention is permutation-equivariant**: shuffle the input tokens and the outputs shuffle identically (`test_head_symmetry_permutation_equivariance`). That is why Tier 6 injected positions (see [Tier 6](../tier-06-tokenization-embeddings/README.md)). Self-attention appears in every Transformer block; with a causal mask it is the engine of decoder-only LLMs ([7.14 Causal attention](07.14-causal-attention.md)), without it of encoders ([7.15 Bidirectional attention](07.15-bidirectional-attention.md)). Compare with [7.13 Cross-attention](07.13-cross-attention.md).

```
 tokens: The  cat  sat
          │    │    │      each token: Q, K, V from itself
          └────┴────┘      every token attends to every (allowed) token
```

### 4. HOW DOES IT WORK?

1. `Q = X W_q`, `K = X W_k`, `V = X W_v` from the same `X`.
2. Run scaled dot-product attention ([7.11 Scaled dot-product attention](07.11-scaled-dot-product-attention.md)) with the appropriate mask.
3. Each output row now mixes information from the sequence.

### 5. SIMPLE EXAMPLE

A meeting where everyone listens to everyone else in the room and updates their own notes.

### 6. TECHNICAL EXAMPLE

In GPT-style LLMs each layer's self-attention reads earlier tokens' K/V (cached at inference).

### 7. CODE

```python
import numpy as np
from attention_np import MultiHeadAttention, causal_mask
x = np.random.default_rng(1).normal(size=(2, 5, 16))
mha = MultiHeadAttention(16, 4)
y = mha(x, mask=causal_mask(5))      # self-attention: context=None means K, V from x
print(y.shape)                       # (2, 5, 16)
# permutation-equivariance without a mask:
perm = np.random.default_rng(2).permutation(5)
print(np.allclose(mha(x)[:, perm], mha(x[:, perm])))   # True
```

### 8. INPUT → PROCESS → OUTPUT

```
X (T×d) ─► Q,K,V (all from X) ─► attention ─► Y (T×d)
```

### 9. ENTERPRISE USE CASE

Backbone of document-understanding encoders and chat LLMs alike.

### 10. AI ENGINEERING CONNECTION

Every LLM layer; its n² cost is why context length is expensive ([7.23 Attention complexity](07.23-attention-complexity.md)).

### 11. ADVANTAGES

Long-range, content-based mixing in one step; parallel.

### 12. LIMITATIONS

Order-blind without positions; quadratic cost.

### 13. TRADE-OFFS

Full mixing (rich) versus restricted patterns (cheaper, [7.30 Sliding-window attention (introduction only)](07.30-sliding-window-attention-introduction-only-full-architecture.md)).

### 14. COMMON MISTAKES

Assuming order is known without positional information; forgetting causal mask in generative models.

### 15. PERFORMANCE / COST CONSIDERATIONS

O(n²·d) attention plus O(n·d²) projections ([7.23 Attention complexity](07.23-attention-complexity.md)).

### 16. SECURITY CONSIDERATIONS

Cross-token leakage is only prevented by masks ([7.16 Attention masks](07.16-attention-masks.md)).

### 17. INTERVIEW EXPLANATION

*"In self-attention queries, keys and values all come from the same sequence, so each token gathers information from the others. Alone it is permutation-equivariant, so position information is added elsewhere."*

### 18. RAPID-FIRE ANSWER

Q, K, V from the same sequence.
