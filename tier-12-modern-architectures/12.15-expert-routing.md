### 1. WHAT IS IT?

Expert routing is the rule that assigns tokens to experts: token-choice top-k, expert-choice, hashing, plus capacity limits for overflow.

### 2. WHY DOES IT EXIST?

The router decides model quality and hardware efficiency: bad routing wastes experts or overloads some.

### 3. DETAILED EXPLANATION

**Token-choice top-k:** each token picks its `k` best experts. **Expert-choice:** each expert picks its top tokens (balanced by construction, awkward for autoregressive decoding). **Capacity** `C = ⌈cf·T·k/E⌉`; tokens beyond it are dropped or rerouted. Shared experts (always active) appear in some designs (REVIEW_REQUIRED).

### 4. HOW DOES IT WORK?

1. Logits. 2. Top-k. 3. Position within expert queue vs capacity. 4. Dispatch (all-to-all across GPUs). 5. Combine weighted outputs.

### 5. SIMPLE EXAMPLE

Airport check-in desks with limited queue length: if your desk is full you go elsewhere or wait.

### 6. TECHNICAL EXAMPLE

Skew 0.8, E=8, k=2, T=1024, cf=1.25 in the explorer drops some expert slots (read the percentage in the stats row); raise cf to reduce drops at the cost of padding compute.

### 7. CODE

```python
import numpy as np
def route(logits, k, cf):
    T, E = logits.shape; cap = int(np.ceil(cf * T * k / E)); load = np.zeros(E, int); dropped = 0
    for t in range(T):
        for e in np.argsort(-logits[t])[:k]:
            if load[e] < cap: load[e] += 1
            else: dropped += 1
    return load, cap, dropped
```

### 8. INPUT → PROCESS → OUTPUT

```
logits → top-k → capacity → (dispatch | drop) → combine
```

### 9. ENTERPRISE USE CASE

Choosing capacity factor is a cost knob in MoE serving/training.

### 10. AI ENGINEERING CONNECTION

Dispatch is all-to-all traffic on multi-GPU.

### 11. ADVANTAGES

Specialisation, controllable load.

### 12. LIMITATIONS

Dropped tokens harm quality; instability.

### 13. TRADE-OFFS

Capacity factor: padding waste vs drops.

### 14. COMMON MISTAKES

Evaluating routing on large batches only.

### 15. PERFORMANCE / COST CONSIDERATIONS

All-to-all communication cost.

### 16. SECURITY CONSIDERATIONS

Batch-dependent routing can make outputs vary with co-batched requests.

### 17. INTERVIEW EXPLANATION

*"Routing picks the top-k experts per token, subject to capacity; overflow tokens are dropped or rerouted, so capacity factor trades compute waste against quality loss."*

### 18. RAPID-FIRE ANSWER

Router picks experts under a capacity limit.
