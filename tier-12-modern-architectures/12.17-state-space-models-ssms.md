### 1. WHAT IS IT?

A State Space Model processes a sequence with a **fixed-size hidden state** updated by a linear recurrence `hₜ = aₜ⊙hₜ₋₁ + Bₜxₜ`, `yₜ = ⟨Cₜ,hₜ⟩`.

### 2. WHY DOES IT EXIST?

Attention's cache and per-token cost grow with context; an SSM has constant memory and per-token work.

### 3. DETAILED EXPLANATION

The same layer can be computed four ways (all in [`lab/ssm_scan.py`](lab/ssm_scan.py) and tested): a **recurrence** (O(T), used for decoding), a **matrix** `y = M x` with `M[t,s] = ⟨Cₜ, (aₛ₊₁…aₜ)⊙Bₛ⟩` (a masked, decaying attention-like matrix), a **parallel scan** (log-depth, for training) and, if time-invariant, a **convolution**.

### 4. HOW DOES IT WORK?

1. Input `xₜ`. 2. State update with decay `a∈(0,1)`. 3. Readout. 4. Repeat with state carried forward, never revisiting past tokens.

### 5. SIMPLE EXAMPLE

A running tally with forgetting: you keep a summary, not the whole history.

### 6. TECHNICAL EXAMPLE

Decode cost per layer `6·(E·d)·N` independent of context vs `4·n·d` for attention: break-even at `n = 3N` for E=2.

### 7. CODE

```python
import sys; sys.path.insert(0, "lab")
import numpy as np, ssm_scan as ss
x, a, B, C = ss.make_inputs(T=16, N=4)
y = ss.recurrent_scan(x, a, B, C)
print(np.allclose(ss.matrix_form(a, B, C) @ x, y), np.allclose(ss.parallel_scan(x, a, B, C), y))   # True True
```

### 8. INPUT → PROCESS → OUTPUT

```
x_t → h_t = a⊙h_{t-1} + B x_t → y_t = C·h_t   (state size N, independent of T)
```

### 9. ENTERPRISE USE CASE

Streaming sensors/audio/logs where memory must stay bounded.

### 10. AI ENGINEERING CONNECTION

Basis of Mamba and SSM-hybrid LLMs.

### 11. ADVANTAGES

Linear-time, constant-memory decoding; parallelisable training via scan.

### 12. LIMITATIONS

Fixed state compresses history lossily; weaker exact recall (copying, in-context lookup).

### 13. TRADE-OFFS

State size vs memory-of-detail.

### 14. COMMON MISTAKES

Claiming SSMs are strictly better than attention; ignoring recall tasks.

### 15. PERFORMANCE / COST CONSIDERATIONS

Time O(T), state O(N).

### 16. SECURITY CONSIDERATIONS

Fixed state bounds memory but not what is remembered; injected text can still overwrite state.

### 17. INTERVIEW EXPLANATION

*"An SSM keeps a fixed-size state updated by a decaying linear recurrence, so decode cost and memory do not grow with context; the same layer can be trained as a parallel scan or viewed as a masked attention matrix, but exact recall of old tokens is limited by the state size."*

### 18. RAPID-FIRE ANSWER

Fixed state + linear recurrence = O(1) memory per token.
