### 1. WHAT IS IT?

A catalogue of ways to reduce attention cost: **exact but faster** (FlashAttention-style kernels), **fewer KV heads** (MQA/GQA), **fewer pairs** (sparse), **approximate** (low-rank, kernel/linear attention) and **replace** (SSM).

### 2. WHY DOES IT EXIST?

No single trick fixes all costs, so you need to know which cost each attacks.

### 3. DETAILED EXPLANATION

| Pattern | Attacks | Exact? | Notes |
|---|---|---|---|
| FlashAttention-style tiling | memory traffic | yes | Tier 11 |
| MQA/GQA | KV cache | yes (model design) | [12.7 Grouped-Query Attention (GQA) in modern models](12.07-grouped-query-attention-gqa-in-modern-models.md) |
| Sliding/sparse | pairs, cache | no (changes model) | [12.10 Sliding-window attention](12.10-sliding-window-attention.md) |
| Linear attention | compute, state | approximate | below |
| SSM | compute, state | different model | [12.17 State Space Models (SSMs)](12.17-state-space-models-ssms.md) |

**Linear attention** replaces `softmax(QKᵀ)V` by `(φ(Q)(φ(K)ᵀV))`, which can run as a recurrence with a fixed `d×d` state. Without softmax it equals an SSM with decay 1 (tested below).

### 4. HOW DOES IT WORK?

Decide the bottleneck (prefill compute, decode bandwidth, KV memory), then pick the pattern that targets it.

### 5. SIMPLE EXAMPLE

Faster roads (kernels), carpooling (shared K/V), shortcuts (sparse), or replacing the road with a train (SSM).

### 6. TECHNICAL EXAMPLE

Causal linear attention as a recurrence `S_t = S_{t-1} + k_t v_tᵀ`, `y_t = q_t S_t` matches the masked matrix form.

### 7. CODE

```python
import sys; sys.path.insert(0, "lab")
import numpy as np, ssm_scan as ss
q, k, v = np.random.default_rng(0).standard_normal((3, 10, 4))

```
