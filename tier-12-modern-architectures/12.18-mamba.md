### 1. WHAT IS IT?

Mamba is an SSM architecture whose parameters `Δ, B, C` depend on the input (**selectivity**), computed with a hardware-aware parallel scan, inside a gated block with a short convolution.

### 2. WHY DOES IT EXIST?

Time-invariant SSMs cannot choose what to remember; selectivity lets the state keep relevant tokens and ignore filler.

### 3. DETAILED EXPLANATION

Selectivity breaks the convolution form (the lab raises an error for it, tested), so Mamba relies on the scan. Block sketch: `in_proj` → causal conv → selective SSM → gate → `out_proj` (see `ssm_params` in the lab for the counted weights). Later variants reformulate the layer as structured masked attention (the equivalence shown in 12.17); details REVIEW_REQUIRED.

![State recurrence](figures/08_ssm_state_recurrence.gif)

*Animation: a selective model would modulate decay per step instead of using fixed decays shown here.*

### 4. HOW DOES IT WORK?

1. Project input to inner width `E·d`. 2. Compute `Δ, B, C` from the input. 3. Discretise, scan. 4. Gate and project out.

A Mamba-style 48-layer archetype (d=4096, N=16) has ≈5.3 B parameters and ~0.01 GiB state per sequence in the lab (illustrative).

