### 1. WHAT IS IT?

Long-context architectures combine position scaling, cheaper attention (windows, sparse patterns, GQA) and sometimes non-attention mixers so that models can read 32k-1M tokens.

### 2. WHY DOES IT EXIST?

Full attention costs `O(n²)` in prefill and an `O(n)` cache per sequence; at 128k tokens both dominate.

### 3. DETAILED EXPLANATION

Four levers, each taught in its own concept: **positions** ([12.8 RoPE variants and extensions](12.08-rope-variants-and-extensions.md)), **fewer cached bytes** ([12.7 Grouped-Query Attention (GQA) in modern models](12.07-grouped-query-attention-gqa-in-modern-models.md), [12.10 Sliding-window attention](12.10-sliding-window-attention.md)), **fewer computed pairs** ([12.11 Sparse attention](12.11-sparse-attention.md), [12.12 Efficient-attention architecture patterns](12.12-efficient-attention-architecture-patterns.md)), **fixed-size state** ([12.17 State Space Models (SSMs)](12.17-state-space-models-ssms.md), [12.19 Transformer-SSM hybrid architectures](12.19-transformer-ssm-hybrid-architectures.md)). Efficient exact kernels (FlashAttention, paged KV) are Tier 11.

### 4. HOW DOES IT WORK?

Audit a design with three questions: (1) can positions represent n? (2) does cache fit at the target concurrency? (3) can the model actually *use* far tokens (retrieval quality, not just survival)?

### 5. SIMPLE EXAMPLE

A library: shelves (cache) can hold more books if you only keep the recent ones, but you may lose the book you need.

### 6. TECHNICAL EXAMPLE

At n=131072 the archetype dense MHA needs 64 GiB per sequence, GQA-8 16 GiB, a 4096 window 0.5 GiB, an SSM ≈ 0.01 GiB (lab numbers, archetypes).

### 9. ENTERPRISE USE CASE

Contract analysis, codebase Q&A and log triage with whole-document context, often cheaper via retrieval (Tier 20).

### 10. AI ENGINEERING CONNECTION

Decision: bigger context vs retrieval; both appear in RAG design.

### 11. ADVANTAGES

Whole-document reasoning without chunking.

### 12. LIMITATIONS

Recall in the middle of long contexts can be weak (empirical, REVIEW_REQUIRED); cost grows.

### 13. TRADE-OFFS

Context length vs cost vs recall quality.

### 14. COMMON MISTAKES

Equating advertised context with usable context; ignoring prefill latency.

### 15. PERFORMANCE / COST CONSIDERATIONS

Prefill ≈ n²; KV ≈ n; both explode at 1M tokens.

### 16. SECURITY CONSIDERATIONS

Long inputs include untrusted documents; isolate instructions.

### 17. INTERVIEW EXPLANATION

*"Long context needs positions that extrapolate, a cache that fits, attention that is cheaper than n², and tests that the model actually retrieves from far away."*

### 18. RAPID-FIRE ANSWER

Positions + cache + sparse/linear compute + evaluation.
