# 1.22 Partial derivatives

**Metadata** — Tier: 1 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: Medium-High · Hands-on: High
Prerequisites: 1.21 · Leads to: 1.23 Gradients, 1.24 Jacobians

### 1. What is it?
For a function of several variables, `f(x₁,…,xₙ)`, the partial derivative `∂f/∂xᵢ` is the derivative with respect to `xᵢ` while all other variables are held fixed.

### 2. Why does it exist?
Models have millions to billions of parameters. We need the effect of changing *one* parameter at a time, then we assemble the full picture (the gradient, 1.23).

### 3. Detailed explanation
Treat other variables as constants and differentiate normally. Example: `f(x,y) = x² + 3xy` gives `∂f/∂x = 2x + 3y` and `∂f/∂y = 3x`. At `(1,2)`: `∂f/∂x = 8`, `∂f/∂y = 3`. Second-order partials form the Hessian (curvature); for smooth `f` mixed partials commute: `∂²f/∂x∂y = ∂²f/∂y∂x`.

### 4. How does it work?
Mechanically identical to 1-D differentiation per variable. Numerically: perturb one coordinate at a time with a one-hot step `e_i`.

### 5. Simple example
House price depends on area, rooms and age. `∂price/∂area` is the price change per extra square metre with rooms and age unchanged.

### 6. Technical example
For `L = (w·x + b − y)²`: `∂L/∂wᵢ = 2(w·x + b − y)xᵢ` and `∂L/∂b = 2(w·x + b − y)`.

### 8. Input → Process → Output
`f(x₁…xₙ), point → freeze all but xᵢ → slope along axis i`

### 9. Enterprise use case
Feature attribution: sensitivity of a score to each input feature individually (local explanations).

### 10. AI engineering connection
Each weight's update is driven by its own partial derivative of the loss. Backprop is an efficient way to compute all of them at once.

### 11. Advantages
Decomposes a high-dimensional problem into per-coordinate effects.

### 12. Limitations
Ignores interactions; the effect of changing two variables together is not simply the sum beyond first order.

### 13. Trade-offs
One-at-a-time numerical partials cost `2n` evaluations; autodiff cost is a small constant multiple of one forward pass.

### 14. Common mistakes
Forgetting that other variables are held fixed when they actually depend on `xᵢ` (then you need total derivatives/chain rule); mixing up `∂` and `d`.

### 15. Performance / cost
Reverse-mode autodiff returns all `n` partials of a scalar loss for roughly 2–3× the cost of the forward pass; this is why deep learning is feasible.

### 17. Interview explanation
"A partial derivative measures how the output changes when I wiggle one input and freeze the rest. Collect all of them for the loss and you get the gradient, which tells every parameter which way to move."

### 18. Rapid-fire
∂f/∂xᵢ = slope along axis i with others fixed; all of them make the gradient.
