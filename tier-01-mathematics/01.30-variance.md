# 1.30 Variance

**Metadata** — Tier: 1 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: High · Hands-on: High
Prerequisites: 1.29 · Leads to: 1.31, 1.32, normalization layers, initialization, Adam

### 1. What is it?
The expected squared deviation from the mean:

`Var(X) = E[(X − μ)²] = E[X²] − (E[X])²`

It measures spread.

### 2. Why does it exist?
The mean alone doesn't tell how reliable or variable data is. Variance quantifies spread and the uncertainty of estimates. Squaring prevents positive and negative deviations from cancelling and makes the quantity easy to differentiate and to add for independent variables.

### 3. Detailed explanation
- `Var(aX + b) = a²Var(X)` (shifting does nothing; scaling squares). Tested.
- For **independent** `X, Y`: `Var(X + Y) = Var(X) + Var(Y)`. In general `+ 2Cov(X, Y)` (1.32).
- Fair die: `Var = 35/12 ≈ 2.92`.
- **Population vs sample:** population variance divides by `n` (`ddof=0`); the *unbiased sample estimator* divides by `n−1` (`ddof=1`, Bessel's correction) because the sample mean is already fitted to the data. NumPy defaults to `ddof=0`, pandas `.var()` to `ddof=1`; PyTorch `var` defaults to unbiased (`correction=1`). Know your library's default.
- **Numerical pitfall:** the shortcut `E[X²] − E[X]²` suffers catastrophic cancellation when the mean is large relative to the spread (e.g., values near 10⁹ with σ=1). Use the two-pass formula or **Welford's** one-pass algorithm. This is tested below.
- Dot-product connection: for independent zero-mean unit-variance entries, `Var(q·k) = d`; hence the `1/√d` scaling in attention (1.10).
- Normalization layers: LayerNorm/BatchNorm divide by `√(variance + ε)`; `ε` prevents division by zero.

### 4. How does it work?
Compute the mean, average the squared deviations. Streaming: update mean and sum of squared deviations incrementally (Welford).

### 5. Simple example
Two archers both average the centre; one scatters widely (high variance), the other clusters tightly.

### 6. Technical example
Weight initialization (Xavier/He) picks weight variance from the layer width so activations and gradients keep roughly constant variance across layers. Adam keeps a moving average of squared gradients (a second-moment estimate).

### 7. Code
```python
import numpy as np
from calculus_prob import variance, sample_variance, Welford
v, p = np.arange(1, 7), np.full(6, 1/6)
print(variance(v, p))                                   # 2.9167 = 35/12
x = np.array([2, 4, 4, 4, 5, 5, 7, 9.0])
print(sample_variance(x, ddof=0), sample_variance(x, ddof=1))   # 4.0  4.571...
big = np.random.default_rng(7).standard_normal(10_000) + 1e9
w = Welford(); [w.update(float(t)) for t in big]
print(w.var, np.var(big, ddof=1))                       # ≈ 1.0 both; naive E[X²]−E[X]² is badly off
```
TESTED: die variance, `ddof` agreement with NumPy, `Var(aX+b)=a²Var`, Welford vs NumPy at a 10⁹ offset, naive formula's larger error.

### 8. Input → Process → Output
`values → subtract mean → square → average (÷n or ÷n−1) → spread`

### 9. Enterprise use case
Data-drift monitoring compares the mean and variance of features between training and production; sudden variance change is an early warning.

### 10. AI engineering connection
LayerNorm/BatchNorm, initialization schemes, attention scaling, Adam's second moment, variance of gradient estimates (batch-size tuning), seed-to-seed variance in evaluation.

### 11. Advantages
Smooth, additive for independent variables, well-understood estimators.

### 12. Limitations
Units are squared; outlier-sensitive; may be infinite for heavy tails; says nothing about shape.

### 13. Trade-offs
Variance (mathematically convenient) vs MAD/IQR (robust). Larger batch → lower gradient variance but higher compute and sometimes worse generalization.

### 14. Common mistakes
Wrong `ddof` default; using the naive one-pass formula; forgetting `ε` in normalization; computing variance of a single sample (undefined for `n−1`); mixing population and sample variance across libraries (PyTorch vs NumPy).

### 15. Performance / cost
Single pass and O(1) memory with Welford; parallel merges via Chan's algorithm for distributed statistics.

### 16. Security
Distribution-shift monitors based on variance can be evaded by attackers matching the first two moments; combine with other checks.

### 17. Interview explanation
"Variance is the average squared distance from the mean. It tells me how spread out data is and, for independent variables, it adds. I watch out for the n versus n−1 convention across libraries, and I use a stable algorithm like Welford's when values are large relative to their spread."
