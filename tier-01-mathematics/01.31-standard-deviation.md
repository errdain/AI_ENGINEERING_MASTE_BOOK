# 1.31 Standard deviation

**Metadata** — Tier: 1 · Phase: 1 · Priority: P0 · Difficulty: 1/5 · Interview: High · Hands-on: Very high
Prerequisites: 1.30 · Leads to: 1.32, feature scaling, normalization, evaluation reporting

### 1. What is it?
The square root of variance: `σ = √Var(X)`. It measures spread in the same units as the data.

### 2. Why does it exist?
Variance is in squared units (ms², dollars²), which are hard to interpret. Standard deviation (std) brings it back to the original units and gives a practical "typical distance from the mean".

### 3. Detailed explanation
- **Empirical rule for roughly normal data:** ~68% within ±1σ, ~95% within ±2σ, ~99.7% within ±3σ (tested to within 1%). Do not apply it to skewed or heavy-tailed data.
- **z-score / standardization:** `z = (x − μ)/σ` yields mean 0 and std 1 (tested). Used for feature scaling and outlier flags (|z| > 3).
- **Standard error of the mean:** `σ/√n`. Quadrupling samples halves the uncertainty in the mean (tested).
- Population vs sample std: `ddof` as in 1.30. NumPy defaults to `ddof=0`; use `ddof=1` for sample std when estimating from a sample.
- Example: `[2,4,4,4,5,5,7,9]` has population std = 2.0 and sample std ≈ 2.138.
- `σ = 0` (constant feature) makes z-scores undefined; guard with `ε` or drop the feature.
- Std is not invariant to outliers: a single extreme value can dominate it. Robust alternatives: MAD or IQR.

### 4. How does it work?
`std = sqrt(variance)`; standardize by subtracting the mean and dividing by std, computed on the **training set only** and reused on validation/test/production.

### 5. Simple example
Exam scores with mean 70 and std 10: most students scored between 60 and 80.

### 6. Technical example
Reporting results: "accuracy 87.2 ± 0.6 (std over 5 seeds)". Feature scaling before k-NN, SVMs, gradient descent. LayerNorm output has per-token zero mean and unit variance across features (before learned scale/shift).

### 7. Code
```python
import numpy as np
x = np.random.default_rng(1).normal(10, 3, size=200_000)
z = (x - x.mean()) / x.std()
print(z.mean().round(6), z.std().round(6))                      # 0.0 1.0
print((np.abs(z) < 1).mean(), (np.abs(z) < 2).mean())          # ≈ 0.683, 0.954
m100 = np.random.default_rng(2).normal(0, 1, (5000, 100)).mean(axis=1).std()
m400 = np.random.default_rng(2).normal(0, 1, (5000, 400)).mean(axis=1).std()
print(m100, m400, m100 / m400)                                  # ≈ 0.1, 0.05, ≈ 2
```

### 8. Input → Process → Output
`data → variance → square root → spread in original units → z-scores / error bars`

### 9. Enterprise use case
Alerting on metrics: flag when a value exceeds `mean + 3σ` of a rolling baseline (with caution for non-normal data); reporting experiment results with error bars.

### 10. AI engineering connection
Feature standardization, normalization layers, weight init scales, evaluation variance across seeds and bootstrap resamples, confidence intervals.

### 11. Advantages
Interpretable units; standard in reporting.

### 12. Limitations
Outlier-sensitive; assumes the mean is a good centre; the empirical rule fails for non-normal data.

### 13. Trade-offs
Std (efficient for normal data) vs MAD/IQR (robust for skewed or contaminated data).

### 14. Common mistakes
Fitting the scaler on the full dataset including test data (**data leakage**); dividing by zero std; mixing population/sample std; quoting ± without saying what it is (std across seeds? standard error? 95% CI?); applying 68-95-99.7 to heavy tails.

### 15. Performance / cost
Online computation (Welford) needs O(1) memory, which matters for monitoring streams and large-scale preprocessing.

### 16. Security
Anomaly detectors based on z-scores can be shifted gradually by an attacker ("boiling frog" drift); anchor baselines and monitor drift separately.

### 17. Interview explanation
"Standard deviation is the square root of variance, so it's the typical distance from the mean in the data's own units. I use it to standardize features, flag outliers, and report results as mean ± std across seeds. I fit the scaler on training data only to avoid leakage."

### 18. Rapid-fire
σ = √Var; z = (x−μ)/σ; 68-95-99.7 for normal data; SE = σ/√n.
