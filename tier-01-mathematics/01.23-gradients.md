# 1.23 Gradients

**Metadata** — Tier: 1 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: Very high · Hands-on: Very high
Prerequisites: 1.15, 1.22 · Leads to: 1.24, 1.25, 1.46, Tier 4 (optimizers)

### 1. What is it?
For a scalar-valued function `f: ℝⁿ → ℝ`, the gradient is the vector of all partial derivatives:

`∇f(x) = [∂f/∂x₁, …, ∂f/∂xₙ]`

It has the same shape as `x`.

### 2. Why does it exist?
It packages "how to change every parameter to change the loss" into one vector. It points in the direction of steepest increase.

### 3. Detailed explanation
- Direction of steepest ascent is `∇f`; steepest descent is `−∇f`; the rate of change in that direction is `‖∇f‖`.
- `∇f` is perpendicular to level sets (contours) of `f`.
- `∇f = 0` marks a critical point (minimum, maximum or saddle). In high-dimensional nets saddle points are far more common than bad local minima (1.47).
- **Gradient descent:** `x ← x − η∇f(x)`. With `f = ‖x‖²`, `∇f = 2x` and the update multiplies `x` by `(1 − 2η)`: converges for `0<η<1`, diverges when `|1 − 2η| > 1`, e.g. `η = 1.5` (tested).
- Gradient scale problems: vanishing (≈0, no learning) and exploding (huge steps). Mitigations: initialization, normalization, residual connections, gradient clipping by global norm (1.15).
- **Gradient checking:** compare analytic/autodiff gradients with central differences; relative error around 1e-6–1e-7 in float64 is a pass.

### 4. How does it work?
Backpropagation computes `∇_θ L` for all parameters in one backward pass (1.25). Optimizers then turn gradients into updates (momentum, Adam…).

### 5. Simple example
Standing on a foggy hillside: feel which way the ground rises most steeply, then step the opposite way to go down.

### 6. Technical example
`L(w) = ‖Xw − y‖²` has `∇L = 2Xᵀ(Xw − y)` — note the transpose (1.12) from the chain rule.

### 7. Code
```python
import numpy as np
from calculus_prob import numerical_gradient, gradient_descent
f = lambda v: float((v ** 2).sum())
x = np.array([3.0, -4.0])
print(numerical_gradient(f, x))                                    # ≈ [6, -8] = 2x
print(gradient_descent(lambda v: 2 * v, x, lr=0.1, steps=200))     # ≈ [0, 0]
print(gradient_descent(lambda v: 2 * v, np.array([1.0]), lr=1.5, steps=20))  # blows up
```
TESTED: ascent direction, convergence, divergence with a large learning rate.

### 8. Input → Process → Output
`loss(θ) → backward pass → ∇θ L (same shape as θ) → optimizer step`

### 9. Enterprise use case
Monitoring gradient norms during training jobs catches divergence early and saves GPU-hours.

### 10. AI engineering connection
Everything in training: SGD/Adam, clipping, mixed-precision loss scaling (to prevent gradient underflow), LoRA (gradients only through small adapters), and adversarial attacks (gradient with respect to inputs).

### 11. Advantages
One vector gives a locally optimal direction; cheap via backprop.

### 12. Limitations
Local information only; sensitive to scaling/conditioning; noisy with mini-batches; tells nothing about global optimum.

### 13. Trade-offs
Learning rate: large = fast but unstable; small = stable but slow. Mini-batch size: noise vs compute.

### 14. Common mistakes
Wrong sign (ascending instead of descending); forgetting `zero_grad` (accumulating gradients) in PyTorch; confusing gradient shape with loss shape; non-scalar "loss" passed to backward; ignoring that gradients are only for differentiable paths (detached tensors, `argmax`).

### 15. Performance / cost
Backward pass ≈ 2× forward FLOPs; activations must be stored (or recomputed with checkpointing) for backprop, so memory grows with depth × batch × sequence.

### 16. Security
Gradient leakage: shared gradients in federated/distributed training can reveal training data. Adversarial examples use input gradients (FGSM etc.).

### 17. Interview explanation
"The gradient is the vector of partial derivatives of the loss. It points uphill, so we step the opposite way, scaled by the learning rate. Backprop computes it for all parameters in one backward pass. In practice I watch the gradient norm and clip it to keep training stable."

### 18. Rapid-fire
∇L points uphill; step −η∇L; same shape as parameters; clip when it explodes.
