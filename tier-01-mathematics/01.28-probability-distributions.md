# 1.28 Probability distributions

**Metadata** — Tier: 1 · Phase: 1 · Priority: P0 · Difficulty: 3/5 · Interview: High · Hands-on: High
Prerequisites: 1.26, 1.27 · Leads to: 1.29–1.38, Tier 2 (generative/discriminative), Tier 16 sampling

### 1. What is it?
A description of how probability is spread over the values of a random variable.
- **PMF** `p(x) = P(X = x)` for discrete variables; sums to 1.
- **PDF** `f(x)` for continuous variables; `P(a ≤ X ≤ b) = ∫ₐᵇ f(x)dx`; integrates to 1.
- **CDF** `F(x) = P(X ≤ x)`; non-decreasing from 0 to 1.

### 2. Why does it exist?
A single number (mean) is not enough. The distribution says what values are likely, how spread out, how heavy the tails. Models either output a distribution (classifier, language model) or assume one (noise, priors, initialization).

### 3. Detailed explanation
Core families:
- **Bernoulli(p):** one yes/no trial. PMF `p` for 1, `1−p` for 0.
- **Categorical(p₁…p_K):** one of K classes; the output of softmax. A language model's next token is a categorical over the vocabulary.
- **Binomial(n, p):** number of successes in n Bernoulli trials.
- **Uniform(a, b):** all values equally likely.
- **Normal (Gaussian) 𝒩(μ, σ²):** `f(x) = exp(−(x−μ)²/2σ²)/(σ√2π)`. Appears via the central limit theorem (sums of many small effects), and as default for noise and weight initialization. Rule: ~68% within 1σ, ~95% within 2σ, ~99.7% within 3σ.

Careful points:
- A **density can exceed 1** (a narrow normal with σ=0.1 peaks at ≈3.99); only *areas* are probabilities.
- Real data often has **heavy tails** (latencies, token frequencies, losses); a normal assumption underestimates extremes.
- **Temperature** `T` reshapes a categorical: `softmax(z/T)`; `T→0` approaches argmax, large `T` approaches uniform. Top-k/top-p truncate the categorical before sampling.

### 4. How does it work?
Parametrize (e.g., `μ`, `σ`), compute PMF/PDF/CDF, sample, or fit parameters from data (maximum likelihood, 1.35).

### 5. Simple example
Heights of adults ≈ bell-shaped normal; a coin ≈ Bernoulli(0.5).

### 6. Technical example
Initializing weights from `𝒩(0, σ²)` with σ chosen from layer sizes; LLM decoding samples from the softmax categorical after applying temperature/top-p.

### 7. Code
```python
import numpy as np
from calculus_prob import normal_pdf, softmax, bernoulli_pmf
xs = np.linspace(-8, 8, 20001)
print(np.trapezoid(normal_pdf(xs), xs))               # ≈ 1.0 (total probability)
print(normal_pdf(np.array(0.0), sigma=0.1))           # ≈ 3.99 — a density, not a probability
z = np.array([2.0, 1.0, 0.1])
print(softmax(z / 0.5), softmax(z / 5.0))             # low T = peaked; high T = flatter
```
TESTED: normal PDF integrates to 1, peak value, density > 1, `sigma ≤ 0` rejected, Bernoulli PMF and invalid `p`, softmax properties.

### 8. Input → Process → Output
`parameters → PMF/PDF → probabilities of values/ranges → samples`

### 9. Enterprise use case
SLO engineering models latency with heavy-tailed distributions (log-normal/Pareto) rather than normal when estimating p99; capacity planning uses the tail, not the mean.

### 10. AI engineering connection
Classification heads (categorical), regression with Gaussian noise (MSE ↔ Gaussian likelihood), VAEs/diffusion (Gaussians), sampling controls (temperature, top-k, top-p), weight init, priors.

### 11. Advantages
Compact descriptions of uncertainty; enable sampling and likelihood-based training.

### 12. Limitations
Wrong family → wrong conclusions; parametric assumptions rarely hold exactly.

### 13. Trade-offs
Simple parametric forms are data-efficient but may be misspecified; flexible/nonparametric forms need more data.

### 14. Common mistakes
Reading a PDF value as a probability; assuming normality for skewed or heavy-tailed data; forgetting that softmax outputs must be computed stably; applying temperature to probabilities instead of logits.

### 15. Performance / cost
Sampling a categorical over a 100k-token vocabulary each step is cheap relative to the forward pass, but top-p requires sorting/cumsum; careful implementations avoid full sorts.

### 16. Security
Sampling randomness affects reproducibility and safety testing; set seeds for evaluation runs, and test safety at the sampling settings used in production, not just greedy decoding.

### 17. Interview explanation
"A distribution says how likely each value is. For discrete variables that's a PMF, for continuous ones a PDF where only areas are probabilities. A classifier or language model outputs a categorical distribution via softmax, and temperature or top-p just reshape that distribution before sampling."
