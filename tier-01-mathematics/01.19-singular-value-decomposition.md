# 1.19 Singular Value Decomposition (SVD)

**Metadata** — Tier: 1 · Phase: 1 · Priority: P1 · Difficulty: 4/5 · Interview: High · Hands-on: Medium-High
Prerequisites: 1.11, 1.12, 1.14, 1.18 · Leads to: PCA (Tier 2), LoRA / low-rank adaptation (Tier 10), embedding compression, pseudo-inverse

### 1. What is it?
Any real `m×n` matrix factors as

`A = U Σ Vᵀ`

- `U (m×m)` and `V (n×n)`: orthogonal matrices (rotations/reflections).
- `Σ (m×n)`: diagonal with **singular values** `σ₁ ≥ σ₂ ≥ … ≥ 0`.

The "economy" form (`full_matrices=False`) keeps only `r = min(m,n)` columns: `U (m×r)`, `Σ (r)`, `Vᵀ (r×n)`.

### 2. Why does it exist?
Eigendecomposition (1.18) needs square matrices and may be complex. SVD exists for **every** matrix and says: any linear map = rotate (`Vᵀ`) → scale each axis (`Σ`) → rotate (`U`).

### 3. Detailed explanation
- Singular values are square roots of the eigenvalues of `AᵀA` (and `AAᵀ`).
- **Rank** = number of non-zero singular values.
- **Condition number** `κ = σ_max/σ_min` (1.14).
- **Eckart–Young theorem:** keeping the top `k` terms, `A_k = Σᵢ≤k σᵢ uᵢ vᵢᵀ`, is the best rank-`k` approximation to `A` in both Frobenius and spectral norm. The error is exactly `√(σ_{k+1}² + … + σ_r²)` (Frobenius).
- Pseudo-inverse: `A⁺ = V Σ⁺ Uᵀ` (invert non-zero `σ`s), giving least-squares solutions for non-square or singular systems.
- PCA = SVD of the *centered* data matrix.
- Sign ambiguity: `(uᵢ, vᵢ)` and `(−uᵢ, −vᵢ)` are equivalent, so don't test for specific signs.

### 4. How does it work?
Conceptually: the unit sphere maps to an ellipsoid; `σᵢ` are its semi-axis lengths, `vᵢ` the input directions, `uᵢ` the output directions. Computation uses bidiagonalization + iterative methods (`~O(mn·min(m,n))`); randomized/truncated SVD gets the top-`k` much faster for big matrices.

### 5. Simple example
An image as a matrix: the first few singular values capture the broad shapes; later ones capture fine noise. Keep the top `k` and the picture is still recognizable.

### 6. Technical example
- **Compression:** a `4096×4096` weight matrix has 16.8M numbers; rank-16 factors `(4096×16)` and `(16×4096)` have 131k — 128× fewer.
- **LoRA (Tier 10):** assumes the fine-tuning update `ΔW` is low-rank, `ΔW = BA`, so only thin matrices are trained.
- **LSA / embedding denoising / whitening.**

### 7. Code
```python
import numpy as np
from linalg_core import low_rank
M = np.random.default_rng(0).standard_normal((20, 12))
U, s, Vt = np.linalg.svd(M, full_matrices=False)     # U:(20,12) s:(12,) Vt:(12,12)
assert np.allclose((U * s) @ Vt, M)                    # exact reconstruction
k = 4
Mk = low_rank(M, k)
print(np.linalg.matrix_rank(Mk))                       # 4
print(np.isclose(np.linalg.norm(M - Mk), np.sqrt(np.sum(s[k:] ** 2))))   # True (Eckart–Young)
```
TESTED: reconstruction, Eckart–Young error identity, resulting rank, parameter-count saving.

### 8. Input → Process → Output
`A (m,n) → U, σ, Vᵀ → truncate top-k → A_k (rank k)`

### 9. Enterprise use case
Compress embedding stores or model weights; denoise sensor/telemetry matrices; recommender systems (matrix factorization).

### 10. AI engineering connection
LoRA and rank analysis of weight updates; embedding dimensionality reduction; analyzing anisotropy/collapse; stability checks (singular values of weights/Jacobians); spectral normalization.

### 11. Advantages
Exists for every matrix; optimal low-rank approximation; numerically stable; reveals rank and conditioning.

### 12. Limitations
Linear only (can't capture nonlinear manifolds); `O(mn·min(m,n))` cost for full SVD; top-`k` truncation can discard rare-but-important signal.

### 13. Trade-offs
Rank `k`: lower = smaller and smoother but more reconstruction error. Choose `k` by explained energy `Σσᵢ² / Σσ²` or by task metric, not by guess.

### 14. Common mistakes
Forgetting to center data for PCA; confusing `Vᵀ` and `V` (NumPy returns `Vt`); using `full_matrices=True` on tall matrices (huge `U`); testing for specific signs; applying SVD to data with very different feature scales without standardizing.

### 15. Performance / cost
Full SVD of a `10⁴×10⁴` float64 matrix needs ~800 MB per matrix and is slow; use randomized/truncated SVD for top-`k`. Low-rank factorization saves `mn − k(m+n)` parameters but adds a second matmul at inference.

### 16. Security
Low-rank structure of released weights/embeddings can enable model-extraction or membership inference attacks; consider this when sharing compressed artifacts. REVIEW_REQUIRED: cite specific literature before publishing this claim in the book.

### 17. Interview explanation
"SVD factors any matrix into a rotation, a scaling by singular values, and another rotation. Keeping the top k singular values gives the best rank-k approximation, which is the idea behind PCA, embedding compression and LoRA. It's more general than eigendecomposition because it works on any rectangular matrix."
