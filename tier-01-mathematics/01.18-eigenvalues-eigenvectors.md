# 1.18 Eigenvalues and eigenvectors

**Metadata** — Tier: 1 · Phase: 1 · Priority: P1 · Difficulty: 4/5 · Interview: Medium-High · Hands-on: Medium
Prerequisites: 1.3, 1.11, 1.12, 1.15 · Leads to: 1.19 SVD, PCA (Tier 2), RNN stability (Tier 5), optimization curvature (Tier 4)

### 1. What is it?
For a square matrix `A`, a non-zero vector `v` is an **eigenvector** with **eigenvalue** `λ` if

`A v = λ v`

`A` only stretches (or flips) `v`; it does not change its direction.

### 2. Why does it exist?
Most vectors get rotated and sheared by `A`. Eigenvectors are the special axes along which `A` acts as simple scaling, so they reveal the matrix's intrinsic behaviour: dominant directions, stability, curvature, variance.

### 3. Detailed explanation
- Found from `det(A − λI) = 0`.
- `λ > 1` stretches, `|λ| < 1` shrinks, `λ < 0` flips, `λ = 0` means singular (1.14).
- Real **symmetric** matrices (e.g., covariance, `AᵀA`) have **real** eigenvalues and **orthonormal** eigenvectors: `S = QΛQᵀ`. Use `np.linalg.eigh` for them (faster, stable, sorted real output).
- General matrices can have complex eigenvalues: a 90° rotation `[[0,−1],[1,0]]` has `±i`, because no real direction is preserved.
- Powers: `Aᵏv = λᵏv`. Repeated multiplication is dominated by the largest `|λ|`: if `ρ(A) > 1` things explode, `< 1` vanish. This is the linear-algebra core of exploding/vanishing gradients in RNNs (Tier 5).
- Trace = sum of eigenvalues; determinant = product.

### 4. How does it work?
**Power iteration** finds the dominant eigenpair: start with random `v`, repeat `v ← Av/‖Av‖`; it converges to the top eigenvector (if the largest `|λ|` is unique and `v` has a component in that direction). The Rayleigh quotient `vᵀAv/vᵀv` estimates `λ`. Production libraries use more robust QR/Lanczos-type methods.

### 5. Simple example
Stretching a rubber sheet along one axis: points along the stretch axis keep their direction; others slide.

### 6. Technical example
- **PCA:** principal components are eigenvectors of the covariance matrix; eigenvalues are explained variances (see 1.32).
- **PageRank:** dominant eigenvector of a link matrix.
- **Hessian eigenvalues:** curvature along each direction of the loss surface (large spread ⇒ hard to optimize; see 1.46).

### 7. Code
```python
import numpy as np
from linalg_core import power_iteration
A = np.array([[4.0, 1.0], [2.0, 3.0]])
lam, v = power_iteration(A)               # lam ≈ 5.0
print(lam, np.linalg.eigvals(A))          # 5.0 [5. 2.]
assert np.allclose(A @ v, lam * v, atol=1e-8)

S = A + A.T                                # symmetric
w, Q = np.linalg.eigh(S)
assert np.allclose(Q @ np.diag(w) @ Q.T, S)
```
TESTED: power iteration vs NumPy, `Av = λv` residual, symmetric reconstruction and orthonormality.

### 8. Input → Process → Output
`square matrix → solve det(A−λI)=0 / iterate → (λᵢ, vᵢ)`

### 9. Enterprise use case
Dimensionality reduction (PCA) for feature compression and anomaly detection on high-dimensional telemetry.

### 10. AI engineering connection
PCA/whitening of embeddings, analysis of loss-surface curvature, stability of recurrent dynamics, spectral normalization of weights, graph methods (spectral clustering).

### 11. Advantages
Explains matrix behaviour with a few numbers; decouples a symmetric transformation into independent axes.

### 12. Limitations
Only for square matrices; may be complex; defective (non-diagonalizable) matrices exist; non-symmetric matrices have non-orthogonal, ill-conditioned eigenvectors. For general rectangular data use SVD (1.19).

### 13. Trade-offs
Full decomposition `O(n³)`; iterative/partial methods (top-k) are far cheaper when only leading components are needed.

### 14. Common mistakes
Using `eig` instead of `eigh` for symmetric matrices (returns possibly complex, unsorted); assuming eigenvectors are unique (sign/scale ambiguity); forgetting to center data before covariance; treating small non-symmetric numerical noise as symmetric.

### 15. Performance / cost
Dense eigendecomposition `~O(n³)`; for embeddings with `d=4096` this is feasible, for `n=10⁶` it is not (use randomized/truncated methods).

### 17. Interview explanation
"An eigenvector is a direction a matrix only stretches, and the eigenvalue is the stretch factor. For symmetric matrices like covariance, the eigenvectors are orthogonal axes ordered by importance — that's PCA. In recurrent networks the largest eigenvalue of the recurrent matrix tells you whether signals explode or fade."

### 18. Rapid-fire
`Av = λv`; symmetric ⇒ real λ, orthogonal v; largest |λ| dominates repeated products.
