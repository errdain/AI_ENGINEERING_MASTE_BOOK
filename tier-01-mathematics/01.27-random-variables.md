# 1.27 Random variables

**Metadata** — Tier: 1 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: Medium-High · Hands-on: High
Prerequisites: 1.26 · Leads to: 1.28–1.32, sampling, noise, stochastic training

### 1. What is it?
A function `X: Ω → ℝ` that maps each outcome of a random experiment to a number. We then ask questions like `P(X = 3)` or `P(X ≤ 2)`.

### 2. Why does it exist?
Outcomes (a coin face, a word, an image) are not numbers. A random variable converts them to numbers so we can compute averages, spreads and distributions.

### 3. Detailed explanation
- **Discrete** (countable values: die roll, token id) vs **continuous** (real values: height, noise).
- A model's input features, labels, activations under dropout, and sampled tokens can all be viewed as random variables.
- **i.i.d.** (independent and identically distributed) samples: each draw independent, same distribution. Standard assumption behind training/test generalization, and often violated (time series, user sessions, duplicated documents → leakage).
- **Law of large numbers:** the sample mean converges to the true mean as samples grow.
- **Randomness in code:** use a seeded generator (`np.random.default_rng(seed)`) for reproducibility; the same seed gives the same samples (tested). Seeds do not guarantee bitwise reproducibility across devices or frameworks in GPU training.

### 4. How does it work?
Define the outcome → number mapping, then describe its distribution (1.28). Multiple variables can be related through joint distributions, covariance (1.32) and conditional probability (1.33).

### 5. Simple example
Roll two dice; `X` = sum. `X` takes values 2…12 with unequal probabilities.

### 6. Technical example
Mini-batch loss is a random variable (depends on which examples are drawn); its expectation is the full-data loss (1.29), which is why SGD works. Dropout masks and sampled tokens are random variables.

### 7. Code
```python
import numpy as np
rng = np.random.default_rng(0)
rolls = rng.integers(1, 7, size=200_000)      # X: die roll
print(rolls.mean())                           # ≈ 3.5 (law of large numbers)
same = np.random.default_rng(0).integers(1, 7, size=200_000)
assert (rolls == same).all()                  # seeded => reproducible
```
TESTED (`test_law_of_large_numbers_die`).

### 8. Input → Process → Output
`random experiment → map outcome to number → X with a distribution`

### 9. Enterprise use case
Latency per request is a random variable; SLOs are statements about its distribution (p50/p95/p99), not its single values.

### 10. AI engineering connection
Stochastic gradient descent, dropout, data augmentation, LLM decoding (temperature/top-k/top-p sampling), evaluation noise across seeds.

### 11. Advantages
Lets us reason about averages, spread, tails and uncertainty with one formalism.

### 12. Limitations
The true distribution is unknown; estimates from finite samples are noisy.

### 13. Trade-offs
More samples reduce estimation noise (error ∝ 1/√n) at linear cost.

### 14. Common mistakes
Treating one sample as the truth (single-seed results); assuming i.i.d. with correlated data (train/test leakage); not seeding or logging seeds; reporting mean without spread.

### 15. Performance / cost
Monte-Carlo accuracy improves as `1/√n`: 100× more samples for 10× less error.

### 16. Security
Weak or predictable RNGs are a security issue when randomness protects something (tokens, keys); use a cryptographic RNG (`secrets`), not `numpy` or `random`, for security purposes.

### 17. Interview explanation
"A random variable assigns numbers to random outcomes so we can talk about their distribution, mean and variance. In ML, the mini-batch loss, sampled tokens and dropout masks are random variables, and I report results over several seeds because a single run is just one draw."

### 18. Rapid-fire
A random variable maps outcomes to numbers; discrete or continuous; i.i.d. is an assumption.

### 19. Interview questions
- Basic: Discrete vs continuous random variable?
- Intermediate: What does i.i.d. mean and when does it fail?
- Advanced: State the law of large numbers. Why is SGD's mini-batch gradient an unbiased estimate?
- Scenario: Two model versions differ by 0.4% accuracy on one seed. How do you decide which is better?
