# 1.25 Chain rule

**Metadata** — Tier: 1 · Phase: 1 · Priority: P0 · Difficulty: 3/5 · Interview: Very high · Hands-on: Very high
Prerequisites: 1.20–1.24 · Leads to: Tier 3 Backpropagation, Tier 4 vanishing/exploding gradients

### 1. What is it?
The rule for differentiating a composition. If `y = g(u)` and `u = f(x)`:

`dy/dx = (dy/du)(du/dx)`

Multivariable form with Jacobians: `J_{g∘f}(x) = J_g(f(x)) · J_f(x)`.

### 2. Why does it exist?
Networks are compositions of many functions (1.20). The chain rule lets us get the derivative of the whole from the derivatives of each small part. Backpropagation *is* the chain rule applied efficiently.

### 3. Detailed explanation
- Local derivatives multiply along the path. If one factor is ≈ 0 the whole product vanishes; if factors are > 1 it explodes. Example: a sigmoid has `σ′ ≤ 0.25`; ten sigmoid layers contribute at most `0.25¹⁰ ≈ 9.5×10⁻⁷`.
- When a variable affects the output via several paths, **sum** the path contributions (e.g., a shared weight, a residual connection `x + F(x)` gives `1 + F′`, which keeps a gradient path alive).
- Reverse-mode autodiff: do a forward pass storing intermediates, then walk backward multiplying local derivatives with the upstream gradient.
- Worked example (2-layer net, scalar output): `z₁ = W₁x`, `a₁ = tanh(z₁)`, `ŷ = W₂·a₁`, `L = (ŷ − y)²`.
  `dL/dŷ = 2(ŷ−y)` → `dL/dW₂ = dL/dŷ · a₁` → `dL/da₁ = dL/dŷ · W₂` → `dL/dz₁ = dL/da₁ ⊙ (1 − a₁²)` → `dL/dW₁ = dL/dz₁ xᵀ`.

### 4. How does it work?
Each node stores its inputs. Backward: receive upstream gradient, multiply by the node's local derivative (or Jacobian-vector product), pass downstream, accumulate over multiple uses.

### 5. Simple example
Gear train: if gear A turns 2× per B-turn and B 3× per C-turn, A turns 6× per C-turn.

### 6. Technical example
The code below is a manual backprop of the worked example. Its gradients match central finite differences to ~1e-6, which is the standard gradient check.

### 7. Code
```python
import numpy as np
from calculus_prob import tiny_net_forward_backward, numerical_gradient
rng = np.random.default_rng(7)
x, y = rng.standard_normal(3), 0.7
W1, W2 = rng.standard_normal((4, 3)), rng.standard_normal(4)
loss, dW1, dW2 = tiny_net_forward_backward(x, W1, W2, y)
num_dW2 = numerical_gradient(lambda w: tiny_net_forward_backward(x, W1, w, y)[0], W2)
print(np.allclose(dW2, num_dW2, atol=1e-6))    # True
```

### 8. Input → Process → Output
`forward: store intermediates → backward: upstream grad × local derivative → gradients for all parameters`

### 9. Enterprise use case
Gradient checking is a standard unit test when implementing custom layers/ops in an internal ML framework.

### 10. AI engineering connection
Backpropagation, autograd, custom CUDA ops (must supply their backward), gradient checkpointing (recompute activations on the backward pass to trade compute for memory), and residual connections (additive gradient path).

### 11. Advantages
Modular: add a layer by writing only its local derivative.

### 12. Limitations
Requires storing activations (memory); multiplicative accumulation causes vanishing/exploding gradients; non-differentiable steps (argmax, sampling, rounding) break the chain.

### 13. Trade-offs
Store activations (fast, memory-hungry) vs recompute (slower, saves memory); straight-through estimators or REINFORCE for non-differentiable steps.

### 14. Common mistakes
Forgetting to sum over multiple paths; wrong order in matrix chain rule (transposes!); applying activation derivative at the wrong point (use the pre- or post-activation consistently); detaching tensors unintentionally.

### 15. Performance / cost
Backward ≈ 2× forward FLOPs; peak memory is dominated by stored activations, which is why activation checkpointing and smaller batches exist.

### 16. Security
N/A beyond gradient leakage (see 1.23).

### 17. Interview explanation
"The chain rule says the derivative of a composition is the product of the local derivatives along the path. Backprop is just that: run forward and store things, then multiply local derivatives backward. If those local factors are small the gradient vanishes, which is why we use ReLU, good initialization, normalization and residual connections."

### 18. Rapid-fire
d(g∘f) = g′(f)·f′; backprop = chain rule backwards; sum over paths, multiply along them.
