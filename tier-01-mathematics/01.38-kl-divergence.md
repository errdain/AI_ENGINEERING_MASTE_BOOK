# 1.38 KL divergence

**Metadata** — Tier: 1 · Phase: 1 · Priority: P0 · Difficulty: 3/5 · Interview: High · Hands-on: Medium
Prerequisites: 1.36, 1.37 · Leads to: VAEs, distillation, RLHF/PPO/DPO (Tier 10), drift detection

### 1. What is it?
Kullback–Leibler divergence from `q` to `p`:

`KL(p ‖ q) = Σ p(x) log (p(x)/q(x)) = H(p, q) − H(p)`

The extra surprise (bits/nats) paid for using `q` when the truth is `p`.

### 2. Why does it exist?
We need a way to say how different two distributions are, one that is zero only when they match and works with likelihood-based training.

### 3. Detailed explanation
- `KL ≥ 0`, and `KL = 0 ⇔ p = q` (Gibbs). Tested.
- **Not symmetric:** `KL(p‖q) ≠ KL(q‖p)`. Example: `p=[.5,.5]`, `q=[.9,.1]` gives 0.737 bits one way and 0.531 the other (tested). Not a metric (no triangle inequality).
- **Infinite** if `q(x)=0` where `p(x)>0` (tested); terms with `p(x)=0` contribute 0.
- **Direction matters:**
  - *Forward* `KL(p‖q)` (data → model) is what MLE minimizes; it is **mass-covering**: `q` is punished for missing any region where `p` has mass.
  - *Reverse* `KL(q‖p)` is **mode-seeking**: `q` may collapse onto one mode of `p`. Variational inference uses this direction.
- Closed form for two Gaussians exists (used in VAEs: KL between the encoder posterior and a standard normal).
- **In RLHF/PPO:** a KL penalty keeps the tuned policy near the reference model. **Distillation** minimizes KL from teacher to student. **Drift detection** compares feature distributions.
- Jensen–Shannon divergence is a symmetric, bounded smoothing of KL. Estimation from samples requires care (binning, smoothing, epsilons).

### 4. How does it work?
Compare log-ratios, weighted by `p`. Compute in log space to avoid zero/underflow issues.

### 5. Simple example
Using a map of another city to navigate: the extra detours are the KL cost.

### 6. Technical example
During RLHF, each token's penalty `β·log(π_θ(a|s)/π_ref(a|s))` is a sample estimate of the KL between the tuned and reference policies.

### 7. Code
```python
from info_numerics import kl_divergence
p, q = [0.5, 0.5], [0.9, 0.1]
print(kl_divergence(p, q), kl_divergence(q, p))        # 0.737  0.531 bits (asymmetric)
print(kl_divergence([0.5, 0.5], [1.0, 0.0]))           # inf
print(kl_divergence([1.0, 0.0], [0.5, 0.5]))           # 1.0
```
TESTED: non-negativity, zero at equality, asymmetry, infinity, decomposition.

### 8. Input → Process → Output
`p, q → Σ p log(p/q) → non-negative asymmetric "cost of using q instead of p"`

### 9. Enterprise use case
Data drift monitors compare today's feature (or prediction) distribution with a training baseline using KL/JS/PSI and alert past a threshold.

### 10. AI engineering connection
VAE loss, knowledge distillation, RLHF/PPO KL penalty, DPO's implicit KL constraint, comparing model outputs before and after quantization or fine-tuning.

### 11. Advantages
Principled, differentiable, tied to likelihood.

### 12. Limitations
Asymmetric, unbounded, infinite with disjoint support; sample estimates are noisy and sensitive to binning; says nothing about *which* differences matter to users.

### 13. Trade-offs
KL (sensitive, likelihood-linked) vs JS (symmetric, bounded) vs Wasserstein (respects geometry, harder to compute).

### 14. Common mistakes
Swapping the arguments; calling KL a "distance"; forgetting smoothing so a single zero bin yields infinity; mixing logs of different bases; using unnormalized inputs.

### 15. Performance / cost
`O(K)` per distribution. In RLHF, per-token log-ratios cost an extra forward pass of the reference model.

### 16. Security
Drift alarms on KL can be evaded by gradual shifts (below threshold per window). Track cumulative drift as well.

### 17. Interview explanation
"KL divergence measures the extra surprise from using a model q when the truth is p. It's zero only when they match, but it's asymmetric, so it isn't a distance. Training with cross-entropy is minimizing the forward KL to the data, and in RLHF we add a KL penalty to stay close to the reference model."

### 18. Rapid-fire
KL(p‖q)=Σp log(p/q) ≥ 0; asymmetric; ∞ if q=0 where p>0; CE = H + KL.
