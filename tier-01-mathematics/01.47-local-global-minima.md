# 1.47 Local and global minima (intuition)

**Metadata** — Tier: 1 · Phase: 1 · Priority: P1 · Difficulty: 2/5 · Interview: High · Hands-on: Medium
Prerequisites: 1.23, 1.45, 1.46 · Leads to: Tier 4 training and optimization, initialization, ensembling, multiple restarts

### 1. What is it?
- **Local minimum:** a point where the loss is lower than at all nearby points (gradient zero, curvature up in every direction).
- **Global minimum:** the lowest loss over the entire parameter space.

### 2. Why does it matter?
Gradient descent only sees the local slope, so it finds *a* minimum near where it started, not necessarily the best one. Understanding this explains seed-to-seed variation, the value of good initialization, and why we compare multiple runs.

### 3. Detailed explanation
- For the double-well `f(x) = x⁴ − 3x² + x`, gradient descent from `x=−2` converges to `x ≈ −1.30` (global minimum), but from `x=+2` it converges to `x ≈ 1.13` (a worse local minimum). Both stop with gradient ≈ 0, so *from the optimizer's view both look converged* (tested: `f(−1.30) < f(1.13)`).
- The starting point (initialization) decides which basin you fall into. Learning rate and noise can hop between basins.
- **Convex problems:** local = global (1.45). **Deep networks:** many local minima exist, but in practice:
  - Many local minima have loss values close to the global one (empirical and theoretical results in overparameterized settings; REVIEW_REQUIRED for precise statements).
  - Many apparent "stuck" cases are actually saddles, plateaus or bad hyperparameters (1.46).
- **The global minimum of the training loss isn't the goal.** A model that drives training loss to zero can overfit; we want low *generalization* error. Early stopping, regularization, and flat-minimum preferences matter more than hitting the exact global minimum.
- First-order test `∇f = 0` finds critical points only. Second-order test (Hessian eigenvalues, 1.18) distinguishes min (all > 0), max (all < 0), saddle (mixed).
- Practical strategies: random restarts and picking the best on validation, ensembling several runs, SGD noise, learning-rate schedules with restarts (cosine with warm restarts), better initialization, larger models.
- **Non-uniqueness:** equivalent minima from symmetry (neuron permutations), so "which minimum" can be a meaningless question about parameters even when the function is identical.

### 4. How does it work?
Think of basins of attraction: all starting points that roll into the same minimum under gradient descent. Basin sizes differ; step size and noise change which basin you land in.

### 8. Input → Process → Output
`init θ₀ → follow −∇L → basin → local (or global) minimum → performance depends on which`

### 9. Enterprise use case
Model-selection pipelines run multiple seeds/restarts, track the variance, and pick or ensemble; "one lucky seed" results are rejected in review.

### 10. AI engineering connection
Initialization schemes, seeds and reproducibility, ensembling, learning-rate restarts, checkpoint averaging (weight averaging often lands in flatter regions), why fine-tuning from pretrained weights beats random init.

### 11. Advantages (of the viewpoint)
Explains run-to-run variance and motivates restarts/ensembles.

### 12. Limitations
1-D intuition misleads in high dimensions; no practical way to certify global optimality for deep nets.

### 13. Trade-offs
More restarts/ensembles: better and more robust results at higher compute. Pretrained initialization: much better starting basin, but inherits its biases.

### 14. Common mistakes
Equating "gradient is zero" with "best possible"; judging a method from a single seed; blaming local minima for generic training problems; chasing zero training loss.

### 15. Performance / cost
Each restart costs a full training run; cheaper alternatives are checkpoint averaging, snapshot ensembles, and warm restarts.

### 16. Security
Backdoored or poisoned pretrained initializations bias fine-tuning toward bad basins; verify provenance of pretrained weights.

### 17. Interview explanation
"A local minimum is lower than its neighbours; the global minimum is the lowest overall. Gradient descent only follows local slope, so where you start decides which basin you end in. For convex problems that doesn't matter, but in deep nets I run multiple seeds, use good initialization or pretrained weights, and care more about validation performance than about reaching the exact global minimum."
