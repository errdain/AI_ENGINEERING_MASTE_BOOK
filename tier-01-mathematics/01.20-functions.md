# 1.20 Functions

**Metadata** — Tier: 1 · Phase: 1 · Priority: P0 · Difficulty: 1/5 · Interview: Medium · Hands-on: High

### 1. What is it?
A rule `f: X → Y` that assigns each input in the domain `X` exactly one output in the codomain `Y`. Inputs and outputs may be scalars, vectors or tensors: `f: ℝⁿ → ℝᵐ`.

### 2. Why does it exist?
It is the vocabulary for "a thing that transforms inputs into outputs". A model, a layer, an activation, a loss and a metric are all functions.

### 3. Detailed explanation
- **Composition:** `(g ∘ f)(x) = g(f(x))`. A neural network is a long composition of simple functions.
- **Linear** `f(ax+by) = af(x)+bf(y)` vs **nonlinear**. A stack of linear layers collapses into one linear layer (`W₂(W₁x) = (W₂W₁)x`), so without nonlinear activations depth adds nothing.
- **Scalar-valued** (`ℝⁿ → ℝ`, e.g. a loss) vs **vector-valued** (`ℝⁿ → ℝᵐ`, e.g. a layer).
- Useful properties: monotonic, bounded, smooth (differentiable), invertible, convex (1.45).
- **Parameters vs inputs:** `f(x; θ)`. Training changes `θ` with `x` fixed; inference does the opposite.
- In code, prefer *pure* functions (same input, same output, no hidden state) for testability; randomness and state must be explicit.

### 4. How does it work?
Evaluate the rule on the input. Common ML functions: linear `Wx+b`, ReLU `max(0,x)`, sigmoid `1/(1+e⁻ˣ)` (range (0,1)), tanh (range (−1,1)), softmax (vector → probability vector), loss `L(ŷ, y) → ℝ`.

### 5. Simple example
A vending machine: money + button in, snack out.

### 6. Technical example
`ŷ = softmax(W₂ · ReLU(W₁x + b₁) + b₂)` is a composition of five functions; the loss `L(ŷ, y)` sits on the end.

### 7. Code
```python
import numpy as np
rng = np.random.default_rng(7)
x = rng.standard_normal(5)
W1, W2 = rng.standard_normal((4, 5)), rng.standard_normal((3, 4))
relu = lambda v: np.maximum(v, 0)
np.allclose(W2 @ (W1 @ x), (W2 @ W1) @ x)        # True: linear layers collapse
np.allclose(W2 @ relu(W1 @ x), (W2 @ W1) @ x)    # False: ReLU breaks the collapse
```

### 8. Input → Process → Output
`x ∈ domain → f(x; θ) → y ∈ codomain`

### 9. Enterprise use case
Feature transformations in a pipeline are functions; versioning them (and keeping them pure) makes training and serving consistent and avoids training/serving skew.

### 10. AI engineering connection
Layers, activations, losses, metrics, tokenizers and even tools in an agent ("function calling") are functions with typed inputs/outputs.

### 11. Advantages
Compositional: complex behaviour from simple parts, each testable.

### 12. Limitations
A function maps each input to one output; one-to-many behaviour (sampling) needs randomness modelled explicitly (1.27).

### 13. Trade-offs
Deeper composition = more expressive but harder to optimize and debug.

### 14. Common mistakes
Forgetting nonlinearity between layers; confusing the domain (e.g., softmax is defined over a vector, not a scalar); hidden global state or randomness in "functions".

### 15. Performance / cost
Cost of a composition is the sum of its parts; activation memory for backprop grows with depth.

### 16. Security
Treat every function exposed to a model (tool/function call) as an untrusted-input boundary: validate arguments.

### 17. Interview explanation
"A function maps inputs to outputs. A neural network is just a big composition of simple functions — linear maps and nonlinearities — with a loss function at the end. The nonlinearities matter because stacked linear maps would collapse into a single linear map."

### 18. Rapid-fire
A function maps each input to one output; networks are compositions; nonlinearity prevents collapse.
