# 1.43 Log-sum-exp

**Metadata** — Tier: 1 · Phase: 1 · Priority: P0 · Difficulty: 3/5 · Interview: High · Hands-on: Very high
Prerequisites: 1.41, 1.42, 1.39 · Leads to: stable softmax and cross-entropy, CTC/HMM/CRF, flash-attention's online softmax

### 1. What is it?
`LSE(x₁…xₙ) = log Σ exp(xᵢ)`. A smooth approximation of `max`:

`max(x) ≤ LSE(x) ≤ max(x) + log n`

### 2. Why does it exist?
Adding probabilities that are stored as log-probabilities requires `log(exp(a) + exp(b))`. Computing that directly overflows or underflows. The log-sum-exp trick computes it safely.

### 3. Detailed explanation
**The trick:** let `m = max(x)`. Then

`LSE(x) = m + log Σ exp(xᵢ − m)`

All exponents are ≤ 0, so no overflow, and at least one term equals 1, so the sum is ≥ 1 and there's no underflow to `log 0`. Verified: `LSE([1000,1000]) = 1000 + ln 2`; `LSE([−1000,−1000]) = −1000 + ln 2`; naive formulas give `inf` and `−inf` (tested).

Consequences:
- **Stable log-softmax:** `log softmax(z)ᵢ = zᵢ − LSE(z)`. Softmax is `exp` of that. Shift invariance follows (tested).
- **Cross-entropy from logits:** `−z_y + LSE(z)` (1.37). Extreme logits `[−1000, 1000]` → finite loss 2000 (tested).
- **Edge case:** all `−inf` input → `m = −inf`; implementation replaces `m` with 0 so the result is `−inf` (a correct `log 0`), not NaN (tested).
- **Smooth max / soft-min** (temperature version `T·LSE(x/T)`) appears in contrastive losses (InfoNCE) and in "soft" dynamic programming.
- **Gradient of LSE is softmax:** `∂LSE/∂xᵢ = softmax(x)ᵢ`. This is why softmax and LSE are twin concepts.
- Dynamic programming over sequences with probabilities (HMM forward algorithm, CTC loss, CRF partition function) runs in log space using LSE.
- **Online/streaming version:** keep a running max and a rescaled running sum; this is the idea inside fused attention kernels, avoiding a second pass over scores.

### 4. How does it work?
Find the max, subtract, exponentiate, sum, log, add the max back. Vectorized along an axis with `keepdims` for broadcasting (1.7).

### 5. Simple example
Combining two very unlikely events with probabilities `e⁻¹⁰⁰⁰` and `e⁻¹⁰⁰¹`: factor out the larger one, then add the ratio `1 + e⁻¹`.

### 6. Technical example
CTC loss sums over all alignments of a transcript; the sum of tiny alignment probabilities is done with LSE at every dynamic-programming step.

### 7. Code
```python
import numpy as np
from info_numerics import logsumexp, log_softmax
print(logsumexp(np.array([1000.0, 1000.0])), 1000 + np.log(2))     # 1000.693 both
print(np.log(np.sum(np.exp([1000.0, 1000.0]))))                    # inf  (naive fails)
print(logsumexp(np.array([-np.inf, -np.inf])))                     # -inf
z = np.array([1000.0, 1001.0, 1002.0]); print(np.exp(log_softmax(z)))   # [0.09 0.2447 0.6652]
```
TESTED: agreement with naive when safe, extreme positive/negative inputs, all −inf row, softmax shift invariance.

### 8. Input → Process → Output
`values (maybe huge) → subtract max → exp → sum → log → add max`

### 9. Enterprise use case
Any scoring system that aggregates probabilities across many hypotheses or segments (speech recognition decoding, sequence labeling) depends on LSE-based dynamic programming.

### 10. AI engineering connection
Stable softmax/cross-entropy/log-softmax in every framework (`torch.logsumexp`, `log_softmax`), contrastive losses, sequence models, flash-attention.

### 11. Advantages
Exact (not approximate) result with stable arithmetic; differentiable.

### 12. Limitations
Two passes over the data unless online variant is used; `−inf` handling needs care; not a hard max (bias up to `log n`).

### 13. Trade-offs
Exact LSE vs approximating `max` (Viterbi) for speed when the soft sum isn't needed.

### 14. Common mistakes
`np.log(np.sum(np.exp(x)))`; subtracting a max across the wrong axis (mixing batch rows); missing `keepdims` so broadcasting misaligns; NaN from `−inf − (−inf)`; computing softmax then log.

### 15. Performance / cost
One extra reduction (max) per row; fused kernels remove extra memory traffic. For vocab 100k × batch tokens this is a key memory/time item in the loss.

### 16. Security
N/A beyond NaN/Inf validation of untrusted numeric inputs.

### 17. Interview explanation
"Log-sum-exp computes the log of a sum of exponentials without overflow by factoring out the maximum: max plus log of the sum of exp(x minus max). It's how softmax and cross-entropy are implemented stably, and its gradient is exactly the softmax."

### 18. Rapid-fire
LSE = m + log Σ exp(x−m); smooth max; gradient = softmax; cross-entropy = −z_y + LSE(z).
