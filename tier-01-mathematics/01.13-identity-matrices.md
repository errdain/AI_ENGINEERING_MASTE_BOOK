# 1.13 Identity matrices

**Metadata** — Tier: 1 · Phase: 1 · Priority: P1 · Difficulty: 1/5 · Interview: Low · Hands-on: Medium
Prerequisites: 1.3, 1.11 · Leads to: 1.14 Inverse, ridge regularization, residual connections

### 1. What is it?
The square matrix `I` with ones on the diagonal and zeros elsewhere. It is the "do nothing" transformation.

### 2. Why does it exist?
Every number system needs a neutral element. `I` is to matrix multiplication what `1` is to scalars; without it, "inverse" has no meaning.

### 3. Detailed explanation
`AI = IA = A` and `Ix = x` for any compatible `A`, `x`. `Iᵀ = I`, `I⁻¹ = I`, `I` has all eigenvalues equal to 1. Inverse is defined by `AA⁻¹ = I`.

### 4. How does it work?
`I[i, j] = 1 if i == j else 0`. `Iₙ` is `n×n`; for non-square products the left and right identities have different sizes.

### 5. Simple example
Multiplying by 1; a photo filter set to "no change".

### 6. Technical example
Ridge regression solves `(XᵀX + λI)w = Xᵀy`: adding `λI` makes the matrix invertible and stabilizes the solution. A residual block computes `x + F(x) = (I + F)x` in the linear case.

### 7. Code
```python
import numpy as np
from linalg_core import identity
A = np.random.default_rng(0).standard_normal((3, 3))
I = np.array(identity(3))
assert np.allclose(A @ I, A) and np.allclose(I @ A, A)   # np.eye(3) is the library form
```

### 8. Input → Process → Output
`x → I → x`

### 9. Enterprise use case
Regularization (`+λI`) is a standard fix in analytics/regression pipelines when features are collinear.

### 10. AI engineering connection
Residual connections, identity initialization, `λI` regularization/damping in optimizers (e.g., Levenberg–Marquardt, second-order methods).

### 11. Advantages
Simple, exactly representable, always invertible.

### 12. Limitations
Square only; adding `λI` biases the solution when `λ` is large.

### 13. Trade-offs
Larger `λ` → more stability, more bias.

### 14. Common mistakes
Using `np.ones` instead of `np.eye`; mismatched sizes (`I` must be `n×n` for the dimension it acts on).

### 15. Performance / cost
Never materialize `I` just to multiply by it; it is a no-op. Dense `n×n` costs `O(n²)` memory.

### 17. Interview explanation
"The identity matrix leaves any vector unchanged. It matters because it defines the inverse, and because adding a small multiple of it to a nearly singular matrix, as in ridge regression, makes the problem solvable."

### 18. Rapid-fire
Ones on the diagonal; `AI = IA = A`; defines inverses; `+λI` stabilizes.
