# 1.32 Covariance

**Metadata** — Tier: 1 · Phase: 1 · Priority: P0 · Difficulty: 3/5 · Interview: High · Hands-on: High
Prerequisites: 1.18, 1.29, 1.30 · Leads to: PCA (Tier 2), whitening, Gaussian models, embedding analysis

### 1. What is it?
A measure of how two variables vary *together*:

`Cov(X, Y) = E[(X − μ_X)(Y − μ_Y)] = E[XY] − E[X]E[Y]`

For a dataset with `d` features, the **covariance matrix** `C` (`d×d`) holds `Cov(feature i, feature j)`; its diagonal is the variances. **Correlation** rescales covariance to `[−1, 1]`: `ρ = Cov(X,Y)/(σ_X σ_Y)`.

### 2. Why does it exist?
Variance describes one variable. Real data has many variables that move together (height–weight, neighbouring pixels, embedding dimensions). Covariance captures those linear relationships and defines the shape of a data cloud.

### 3. Detailed explanation
- `Cov > 0`: tend to rise together; `< 0`: one up, other down; `≈ 0`: no *linear* relationship.
- `Cov(X, X) = Var(X)`; `Var(X + Y) = Var(X) + Var(Y) + 2Cov(X, Y)`.
- Covariance depends on units; correlation does not (tested: scaling a column by 1000 leaves correlation unchanged).
- **Uncorrelated ≠ independent.** If `Y = X²` with symmetric `X`, then `Corr(X, Y) ≈ 0` yet `Y` is fully determined by `X` (tested). Correlation only detects *linear* dependence. And correlation is not causation.
- Matrix form with centered data `Xc (n×d)`: `C = XcᵀXc / (n − 1)`. `C` is symmetric and positive semi-definite, so it has real non-negative eigenvalues (1.18; tested).
- **PCA** = eigendecomposition of `C` (or SVD of `Xc`, 1.19): eigenvectors are principal directions, eigenvalues are variances along them.
- With `n < d` the sample covariance is rank-deficient (rank ≤ `n−1`) and not invertible; use shrinkage/regularization (`C + λI`, 1.13).

### 4. How does it work?
Center each feature, multiply `XcᵀXc`, divide by `n−1` (or `n`). Optionally divide by the outer product of standard deviations to get correlation.

### 5. Simple example
Ice-cream sales and temperature rise together (positive covariance); umbrella sales and sunshine move oppositely (negative).

### 6. Technical example
Embedding vectors often show strong correlation between dimensions (an anisotropic cloud); whitening with `C^(-1/2)` makes the cloud spherical. Multi-head attention and Gaussian priors also use covariance structure.

### 7. Code
```python
import numpy as np
from info_numerics import covariance_matrix, correlation_matrix
X = np.random.default_rng(11).standard_normal((200, 4))
C = covariance_matrix(X)                     # (4, 4), symmetric, PSD
assert np.allclose(C, np.cov(X, rowvar=False))
x = np.random.default_rng(0).standard_normal(200_000)
print(np.corrcoef(x, x**2)[0, 1])            # ≈ 0 although y is a function of x
```
TESTED: matches `np.cov`, symmetric and PSD, correlation bounded and scale-invariant, zero-variance feature rejected, uncorrelated-but-dependent example.

### 8. Input → Process → Output
`data (n,d) → center → XcᵀXc/(n−1) → covariance (d,d) → eigen/SVD → principal axes`

### 9. Enterprise use case
Feature-selection pipelines drop highly correlated features; portfolio/risk models use covariance matrices; monitoring tracks correlation drift between features.

### 10. AI engineering connection
PCA/whitening of embeddings, LayerNorm/BatchNorm statistics, Gaussian models, multicollinearity in linear models, analysis of embedding anisotropy, Fisher information and natural gradient (advanced).

### 11. Advantages
Compact summary of pairwise linear structure; closed-form, cheap.

### 12. Limitations
Linear only; sensitive to outliers; unstable when `n` is not much larger than `d`; `d×d` memory grows quadratically (4096² = 16.8M entries).

### 13. Trade-offs
Full covariance (expressive, `O(d²)`) vs diagonal (cheap, ignores correlation) vs low-rank + diagonal (compromise). Rank correlations (Spearman) handle monotone nonlinear relations robustly.

### 14. Common mistakes
Forgetting to center; `n` vs `n−1`; treating zero correlation as independence; reading correlation as causation; computing covariance across the wrong axis (`rowvar`); fitting statistics on test data (leakage).

### 15. Performance / cost
`O(n·d²)` time, `O(d²)` memory. For large `d`, use randomized/truncated SVD or streaming estimators.

### 16. Security
Covariance of embeddings can leak distributional information about training data; treat as sensitive when derived from private data.
