# 1.12 Matrix transpose

**Metadata** — Tier: 1 · Phase: 1 · Priority: P0 · Difficulty: 1/5 · Interview: Medium · Hands-on: Very high
Prerequisites: 1.3, 1.11 · Leads to: 1.14, 1.18, 1.19, Tier 7 (`QKᵀ`)

### 1. What is it?
`Aᵀ` flips a matrix over its diagonal: `(Aᵀ)[i, j] = A[j, i]`. Shape `(m, n)` becomes `(n, m)`.

### 2. Why does it exist?
To make shapes line up for products, and to relate rows to columns (e.g., dot products between all rows of one matrix and all rows of another).

### 3. Detailed explanation
Key identities: `(Aᵀ)ᵀ = A`; `(A+B)ᵀ = Aᵀ+Bᵀ`; `(AB)ᵀ = BᵀAᵀ` (order reverses). A matrix with `A = Aᵀ` is **symmetric** (covariance matrices, `AᵀA`). For real matrices, `AᵀA` is always symmetric and positive semi-definite.

### 4. How does it work?
Swap row and column indices. In NumPy/PyTorch, `.T` / `.transpose` returns a **view** (strides swapped, no data copy), so the result may be non-contiguous.

### 5. Simple example
Turning a table with students in rows and subjects in columns into subjects in rows and students in columns.

### 6. Technical example
`S = Q Kᵀ`: with `Q:(T,d)` and `K:(T,d)`, `Kᵀ:(d,T)` makes `S:(T,T)`, the matrix of all query–key dot products. PyTorch `Linear` stores `W:(out,in)` and computes `x Wᵀ`.

### 7. Code
```python
import numpy as np
from linalg_core import transpose_manual
A = np.arange(6.0).reshape(2, 3); B = np.arange(12.0).reshape(3, 4)
assert np.allclose(transpose_manual(A.tolist()), A.T)
assert np.allclose((A @ B).T, B.T @ A.T)     # order reverses
print(A.T.flags["C_CONTIGUOUS"])             # False: it is a view
```

### 8. Input → Process → Output
`(m,n) → swap indices → (n,m)`

### 9. Enterprise use case
Converting between row-major feature layouts expected by different libraries/serving formats.

### 10. AI engineering connection
Attention scores, normal equations (`XᵀX`), covariance, and backprop (gradient of `Y = XW` w.r.t. `W` is `Xᵀ·dY`) all use transposes.

### 11. Advantages
Free in most libraries (a view).

### 12. Limitations
Views can be non-contiguous; some ops (`view`) then fail or copy.

### 13. Trade-offs
Explicit `.contiguous()` costs memory/time but can speed later ops.

### 14. Common mistakes
Believing `(AB)ᵀ = AᵀBᵀ`; transposing a 1-D array (a no-op: shape `(n,)` stays `(n,)`); `.T` on tensors with >2 axes (use `transpose(axes)`/`permute` explicitly).

### 15. Performance / cost
O(1) as a view; O(mn) if materialized. Memory-bound.
