# 1.24 Jacobians

**Metadata** — Tier: 1 · Phase: 1 · Priority: P1 · Difficulty: 3/5 · Interview: Medium · Hands-on: Medium
Prerequisites: 1.3, 1.11, 1.23 · Leads to: 1.25 Chain rule, backprop (Tier 3), attention/softmax analysis

### 1. What is it?
For a vector-valued function `f: ℝⁿ → ℝᵐ`, the Jacobian is the `m×n` matrix of all first partial derivatives:

`J[i, j] = ∂fᵢ/∂xⱼ`

It is the best *linear* approximation of `f` near `x`: `f(x+δ) ≈ f(x) + J δ`.

### 2. Why does it exist?
Gradients (1.23) handle one output. Layers have many outputs, so we need a matrix describing how every output responds to every input.

### 3. Detailed explanation
- Gradient of a scalar function = its `1×n` Jacobian (as a row; usually written as a column).
- Linear map `f(x) = Ax` has `J = A` everywhere.
- Elementwise activation `f(x) = φ(x)` has a **diagonal** Jacobian `diag(φ′(x))`.
- Softmax `p = softmax(z)` has `J = diag(p) − ppᵀ`: symmetric, each column sums to 0 (because the outputs always sum to 1), and it is singular.
- Chain rule in matrix form: `J_{g∘f} = J_g(f(x)) · J_f(x)` (1.25).
- Practical rule: **never build full Jacobians for big layers.** An `n×n` Jacobian for `n = 4096` has 16.8M entries *per token*. Backprop instead computes **vector–Jacobian products** `vᵀJ`, which cost about as much as a forward pass.
- Forward-mode computes Jacobian–vector products `Jv` (cheap when inputs are few); reverse-mode computes `vᵀJ` (cheap when outputs are few, e.g. a scalar loss), hence reverse-mode in deep learning.

### 4. How does it work?
Row `i` = gradient of output `fᵢ`. Column `j` = how all outputs react to `xⱼ`. Numerical: perturb each input coordinate and difference the outputs.

### 5. Simple example
A map from (width, height) to (area, perimeter): a 2×2 matrix of sensitivities.

### 6. Technical example
Backward through a softmax layer: `dz = (diag(p) − ppᵀ) dp`, usually fused with cross-entropy into the simple `dz = p − y` (see 1.37).

### 7. Code
```python
import numpy as np
from calculus_prob import numerical_jacobian, softmax
A = np.random.default_rng(0).standard_normal((3, 4))
J = numerical_jacobian(lambda x: A @ x, np.ones(4))       # shape (3, 4), equals A
z = np.array([0.5, -1.0, 2.0, 0.0]); p = softmax(z)
Js = numerical_jacobian(softmax, z)
assert np.allclose(Js, np.diag(p) - np.outer(p, p), atol=1e-6)
```
TESTED: linear map `J=A`, elementwise `tanh` diagonal, softmax formula and zero column sums.

### 8. Input → Process → Output
`f: ℝⁿ→ℝᵐ, x → matrix of ∂fᵢ/∂xⱼ (m×n)`

### 9. Enterprise use case
Sensitivity/robustness analysis of multi-output models (e.g., how each risk score reacts to each input feature).

### 10. AI engineering connection
Backprop is repeated vector–Jacobian products; Jacobian norms measure layer stability and Lipschitz behaviour (spectral norm of weights); normalizing flows use Jacobian determinants.

### 11. Advantages
Complete first-order description of a multi-output function.

### 12. Limitations
Large (`m×n`); only local; first-order.

### 13. Trade-offs
Explicit Jacobian (debugging, small systems) vs matrix-free products (training).

### 14. Common mistakes
Shape errors (`m×n` vs `n×m`); materializing huge Jacobians; forgetting that elementwise ops give diagonal (cheap) Jacobians; confusing Jacobian (first derivatives, matrix) with Hessian (second derivatives, of a scalar).

### 15. Performance / cost
Full Jacobian: `m` backward passes (reverse mode) or `n` forward passes (forward mode). VJP: one backward pass.

### 16. Security
Input–output Jacobians quantify model sensitivity; they can guide adversarial attacks and model extraction. Limit access to gradients/Jacobians for deployed models.

### 17. Interview explanation
"The Jacobian is the matrix of partial derivatives for a function with vector output. It tells how each output reacts to each input. In backprop we never form it: we multiply a vector by it, a vector–Jacobian product, which is how one backward pass gets all gradients."

### 18. Rapid-fire
Jacobian = m×n derivative matrix; backprop uses vector–Jacobian products; softmax J = diag(p) − ppᵀ.
