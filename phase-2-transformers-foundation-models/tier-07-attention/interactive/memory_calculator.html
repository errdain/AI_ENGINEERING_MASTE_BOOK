Attention O(n²) memory & KV-cache calculator

Slide the sequence length and model shape: the naive score matrix grows quadratically, the KV cache linearly in n; GQA, sliding windows and FlashAttention each attack a different term.

Exact formulas: score matrix B·H·n² (one layer, materialised naively); KV cache 2·L·H_kv·d_h·n·B; attention FLOPs/layer ≈ 4·B·H·n²·d_h (QKᵀ and PV, multiply-add = 2 FLOPs, projections excluded). FlashAttention computes the same result in tiles and never stores the n×n matrix (memory O(n) for activations), but compute is still O(n²). The 80 GiB reference line is a typical size, not a claim about any device (REVIEW_REQUIRED per hardware).
