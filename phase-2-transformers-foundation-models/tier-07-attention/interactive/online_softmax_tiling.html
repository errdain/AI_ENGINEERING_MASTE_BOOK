Online softmax and tiled attention (the FlashAttention idea)

One query row, scores split into key tiles. The running max m, running denominator l and running numerator are rescaled after each tile. The final weights match the ordinary softmax exactly (up to rounding).

Bars = exp(score - running max) of the keys seen so far (tile boundaries as dashed lines). Faded bars are not yet processed.

The check row compares against the full softmax computed in one pass. The tiled version never needs all S scores at once: it keeps only (m, l, numerator) per query row. This reduces memory traffic, not the O(S) work per query.
