### 1. WHAT IS IT?

Scaled dot-product attention is the complete single-head operation:
`Attention(Q, K, V) = softmax(Q Kᵀ / √d_k + M) V`, where `M` is a mask (0 where allowed, −∞ where blocked).

### 2. WHY DOES IT EXIST?

It combines the pieces of 7.6–7.10 into one reusable primitive. Every attention variant in the book (self, cross, causal, multi-head, MQA/GQA, flash) is this formula with different inputs, masks or memory layout.

### 3. DETAILED EXPLANATION

Shapes for one head: `Q: T×d_k`, `K: S×d_k`, `V: S×d_v`, scores `T×S`, output `T×d_v`. Batched: `(B, H, T, d)`. Softmax is over the key axis. The formula is the whole mathematical content of attention; the rest of the tier is about *where Q, K, V come from*, *which pairs are allowed*, *how many heads*, and *how to compute it cheaply*.

### 4. HOW DOES IT WORK?

1. `scores = Q @ Kᵀ`
2. `scores = scores / √d_k`
3. `scores = where(mask, scores, −large)`
4. `weights = softmax(scores, axis=keys)`
5. `out = weights @ V`

### 5. SIMPLE EXAMPLE

For each reader: score every book label, turn scores into shares, read a blend. Repeat for all readers at once with matrices.

### 6. TECHNICAL EXAMPLE

PyTorch exposes the same operation as `torch.nn.functional.scaled_dot_product_attention(q, k, v, attn_mask=None, is_causal=False)` (verify signature against your installed version — `REVIEW_REQUIRED`).

### 7. CODE

```python
# 1. manual math, NumPy (../lab/attention_np.py)
def scaled_dot_product_attention(q, k, v, mask=None, scale=None):
    scores = (q @ np.swapaxes(k, -1, -2)) / np.sqrt(q.shape[-1])
    if mask is not None: scores = np.where(mask, scores, NEG)
    w = softmax(scores, axis=-1);  return w @ v, w

# 2. raw PyTorch: sdpa_manual in ../lab/attention_torch.py (masked_fill with -inf)
# 3. framework equivalent
out = torch.nn.functional.scaled_dot_product_attention(q, k, v, attn_mask=None, is_causal=False)
```
Verify equality yourself:

### 8. INPUT → PROCESS → OUTPUT

```
Q (T×d_k), K (S×d_k), V (S×d_v), mask (T×S)
   └► QKᵀ ─► ÷√d_k ─► +mask ─► softmax ─► ·V ─► out (T×d_v), weights (T×S)
```

### 9. ENTERPRISE USE CASE

Attention is the hot loop of LLM inference; teams profile it, choose fused kernels, and set context limits from its cost ([7.23 Attention complexity](07.23-attention-complexity.md), [7.25 FlashAttention](07.25-flashattention.md)).

### 10. AI ENGINEERING CONNECTION

This is the operation inside every Transformer layer (Tier 8); RAG context length, agent memory limits and serving cost all trace back to it.

### 11. ADVANTAGES

Direct token-to-token paths; parallel; one primitive reused everywhere; intermediate weights inspectable ([7.26 Attention visualization](07.26-attention-visualization.md)).

### 12. LIMITATIONS

n² time/memory (naive); no order information alone; weights ≠ explanation.

### 13. TRADE-OFFS

Expressiveness and parallelism versus quadratic cost.

### 14. COMMON MISTAKES

Scaling by `1/d_k`; softmax over the wrong axis (must be over **keys**, last axis); boolean mask polarity (True = *keep* in this book and PyTorch's boolean `attn_mask`; some libraries invert it); `−inf` on a fully masked row gives NaN ([7.17 Padding masks](07.17-padding-masks.md)).

### 15. PERFORMANCE / COST CONSIDERATIONS

Two matmuls: ≈ `4·B·H·n²·d_h` FLOPs per layer ([7.23 Attention complexity](07.23-attention-complexity.md)).

### 16. SECURITY CONSIDERATIONS

No privilege levels between tokens: prompt injection is possible at the architecture level; the mask is the only structural isolation ([7.16 Attention masks](07.16-attention-masks.md)).

### 17. INTERVIEW EXPLANATION

*"Scores are dot products of queries and keys, divided by √d_k so their variance stays about one regardless of head size, otherwise softmax saturates and gradients vanish. Softmax turns each row into weights; the output is those weights times the values. It's two matrix multiplies and a softmax."*

### 18. RAPID-FIRE ANSWER

`softmax(QKᵀ/√d_k + mask)V`.

### 19. INTERVIEW QUESTIONS

**Basic.** What do Q, K, V stand for and what is the formula?

**Intermediate.** Why √d_k and not d_k?

**Advanced.** Show scaling does not change the largest-weight key but changes peakedness; what happens to gradients when saturated?

**Scenario.** Training loss becomes NaN after switching to fp16. Which attention step do you suspect first, and how do you fix it?
