### 1. WHAT IS IT?

Sliding-window attention (introduction only): each query attends only to the previous `w` tokens (and itself).

### 2. WHY DOES IT EXIST?

To cut compute and bounded-memory cost for long sequences: pairs drop from ≈ n²/2 to ≈ n·w and the per-layer KV cache is bounded by `w`.

### 3. DETAILED EXPLANATION

Information can travel farther than `w` because stacking `L` layers gives a receptive field of roughly `L·w` (indirectly). Used in Longformer-style models and some LLMs (e.g. Mistral-7B reported a window mechanism — `REVIEW_REQUIRED`). Variants (dilated, global tokens, interleaving local/global layers) and full architectures are covered in Tier 12, not here. Streaming use needs sinks ([7.28 Attention sinks](07.28-attention-sinks.md)).

Explore window and sinks in [the mask explorer](../interactive/mask_explorer.html) and cost in [the memory calculator](../interactive/memory_calculator.html).

### 4. HOW DOES IT WORK?

1. Mask `j ≤ i − w` (plus the causal mask).
2. Keep only `w` K/V entries per layer.

### 5. SIMPLE EXAMPLE

Only listening to the last few sentences of a conversation.

### 6. TECHNICAL EXAMPLE

```python
from attention_np import sliding_window_mask
for w in (4, 8, 16):
    m = sliding_window_mask(64, w)
    print(w, int(m.sum()), "pairs vs", 64 * 65 // 2, "causal")
```

### 8. INPUT → PROCESS → OUTPUT

```
causal scores ─► keep only last w keys ─► softmax ─► output (cost ≈ n·w)
```

### 9. ENTERPRISE USE CASE

Long-document and streaming workloads with bounded memory.

### 10. AI ENGINEERING CONNECTION

Building block of efficient long-context LLMs (Tier 12).

### 11. ADVANTAGES

Cheaper; bounded memory.

### 12. LIMITATIONS

Direct long-range access lost; the `L·w` receptive-field argument is about information flow, not equal ability to retrieve a distant fact.

### 13. TRADE-OFFS

Cost versus global reach; needs sinks for streaming.

### 14. COMMON MISTAKES

Assuming a window equals full context; dropping sink tokens.

### 15. PERFORMANCE / COST CONSIDERATIONS

O(n·w) compute and O(w) cache per layer.

### 16. SECURITY CONSIDERATIONS

Hidden facts outside the window cannot be used; account for that in safety/guardrail instructions.

### 17. INTERVIEW EXPLANATION

*"Sliding-window attention lets each token attend only to the last w tokens, so cost is n·w and the cache is bounded; stacking layers extends the effective reach indirectly."*

### 18. RAPID-FIRE ANSWER

Attend only to the last w tokens: O(n·w).
