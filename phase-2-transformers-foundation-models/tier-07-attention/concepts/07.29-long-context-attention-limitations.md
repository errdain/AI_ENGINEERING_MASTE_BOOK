### 1. WHAT IS IT?

Long-context attention limitations: cost, position generalisation, usage quality and dilution problems that appear as context grows.

### 2. WHY DOES IT EXIST?

A big context window is a capacity, not a guarantee that the model uses it well; engineers must budget context rather than stuff it.

### 3. DETAILED EXPLANATION

* **Cost:** n² compute, linear-in-n cache and bandwidth per decode step ([7.23 Attention complexity](07.23-attention-complexity.md), [7.24 Attention memory requirements](07.24-attention-memory-requirements.md)).
* **Position generalisation:** models trained on short contexts degrade beyond the trained length unless positional methods are adapted (Tier 6; Tier 12 owns the variants).
* **Usage quality:** longer *capacity* ≠ better *use*; retrieval accuracy can depend on where evidence sits (e.g. "lost in the middle", Liu et al., 2023 — `REVIEW_REQUIRED`).
* **Dilution:** with many irrelevant tokens softmax spreads mass thinly over noise.
* **Security:** long contexts widen the prompt-injection surface.
* **Cost model:** billing and latency scale with prompt tokens; prefer retrieval and context budgeting (Tiers 17, 20).

### 4. HOW DOES IT WORK?

1. Estimate cost at target n.
2. Test retrieval accuracy by evidence position.
3. Decide: retrieval, summarisation, windows, or long-context model.

### 5. SIMPLE EXAMPLE

A very long meeting: everyone could speak, but important points get lost in the middle.

### 6. TECHNICAL EXAMPLE

Needle-in-a-haystack-style tests measure where in the prompt facts are recalled (`REVIEW_REQUIRED` for methodology).

### 13. TRADE-OFFS

Long context (simple) versus retrieval/windowing (cheaper, may lose recall).

### 14. COMMON MISTAKES

Assuming the advertised window is fully usable.

### 15. PERFORMANCE / COST CONSIDERATIONS

Latency and cost scale with prompt tokens.

### 16. SECURITY CONSIDERATIONS

Long contexts widen prompt-injection and "needle" attack surface.

### 17. INTERVIEW EXPLANATION

*"Long context is expensive and not automatically better: cost is quadratic, position generalisation can fail, evidence in the middle may be missed, and irrelevant tokens dilute attention. I'd budget context and use retrieval."*

### 18. RAPID-FIRE ANSWER

Capacity ≠ use: cost, position extrapolation, middle-loss, dilution.
