### 1. WHAT IS IT?

Attention visualization: plotting the weight matrix `W` (rows = queries, columns = keys), per layer and head, often annotated with token strings.

### 2. WHY DOES IT EXIST?

To debug (is the model attending to padding or the wrong document?) and to build intuition about learned behaviour.

### 3. DETAILED EXPLANATION

Return the weights from the attention function and plot with `imshow`. Causal heatmaps show a triangle; averaging heads blurs distinct patterns. Attention weights show where **values were read from at one layer and head**; the output then passes through `W_o`, residuals, MLPs and later layers. Research debated whether attention weights are explanations (`REVIEW_REQUIRED`: see "Attention is not explanation" and replies). Use heatmaps to **debug**, not as proof of reasoning.

### 4. HOW DOES IT WORK?

1. Run attention with weights returned.
2. Pick layer/head.
3. Plot `weights[head]` with token labels.

### 5. SIMPLE EXAMPLE

A heat map of where a reader's eyes rested on a page.

### 6. TECHNICAL EXAMPLE

Debug checks: weight on PAD should be 0; first-token mass shows sinks ([7.28 Attention sinks](07.28-attention-sinks.md)).

### 7. CODE

```python
import numpy as np
import matplotlib; matplotlib.use("Agg")
import matplotlib.pyplot as plt
from attention_np import scaled_dot_product_attention, causal_mask
rng = np.random.default_rng(0)
q, k, v = (rng.normal(size=(6, 8)) for _ in range(3))
_, w = scaled_dot_product_attention(q, k, v, causal_mask(6))
plt.imshow(w, cmap="Blues"); plt.xlabel("key"); plt.ylabel("query"); plt.colorbar(); plt.savefig("w.png")
```

### 9. ENTERPRISE USE CASE

### 11. ADVANTAGES

Cheap and intuitive.

### 12. LIMITATIONS

Not an explanation; layer/head scales differ.

### 13. TRADE-OFFS

Per-head detail versus readability.

### 14. COMMON MISTAKES

Averaging heads before plotting; comparing across layers as if same scale; ignoring the causal triangle; presenting weights as "why the model decided".

### 15. PERFORMANCE / COST CONSIDERATIONS

Storing all weights costs memory; extract selectively (flash kernels do not return weights).

### 16. SECURITY CONSIDERATIONS

Do not present attention maps as audit evidence of model reasoning.
