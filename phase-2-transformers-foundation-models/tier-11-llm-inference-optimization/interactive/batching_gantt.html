Static vs continuous batching (animated Gantt)

Same requests, same GPU slots. Static batching waits for the whole batch to finish before admitting new work; continuous batching refills a slot the moment its request ends. Each box = one request: thin light part = waiting in queue, solid = prefill + decode.
