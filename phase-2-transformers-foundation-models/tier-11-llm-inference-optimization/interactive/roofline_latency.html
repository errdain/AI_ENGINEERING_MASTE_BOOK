Memory-bound decode vs compute-bound prefill

Roofline: attainable FLOP/s = min(peak compute, bandwidth × arithmetic intensity). Decode reads every weight once per step for only a few FLOPs each, so it sits left of the ridge point (memory-bound); a long prefill reuses each weight across many tokens (compute-bound). Hardware presets are illustrative round numbers (REVIEW_REQUIRED).
