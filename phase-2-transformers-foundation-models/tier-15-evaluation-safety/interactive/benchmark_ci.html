Simulate a benchmark of n examples for two models. Models A and B err on mostly the same items (error overlap), so a paired bootstrap is far tighter than comparing two separate CIs. Click re-draw for a new random benchmark.

Histogram = bootstrap distribution of the paired difference (A−B). If the 95% interval excludes 0 the gap is reliable on this sample. Wilson/percentile intervals use the observed sample, so they vary with the seed.
