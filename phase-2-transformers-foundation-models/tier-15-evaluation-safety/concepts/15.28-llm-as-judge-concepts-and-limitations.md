### 1. WHAT IS IT?

LLM-as-judge uses a language model to grade or compare other models' outputs against a rubric or reference, as a scalable stand-in for human evaluation.

### 2. WHY DOES IT EXIST?

Human review does not scale to every change; judges are fast and cheap, but they have systematic biases that must be measured, not assumed away.

### 3. DETAILED EXPLANATION

Modes: single-answer scoring with a rubric, pairwise comparison, reference-guided grading.

Known biases (reported in the literature; sizes are model- and task-specific, REVIEW_REQUIRED):
- **Position bias**: preferring the first (or second) slot.
- **Verbosity bias**: preferring longer answers.
- **Self-preference**: favouring outputs from the same model family.
- Sensitivity to formatting, rubric wording, and to confident-sounding but wrong answers; weak at verifying hard facts or maths it cannot itself solve.

Controls: **swap order** and require agreement (report swap consistency), normalise or control length, use a different model family than the one being judged, give a clear rubric with examples, use reference answers where possible, calibrate against human labels (agreement or kappa with humans, [15.27 Human evaluation](15.27-human-evaluation.md)) on a sample and monitor it over time, and use judges for ranking and triage rather than as the sole safety authority.

The lab's `MockJudge` has injectable position and verbosity bias so you can see the effects without any API: Figure 8 shows swap consistency dropping and slot-1 win rate rising with position bias, and a worse-but-longer answer winning under verbosity bias.

### 4. HOW DOES IT WORK?

Rubric -> judge prompt -> run each pair in both orders -> aggregate with consistency check -> compare with human labels on a validation sample -> report judge-human agreement beside the result.

### 5. SIMPLE EXAMPLE

A restaurant critic who always prefers the bigger portion or whichever dish arrives first is a biased judge; swapping the order and checking for consistency exposes it.

### 6. TECHNICAL EXAMPLE

Illustrative: in a pairwise run, swap consistency 0.62 and slot-1 win rate 0.68 would indicate position bias; only the 62% consistent pairs are counted, the rest are called ties.

### 7. CODE

```python
# run inside lab/
from toy import MockJudge, swap_consistency
for pb in (0.0, 1.0, 3.0):
    cons, first = swap_consistency(MockJudge(position_bias=pb, seed=1), 0.65, 0.55, 100, 100, n=800)
    print(f"position bias {pb}: swap consistency {cons:.2f}, slot-1 win rate {first:.2f}")
print("verbosity bias: P(pick worse-but-longer A) =", round(MockJudge(0, 1.0).p_first(0.5, 0.6, 300, 100), 2))
```

### 8. INPUT → PROCESS → OUTPUT

```
pair (A, B) -> judge in order AB and BA -> consistent? count : tie -> win rate; compare with human sample
```

### 9. ENTERPRISE USE CASE

Teams use judges in CI for fast signal and humans for periodic calibration; a drop in judge-human agreement triggers re-calibration.

### 10. AI ENGINEERING CONNECTION

Underpins automated evaluation of RAG, agents and chat quality in Tier 30.

### 11. ADVANTAGES

- Scalable and cheap; consistent given a fixed prompt.

### 12. LIMITATIONS

- Biased; can be gamed; weak on hard verification; drifts when the judge model changes.

### 13. TRADE-OFFS

- Cost vs fidelity; stronger judge costs more.

### 14. COMMON MISTAKES

- Single-order comparisons.
- Same model judging itself.
- No human calibration.
- Changing the judge model mid-experiment.

### 15. PERFORMANCE / COST CONSIDERATIONS

Two calls per pair when swapping; batch and cache.

### 16. SECURITY CONSIDERATIONS

Judges can be manipulated by prompt injection inside the evaluated text; sanitise outputs and do not let judge output trigger actions.

### 17. INTERVIEW EXPLANATION

LLM-as-judge scales grading but has position, verbosity and self-preference biases. I swap order and report consistency, control length, use a different model family, supply rubrics and references, and validate against human labels on a sample, treating judge scores as estimates with measured agreement.

### 18. RAPID-FIRE ANSWER

Swap, control length, different family, calibrate to humans.
