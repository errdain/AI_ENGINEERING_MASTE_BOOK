## 15.4 Intrinsic vs extrinsic evaluation

- Difficulty: Beginner
- Interview Importance: High
- Hands-on Importance: Low

---

### 1. WHAT IS IT?

Intrinsic evaluation measures a model's internal property (for example perplexity on text). Extrinsic evaluation measures performance on a downstream task (for example answer accuracy).

### 2. WHY DOES IT EXIST?

Intrinsic metrics are cheap and available during training; extrinsic metrics reflect the actual goal. They do not always agree, so you need to know which question each answers.

### 3. DETAILED EXPLANATION

| | Intrinsic | Extrinsic |
|---|---|---|
| Example | perplexity ([15.5 Perplexity](15.05-perplexity.md)), loss | task accuracy ([15.9 Accuracy](15.09-accuracy.md)), F1 ([15.10 Precision/recall/F1 in model evaluation](15.10-precision-recall-f1-in-model-evaluation.md)) |
| Needs task labels | no | yes |
| Cost | cheap | moderate to high |
| Tracks the goal | loosely | directly |
| Use | training monitoring, tokenizer or architecture comparison on identical data | selection, release |

Caveat: perplexity is only comparable between models using the **same tokenizer and test text**, and lower perplexity does not guarantee better instruction following or safety.

### 4. HOW DOES IT WORK?

Monitor intrinsic metrics during pretraining (Tier 9) and run extrinsic suites at checkpoints and before release.

### 5. SIMPLE EXAMPLE

Intrinsic: a runner's resting heart rate. Extrinsic: the race time.

### 6. TECHNICAL EXAMPLE

A model with lower perplexity but trained without instruction data can still follow instructions worse than a higher-perplexity instruction-tuned model.

### 7. CODE

```python
# run inside lab/ -- intrinsic (perplexity) vs extrinsic (accuracy) on toy things
from toy import BigramLM
from metrics import perplexity, accuracy
lm = BigramLM("the cat sat on the mat the cat ran")
print("intrinsic: perplexity of 'the cat sat' =", round(perplexity(lm.token_nlls("the cat sat")), 2))
print("extrinsic: task accuracy =", accuracy([1, 0, 1, 1], [1, 0, 0, 1]))
```

### 8. INPUT → PROCESS → OUTPUT

```
intrinsic: text -> model -> token probabilities -> perplexity
extrinsic: task input -> model -> answer -> compare with label -> accuracy
```

### 9. ENTERPRISE USE CASE

Training teams watch loss/perplexity curves; product teams gate on task metrics.

### 10. AI ENGINEERING CONNECTION

Pretraining quality (Tier 9) is tracked intrinsically; alignment and applications (Tier 10, Tier 30) need extrinsic and behavioural measures.

### 11. ADVANTAGES

- Intrinsic is cheap and label-free.
- Extrinsic is goal-aligned.

### 12. LIMITATIONS

- Intrinsic can mislead about downstream quality.
- Extrinsic depends on dataset choice and scorer.

### 13. TRADE-OFFS

- Cost and speed vs goal-alignment.

### 14. COMMON MISTAKES

- Comparing perplexities across tokenizers.
- Assuming lower perplexity means a better assistant.

### 15. PERFORMANCE / COST CONSIDERATIONS

Perplexity needs one forward pass; extrinsic suites need generation and scoring.

### 16. SECURITY CONSIDERATIONS

Neither detects safety failures; those need dedicated tests ([15.23 Harmful-output evaluation](15.23-harmful-output-evaluation.md)).

### 17. INTERVIEW EXPLANATION

Intrinsic metrics such as perplexity measure how well the model predicts text; extrinsic metrics measure task performance. I use intrinsic for fast training signals and architecture comparisons under identical conditions, and extrinsic for decisions.

### 18. RAPID-FIRE ANSWER

Intrinsic = how well it models text; extrinsic = how well it does the job.

### 19. INTERVIEW QUESTIONS

- **Basic:** Give one intrinsic and one extrinsic metric.
- **Intermediate:** Why can't you compare perplexity across tokenizers?
- **Advanced:** When can perplexity and downstream accuracy diverge?
- **Scenario:** Your new checkpoint has lower loss but worse task scores; what do you investigate?
