### 1. WHAT IS IT?

Precision, recall and F1 describe a classifier's errors separately: precision = TP/(TP+FP) (how many flagged items were right), recall = TP/(TP+FN) (how many true items were found), F1 = their harmonic mean.

### 2. WHY DOES IT EXIST?

Accuracy hides which kind of error occurs. Precision and recall make the false-positive versus false-negative trade-off explicit and let you set a threshold to match business costs.

### 3. DETAILED EXPLANATION

Confusion counts for the positive class: TP, FP, FN, TN.

- Precision = TP/(TP+FP). Recall = TP/(TP+FN). F1 = 2PR/(P+R), the harmonic mean, which is dragged toward the smaller value: P=1, R=0.1 gives F1 = 0.18, not 0.55.
- Moving the decision threshold slides along the PR curve: lower threshold raises recall, usually lowers precision (Figure 2).
- **Averaging for multiple classes**: macro (mean of per-class scores; each class equal), micro (pool counts; dominated by big classes), weighted (by support).
- Precision depends on the base rate; recall does not. A 90%-precise detector at 50% prevalence is much worse at 1% prevalence.
- In LLM use: hallucination detectors, toxicity classifiers, retrieval relevance (precision@k, recall@k) and PII filters are all evaluated this way.
- F-beta weights recall beta times as much as precision; choose beta from error costs.

Hand check: y=[1,1,1,0,0], pred=[1,1,0,1,0] gives TP=2, FP=1, FN=1, TN=1, so P=R=F1=2/3.

### 4. HOW DOES IT WORK?

Count the four outcomes, compute the ratios, sweep the threshold to get the PR curve, then pick the operating point from costs (for example, recall >= 0.95 at the best achievable precision).

### 5. SIMPLE EXAMPLE

A smoke alarm: high recall means it never misses a fire; high precision means it rarely rings for toast. You want to choose the balance deliberately.

### 6. TECHNICAL EXAMPLE

A PII filter on model outputs: missing PII (FN) is a privacy incident, flagging safe text (FP) is a nuisance. Set the threshold for recall >= 0.99 and accept lower precision; review the flagged items by hand.

### 7. CODE

```python
# run inside lab/
from metrics import prf1, pr_curve
y    = [1, 1, 1, 0, 0]
pred = [1, 1, 0, 1, 0]
m = prf1(y, pred)
print({k: round(v, 3) for k, v in m.items()})         # tp 2, fp 1, fn 1, tn 1, P=R=F1=0.667
scores = [0.9, 0.8, 0.4, 0.6, 0.1]
for t, p, r in pr_curve(y, scores): print(f"t>={t:.1f}  P={p:.2f}  R={r:.2f}")
```

Lab code: [`lab/metrics.py`](../lab/metrics.py).

### 8. INPUT → PROCESS → OUTPUT

```
scores + labels + threshold -> TP/FP/FN/TN -> precision, recall, F1 -> choose threshold from costs
```

### 9. ENTERPRISE USE CASE

Trust-and-safety teams set per-category thresholds and monitor precision on human-audited samples because precision shifts with traffic mix.

### 10. AI ENGINEERING CONNECTION

Used to evaluate detectors around LLMs (toxicity, PII, injection, hallucination) and retrieval (precision@k); Tier 32 builds guardrails from such detectors.

### 11. ADVANTAGES

- Exposes the FP/FN trade-off.
- Threshold-aware.
- Standard vocabulary.

### 12. LIMITATIONS

- Binary framing; F1 ignores TN and error costs; depends on base rate and threshold.

### 13. TRADE-OFFS

- Precision vs recall via threshold; macro vs micro averaging choices.

### 14. COMMON MISTAKES

- Reporting F1 without the threshold or base rate.
- Micro-averaging when rare classes matter.
- Computing precision on a re-balanced set and quoting it for production prevalence.

### 15. PERFORMANCE / COST CONSIDERATIONS

Cheap to compute; the cost is labelling enough positives.

### 16. SECURITY CONSIDERATIONS

Attackers probe the threshold; evaluate recall on adversarial positives too ([15.16 Adversarial testing](15.16-adversarial-testing.md)).

### 17. INTERVIEW EXPLANATION

Precision is the share of flagged items that are right; recall is the share of true items found; F1 is their harmonic mean. They trade off through the threshold, precision depends on prevalence, and the right operating point comes from error costs. I report per-class values, macro and micro averages and the PR curve.

### 18. RAPID-FIRE ANSWER

P = TP/(TP+FP), R = TP/(TP+FN), F1 harmonic; threshold slides along the PR curve.
