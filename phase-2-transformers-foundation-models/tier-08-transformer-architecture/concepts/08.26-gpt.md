### 1. WHAT IS IT?

**GPT** (Generative Pre-trained Transformer) is the decoder-only family from OpenAI that scaled the recipe: GPT-1 (2018), GPT-2 (2019), GPT-3 (2020) and later. GPT-2 is the template the lab follows.

### 2. WHY DOES IT EXIST?

It showed a decoder-only model pre-trained on next-token prediction transfers to many tasks, first by fine-tuning, then by prompting with scale.

### 3. DETAILED EXPLANATION

- GPT-2 small (`REVIEW_REQUIRED`): 12 layers, `d=768`, 12 heads, context 1024, vocabulary 50,257 (byte-level BPE), learned positions, GELU, Pre-LN-style placement with a final norm, tied embeddings, about 124 M parameters. The formula gives exactly **124,439,808** for this shape.
- GPT-3: 96 layers, `d=12288`, 96 heads, ~175 B parameters (`REVIEW_REQUIRED`).
- The lab's Mini-GPT keeps the structure with `d=96, L=3`: 345,792 parameters.

{fig('09_attention_maps_trained.png', 'Figure 9 - Attention maps of the Mini-GPT trained for 60 s: causal, with heads of different reach.')}

### 4. HOW DOES IT WORK?

1. Byte-pair tokens + learned positions. 2. Pre-LN decoder blocks with causal attention. 3. Final norm + tied head. 4. Next-token loss.

### 5. SIMPLE EXAMPLE

A very well-read autocomplete.

### 6. TECHNICAL EXAMPLE

Check: `count_params_formula` for the GPT-2 shape = 124,439,808, matching the widely quoted 124 M.

### 7. CODE

```python
from mini_gpt import GPTConfig, count_params_formula

gpt2_small = GPTConfig(vocab_size=50257, block_size=1024, n_layer=12, n_head=12, d_model=768)
n = count_params_formula(gpt2_small)
print(f"{n:,}")
assert n == 124_439_808
gpt3_shape = GPTConfig(vocab_size=50257, block_size=2048, n_layer=96, n_head=96, d_model=12288)
print(f"{count_params_formula(gpt3_shape)/1e9:.0f} B")      # ~175 B (REVIEW_REQUIRED vs published figure)
```

### 8. INPUT → PROCESS → OUTPUT

```
text -> BPE tokens -> embeddings+pos -> [Pre-LN causal block x12..96] -> final norm -> tied head -> next-token probs
```

### 9. ENTERPRISE USE CASE

GPT-family models underpin many commercial LLM products; open GPT-2-class models are used for small-scale experiments and teaching.
