### 1. WHAT IS IT?

The **original Transformer** is the 2017 encoder-decoder network from *Attention Is All You Need* (Vaswani et al.), built for machine translation. It is a stack of identical **encoder layers** and a stack of identical **decoder layers**. Attention is the only operation that mixes information across sequence positions: there is no recurrence and no convolution.

### 2. WHY DOES IT EXIST?

Recurrent networks (Tier 5) read tokens one at a time. Training cannot be parallelised across time, and a signal from token 1 to token 500 must survive 500 multiplications. Attention connects any two positions in a single step and is a handful of large matrix multiplications, which GPUs execute efficiently. The price is `O(T^2)` score computation (costs: Tier 7, Tier 11).

### 3. DETAILED EXPLANATION

**The base configuration** (numbers from the paper; `REVIEW_REQUIRED` against the original text): 6 encoder + 6 decoder layers, `d_model = 512`, 8 heads (`d_k = 64`), `d_ff = 2048`, ReLU, **Post-LN** (norm after the residual add), fixed **sinusoidal** positions, dropout 0.1, a shared source/target subword vocabulary with tied embeddings, about 65 M parameters. A "big" variant roughly doubles the width (`REVIEW_REQUIRED`).

**What an encoder layer is.** Bidirectional self-attention, then a position-wise FFN, each wrapped in `Norm(x + sublayer(x))`.

**What a decoder layer is.** *Masked* (causal) self-attention, then **cross-attention** whose queries come from the decoder and whose keys/values come from the encoder output, then an FFN; three residual-wrapped sub-layers.

**What changed since 2017** (each is its own concept in this tier): Post-LN became [8.12 Pre-LN](08.12-pre-ln.md); LayerNorm became [8.14 RMSNorm](08.14-rmsnorm.md) in many LLMs; ReLU became [8.15 GELU](08.15-gelu.md) / [8.16 SwiGLU](08.16-swiglu.md); sinusoidal positions became learned or RoPE ([Tier 6 — Tokenization & Embeddings](../../tier-06-tokenization-embeddings/README.md)); and the family split into encoder-only, decoder-only and encoder-decoder ([8.23 Encoder-only architecture](08.23-encoder-only-architecture.md), [8.25 Decoder-only architecture](08.25-decoder-only-architecture.md), [8.27 Encoder-decoder architecture](08.27-encoder-decoder-architecture.md)). Most modern LLMs keep only the decoder half.

### 4. HOW DOES IT WORK?

1. Source tokens -> embeddings (scaled by `sqrt(d_model)` in the paper) + positional encoding.
2. The encoder stack processes them with full self-attention and FFNs -> one contextual vector per source token (`memory`).
3. The decoder receives the shifted-right target tokens (teacher forcing in training), applies causal self-attention, then cross-attends to `memory`, then an FFN.
4. A final linear layer (tied with the embedding) plus softmax gives next-token probabilities; training uses cross-entropy against the unshifted target.
5. At inference the decoder runs autoregressively, one token at a time, while the encoder runs once.

### 5. SIMPLE EXAMPLE

Translating "the cat sleeps": the encoder reads the whole English sentence at once and builds a rich representation of each word in context. The decoder then writes the French sentence word by word, and at every step it can "look back" at the English words it finds most relevant (cross-attention).

### 6. TECHNICAL EXAMPLE

For the base model, parameters split roughly as: embeddings (shared) ~ `V*d`, each encoder layer ~ `12 d^2`, each decoder layer ~ `16 d^2` (extra `4 d^2` of cross-attention). The code below counts this for `d=512`, `d_ff=2048`, `V=37000` (`REVIEW_REQUIRED` vocabulary size) and lands near the published ~65 M (biases and layer-norms included; positions have no parameters).

### 7. CODE

```python
# Parameter count of the original encoder-decoder (Post-LN, ReLU, sinusoidal positions, tied embeddings)
def attn_params(d):            # Q, K, V, O with biases
    return 4 * d * d + 4 * d

def ffn_params(d, ff):         # two linear layers with biases
    return 2 * d * ff + ff + d

def original_transformer_params(d=512, ff=2048, n_enc=6, n_dec=6, vocab=37000):
    ln = 2 * d                                   # gamma + beta
    enc_layer = attn_params(d) + ffn_params(d, ff) + 2 * ln
    dec_layer = 2 * attn_params(d) + ffn_params(d, ff) + 3 * ln   # self + cross attention
    return vocab * d + n_enc * enc_layer + n_dec * dec_layer

n = original_transformer_params()
print(f"{n:,} parameters  (~{n/1e6:.1f} M)")
assert 60e6 < n < 70e6
```

### 8. INPUT → PROCESS → OUTPUT

```
source tokens --> embed + position --> [Encoder x6] --> memory (B,S,d)
                                                           |  (cross-attention K,V)
target tokens (shifted right) --> embed + position --> [Decoder x6] --> linear --> softmax --> next token
```

### 9. ENTERPRISE USE CASE

Neural machine translation and other sequence-to-sequence products (document translation, summarisation, structured rewriting) used this layout directly. Today an enterprise typically meets it through T5/BART-family models ([8.28 T5/BART](08.28-t5-bart.md)) or sees the same *block* inside decoder-only LLMs.

### 10. AI ENGINEERING CONNECTION

Every foundation model in Phase 2 is a descendant: the block ([8.5 Transformer block](08.05-transformer-block.md)), residual stream ([8.10 Residual connections](08.10-residual-connections.md)), and the parameter arithmetic ([8.21 Parameter counting](08.21-parameter-counting.md)) are unchanged. Knowing the original lets you read model cards that say "Post-LN", "encoder-decoder" or "shared embeddings".

### 11. ADVANTAGES

Parallel training across positions; direct long-range connections; a uniform repeating layer that scales by changing width, depth and heads; strong translation quality for its time.

### 12. LIMITATIONS

`O(T^2)` attention cost; Post-LN trains poorly for deep stacks without warm-up; sinusoidal positions extrapolate imperfectly; two stacks means more serving complexity than decoder-only.

### 13. TRADE-OFFS

Parallelism and expressiveness (attention) versus quadratic memory and compute. Encoder-decoder separation versus a single stack that is simpler to scale and serve.

### 14. COMMON MISTAKES

Quoting the 65 M figure without saying which vocabulary and bias conventions were used; confusing the 2017 *Post-LN* layer with modern Pre-LN code; assuming every Transformer has both halves; forgetting the decoder inputs are shifted right.

### 15. PERFORMANCE / COST CONSIDERATIONS

Training is parallel over all target positions; inference is sequential in the decoder. Cost grows with `L * d^2` plus `T^2` terms; see [8.21 Parameter counting](08.21-parameter-counting.md) for the arithmetic and [Tier 11 — Inference](../../tier-11-llm-inference-optimization/README.md) for serving.

### 16. SECURITY CONSIDERATIONS

Architecture choice has no direct attack surface, but checkpoints loaded with the wrong variant (Post-LN weights in Pre-LN code) fail silently; treat the config file as part of the model. Pickle-format checkpoints can execute code (prefer `safetensors` / `weights_only=True`).

### 17. INTERVIEW EXPLANATION

*"The original Transformer replaced recurrence with attention so a whole sequence is processed in parallel. It is an encoder-decoder: the encoder builds contextual representations of the source; the decoder generates the target token by token with causal self-attention plus cross-attention to the encoder. Each layer is attention plus a position-wise feed-forward network, wrapped in residual connections and layer norm. Compared with today's models it uses Post-LN, ReLU and sinusoidal positions."*

### 18. RAPID-FIRE ANSWER

An encoder-decoder network built only from attention + feed-forward layers, with residuals and layer norm, that replaced RNNs for sequence modelling.
