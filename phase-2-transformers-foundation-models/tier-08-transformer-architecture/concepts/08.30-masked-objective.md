### 1. WHAT IS IT?

The **masked objective** (masked language modelling) hides a fraction of tokens and trains an encoder to recover them from the context on both sides.

### 2. WHY DOES IT EXIST?

A bidirectional encoder cannot be trained with next-token prediction (it would see the answer). Masking creates a prediction problem that needs both sides.

### 3. DETAILED EXPLANATION

- ~15 % of positions are supervised per sequence (BERT, `REVIEW_REQUIRED`), so each sequence gives less signal than a causal LM.
- Train/inference mismatch: `[MASK]` is absent at inference; the 80/10/10 recipe mitigates this ([8.24 BERT](08.24-bert.md)).
- Produces representations, not a generator.

### 4. HOW DOES IT WORK?

1. Corrupt tokens. 2. Encode with full attention. 3. Compute logits for all positions but loss only at masked ones (`ignore_index=-100`).

### 5. SIMPLE EXAMPLE

A fill-in-the-blank exam.

### 6. TECHNICAL EXAMPLE

BERT-style pre-training on a corpus, then fine-tuning.

### 7. CODE

```python
import torch, torch.nn as nn, torch.nn.functional as F

d, V = 32, 50
emb = nn.Embedding(V, d)
enc = nn.TransformerEncoder(nn.TransformerEncoderLayer(d, 4, 64, 0.0, batch_first=True, norm_first=True), 2)
head = nn.Linear(d, V)
x = torch.randint(5, V, (4, 20))
chosen = torch.rand(x.shape) < 0.15
chosen[:, 0] = True                                      # ensure at least one target
labels = torch.where(chosen, x, torch.full_like(x, -100))
corrupt = torch.where(chosen, torch.full_like(x, 4), x)  # token 4 = [MASK]
logits = head(enc(emb(corrupt)))
loss = F.cross_entropy(logits.reshape(-1, V), labels.reshape(-1), ignore_index=-100)
print(loss.item())
assert loss.item() > 0
```

### 8. INPUT → PROCESS → OUTPUT

```
tokens -> mask 15% -> encoder (full attention) -> logits -> CE only on masked positions
```

### 9. ENTERPRISE USE CASE

Pre-training of retrieval/classification encoders.

### 10. AI ENGINEERING CONNECTION

Foundation for encoder models used in RAG retrieval (Tier 20).

### 11. ADVANTAGES

Bidirectional context; good representations.

### 12. LIMITATIONS

Low supervision per sequence; mask mismatch.

### 13. TRADE-OFFS

Representation quality versus training efficiency.

### 14. COMMON MISTAKES

Computing loss on unmasked positions; masking special tokens/padding.

### 15. PERFORMANCE / COST CONSIDERATIONS

Needs more steps than causal LM for the same token count.

### 16. SECURITY CONSIDERATIONS

Corrupted-input pre-training does not provide robustness guarantees.

### 17. INTERVIEW EXPLANATION

*"Masked language modelling hides about 15 percent of tokens and predicts them from both directions. It trains good bidirectional encoders but supervises only the masked positions and has a train/inference mismatch because the mask token never appears at inference."*

### 18. RAPID-FIRE ANSWER

Mask some tokens, predict them from both sides.
