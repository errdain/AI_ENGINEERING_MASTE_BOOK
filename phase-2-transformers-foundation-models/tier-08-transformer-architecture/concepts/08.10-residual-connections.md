### 1. WHAT IS IT?

A **residual connection** adds a sub-layer's input to its output: `x_out = x + F(x)`. Each sub-layer writes an *update* to a shared stream instead of replacing it.

### 2. WHY DOES IT EXIST?

Deep stacks suffer from vanishing or exploding gradients and degradation. With `x + F(x)`, `d x_out / d x = I + dF/dx`: the identity term lets gradients reach early layers undamped (the idea from ResNets, Tier 13).

### 3. DETAILED EXPLANATION

1. **Gradient highway.** The identity term carries gradient directly to earlier layers.
2. **Incremental refinement.** A sub-layer only learns a correction; with small initial weights a block starts near the identity, so a deep model starts as a shallow one.
3. **Residual-stream view.** All layers read from and write to one shared `d`-dimensional workspace; the final stream is the sum of the embedding and all sub-layer outputs.
4. **Shape rule.** Every sub-layer must map `d -> d`.
5. **Init tip used in the lab.** Output projections are scaled by `1/sqrt(2L)` (GPT-2 style) so the sum of `2L` writes does not blow up the stream variance at the start.

### 4. HOW DOES IT WORK?

1. Keep the input `x`.
2. Compute the sub-layer output `F(Norm(x))` (Pre-LN).
3. Return `x + F(...)`.
4. In backprop the gradient splits: one copy through `F`, one straight through the identity.

### 5. SIMPLE EXAMPLE

A river with side canals: the main channel (the stream) always flows; each canal (sub-layer) adds or removes a little water.

### 6. TECHNICAL EXAMPLE

A 24-layer model has 48 residual additions. Without them a gradient would pass through 48 sub-layer Jacobians; with them it always has an identity path of gain 1.

### 7. CODE

```python
import torch, torch.nn as nn

def depth_grad(residual: bool, L=40, d=32, gain=0.5, seed=0):
    torch.manual_seed(seed)
    layers = [nn.Sequential(nn.Linear(d, d), nn.Tanh()) for _ in range(L)]
    for l in layers: nn.init.normal_(l[0].weight, 0, gain / d ** 0.5)
    x = torch.randn(8, d, requires_grad=True); h = x
    for l in layers: h = h + l(h) if residual else l(h)
    h.pow(2).mean().backward()
    return x.grad.norm().item()

g_plain, g_res = depth_grad(False), depth_grad(True)
print(f"grad at input: plain {g_plain:.2e}  residual {g_res:.2e}")
assert g_res > 100 * g_plain                    # residual path keeps the gradient alive
```

Code in the model: `x = x + self.attn(self.n1(x))` in [`../lab/mini_gpt.py`](../lab/mini_gpt.py).

### 8. INPUT → PROCESS → OUTPUT

```
x --------------------+
 |                     v
 +--> F(Norm(x)) ----> (+) --> x + F(Norm(x))
```

### 9. ENTERPRISE USE CASE

When fine-tuning with adapters/LoRA (Tier 10) the added path is itself a residual-style update to a frozen model.

### 10. AI ENGINEERING CONNECTION

Explains why layer-wise analysis, early exit, logit-lens style probing and layer pruning work at all: intermediate states live in the same space.

### 11. ADVANTAGES

Trainable depth; simple; cheap (one add); makes modular updates possible.

### 12. LIMITATIONS

Stream norm grows with depth in Pre-LN (needs a final norm); cannot change width between layers without a projection.

### 13. TRADE-OFFS

Identity preservation versus representational mixing; Pre-LN stability versus growing scale ([8.12 Pre-LN](08.12-pre-ln.md)).

### 14. COMMON MISTAKES

Mismatched shapes; adding in the wrong place (after the norm); forgetting output-projection scaling in very deep stacks; applying dropout on the skip path.

### 15. PERFORMANCE / COST CONSIDERATIONS

Free in FLOPs but the stream must be kept in memory for the skip; activation memory is a major training cost (checkpointing recomputes it).

### 16. SECURITY CONSIDERATIONS

Small perturbations carried along the stream can propagate to all later layers; low-precision accumulation of the stream (fp16) can overflow in very deep models.

### 17. INTERVIEW EXPLANATION

*"A residual connection adds a sub-layer's output to its input, so the derivative contains an identity term and gradients flow to early layers; each layer only learns a correction. It also gives the residual-stream view where all layers write into one shared workspace. That is why 100-layer Transformers are trainable."*

### 18. RAPID-FIRE ANSWER

`x + F(x)`: an identity path for gradients and a shared workspace for layers.
