### 1. WHAT IS IT?

**BERT** (Devlin et al., 2018) is the landmark encoder-only model: a Post-LN encoder stack pre-trained with **masked language modelling** and, in the original, **next-sentence prediction**, then fine-tuned for downstream tasks.

### 2. WHY DOES IT EXIST?

Before BERT, task-specific models were trained from scratch or with shallow pre-trained embeddings. BERT showed a single pre-trained bidirectional model fine-tunes well for many tasks.

### 3. DETAILED EXPLANATION

- Original sizes (`REVIEW_REQUIRED`): BERT-base 12 layers, `d=768`, 12 heads, ~110 M parameters; BERT-large 24 layers, `d=1024`, 16 heads, ~340 M; WordPiece vocabulary ~30 k; learned positions; GELU; Post-LN.
- Masking recipe (`REVIEW_REQUIRED`): choose ~15 % of tokens; of these 80 % become `[MASK]`, 10 % a random token, 10 % unchanged. The model predicts the original at the chosen positions.
- Next-sentence prediction was later found unnecessary by follow-up work (`REVIEW_REQUIRED`).
- Input: `[CLS] A [SEP] B [SEP]` with segment embeddings; `[CLS]` vector used for classification heads.

### 4. HOW DOES IT WORK?

1. Mask tokens by the 80/10/10 recipe. 2. Encode bidirectionally. 3. Cross-entropy at masked positions only.

### 5. SIMPLE EXAMPLE

A cloze test: fill in the blanks in a passage using the words on both sides.

### 6. TECHNICAL EXAMPLE

Fine-tune BERT-base with a linear head for sentiment, or use its descendants as embedding and reranking backbones.

### 7. CODE

```python
import torch

def bert_mask(ids, mask_id, vocab, p=0.15, gen=None):
    """80/10/10 masking. Returns (corrupted ids, labels with -100 where not predicted)."""
    ids = ids.clone(); labels = ids.clone()
    chosen = torch.rand(ids.shape, generator=gen) < p
    labels[~chosen] = -100                                  # loss only on chosen positions
    r = torch.rand(ids.shape, generator=gen)
    ids[chosen & (r < 0.8)] = mask_id                       # 80 % -> [MASK]
    rnd = chosen & (r >= 0.8) & (r < 0.9)                   # 10 % -> random token
    ids[rnd] = torch.randint(0, vocab, (int(rnd.sum()),), generator=gen)
    return ids, labels                                      # remaining 10 % unchanged

g = torch.Generator().manual_seed(0)
x = torch.randint(5, 100, (4, 50))
y, lab = bert_mask(x, mask_id=4, vocab=100, gen=g)
print((lab != -100).float().mean().item(), (y == 4).float().mean().item())   # about 0.15 chosen, about 0.12 masked (random, so approximate)
assert (lab[lab != -100] == x[lab != -100]).all()
```

### 8. INPUT → PROCESS → OUTPUT

```
text -> mask 15% (80/10/10) -> encoder -> logits at masked positions -> CE vs original tokens
```

### 9. ENTERPRISE USE CASE

Fine-tuned BERT-family models remain a workhorse for classification and NER in production.

### 10. AI ENGINEERING CONNECTION

Its descendants power embedding models and rerankers (Tier 20).

### 11. ADVANTAGES

Strong understanding accuracy; small and fast; easy fine-tuning.

### 12. LIMITATIONS

No generation; `[MASK]` mismatch between pre-training and inference; fixed 512-token context in the original (`REVIEW_REQUIRED`).

### 13. TRADE-OFFS

Understanding quality versus generation ability.

### 14. COMMON MISTAKES

Assuming BERT = old = useless; mixing tokenizers/checkpoints; large learning rate without warm-up on Post-LN.

### 15. PERFORMANCE / COST CONSIDERATIONS

Cheap to serve; cost grows with sequence length quadratically.

### 16. SECURITY CONSIDERATIONS

Fine-tuning data can leak through model outputs; validate downloaded weights and tokenizers.

### 17. INTERVIEW EXPLANATION

*"BERT is an encoder-only Transformer pre-trained by masking about 15 percent of tokens and predicting them from both sides, then fine-tuned with a small head. It gave contextual embeddings that transfer to classification, tagging and QA, and its descendants remain the workhorse for classification and retrieval."*

### 18. RAPID-FIRE ANSWER

BERT: masked-language-model encoder, fine-tuned for tasks.
