### 1. WHAT IS IT?

CLIP (Radford et al., OpenAI, 2021) trains an image encoder and a text encoder jointly with a contrastive loss on hundreds of millions of web image-caption pairs (about 400M per the paper - REVIEW_REQUIRED), so that images and captions share one embedding space.

### 2. WHY DOES IT EXIST?

Supervised classifiers know a fixed label set. CLIP learns from natural language, so you can classify or search with *any* text prompt without retraining (zero-shot).

### 3. DETAILED EXPLANATION

**Zero-shot classification.** Embed prompts like 'a photo of a {class}', embed the image, pick the class with the highest cosine similarity.

**Architecture.** Image tower (ResNet or ViT variants) + text Transformer; both project to a shared dimension; a learned temperature scales logits.

**Strengths.** Open-vocabulary retrieval, robust transfer, backbone for VLMs and image generators (as a text/image conditioner).

**Weaknesses.** Weak at counting, spatial relations and fine-grained text-in-image reading; sensitive to prompt wording; inherits web biases (REVIEW_REQUIRED for specific measured numbers). Successors (OpenCLIP, SigLIP, others) change data, loss or scale.

**Toy replica.** The lab's CLIP-style model uses a CNN image tower and a tiny text tower over (colour, shape) captions.

### 4. HOW DOES IT WORK?

Batch of (image, text) -> two encoders -> L2-normalize -> N x N similarity x learned scale -> symmetric cross-entropy ([13.19 Contrastive learning](13.19-contrastive-learning.md)). Inference: compare embeddings.

### 5. SIMPLE EXAMPLE

Search photos with the words 'red circle' without ever training a 'red circle' classifier.

### 6. TECHNICAL EXAMPLE

Lab zero-shot-style test: caption embedding vs gallery image embeddings -> recall@1. Measured after 12-15 epochs: about 1.0 vs chance about 0.08 on 12 captions. This is a toy with an easy domain.

### 7. CODE

```python
import sys; sys.path.insert(0, "../lab")
from vision import make_dataset
from models import TinyCNN, TextTower, fit_clip, retrieval_recall
Xtr, ys, yc = make_dataset(900, seed=0); Xte, ys2, yc2 = make_dataset(300, seed=1)
img, txt = TinyCNN(), TextTower()
fit_clip(img, txt, Xtr, yc, ys, epochs=12)
print(retrieval_recall(img, txt, Xte, yc2, ys2, k=1))     # (recall, chance)
```

### 8. INPUT → PROCESS → OUTPUT

Input: images and text prompts. Process: encode, normalize, compare. Output: similarity scores / retrieval ranking / zero-shot labels.

### 9. ENTERPRISE USE CASE

Content moderation and digital-asset search: embed all assets once, search by free text; the policy team edits prompts rather than retraining.

### 10. AI ENGINEERING CONNECTION

CLIP-like encoders are the vision towers in many VLMs ([13.22 Vision-language models (VLMs)](13.22-vision-language-models-vlms.md)) and the retrieval backbone of multimodal RAG (Tier 20).

### 11. ADVANTAGES

Zero-shot, open vocabulary, cheap inference, shared space.

### 12. LIMITATIONS

Bag-of-words-like text understanding, struggles with composition/counting/small text; biased web data.

### 13. TRADE-OFFS

Prompt engineering vs fine-tuning; large batch/data vs compute; generic vs domain adaptation.

### 14. COMMON MISTAKES

Using one prompt template; comparing similarity scores across different models; treating zero-shot accuracy as production accuracy; ignoring biases.

### 15. PERFORMANCE / COST CONSIDERATIONS

Embed corpus once; query is one text-encoder pass + ANN search.

### 16. SECURITY CONSIDERATIONS

Typographic attacks (text overlaid on an image changes its predicted class) are documented for CLIP-like models; prompt/label wording can encode biases; filter uploaded data.

### 17. INTERVIEW EXPLANATION

CLIP trains an image and a text encoder contrastively on web pairs so both live in one space. That enables zero-shot classification and retrieval from text prompts. It is strong at coarse semantics but weak at counting, spatial relations and reading small text, and it inherits web biases.

### 18. RAPID-FIRE ANSWER

Contrastively trained image+text encoders sharing one embedding space; zero-shot via text prompts.
