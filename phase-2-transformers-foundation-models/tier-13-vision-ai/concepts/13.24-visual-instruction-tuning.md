### 1. WHAT IS IT?

Visual instruction tuning fine-tunes a VLM on (image, instruction, response) examples so it follows free-form requests about images rather than just captioning them.

### 2. WHY DOES IT EXIST?

Pretraining on captions yields descriptions, not helpful assistants; instruction data teaches question answering, reasoning, formatting and refusal behaviour.

### 3. DETAILED EXPLANATION

**Typical staged recipe (LLaVA-style, REVIEW_REQUIRED for exact data/size).** Stage 1: align the projector on image-caption pairs (encoder and LLM frozen). Stage 2: instruction-tune projector (+LLM) on multimodal conversations.

**Data.** Human-written or LLM-generated conversations grounded on image captions/annotations; synthetic data risks inherited errors and hallucinations.

**Techniques.** Full fine-tuning vs LoRA ([Tier 10 Fine-tuning & Alignment](../../tier-10-fine-tuning-alignment/)); mixing in text-only instruction data to keep language skills; preference tuning to reduce hallucination (REVIEW_REQUIRED).

**Evaluation.** VQA-style benchmarks, hallucination probes, human review ([13.31 Vision evaluation](13.31-vision-evaluation.md)).

### 4. HOW DOES IT WORK?

Format `[image tokens][instruction] -> [response]`; loss on response tokens only; gradient updates to selected parameters.

### 5. SIMPLE EXAMPLE

Image of a chart + 'Which quarter was highest?' -> 'Q3'.

### 6. TECHNICAL EXAMPLE

Not trained in this lab (CPU/no-download constraint). The mechanics of masked response loss are the same as text SFT ([Tier 10 Fine-tuning & Alignment](../../tier-10-fine-tuning-alignment/)).

### 7. CODE

```python
# Response-only loss masking, the key mechanical detail (token ids are illustrative)
labels = [-100] * 580 + [812, 90, 3]     # ignore image+prompt tokens, learn the answer tokens
print(sum(l != -100 for l in labels), "supervised tokens of", len(labels))
```

### 8. INPUT → PROCESS → OUTPUT

Input: (image, instruction, answer) triples. Process: SFT with response-only loss. Output: instruction-following VLM.

### 9. ENTERPRISE USE CASE

A bank fine-tunes a VLM with LoRA on its own redacted forms and Q&A to extract fields; evaluation gate: field-level accuracy and a zero-PII-leak test.

### 10. AI ENGINEERING CONNECTION

Same alignment path as LLMs ([Tier 10 Fine-tuning & Alignment](../../tier-10-fine-tuning-alignment/)) applied to multimodal data.

### 11. ADVANTAGES

Large behavioural gain from modest data.

### 12. LIMITATIONS

Synthetic-data errors, hallucination, catastrophic forgetting of language skills.

### 13. TRADE-OFFS

Full tuning vs LoRA; synthetic vs human data (cost vs quality).

### 14. COMMON MISTAKES

Training loss on prompt tokens; leaking test images into training; ignoring licensing of images.

### 15. PERFORMANCE / COST CONSIDERATIONS

Dominated by LLM size and visual-token length.

### 16. SECURITY CONSIDERATIONS

Training data may contain private/biased images; poisoned instructions can embed backdoors; audit provenance.

### 17. INTERVIEW EXPLANATION

Visual instruction tuning is supervised fine-tuning of a VLM on image-instruction-response data, usually after aligning the projector on captions. Loss is on response tokens only. Quality depends on data quality and hallucination control; I would use LoRA and a gated evaluation set.
