### 1. WHAT IS IT?

Object detection predicts, for every object in an image, a class label and a bounding box (x1,y1,x2,y2), plus a confidence score.

### 2. WHY DOES IT EXIST?

Classification says 'a dog is present'; many applications need *where* and *how many* (autonomous driving, retail, safety).

### 3. DETAILED EXPLANATION

**Families.** Two-stage (region proposals then classify; Faster R-CNN family), one-stage (dense predictions; YOLO/SSD/RetinaNet families), and set-prediction Transformers (DETR-style) - REVIEW_REQUIRED for the current state of the art.

**IoU.** `IoU = area(A and B) / area(A or B)`, in [0,1]; the standard overlap measure for matching predictions to ground truth and for NMS.

**NMS.** Detectors emit many overlapping boxes. Greedy NMS: sort by score, keep the best, drop boxes with IoU > threshold to it, repeat. Threshold trades duplicates against merged nearby objects. (DETR-style models avoid NMS by design.)

**Metrics.** Precision/recall at an IoU threshold, AP per class, mAP (COCO averages over IoU 0.5-0.95; REVIEW_REQUIRED for exact protocol).

### 4. HOW DOES IT WORK?

Backbone ([13.13 ResNet](13.13-resnet.md)) -> feature maps ([13.11 Feature maps](13.11-feature-maps.md)) -> head predicts boxes+scores at many anchors/locations -> score threshold -> NMS -> detections.

### 5. SIMPLE EXAMPLE

Two boxes around the same car (IoU 0.7): keep the one with the higher score.

### 6. TECHNICAL EXAMPLE

Lab: `iou`, `nms` in `vision.py`; tests check IoU of identical (1), disjoint (0), half-overlap (2/6), nested (4/16), touching edges (0), and an NMS case where box #1 (score .9) suppresses #0 and #3 but #2 survives.

### 7. CODE

```python
import sys; sys.path.insert(0, "../lab")
from vision import iou, nms
boxes = [(0, 0, 10, 10), (1, 1, 11, 11), (50, 50, 60, 60), (0, 0, 10, 9)]
print(round(iou(boxes[0], boxes[1]), 3), nms(boxes, [0.8, 0.9, 0.7, 0.6], 0.5))   # 0.681 [1, 2]
```

### 8. INPUT → PROCESS → OUTPUT

Input: image. Process: backbone, head, threshold, NMS. Output: list of (class, box, score).

### 9. ENTERPRISE USE CASE

Retail shelf analytics counts products per SKU; operating point (score/NMS thresholds) is tuned per store to balance false alarms against missed items.

### 10. AI ENGINEERING CONNECTION

Grounding in VLMs and open-vocabulary detectors combine text queries with detection heads (REVIEW_REQUIRED); text detection in OCR is detection ([13.25 OCR fundamentals](13.25-ocr-fundamentals.md)).

### 11. ADVANTAGES

Localization + counting; mature, real-time options.

### 12. LIMITATIONS

Needs box labels; small/occluded objects; crowded scenes (NMS merges neighbours).

### 13. TRADE-OFFS

Speed (one-stage) vs accuracy (two-stage); NMS threshold: duplicates vs missed adjacent objects.

### 14. COMMON MISTAKES

Computing IoU with (x,y,w,h) vs (x1,y1,x2,y2) confusion; per-class NMS forgotten; evaluating at one IoU only; leaking validation images.

### 15. PERFORMANCE / COST CONSIDERATIONS

NMS is O(n^2) naive; many candidates before thresholding; batched/GPU NMS in frameworks.

### 16. SECURITY CONSIDERATIONS

Adversarial patches can hide or create detections; safety-critical use needs redundancy and monitoring.

### 17. INTERVIEW EXPLANATION

A detector outputs class, box and score per object. Many overlapping candidates are pruned by greedy NMS: keep the highest score and drop boxes whose IoU with it exceeds a threshold. IoU is intersection over union; evaluation uses AP/mAP across IoU thresholds. NMS threshold trades duplicates against merged neighbours.

### 18. RAPID-FIRE ANSWER

Predict class + box + score per object; prune duplicates with IoU-based NMS.
