### 1. WHAT IS IT?

Techniques that let a RoPE model run at contexts longer than it was trained on by rescaling its rotation frequencies: position interpolation, base change, NTK-aware scaling and by-parts (YaRN-style) schemes.

### 2. WHY DOES IT EXIST?

Quality degrades when RoPE angles exceed the range seen in training; retraining at long length is expensive.

### 3. DETAILED EXPLANATION

RoPE pair `i` rotates by `θᵢ = base^(−2i/d)` per token (definition: [Tier 6 (RoPE, positions)](../../tier-06-tokenization-embeddings/README.md)).

* **Position interpolation (PI):** use positions `m/s` → all `θᵢ/s`; nothing is extrapolated but local resolution drops.
* **Base change:** raise the base (≈ ×`s`); slows low-frequency pairs, high ones almost unchanged.
* **NTK-aware:** `base' = base·s^(d/(d−2))` stretches the slowest pair by ≈`s` and leaves the fastest nearly intact (a heuristic name).
* **By-parts / YaRN-style:** keep pairs with many turns inside `L`, interpolate pairs with under one turn, ramp in between; real YaRN also rescales attention logits (omitted in the explorer).

Exact recipes and benefits are model-specific (REVIEW_REQUIRED).

### 4. HOW DOES IT WORK?

1. Pick `s = target/L`. 2. Transform `θᵢ`. 3. Optionally fine-tune briefly at the new length. 4. Evaluate on long-range retrieval, not perplexity alone.

### 5. SIMPLE EXAMPLE

Stretching a ruler's markings so a longer table fits the same ruler: either squeeze every mark (PI) or stretch only the coarse marks (NTK).

### 6. TECHNICAL EXAMPLE

L=4096, s=8, d=128: with PI the fastest pair's step falls 8×; with NTK-aware its step is almost unchanged while the slowest wavelength grows ≈8×.

### 7. CODE

```python
import numpy as np
def wavelengths(d=128, base=1e4, scheme="none", s=8.0):
    i = np.arange(d // 2)
    if scheme == "ntk": base = base * s ** (d / (d - 2))
    if scheme == "base": base = base * s
    theta = base ** (-2 * i / d)
    if scheme == "pi": theta = theta / s
    return 2 * np.pi / theta
```
Same function is used in `scripts/make_figures.py`.

### 8. INPUT → PROCESS → OUTPUT

```
(trained L, target L·s, base, d) → rescaled θ → rotate Q,K → long-range attention
```

### 9. ENTERPRISE USE CASE

Extending a model to a long-document use case without full retraining.

### 10. AI ENGINEERING CONNECTION

Long-context RAG and agent histories (Tiers 20-21) need it, but retrieval may be cheaper.

### 11. ADVANTAGES

Cheap context extension; no new parameters.

### 12. LIMITATIONS

Quality at long range is not guaranteed; needs evaluation; interacts with attention sinks and windows.

### 13. TRADE-OFFS

Local resolution (PI loses it) vs extrapolation safety.

### 14. COMMON MISTAKES

Changing the base at inference without matching the fine-tune; judging by perplexity only.

### 15. PERFORMANCE / COST CONSIDERATIONS

No extra cost at inference; the cost is KV cache at longer n.

### 16. SECURITY CONSIDERATIONS

Longer contexts widen injection surface (Tier 24).

### 17. INTERVIEW EXPLANATION

*"RoPE extension rescales the frequencies so angles stay in the trained range: interpolation squeezes positions, base-change and NTK-aware slow the low-frequency pairs, and by-parts schemes mix them; you still have to evaluate long-range retrieval."*

### 18. RAPID-FIRE ANSWER
