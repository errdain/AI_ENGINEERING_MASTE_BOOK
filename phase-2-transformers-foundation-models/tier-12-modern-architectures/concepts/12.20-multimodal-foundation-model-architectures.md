### 1. WHAT IS IT?

Multimodal foundation models add non-text inputs (and sometimes outputs) to a language backbone, usually through a modality encoder, a projection/adapter and tokens fed into the decoder.

### 2. WHY DOES IT EXIST?

One model that reads images/audio/video and text enables document understanding, GUI agents and speech assistants.

### 3. DETAILED EXPLANATION

Common layouts (concepts owned by Tier 13 (Vision AI) and Tier 14): (1) **encoder + projector + LLM** — a vision/audio encoder produces embeddings that are projected to the LLM's width and inserted as tokens; (2) **cross-attention fusion**; (3) **early-fusion / natively multimodal** token streams. Architectural consequence: modality tokens count against context length and KV cache (an image can be hundreds to thousands of tokens, REVIEW_REQUIRED per model).

### 4. HOW DOES IT WORK?

1. Encode image → patch embeddings. 2. Project to `d_model`. 3. Concatenate with text embeddings. 4. Decode text.

### 5. SIMPLE EXAMPLE

Giving a reader photographs interleaved with text: each photo is translated into a short 'caption-like' vector sequence first.

### 6. TECHNICAL EXAMPLE

1,000 image tokens at 128 KiB/token (GQA-8 archetype) add ≈125 MiB of KV per request.

### 8. INPUT → PROCESS → OUTPUT

```
image → encoder → projector → [img tokens | text tokens] → LLM → text
```

### 9. ENTERPRISE USE CASE

Invoice/contract processing, chart reading, visual QA.

### 10. AI ENGINEERING CONNECTION

Context budget and cost must include modality tokens.

### 11. ADVANTAGES

One interface for several modalities.

### 12. LIMITATIONS

Token-hungry; alignment data required.

### 13. TRADE-OFFS

Resolution/tokens vs cost.

### 14. COMMON MISTAKES

### 15. PERFORMANCE / COST CONSIDERATIONS

### 16. SECURITY CONSIDERATIONS

### 17. INTERVIEW EXPLANATION

*"Multimodal LLMs encode other modalities into embeddings, project them to the LLM width and feed them as tokens, so they consume context and KV cache."*

### 18. RAPID-FIRE ANSWER

Encoder + projector + LLM; modality tokens cost context.
