### 1. WHAT IS IT?

Expert load balancing encourages tokens to spread over experts, via an auxiliary loss, router noise, capacity limits or bias adjustment.

### 2. WHY DOES IT EXIST?

Without it routers collapse: a few experts get most tokens, others never train.

### 3. DETAILED EXPLANATION

A common auxiliary loss is `E·Σₑ fₑ·Pₑ` where `fₑ` is the fraction of tokens routed to expert `e` and `Pₑ` its mean router probability; it is minimised by uniform loads (Switch-Transformer-style, REVIEW_REQUIRED). Alternatives: noisy gating, expert-choice routing, auxiliary-loss-free bias updates. Training detail lives in [Tier 9 Pre-training](../../tier-09-foundation-model-pretraining/README.md).

[Explore: moe_explorer.html](../interactive/moe_explorer.html) — raise skew to see max/mean load and drops.

### 4. HOW DOES IT WORK?

Compute `fₑ` and `Pₑ` per batch, add `α·loss` to the main loss, tune `α` (too high hurts quality).

### 5. SIMPLE EXAMPLE

A manager rotating tasks so no specialist is idle or swamped.

### 6. TECHNICAL EXAMPLE

With perfectly uniform routing, `fₑ = Pₑ = 1/E` and the loss equals 1 (for the top-1 definition).

### 7. CODE

```python
import numpy as np
def balance_loss(probs, assign, E):          # probs: (T,E) softmax; assign: (T,) top-1 expert
    f = np.bincount(assign, minlength=E) / len(assign); P = probs.mean(0)
    return E * float(f @ P)                  # 1.0 when perfectly balanced
```

### 8. INPUT → PROCESS → OUTPUT

```
router stats (f, P) → auxiliary loss → gradient → flatter expert loads
```

### 9. ENTERPRISE USE CASE

Expert utilisation dashboards in training and serving.

### 10. AI ENGINEERING CONNECTION

Imbalance means some GPUs idle in expert parallelism.

### 11. ADVANTAGES

Better hardware use and quality.

### 12. LIMITATIONS

Extra hyperparameter; may fight specialisation.

### 13. TRADE-OFFS

Balance vs specialisation.

### 14. COMMON MISTAKES

Monitoring only the mean loss, not per-expert load.

### 15. PERFORMANCE / COST CONSIDERATIONS

Hot experts become latency tail.

### 16. SECURITY CONSIDERATIONS

Hot experts leak information about inputs through timing (REVIEW_REQUIRED).

### 17. INTERVIEW EXPLANATION

*"Load balancing adds a loss, or bias updates, that pushes the router toward uniform expert use so no expert collapses or becomes a hotspot."*

### 18. RAPID-FIRE ANSWER

Auxiliary loss/noise to even out expert loads.
