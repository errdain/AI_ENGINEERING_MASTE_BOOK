### 1. WHAT IS IT?

Sliding-window attention lets each token attend only to the previous `w` tokens. Per-layer cache is capped at `w`. Introduced in [Tier 7 Attention](../../tier-07-attention/README.md); here: its role inside architectures.

### 2. WHY DOES IT EXIST?

Cuts compute from `n²/2` to about `n·w` and caps cache memory independent of `n`.

### 3. DETAILED EXPLANATION

Stacked windows still propagate information: after `L` layers the reach is about `L·(w−1)+1`. Many models **interleave** local and global layers (the Gemma-2 shape alternates, REVIEW_REQUIRED), so cheap local layers do most work and a few global layers move information far.

### 4. HOW DOES IT WORK?

Mask: allow `0 ≤ i−j < w`. Cache: ring buffer of the last `w` keys/values per local layer.

### 5. SIMPLE EXAMPLE

Reading a book with a ruler under the line: you see only the last few lines, but earlier lines changed what you remember.

### 6. TECHNICAL EXAMPLE

Archetype 32-layer all-window (w=4096): cache at n=131072 is 0.5 GiB vs 16 GiB for full GQA-8 (lab).

### 8. INPUT → PROCESS → OUTPUT

```
layer type L: Q_t · K[t-w+1..t] → softmax → V → ring-buffer cache of size w
```

### 9. ENTERPRISE USE CASE

Long-document summarisation or log streaming with bounded memory.

### 10. AI ENGINEERING CONNECTION

Interleaved local/global layers in open models; interacts with attention sinks (Tier 7).

### 11. ADVANTAGES

Linear compute, constant cache.

### 12. LIMITATIONS

No direct access beyond `w`; exact recall of far tokens must flow through layers.

### 13. TRADE-OFFS

Window size vs recall; local-to-global ratio.

### 14. COMMON MISTAKES

Assuming effective context = trained length when only local layers exist; forgetting sink tokens.

### 15. PERFORMANCE / COST CONSIDERATIONS

Pairs ≈ n·w; cache capped.

### 16. SECURITY CONSIDERATIONS

An attacker's instruction outside the window is invisible to local layers but may still reach through global ones.

### 17. INTERVIEW EXPLANATION

*"Sliding windows restrict attention to the last w tokens, giving linear compute and a fixed cache; information still travels w−1 tokens per layer, and models interleave global layers for long-range access."*

### 18. RAPID-FIRE ANSWER

Attend to last w tokens; cache ≤ w.
