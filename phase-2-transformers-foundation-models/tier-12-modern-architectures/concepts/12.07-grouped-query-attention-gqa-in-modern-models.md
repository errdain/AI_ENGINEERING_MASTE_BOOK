### 1. WHAT IS IT?

GQA partitions query heads into `H_kv` groups, each sharing one K/V head: `H_kv = H` is MHA, `H_kv = 1` is MQA.

### 2. WHY DOES IT EXIST?

Keeps most MHA quality while cutting the KV cache by `H/H_kv` (typically 4-8×).

### 3. DETAILED EXPLANATION

Mechanics: [Tier 7 Attention](../../tier-07-attention/README.md). Architecture-level view: GQA is now the default dense-decoder choice (Llama-2-70B/Llama-3, Qwen, Gemma and Mixtral shapes in the case studies use it; REVIEW_REQUIRED per model).

Parameter effect: only K and V projections shrink; for the Llama-3-8B shape the lab gives ~8.03 B total.

### 4. HOW DOES IT WORK?

1. Choose `H_kv` dividing `H`. 2. Project K,V to `H_kv·d_h`. 3. Repeat/broadcast each K/V head to its group. 4. Attention as usual.

### 5. SIMPLE EXAMPLE

Six teams (query heads) share two reference libraries (K/V heads).

### 6. TECHNICAL EXAMPLE

Llama-3-8B shape: 32 heads, 8 KV heads → 128 KiB/token, 1 GiB at 8192 (REVIEW_REQUIRED shape).

### 8. INPUT → PROCESS → OUTPUT

```
Q: H heads | K,V: H_kv heads → group-broadcast → attention → KV cache ÷ (H/H_kv)
```

### 9. ENTERPRISE USE CASE

Default for self-hosted LLM serving: more users per GPU at near-MHA quality.

### 10. AI ENGINEERING CONNECTION

Long-context and high-concurrency RAG/agents depend on cheap KV (Tier 11).

### 11. ADVANTAGES

Near-MHA quality, big cache savings; can uptrain MHA checkpoints.

### 12. LIMITATIONS

Some capacity loss versus MHA; must pick `H_kv`.

### 13. TRADE-OFFS

`H_kv` is a dial between quality and memory.

### 14. COMMON MISTAKES

Using `H` instead of `H_kv` in cache math (4× over-estimate).

### 15. PERFORMANCE / COST CONSIDERATIONS

Cache bytes ∝ `H_kv`; decode latency improves with less KV traffic.

### 16. SECURITY CONSIDERATIONS

None specific.

### 17. INTERVIEW EXPLANATION

*"GQA gives groups of query heads a shared K/V head, interpolating between MHA and MQA; it cuts the KV cache by H/H_kv with little quality loss, so it is the default in recent dense decoders."*

### 18. RAPID-FIRE ANSWER

Groups share K/V heads; cache ÷ H/H_kv.
