### 1. WHAT IS IT?

Hybrids interleave attention layers with SSM layers (and often MoE FFNs) to get cheap long context plus precise token lookup.

### 2. WHY DOES IT EXIST?

Pure SSMs lack exact recall; pure attention is expensive. Mixing keeps a few global layers.

### 3. DETAILED EXPLANATION

Layer patterns are strings such as `SSSSSSSA` repeated (1 attention : 7 SSM). Cache: only `A` layers keep a growing KV cache, `L` layers a capped one, `S` layers a constant state. The lab's `ArchSpec.pattern` encodes this; published hybrids exist (e.g. Jamba-style mixes with MoE; REVIEW_REQUIRED).

### 4. HOW DOES IT WORK?

Choose ratio and placement; attention layers handle lookup, SSM layers handle bulk sequence mixing.

### 5. SIMPLE EXAMPLE

A newsroom: reporters stream stories (SSM), a few archivists fetch exact quotes (attention).

### 6. TECHNICAL EXAMPLE

Archetype 1A:7S, 32 layers: 16 KiB/token marginal KV, 0.13 GiB at 8192 vs 1 GiB for GQA-8 dense (lab).

```

```

### 9. ENTERPRISE USE CASE

Very long-context serving at low memory.

### 10. AI ENGINEERING CONNECTION

Frontier research direction; ecosystem support varies.

### 11. ADVANTAGES

Much smaller cache than dense; retains lookup.

### 12. LIMITATIONS

More complex to train/serve; ratio is empirical.

### 13. TRADE-OFFS

Attention fraction vs memory and recall.

### 14. COMMON MISTAKES

Assuming the ratio is universal.

### 15. PERFORMANCE / COST CONSIDERATIONS

Cost ∝ number of A layers × n.

### 16. SECURITY CONSIDERATIONS

State and cache have different isolation needs per request.

### 17. INTERVIEW EXPLANATION

*"Hybrids interleave a few attention layers with SSM layers so you pay the KV cache only for the attention layers while keeping exact lookup ability."*

### 18. RAPID-FIRE ANSWER

Few attention layers + many SSM layers.
