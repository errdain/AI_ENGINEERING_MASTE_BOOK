CTC collapse and WER calculator

Part 1: type a per-frame label path (use _ for the CTC blank). Collapse = merge repeats, then drop blanks. Part 2: type a reference and a hypothesis; the page computes the minimum edit distance with substitutions, deletions and insertions.

1. CTC frame path to text

Note how "l l _ l" gives "ll" (the blank separates two real l's) while "l l" alone gives just one l. Count how many different paths collapse to the same text: it grows exponentially with the number of frames, which is why CTC loss sums over all of them.

2. Word / character error rate

WER = (S + D + I) / N_ref. It can exceed 100% when the hypothesis has many insertions. Always normalise text (case, punctuation, numbers) the same way before scoring.
