### 1. WHAT IS IT?

Temporal attention applies self-attention along the time axis of video tokens so that each frame (or tubelet) can gather information from other times. Variants: full space-time attention, factorized (spatial then temporal) attention, local windows and causal masks.

### 2. WHY DOES IT EXIST?

Actions unfold over time; joint attention over all space-time tokens is quadratic in `T x S` and quickly unaffordable, so we need patterns that keep the benefit at manageable cost.

### 3. DETAILED EXPLANATION

(Attention math is owned by [Tier 7](../../tier-07-attention/README.md); this file covers only the video-specific patterns.)

**Patterns (Figure 11).**
- *Full (bidirectional):* every frame attends to every frame; best for offline understanding.
- *Local window `+-w`:* frames attend to neighbours; cost linear in `T`, captures motion.
- *Causal:* frame `t` attends only to `<= t`; needed for streaming ([14.31](14.31-streaming-realtime-video-considerations.md)).
- *Factorized / divided space-time attention* (TimeSformer/ViViT variants, `REVIEW_REQUIRED`): attend over `S` spatial tokens within each frame, then over `T` frames at each spatial location.

**Cost.** Joint: `(T S)^2` score pairs. Factorized: `T S^2 + S T^2`. For `T=16, S=196` joint is 9.8 M pairs vs 0.66 M factorized (about 15x, `factorized_attention_cost`); at `T=64` the gap grows to about 48x (Figure 11, right).

**Practical tricks.** Sparse frames (low fps), token pooling, memory banks for long videos, cross-attention from a small set of queries (Perceiver/Q-Former-style resamplers, `REVIEW_REQUIRED`).

### 4. HOW DOES IT WORK?

![Figure 11 - three temporal attention masks and the cost of joint vs factorized attention](../figures/11_temporal_attention_patterns.png)

*Figure 11 - Left three: boolean masks over 12 frames (rows = query, columns = key): full, local window +-2 and causal. Right: score pairs vs number of frames for joint and factorized attention at 196 patches per frame (log-log).*

```
tokens [T,S,d] ─► spatial attention (within each frame) ─► temporal attention (within each location across frames) ─► FFN
```

### 5. SIMPLE EXAMPLE

Watching a match: first look around the pitch in one moment (spatial), then follow one player across seconds (temporal) rather than comparing every player at every second with every other.

### 6. TECHNICAL EXAMPLE

`temporal_attention_mask(12, 'local', 2)` keeps 5 frames per query; `factorized_attention_cost(16, 196)` returns `(9834496, 664832)`.

### 7. CODE

```python
# run inside lab/
from video_core import temporal_attention_mask, factorized_attention_cost

print(temporal_attention_mask(6, "local", 1).astype(int))       # banded matrix
print(int(temporal_attention_mask(6, "full", causal=True).sum()))   # 21 allowed pairs (lower triangle)
for T in (16, 64):
    joint, fact = factorized_attention_cost(T, 196)
    print(T, joint, fact, round(joint / fact, 1))              # cost ratio grows with T
```

### 8. INPUT → PROCESS → OUTPUT

```
video tokens ─► (mask: full | local | causal) attention ─► temporally mixed tokens ─► pooled video feature
```

### 9. ENTERPRISE USE CASE

Action-detection and sports-analytics models use local or factorized temporal attention to stay within GPU budgets on long clips.

### 10. AI ENGINEERING CONNECTION

Same machinery as [Tier 7](../../tier-07-attention/README.md)/[Tier 8](../../tier-08-transformer-architecture/README.md); the KV-cache ideas of [Tier 11](../../tier-11-llm-inference-optimization/README.md) apply to causal streaming video models.

### 11. ADVANTAGES

Models long-range temporal dependencies; flexible masks tailor cost to the task.

### 12. LIMITATIONS

Quadratic cost; local windows miss long-range cues; factorized attention approximates joint interactions.

### 13. TRADE-OFFS

Full vs local vs factorized: accuracy vs cost vs ability to stream.

### 14. COMMON MISTAKES

- Using bidirectional attention in a streaming system.
- Forgetting temporal position embeddings (attention is permutation-invariant).
- Ignoring that padded frames must be masked.

### 15. PERFORMANCE / COST CONSIDERATIONS

Cost patterns above; memory for attention matrices is `O(tokens^2)` without fused kernels.

### 16. SECURITY CONSIDERATIONS

Long-context video models can be prompted via on-screen text (visual prompt injection); sanitize or sandbox outputs that trigger actions.

### 17. INTERVIEW EXPLANATION

*"Temporal attention lets frames exchange information across time. Joint space-time attention is quadratic in the total tokens, so we factorize it into spatial then temporal attention, or restrict it to a local window or causal mask for streaming. The choice trades accuracy against cost and latency."*

### 18. RAPID-FIRE ANSWER

Self-attention along time with full, local, causal or factorized patterns to control quadratic cost.
