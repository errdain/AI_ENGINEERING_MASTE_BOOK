### 1. WHAT IS IT?

Audio-video-text alignment links the modalities on a common timeline and semantic space: which words are spoken during which shot, which sound events match which visual events, and which text describes which moment.

### 2. WHY DOES IT EXIST?

Multimodal search, summarisation, captions and RAG over recordings need to retrieve and cite the *moment* where something happened, not just the video.

### 3. DETAILED EXPLANATION

**Temporal alignment.** Words with timestamps ([14.15](14.15-timestamps-alignment.md)) are assigned to shots ([14.24](14.24-scene-shot-segmentation.md)) by overlap; speakers ([14.14](14.14-speaker-diarization.md)) are assigned to words by overlap; visual events inherit their frame times via `frame_index / fps` (or PTS).

**Semantic alignment.** Contrastive training maps clips, audio and captions into one embedding space (CLIP/CLAP-style, `REVIEW_REQUIRED`); retrieval then uses cosine similarity ([14.27](14.27-video-embeddings.md)).

**Chunking for RAG.** Build segments from shots plus transcript windows, store `{start, end, transcript, shot embedding, speaker}` and retrieve the best segments for an LLM prompt ([Tier 6](../../tier-06-tokenization-embeddings/README.md) covers text embeddings; later tiers cover RAG). Citations must carry timestamps.

**Pitfalls.** Time bases differ (audio 16 kHz samples, video 30 fps frames, PTS in a container), transcripts can lag or lead the visuals (lecture slides change after the sentence), and offsets accumulate in long files ([14.30](14.30-multimodal-synchronization.md)).

### 4. HOW DOES IT WORK?

```
audio ─► ASR + forced alignment ─► words [(w, t0, t1)] ─┐
video ─► shot detection ─► shots [(s, f0, f1)/fps] ───────┼─► interval overlap ─► segments {shot, words, speaker, embedding}
text query ─► embedding ─────────────────────────────────┘                                  ─► retrieval ─► citation (t0..t1)
```

### 5. SIMPLE EXAMPLE

A DVD with subtitles and chapter markers: the subtitles say what is spoken when, the chapters say what is shown when, and matching them tells you which words go with which scene.

### 6. TECHNICAL EXAMPLE

With words `[('hello',0.2,0.5), ('world',0.6,0.9), ('again',1.2,1.5)]` and shots `[(0,1.0), (1.0,2.0)]`, overlap assigns hello and world to shot 1 and again to shot 2.

### 7. CODE

```python
# run inside lab/ -- assign timestamped words to shots by maximum overlap
from video_core import synth_video, detect_shots

v = synth_video(90, 32, shots=(30, 60)); fps = 30
cuts = [0, *detect_shots(v), len(v)]
shots = [(cuts[i] / fps, cuts[i + 1] / fps) for i in range(len(cuts) - 1)]   # [(0,1),(1,2),(2,3)]
words = [("hello", 0.2, 0.5), ("world", 0.8, 1.2), ("again", 1.4, 1.7), ("bye", 2.5, 2.9)]
def overlap(a, b): return max(0.0, min(a[1], b[1]) - max(a[0], b[0]))
for w, t0, t1 in words:
    best = max(range(len(shots)), key=lambda i: overlap((t0, t1), shots[i]))
    print(w, "-> shot", best)       # hello->0, world->0 (overlap .2 vs .2: tie broken by order), again->1, bye->2
```
Code: [`lab/video_core.py`](../lab/video_core.py), [`lab/ctc_asr.py`](../lab/ctc_asr.py) (`forced_align` for word times).

### 8. INPUT → PROCESS → OUTPUT

```
audio, video, text ─► per-modality timestamps ─► common timeline ─► aligned segments ─► index / LLM context (with citations)
```

### 9. ENTERPRISE USE CASE

Meeting and lecture tools offer 'jump to the moment' search; news and sports archives retrieve clips by spoken phrases and visual events; compliance teams cite exact timecodes.

### 10. AI ENGINEERING CONNECTION

This is audio-visual RAG: retrieved aligned segments become context for an LLM ([14.28](14.28-video-language-models.md)), with timestamps for citations to reduce hallucination.

### 11. ADVANTAGES

Precise retrieval and citation; richer context than any single modality.

### 12. LIMITATIONS

Time-base errors, speech-visual lag, noisy ASR/timestamps, subjective semantic alignment.

### 13. TRADE-OFFS

Fine granularity (precise citations, more segments) vs coarse (cheaper index, fuzzier citations).

### 14. COMMON MISTAKES

- Mixing time bases (frames vs seconds vs samples).
- Ignoring VFR timestamps.
- Dropping timestamps when indexing.
- Aligning approximate segment timestamps as if word-accurate.

### 15. PERFORMANCE / COST CONSIDERATIONS

Alignment is cheap compared with ASR and embedding; indexing cost scales with number of segments; store only embeddings plus pointers to media.

### 16. SECURITY CONSIDERATIONS

Segment citations can expose sensitive moments: enforce access controls per segment and redact PII in transcripts.

### 17. INTERVIEW EXPLANATION

*"Alignment puts audio, video and text on one timeline. I get word times from forced alignment, shot boundaries from a cut detector and speakers from diarization, then assign by interval overlap and build segments with embeddings and timestamps. Retrieval returns segments with citations the LLM can quote."*

### 18. RAPID-FIRE ANSWER

Map words, shots and speakers onto one timeline (and shared embedding space) so retrieval can cite moments.
