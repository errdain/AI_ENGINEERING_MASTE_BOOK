### 1. WHAT IS IT?

Relative positional encoding makes attention depend on the *offset* between two tokens (j - i) instead of their absolute indices.

### 2. WHY DOES IT EXIST?

Language is largely about nearby relationships, and relative schemes generalize better to sequence lengths unseen in training than absolute tables.

### 3. DETAILED EXPLANATION

Implementations: learned relative key/value terms (Shaw et al., 2018), Transformer-XL style relative terms, T5-style learned **relative bias** (scalar per bucketed offset per head), and two parameter-free modern methods: **RoPE** ([6.24 RoPE](06.24-rope.md), rotates Q and K) and **ALiBi** ([6.25 ALiBi](06.25-alibi.md), linear bias on logits). All inject relative information into attention scores rather than the input embedding (`REVIEW_REQUIRED` for citations and bucket details).

### 4. HOW DOES IT WORK?

Score `s_ij = f(q_i, k_j, j - i)`; the position dependence is only through the offset.

### 5. SIMPLE EXAMPLE

'The word two places back' instead of 'word number 57'.

### 6. TECHNICAL EXAMPLE

T5 buckets offsets (exact for near, logarithmic for far) and adds a learned scalar per head to each logit.

### 7. CODE

```python
# run inside lab/
import numpy as np
from positional import alibi_bias
b = alibi_bias(5, slope=0.5)       # relative by construction: depends only on i - j
print(b[3, 1], b[4, 2])            # -1.0 -1.0 : same offset (2) -> same bias
print(b[3, 0])                     # -1.5      : offset 3
```

### 8. INPUT → PROCESS → OUTPUT

```
(q_i, k_j, offset j-i) ──► score ──softmax──► weights
```

### 9. ENTERPRISE USE CASE

Long-context products depend on relative schemes (RoPE with scaling, ALiBi).

### 10. AI ENGINEERING CONNECTION

Umbrella concept for [6.24 RoPE](06.24-rope.md) and [6.25 ALiBi](06.25-alibi.md).

### 11. ADVANTAGES

Better length generalization; matches linguistic locality; fewer parameters.

### 12. LIMITATIONS

More complex than adding vectors; implementation details are checkpoint-specific.

### 13. TRADE-OFFS

Generalization versus implementation complexity.

### 14. COMMON MISTAKES

- Treating 'relative' as one method.
- Mixing conventions between code and checkpoint.

### 15. PERFORMANCE / COST CONSIDERATIONS

Extra work inside attention; often fused in kernels.

### 16. SECURITY CONSIDERATIONS

None specific.

### 17. INTERVIEW EXPLANATION

*"Relative encoding makes attention depend on the distance between tokens rather than absolute positions, which generalizes better to longer inputs. RoPE and ALiBi are the parameter-free versions used in modern LLMs."*

### 18. RAPID-FIRE ANSWER

Attention depends on offset j-i, not on absolute positions.
