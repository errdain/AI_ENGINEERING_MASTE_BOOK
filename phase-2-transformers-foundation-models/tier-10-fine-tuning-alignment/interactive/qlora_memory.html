Fine-tuning memory: full vs LoRA vs QLoRA

Rough GPU memory for weights + gradients + optimizer state. Activations, KV cache, CUDA context and fragmentation are NOT included and can add many GB. Formulas are the simple bytes-per-parameter model used in the Tier 10 lab (lab/lora.py: finetune_memory_gb).

Full FT (mixed precision): fp16 weights 2 + fp16 grads 2 + fp32 master copy 4 + optimizer state = 16 B/param with Adam. LoRA: frozen fp16 base (2 B) + fp32 adapter, its grads and optimizer state. QLoRA: base stored in 4 bits (0.5 B) + one fp32 absmax per block + the same adapter state. Real QLoRA uses the NF4 codebook and double quantization of the absmax; this page and the lab use the simpler uniform variant, so treat numbers as estimates (REVIEW_REQUIRED for any specific model).
