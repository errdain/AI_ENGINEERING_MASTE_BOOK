### 1. WHAT IS IT?

**LoRA alpha** is the numerator of the scaling factor `alpha / r` applied to the low-rank update.

### 2. WHY DOES IT EXIST?

It sets the strength of the adapter relative to the frozen weight, so rank can be changed without retuning everything.

### 3. DETAILED EXPLANATION

If you hold `alpha` constant while raising `r`, each rank-1 component contributes less; with `alpha` proportional to `r` (for example `alpha = 2r`) the effective step stays comparable across ranks. Treat `alpha` as a learning-rate-like knob: raising it behaves roughly like raising the adapter's LR (with Adam, not exactly). Variants that change the scaling, such as `alpha / sqrt(r)`, exist (`REVIEW_REQUIRED`).

[Try alpha in the explorer](../interactive/lora_explorer.html).

### 4. HOW DOES IT WORK?

`delta W = (alpha / r) B A`; scaling multiplies the adapter output, and therefore its gradient wrt B and the effective update size.

### 5. SIMPLE EXAMPLE

A volume knob on the correction notes.

### 6. TECHNICAL EXAMPLE

In the lab, `scale = alpha / r` (default alpha 8, r 4 gives 2.0); `test_delta_weight_formula` checks it. No alpha sweep is committed (Exercise 2).

### 7. CODE

```python
layer = LoRALinear(nn.Linear(48, 48), r=8, alpha=16.0)
print(layer.scale)   # 2.0
```

### 8. INPUT → PROCESS → OUTPUT

```
alpha, r --> scale = alpha / r --> delta W = scale * B A
```

### 9. ENTERPRISE USE CASE

Teams fix alpha = 2r or alpha = r and tune only the LR to limit the search space (a common convention, `REVIEW_REQUIRED`).

### 10. AI ENGINEERING CONNECTION

Understanding alpha prevents false conclusions from rank sweeps.

### 11. ADVANTAGES

Decouples rank from step size.

### 12. LIMITATIONS

Interacts with LR, so hard to isolate.

### 13. TRADE-OFFS

Larger alpha = faster adaptation but more instability/forgetting.

### 14. COMMON MISTAKES

Changing r without alpha, then attributing the change to rank alone.

### 15. PERFORMANCE / COST CONSIDERATIONS

None directly; unstable alpha wastes runs.

### 16. SECURITY CONSIDERATIONS

A large effective scale increases drift from the base and safety erosion.

### 17. INTERVIEW EXPLANATION

Alpha divided by r is a fixed multiplier on the LoRA update. It acts like a learning rate for the adapter, so I keep alpha tied to r, for example 2r, when I sweep rank, and tune the LR separately.

### 18. RAPID-FIRE ANSWER

Alpha/r = the adapter's volume.
