### 1. WHAT IS IT?

**LoRA target modules** are the linear layers that receive adapters: attention `q,k,v,o` and/or MLP projections.

### 2. WHY DOES IT EXIST?

Where you put capacity matters as much as how much you add.

### 3. DETAILED EXPLANATION

The original LoRA paper adapted only attention `q` and `v` (`REVIEW_REQUIRED`); practice moved toward **all linear layers** (q,k,v,o plus MLP) because it usually helps at the same rank budget. **Measured here:** q,v with r=4 trained 1,536 parameters and reached **0.00** accuracy in 200 steps, while adapting all six matrices with r=8 reached 0.55 ([figure](../figures/05_full_vs_lora_vs_qlora.png)). In this toy the MLP and output layers are where the new mapping (lower to upper case) must be written; note that r also differed. Single seed.

[Select matrices in the explorer](../interactive/lora_explorer.html).

### 4. HOW DOES IT WORK?

`apply_lora(model, targets=...)` replaces each `nn.Linear` whose attribute name is in `targets`.

### 5. SIMPLE EXAMPLE

Choosing which pages of the book get sticky notes.

### 6. TECHNICAL EXAMPLE

Targets ("q_proj","v_proj") versus all six names (q,k,v,o,fc1,fc2). q,v gave 0.00, all six 0.55 (different r, one seed).

### 7. CODE

```python
ALL_SIX = ("q_proj", "k_proj", "v_proj", "o_proj", "fc1", "fc2")
layers = apply_lora(model, targets=ALL_SIX, r=8, alpha=16)
```
File: [`../lab/lora.py`](../lab/lora.py).

### 8. INPUT → PROCESS → OUTPUT

```
targets list --> replace matching Linear layers --> count params = sum r(in+out)
```

### 9. ENTERPRISE USE CASE

Default to all linear layers when quality matters; restrict to attention when memory is tight.

### 10. AI ENGINEERING CONNECTION

Determines which behaviour the adapter can rewrite (style vs new mappings).

### 11. ADVANTAGES

More targets = more capacity per rank.

### 12. LIMITATIONS

More targets = more parameters and memory.

### 13. TRADE-OFFS

Targets versus rank at a fixed parameter budget.

### 14. COMMON MISTAKES

Using wrong module names for the architecture (names differ per model); confusing rank effects with target effects.

### 15. PERFORMANCE / COST CONSIDERATIONS

Params scale with the number and size of targeted layers.

### 16. SECURITY CONSIDERATIONS

None specific.

### 17. INTERVIEW EXPLANATION

I decide which linear layers get adapters. The paper used q and v; today I usually target all linear layers because it helps at the same budget. In my toy, q,v only did not learn the task while all six matrices did, though rank also differed so I would not generalise.
