### 1. WHAT IS IT?

A video embedding is a vector (or short sequence of vectors) that summarises a clip or video, produced by a video or image encoder with temporal pooling, trained for tasks such as classification, retrieval or video-text alignment.

### 2. WHY DOES IT EXIST?

Search, recommendation, deduplication, clustering, moderation and RAG over video all need compact, comparable representations rather than raw frames.

### 3. DETAILED EXPLANATION

**Common recipes (`REVIEW_REQUIRED` for model specifics).**
1. *Frame-embedding pooling:* run an image encoder (CLIP/ViT, [Tier 13](../tier-13-vision-ai/README.md)) on sampled frames ([14.23](14.23-frame-sampling.md)); mean-pool (or attentively pool) to one vector. Simple, strong baseline, ignores order.
2. *Video transformers* (TimeSformer, ViViT, VideoMAE-style pretraining): tokens from tubelets with temporal attention ([14.25](14.25-temporal-representation.md), [14.26](14.26-temporal-attention.md)).
3. *Video-text contrastive models* (CLIP4Clip-style, `REVIEW_REQUIRED`): align clip and caption embeddings so text queries retrieve videos.
4. *Multimodal fusion:* concatenate or fuse audio embeddings ([14.7](14.07-audio-embeddings.md)) with visual ones.

**Granularity.** One embedding per video is too coarse for long videos; embed per shot ([14.24](14.24-scene-shot-segmentation.md)) or per fixed window and index them, then retrieve segments.

**Toy version in the lab.** `shot_embedding(frames)` is the mean intensity histogram of a shot: frames inside one shot are closer to each other than to frames of other shots (tested). A learned encoder replaces the histogram but keeps the interface.

**Metrics.** Recall@K for retrieval (`recall_at_k`), clustering purity, linear-probe accuracy ([14.32](14.32-video-evaluation.md)).

### 4. HOW DOES IT WORK?

```
video ─► shots/windows ─► sample frames ─► encoder ─► pool over time ─► [d] ─► vector index ─► cosine search
```

### 5. SIMPLE EXAMPLE

A one-line description of each scene on an index card; finding 'the beach scene' means scanning cards, not re-watching the film.

### 6. TECHNICAL EXAMPLE

A media archive embeds every shot, stores vectors in an ANN index with timestamps, and answers text queries by embedding the query with the paired text encoder.

### 7. CODE

```python
# run inside lab/ -- toy shot embeddings and a similarity check
import numpy as np
from video_core import synth_video, shot_embedding

v = synth_video(90, 32, shots=(30, 60))
e = [shot_embedding(v[a:b]) for a, b in [(0, 15), (15, 30), (30, 45), (60, 75)]]
dist = lambda x, y: float(np.abs(x - y).sum())
print(round(dist(e[0], e[1]), 3), round(dist(e[0], e[2]), 3), round(dist(e[0], e[3]), 3))
# same-shot pair is the smallest distance
```

### 8. INPUT → PROCESS → OUTPUT

```
clip frames (+audio) ─► encoder ─► pooled embedding ─► index ─► nearest neighbours (clips) or text-to-video retrieval
```

### 9. ENTERPRISE USE CASE

Stock-footage libraries, news archives and social platforms embed video for search, near-duplicate detection and recommendations.

### 10. AI ENGINEERING CONNECTION

Video embeddings plug into RAG ([14.29](14.29-audio-video-text-alignment.md)) and feed video-language models ([14.28](14.28-video-language-models.md)); evaluation of retrieval is in [14.32](14.32-video-evaluation.md).

### 11. ADVANTAGES

Compact, reusable, enable semantic search.

### 12. LIMITATIONS

Mean pooling ignores order/motion; long videos need segmentation; encoders reflect training data biases; text-video alignment is imperfect.

### 13. TRADE-OFFS

Frame-pooling (cheap, strong baseline) vs video transformers (motion-aware, heavy); granularity vs index size.

### 14. COMMON MISTAKES

- One embedding for a 2-hour video.
- Mixing embedding models in one index.
- Ignoring audio.
- Not storing timestamps with vectors.

### 15. PERFORMANCE / COST CONSIDERATIONS

Embedding cost is frames x encoder FLOPs; index size = number of segments x d; precompute offline.

### 16. SECURITY CONSIDERATIONS

Embeddings of faces/people create biometric risks; apply access control and retention; embedding inversion can reveal content (`REVIEW_REQUIRED`).

### 17. INTERVIEW EXPLANATION

*"A video embedding summarises a clip as a vector. A strong baseline is to embed sampled frames with an image encoder like CLIP and mean-pool; better models use temporal attention or video-text contrastive training. For long videos I embed per shot or window with timestamps and search them in a vector index."*

### 18. RAPID-FIRE ANSWER

Pooled vector of encoded frames/tubelets summarising a clip for search and downstream models.
