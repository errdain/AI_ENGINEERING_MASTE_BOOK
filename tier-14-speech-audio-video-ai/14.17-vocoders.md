### 1. WHAT IS IT?

A vocoder turns an acoustic representation (typically a mel spectrogram, or codec tokens) into a waveform. Classical vocoders (Griffin-Lim, WORLD) estimate phase with signal-processing rules; neural vocoders (WaveNet, WaveGlow, HiFi-GAN, Vocos and others) learn the mapping.

### 2. WHY DOES IT EXIST?

Magnitude spectrograms and mel features contain no phase, and mel features are lossy; to hear audio we need a waveform. Phase and fine structure must be reconstructed convincingly.

### 3. DETAILED EXPLANATION

**Griffin-Lim (implemented here).** Given an STFT magnitude `|S|`, start from random phase, then iterate: invert to a waveform (ISTFT), re-analyse, keep the new phase but reimpose the target magnitude. Converges to a consistent spectrogram but with audible 'phasiness'. Spectral convergence `||ref - |STFT(x)|||/||ref||` improves with iterations (lab: about 0.40 after 1 iteration, 0.28 after 5 and 0.14 after 60 on a chirp+tone). For mel input you must first approximate a linear spectrogram (pseudo-inverse of the filterbank), another source of loss.

**Neural vocoder families (`REVIEW_REQUIRED` for details).**
- *Autoregressive* (WaveNet): excellent quality, very slow sample-by-sample generation.
- *Flow-based* (WaveGlow) and *GAN-based* (HiFi-GAN, MelGAN family): parallel, fast; GAN vocoders are widely used for real-time TTS.
- *Diffusion/flow-matching vocoders:* high quality with multiple steps.
- *Spectral-domain generators* (Vocos-style) predict STFT coefficients and invert with ISTFT.
- *Codec decoders* ([14.8](14.08-audio-tokenization-and-neural-codecs.md)) are vocoders that read discrete tokens.

**Losses.** Multi-resolution STFT loss, mel loss, adversarial and feature-matching losses.

**Metrics.** Mel-cepstral distortion, MOS/predicted MOS, speaker similarity, RTF ([14.20](14.20-audio-evaluation.md)).

### 4. HOW DOES IT WORK?

```
mel [T,80] ─► (neural vocoder: upsample conv blocks ×~256 to sample rate) ─► waveform
|STFT| ─► Griffin-Lim: random phase → ISTFT → STFT → keep phase, reset magnitude → repeat ─► waveform
```

### 5. SIMPLE EXAMPLE

You are given the shape of the waves' loudness over time but not the timing of the ripples; the vocoder fills in ripple timing so the sound is natural.

### 6. TECHNICAL EXAMPLE

A typical GAN vocoder upsamples 100 mel frames/s to 22 050-24 000 samples/s with transposed convolutions; RTF well below 1 on GPU (`REVIEW_REQUIRED`).

### 7. CODE

```python
# run inside lab/ -- classical phase retrieval
import numpy as np
from audio_core import chirp, tone, stft, griffin_lim, spectral_convergence

x = chirp(300, 2500, 0.5, 8000) + 0.5 * tone(1000, 0.5, 8000)
mag = np.abs(stft(x, 256, 64))
for it in (1, 5, 60):
    print(it, round(spectral_convergence(mag, griffin_lim(mag, 256, 64, iters=it)), 3))
# error shrinks with iterations (about 0.40, 0.28, 0.14)
```

### 8. INPUT → PROCESS → OUTPUT

```
acoustic features (mel/codes) ─► vocoder ─► waveform ─► resample/loudness ─► playback
```

### 9. ENTERPRISE USE CASE

Vocoder choice sets the quality/cost floor of every TTS deployment: edge devices use small fast GAN vocoders; studio dubbing can afford slower, higher-quality ones.

### 10. AI ENGINEERING CONNECTION

Vocoders sit at the end of generative speech pipelines ([14.16](14.16-text-to-speech-tts.md)) and in codec decoders; their RTF contributes directly to realtime latency ([14.19](14.19-realtime-speech-systems.md)).

### 11. ADVANTAGES

Neural vocoders are fast, natural and reusable across acoustic models.

### 12. LIMITATIONS

Artifacts on out-of-domain speakers/sounds, tied to the mel recipe, cannot recover information absent from the mel, GAN training instability.

### 13. TRADE-OFFS

Quality vs speed vs size; Griffin-Lim is training-free but robotic.

### 14. COMMON MISTAKES

- Using a vocoder trained on another mel configuration.
- Comparing vocoders without fixing the acoustic model.
- Forgetting loudness normalisation.
- Using Griffin-Lim and expecting studio quality.

### 15. PERFORMANCE / COST CONSIDERATIONS

RTF and time-to-first-chunk matter; streaming vocoders run on small overlapping windows. Quantisation and distillation help on CPU.

### 16. SECURITY CONSIDERATIONS

Vocoders turn leaked features back into voices (voice-reconstruction risk) and underpin deepfake tooling; add provenance/watermarking where possible (`REVIEW_REQUIRED`).

### 17. INTERVIEW EXPLANATION

*"A vocoder converts mel spectrograms or codec tokens into waveforms. The missing piece is phase and fine detail: Griffin-Lim estimates phase iteratively, while neural vocoders like HiFi-GAN learn it and run in parallel, much faster than autoregressive WaveNet. I pick based on quality and real-time factor."*

### 18. RAPID-FIRE ANSWER

Turns mel/codec features into audio by reconstructing phase and detail; Griffin-Lim classically, GANs or diffusion today.
