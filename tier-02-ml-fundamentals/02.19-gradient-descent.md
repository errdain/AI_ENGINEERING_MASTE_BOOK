# 2.19 Gradient descent

**Metadata** — Tier: 2 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: Very high · Hands-on: Very high
Prerequisites: 1.23, 2.17, 2.18 · Leads to: 2.20 SGD, 2.25 Learning rate, Tier 3 Backpropagation, Tier 4 Optimizers

### 1. What is it?
An iterative method that minimizes an objective by repeatedly stepping opposite to its gradient: `θ ← θ − η ∇J(θ)`, with learning rate `η` (2.25).

### 2. Why does it exist?
Closed-form solutions exist only for simple models. Gradient descent works for any differentiable model, including billion-parameter networks.

### 3. Detailed explanation
- **Update rule and intuition:** the gradient (1.23) points uphill; stepping the other way lowers `J` for small enough `η`.
- **Full-batch ("vanilla") gradient descent** uses all `n` samples to compute the gradient each step: exact gradient, one update per epoch, expensive for large data.
- **Convex case:** on linear regression, GD converges to the closed-form solution. In the lab: GD weights (2.0070, −0.9909) and intercept 0.4921 equal the least-squares solution to four decimals; the training loss decreases monotonically and gets within 5% of the optimum in 18 steps (lr 0.1).
- **Non-convex case (neural nets):** GD reaches a stationary point that may be a saddle or a local minimum (1.46, 1.47); good initialization and noise help.
- **Conditioning:** convergence speed depends on the Hessian's condition number; unscaled features create narrow valleys and force tiny learning rates (2.25, 2.47).
- **Stopping criteria:** gradient norm small, loss change small, fixed iteration budget, or validation loss stops improving (early stopping, 2.12).
- **Variants** (SGD 2.20, momentum/Adam in Tier 4) change how the gradient is estimated or used, not the basic idea.
- **Gradient checking** with finite differences validates implementations (1.21, 1.25).

### 4. How does it work?
Initialize `θ` → compute the objective's gradient on the data → update → check stopping rule → repeat.

### 5. Simple example
Walking downhill in fog by always taking a small step in the steepest downward direction.

### 6. Technical example
Fitting a logistic regression with 20,000 iterations of GD matches scikit-learn's unpenalized solution; training a neural network is the same loop with backpropagation providing gradients.

### 7. Code
```python
import mlkit as M
X, y = M.make_linear(300, noise=0.3, seed=0)
w, b, hist = M.sgd_linear(X, y, lr=0.1, batch_size=None, epochs=300)      # batch_size=None = full-batch GD
print(w.round(4), round(b, 4), M.LinearRegression().fit(X, y).coef_.round(4))   # identical to least squares
```
TESTED (`ex_2_19`; logistic GD vs scikit-learn in `test_logistic_regression_matches_sklearn_unpenalized`).

### 8. Input → Process → Output
`θ₀ → ∇J(θ_t) → θ_{t+1} = θ_t − η∇J → … → θ*`

### 9. Enterprise use case
Training jobs are long-running GD loops with checkpoints, monitoring of loss/gradient norm and automatic restarts.

### 10. AI engineering connection
All neural-network training: the forward pass computes `J`, backpropagation computes `∇J`, the optimizer applies the update (Tier 3–4).

### 11. Advantages
General, scalable, simple; works with any differentiable objective.

### 12. Limitations
Only finds stationary points; sensitive to learning rate and scaling; full-batch cost grows with data.

### 13. Trade-offs
Exact gradients (stable, slow per step) vs cheaper noisy gradients (2.20).

### 14. Common mistakes
Learning rate too large; unscaled features; wrong gradient sign; not zeroing accumulated gradients; stopping on training loss only.

### 15. Performance / cost
Cost per step ∝ dataset size (full batch); this is why mini-batches dominate in practice.

### 16. Security
Gradients can leak training data in distributed/federated settings; clip and add noise for privacy.

### 17. Interview explanation
"Gradient descent minimizes the objective by repeatedly stepping against its gradient, scaled by the learning rate. On convex problems like linear regression it converges to the closed-form answer; on neural networks it finds good stationary points. Scaling features and picking the learning rate decide whether it converges quickly or not at all."

### 18. Rapid-fire
θ ← θ − η∇J; converges to least squares on linear regression; speed depends on conditioning and η.
