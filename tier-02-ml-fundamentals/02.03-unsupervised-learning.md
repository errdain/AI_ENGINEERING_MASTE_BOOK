# 2.3 Unsupervised learning

**Metadata** — Tier: 2 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: Medium-High · Hands-on: High
Prerequisites: 2.1, 1.16, 1.32 · Leads to: 2.16 Clustering, embeddings (Tier 6), anomaly detection

### 1. What is it?
Learning structure from data **without labels**: grouping similar items, estimating density, finding low-dimensional representations, flagging outliers.

### 2. Why does it exist?
Most data is unlabeled. Unsupervised methods reveal structure, compress data, and create features without paying for labels.

### 3. Detailed explanation
- **Main families:** clustering (2.16), density estimation/anomaly detection, dimensionality reduction and representation learning (e.g., principal components of the covariance matrix, 1.32/1.18/1.19).
- **No ground truth ⇒ evaluation is harder.** You rely on internal criteria (inertia, silhouette), stability across runs, downstream task performance, or human inspection. A cluster is only "right" if it is useful.
- **Choices matter:** distance metric (1.16), feature scaling (2.47), number of clusters, initialization.
- **Elbow heuristic:** inertia (within-cluster squared distance) always falls as `k` grows; look for the bend. On two well-separated blobs: inertia is 8049 at `k=1`, 799 at `k=2`, 661 at `k=3`, 354 at `k=6`, so the big drop ends at the true `k=2`.
- Self-supervised learning (2.5) is often grouped with unsupervised learning because it uses no human labels; this book separates them because it *creates* labels from the data.

### 4. How does it work?
Define a similarity/objective on the data alone (e.g., minimize within-cluster distance), optimize, then interpret the result.

### 5. Simple example
Sorting a pile of unlabeled photos into piles of similar-looking ones.

### 6. Technical example
Customer segmentation by behaviour; clustering support tickets; detecting unusual server metrics; compressing embeddings.

### 7. Code
```python
import mlkit as M
X, y = M.make_blobs_binary(400, sep=6.0, seed=0)
print({k: round(M.KMeans(k, seed=0).fit(X).inertia_) for k in (1, 2, 3, 4, 6)})   # elbow at k=2
km = M.KMeans(2, seed=0).fit(X)    # labels_ found without ever seeing y; agree with y 100%
```

### 8. Input → Process → Output
`unlabeled X → objective on structure → clusters / density / low-dim codes`

### 9. Enterprise use case
Segmentation for marketing, log/anomaly triage, deduplication, exploratory analysis before labeling.

### 10. AI engineering connection
Clustering of embeddings to organize corpora, topic discovery for RAG corpora, anomaly detection in LLM traffic, dimensionality reduction for vector stores.

### 11. Advantages
No labels needed; scales with raw data; exposes hidden structure.

### 12. Limitations
Results depend on metric/scaling/`k`; clusters may not match business categories; hard to validate.

### 13. Trade-offs
More clusters fit data better but become less interpretable.

### 14. Common mistakes
Not scaling features; treating clusters as ground truth; choosing `k` by inertia alone; ignoring stability across seeds.

### 15. Performance / cost
k-means is `O(n·k·d)` per iteration; distance computation dominates; use mini-batch variants at scale.

### 16. Security
Clusters of user data can reveal sensitive groupings; apply privacy review before use.

### 17. Interview explanation
"Unsupervised learning finds structure without labels: clustering, density estimation, dimensionality reduction. Since there is no answer key, I validate by stability, internal metrics and whether it helps a downstream task, and I'm careful to scale features first."
