> **In plain words**
> In this concept, **bias** means **a systematic error that does not go away with more data**: the model is consistently wrong in the same direction, because the *kind* of model you chose cannot represent the truth.
> Like a bathroom scale that always reads 2 kg heavy: weigh yourself a hundred times and the average is still 2 kg off.
> **Warning:** the word "bias" means five different things in AI. Learn to tell them apart (table below).

**You need first:** 2.26 Underfitting and 1.29 Expectation (an average).

### 1. What is it?
In this concept, **model bias** (statistical bias): the systematic difference between the *average* prediction of a learning procedure and the true function; the error that remains even with unlimited training sets.

### 2. Why does it matter?
Bias explains underfitting and tells you whether a simpler or richer model class can ever fit the truth.

### 3. Detailed explanation
**Five meanings of "bias" in this book. Keep them apart.**
1. **Model / statistical bias (this page):** `Bias(x) = E_D[f̂(x)] − f(x)`, averaged over training sets `D`. Squared and averaged over inputs it is the `bias²` of 2.30.
2. **Inductive bias:** assumptions built into a model that let it generalise from limited data (linearity, locality in CNNs, attention patterns).
3. **Dataset / sampling bias:** the training data does not represent the target population (2.9, 2.10).
4. **Societal / fairness bias:** unjust disparities in outcomes across groups (Tier 32).
5. **The bias term** `b` in `w·x + b` (3.7): unrelated to the others despite the name.

**Facts about model bias**
- A degree-1 model fit to a sine wave has a large `bias²` (well above the noise floor) **however many datasets you average**; a degree-5 model has almost none.
- Because sine is an odd function, adding a degree-2 term to a line does not reduce the bias at all (and degree 4 adds nothing over degree 3).
- **Sampling bias** is different: train a degree-5 polynomial only on `x ∈ [−1, 0]` and it is accurate there but wildly wrong on `[0, 1]`. The training distribution defines where the model can be trusted.
- **Reducing model bias:** a richer model class, better features, less regularisation, ensembling diverse models.
- **Bias and fairness are different problems:** a model can have low statistical bias and still produce disparate outcomes (if the data reflects past discrimination), and vice versa.

### 4. How does it work?
Imagine training the same procedure on many datasets. The gap between the average of all those predictions and the truth is the bias. In practice it is estimated by simulation, or inferred from a high training error.

### 5. Simple example
A scale that always reads 2 kg too heavy: more weighings do not remove the error.

**With numbers.** The true line is `y = 2x`. A model that must pass through the origin with a fixed slope of 1.5 predicts `1.5x`. At `x = 10` it predicts 15 instead of 20: a bias of −5. Collect a million more training points: the model *class* still predicts `1.5x`. The error remains.

### 6. Technical example
A linear model on a quadratic relationship: systematic under-prediction in the middle and over-prediction at the ends.

### 7. Code
**① By hand (plain Python).** A model class that cannot represent the truth.

```python
import random

random.seed(0)
def truth(x): return 2 * x
for n in (10, 1000, 100000):
    xs = [random.uniform(0, 10) for _ in range(n)]
    ys = [truth(x) + random.gauss(0, 1) for x in xs]
    # model class: "y = c" (a constant). Its best fit is the mean of y, however much data there is.
    c = sum(ys) / n
    err_at_9 = c - truth(9)
    print(f"n = {n:>6}: constant model predicts {c:5.2f} everywhere; error at x = 9 is {err_at_9:+.2f}")
```

```text
n =     10: constant model predicts 10.72 everywhere; error at x = 9 is -7.28
n =   1000: constant model predicts  9.89 everywhere; error at x = 9 is -8.11
n = 100000: constant model predicts  9.99 everywhere; error at x = 9 is -8.01
```

**② With NumPy.** Estimating bias² by simulation: average predictions over many datasets.

```python
import numpy as np

f = lambda x: np.sin(np.pi * x)
grid = np.linspace(-1, 1, 200)
xs = np.linspace(-1, 1, 30)
rng = np.random.default_rng(0)
for degree in (0, 1, 2, 3, 5):
    preds = np.array([np.polyval(np.polyfit(xs, f(xs) + rng.normal(0, 0.2, 30), degree), grid) for _ in range(300)])
    bias2 = np.mean((preds.mean(axis=0) - f(grid)) ** 2)             # average over datasets first, then compare with the truth
    print(f"degree {degree}: bias² = {bias2:.4f}   (noise floor 0.04)")
```

```text
degree 0: bias² = 0.4975   (noise floor 0.04)
degree 1: bias² = 0.2018   (noise floor 0.04)
degree 2: bias² = 0.2017   (noise floor 0.04)
degree 3: bias² = 0.0049   (noise floor 0.04)
degree 5: bias² = 0.0000   (noise floor 0.04)
```

**③ With scikit-learn.** Sampling bias: trained on one region, trusted in another.

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures

rng = np.random.default_rng(0)
f = lambda x: np.sin(np.pi * x)
x = rng.uniform(-1, 0, (200, 1))                                  # training data only from [-1, 0]
y = f(x[:, 0]) + rng.normal(0, 0.2, 200)
model = make_pipeline(PolynomialFeatures(5), LinearRegression()).fit(x, y)
for lo, hi in ((-1, 0), (0, 1)):
    xt = rng.uniform(lo, hi, (500, 1))
    print(f"x in [{lo:>2}, {hi}]: MSE {np.mean((model.predict(xt) - f(xt[:, 0])) ** 2):.4f}")
```

```text
x in [-1, 0]: MSE 0.0011
x in [ 0, 1]: MSE 246.0926
```

### 9. Enterprise use case
Audits separate "model too simple" (statistical bias) from "data unrepresentative" (sampling bias) and "unfair outcomes" (governance).

### 10. AI engineering connection
Inductive biases of architectures (attention, convolution) and training-data bias in LLMs shape behaviour; evaluate across slices (Tiers 30, 32).

### 11. Advantages
(Of knowing it) it tells you exactly when more data is useless.

### 12. Limitations
The true function is unknown, so bias is estimated, not observed.

### 13. Trade-offs
Lower bias through flexibility raises variance (2.29, 2.30).

### 14. Common mistakes
Using "bias" without saying which one; assuming more data reduces model bias; ignoring sampling bias because overall accuracy is high.

### 15. Performance / cost
Reducing bias often needs larger models or more features: more compute.

### 16. Security
Dataset and societal bias create legal and ethical exposure; document data provenance and test on protected-group slices.

### 20. Hands-on exercise
**Goal:** see where a sampling-biased model stops being reliable.

1. Train a degree-5 polynomial on `x ∈ [−1, 0]` only (noisy sine).
2. Evaluate the error on 8 equal slices of `[−1, 1]`.
3. Where does the error blow up?

<details>
<summary>Show a solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)
f = lambda x: np.sin(np.pi * x)
x = rng.uniform(-1, 0, 200)
coefs = np.polyfit(x, f(x) + rng.normal(0, 0.2, 200), 5)
edges = np.linspace(-1, 1, 9)
for lo, hi in zip(edges[:-1], edges[1:]):
    xt = np.linspace(lo, hi, 50)
    print(f"x in [{lo:+.2f}, {hi:+.2f}]: error {np.mean((np.polyval(coefs, xt) - f(xt)) ** 2):9.4f}")
```

```text

x in [-0.75, -0.50]: error    0.0013
x in [-0.50, -0.25]: error    0.0003
x in [-0.25, +0.00]: error    0.0027
x in [+0.00, +0.25]: error    0.0140
x in [+0.25, +0.50]: error    3.7685
x in [+0.50, +0.75]: error   95.8834
x in [+0.75, +1.00]: error  994.7815
```
