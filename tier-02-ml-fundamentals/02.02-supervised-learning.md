# 2.2 Supervised learning

**Metadata** — Tier: 2 · Phase: 1 · Priority: P0 · Difficulty: 1/5 · Interview: Very high · Hands-on: Very high
Prerequisites: 2.1, 1.35 · Leads to: 2.14 Classification, 2.15 Regression, 2.17 Loss, Tier 10 Fine-tuning

### 1. What is it?
Learning a function from **labeled examples** `(x, y)` so it predicts `y` for new `x`. The labels are the supervision: the model is told the right answer during training.

### 2. Why does it exist?
When you can obtain correct answers for past cases, supervised learning turns them into a reusable predictor, the most widely used and best-understood ML setting.

### 3. Detailed explanation
- **Two main tasks:** classification (discrete `y`, 2.14) and regression (continuous `y`, 2.15).
- **Objective:** minimize the average loss over training pairs (2.17), then check performance on data not used for fitting (2.13). Under maximum likelihood (1.35) squared error corresponds to Gaussian noise and cross-entropy to categorical labels.
- **Label cost is the bottleneck:** labels require people, time or delayed outcomes. This motivates semi-supervised (2.4) and self-supervised (2.5) methods.
- **Fine-tuning an LLM on instruction/response pairs is supervised learning** (Tier 10).
- **Assumption:** training and deployment data come from (roughly) the same distribution; when they differ you have distribution shift (2.34).
- **Demonstration (two Gaussian classes, 600 samples):** logistic regression gets 91.4% train and 91.7% held-out accuracy vs 50% for the majority-class baseline.

### 4. How does it work?
Pick a model `f(x; θ)` → compute predictions → compare with labels via a loss → update `θ` by gradient descent (2.19) → repeat → evaluate on held-out data.

### 5. Simple example
Flash cards with answers on the back: study the cards, then get quizzed on new ones.

### 6. Technical example
Spam filter: emails (features) with spam/not-spam labels; a logistic regression or neural network learns to separate them.

### 7. Code
```python
import mlkit as M
X, y = M.make_blobs_binary(600, sep=2.0, seed=0)
tr, va, te = M.train_val_test_indices(600, seed=0, stratify=y)
m = M.LogisticRegression(n_iter=3000).fit(X[tr], y[tr])
print(M.accuracy(y[tr], m.predict(X[tr])), M.accuracy(y[te], m.predict(X[te])))   # ≈ 0.914  0.917
```
TESTED (`ex_2_2`; our logistic regression matches scikit-learn's coefficients to 2e-2 in `test_mlkit.py`).

### 8. Input → Process → Output
`(X, y) pairs → fit f by minimizing loss → f(x_new) → prediction`

### 9. Enterprise use case
Churn prediction, credit risk, demand forecasting, document classification, defect detection: any place with historic outcomes.

### 10. AI engineering connection
Reward models, classifiers for guardrails (Tier 32), rerankers (Tier 21), evaluators, and instruction-tuned LLMs are supervised models.

### 11. Advantages
Direct objective, strong theory, easy evaluation against labels.

### 12. Limitations
Needs labels; can only learn what labels reflect (including their biases and mistakes); degrades under shift.

### 13. Trade-offs
More labeled data helps but costs; weak/proxy labels are cheap but noisy (2.8).

### 14. Common mistakes
Evaluating on training data; leaking labels into features (2.33); ignoring label quality; no baseline.

### 15. Performance / cost
Training cost scales with data × model size; label acquisition is often the dominant cost.

### 16. Security
Poisoned or manipulated labels corrupt the model; protect the labeling pipeline and sample for audit.

### 17. Interview explanation
"Supervised learning fits a function to input–label pairs by minimizing a loss, then I check it on held-out data. Classification predicts categories, regression predicts numbers. The main costs are labels and making sure training data matches production."

### 18. Rapid-fire
