# 2.44 Cross-validation

**Metadata** — Tier: 2 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: Very high · Hands-on: Very high
Prerequisites: 2.12, 2.13, 2.33 · Leads to: 2.36 Tuning, 2.31 Generalization, Tier 30 Evaluation

### 1. What is it?
Estimating generalization by **splitting the data into `k` folds**, training on `k−1` folds and validating on the held-out fold, rotating until every fold has served as validation; the scores are averaged.

### 2. Why does it exist?
With limited data, a single validation split is noisy and wastes data. Cross-validation uses every sample for both training and validation (never at the same time).

### 3. Detailed explanation
- **k-fold:** each sample is validated exactly once (tested). Typical `k` = 5 or 10. Larger `k` → less pessimistic bias, more compute; `k = n` is leave-one-out.
- **Variance reduction (n=100 samples, logistic regression, 30 repeated experiments):** a single 70/30 hold-out validation set gives mean 0.827 with standard deviation **0.083** across splits; 5-fold CV gives mean 0.826 with standard deviation **0.0066** — over 12× steadier. The accuracy of the model trained on all 100 points, measured on 2,400 fresh points, is 0.856: both estimates are slightly pessimistic because they train on 70–80% of the data.
- **Stratified k-fold** keeps class proportions in each fold (tested: five folds with exactly 10 positives each). Essential for imbalance (2.45).
- **Group k-fold** keeps all rows of a group (user, patient, document) in one fold (2.10).
- **Time-series CV (expanding window)** trains on the past and validates on the next block (`time_series_splits`; tested: training indices always precede validation). For time-ordered data, random k-fold is optimistic: in the lab, MSE 0.189 (random folds) vs **0.405** (forward folds).
- **All preprocessing inside the fold:** scalers, imputers, feature selection, target encoding, resampling are fit on the training portion only (2.33). Selecting features on all data and then cross-validating gives 90% accuracy on pure noise.
- **CV for model selection vs for error estimation:** choosing hyperparameters by CV makes the best CV score optimistic; use **nested CV** or a final test set for an honest estimate (2.36).
- **Report mean and spread** (standard deviation across folds, or repeated CV); folds are not independent, so the naive standard error understates uncertainty.
- **Not suitable when** training is very expensive (LLM fine-tuning); a single large validation set is used instead.

### 4. How does it work?
Create folds (stratified/grouped/time-aware as needed) → for each fold: fit preprocessing and model on training folds, score on the validation fold → aggregate.

### 5. Simple example
Five study groups take turns being the quiz audience while the other four study.

### 6. Technical example
5×2 repeated stratified CV to compare two models on a 3,000-row dataset; time-series CV for demand forecasting.

### 7. Code
```python
import mlkit as M, numpy as np
for tr, va in M.kfold_indices(len(y), k=5, seed=0, stratify=y):
    sc = M.StandardScaler().fit(X[tr]); m = M.LogisticRegression().fit(sc.transform(X[tr]), y[tr])
    print(M.accuracy(y[va], m.predict(sc.transform(X[va]))))
folds = M.time_series_splits(500, 4)         # expanding-window splits for ordered data
```

### 8. Input → Process → Output
`data → folds → (train on k−1, validate on 1) × k → mean ± spread`

### 9. Enterprise use case
CV scores with spread are required in model cards for tabular models; platforms provide group/time-aware splitters.

### 10. AI engineering connection
Used for classifiers and rerankers on small labeled sets; for LLM evaluation use fixed, versioned dev/test sets and bootstrap intervals instead.

### 11. Advantages
Efficient use of data; steadier estimates; basis for model selection.

### 12. Limitations
`k` times the training cost; invalid if samples are dependent and folds ignore groups/time; folds are correlated.

### 13. Trade-offs
Larger `k`: less bias, more variance in fold scores and more compute.

### 14. Common mistakes
Preprocessing before splitting; random folds for time or grouped data; selecting a model by CV then quoting its CV score as the final performance; ignoring fold-to-fold spread.

### 15. Performance / cost
Cost ∝ `k`; parallelize folds.

### 16. Security
CV does not protect against leakage via duplicates or test contamination; dedupe first.

### 17. Interview explanation
"Cross-validation rotates validation across k folds to get a steadier estimate from limited data. I stratify for imbalance, group by entity, use forward-in-time folds for temporal data, and fit all preprocessing inside each fold. Because choosing by CV is optimistic, I confirm on an untouched test set or use nested CV."

### 18. Rapid-fire
