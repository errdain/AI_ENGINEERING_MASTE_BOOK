# 2.17 Loss functions

**Metadata** — Tier: 2 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: Very high · Hands-on: Very high
Prerequisites: 1.21, 1.35, 1.37 · Leads to: 2.18 Objective, 2.19 Gradient descent, 2.40 F1 (a metric, not a loss), Tier 4 Loss calculation

### 1. What is it?
A function `ℓ(ŷ, y)` that returns a **non-negative number measuring how wrong one prediction is**. The average over the data is what training minimizes.

### 2. Why does it exist?
Optimization needs a single, differentiable score of error. The loss defines what 'good' means to the learning algorithm.

### 3. Detailed explanation
Choice follows the task and the assumed noise (1.35):
| Task | Loss | Notes |
|---|---|---|
| Regression | MSE `(y−ŷ)²` | Gaussian MLE; strongly punishes outliers |
| Regression | MAE `\|y−ŷ\|` | Laplace MLE; robust, non-smooth at 0 |
| Regression | Huber | quadratic near 0, linear in tails; robust and smooth |
| Binary classification | Binary cross-entropy | compute from logits: `softplus(z) − y·z` |
| Multiclass | Categorical cross-entropy | `−log softmax(z)[y]` (1.37) |

- **Outlier demonstration** (100 points on `y = 3x + 1`, 5 gross outliers +40): MSE intercept 3.00 (true 1), MAE 1.007, Huber 1.039. Slopes are all ≈ 3.
- **Why not MSE for classification?** With a sigmoid and a confident wrong prediction (logit −6, true label 1) the gradient of BCE w.r.t. the logit is −0.9975, while that of MSE-on-sigmoid is −0.0049, about 200× smaller: MSE barely corrects confident mistakes (saturation, 1.42).
- **Compute losses from logits** with the log-sum-exp trick (1.43); `bce_from_logits(y, z)` stays finite at `z = ±1000`.
- **A loss is not a metric.** Train with a differentiable loss; judge with the metric that matches the business goal (2.37–2.42, 2.51). Accuracy and F1 are not differentiable and are not used for gradient descent.
- **Class weights and label smoothing** are modifications of the loss for imbalance and overconfidence (2.45).
- Tier 4 (4.3) covers computing the loss inside a PyTorch training loop; this concept is the authoritative definition.

### 4. How does it work?
For each sample compute `ℓ`, average over the batch, differentiate with respect to parameters, update (2.19).

### 5. Simple example
A scoring rule for darts: distance from the bullseye, possibly squared.

### 6. Technical example
LLM pretraining loss: cross-entropy of the next token averaged over all positions; perplexity is its exponential.

### 7. Code
```python
import numpy as np, mlkit as M
y, p = np.zeros(4), np.array([0, 0, 0, 10.0])
print(M.mse(y, p), M.mae(y, p), M.huber(y, p))        # 25.0  2.5  2.375
print(M.bce_from_logits(np.array([1, 0, 1]), np.array([-1000.0, 1000.0, 0.3])))  # finite
```

### 8. Input → Process → Output
`prediction, target → ℓ → average → scalar to minimize`

### 9. Enterprise use case
Custom business losses (asymmetric costs, quantile loss for demand) align training with money, not just statistics.

### 10. AI engineering connection
Cross-entropy (LLMs), contrastive losses (embeddings, Tier 6), preference losses (Tier 10), KL penalties (1.38).

### 11. Advantages
Makes learning a well-posed optimization problem.

### 12. Limitations
Proxy for the real goal; choice affects robustness and calibration.

### 13. Trade-offs
Robust losses resist outliers but may converge slower or ignore informative extremes.

### 14. Common mistakes
MSE for classification; applying softmax then a loss that applies softmax again; unscaled targets; optimizing a loss that disagrees with the evaluation metric; averaging over padding tokens.

### 15. Performance / cost
Loss computation is cheap compared with the forward pass, except for huge vocabularies (logit tensor memory).

### 16. Security
Loss values can leak membership information; do not expose per-example losses for sensitive models.

### 17. Interview explanation
"A loss turns an error into a number we can minimize. MSE for regression is Gaussian maximum likelihood; cross-entropy for classification is categorical maximum likelihood and gives a clean softmax-minus-label gradient. I choose robust losses like Huber when outliers are likely, and I always compute classification losses from logits for stability."

### 18. Rapid-fire
Loss = per-sample error score; MSE/MAE/Huber for regression; cross-entropy for classification; not the same as the metric.
