# 2.15 Regression

**Metadata** — Tier: 2 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: High · Hands-on: Very high

> **In plain words**
> **Regression** predicts **a number**: a price, tomorrow's demand, a delivery time.
> The simplest version, **linear regression**, draws the **best straight line** (or flat plane) through the data. "Best" means the line that makes the **squared gaps** between predictions and true values as small as possible.
> A golden habit: always compare against the dumbest baseline, **"just predict the average"**.

**You need first:** 2.2 Supervised learning; matrix multiplication (1.11) helps.

> **Figure 2.15-1 — the best line and its residuals**
>
> ```mermaid
> flowchart LR
>     D["points (x, y)"] --> F["choose slope and intercept<br/>that minimise the sum of<br/>squared vertical gaps"]
>     F --> L["fitted line ŷ = w·x + b"]
>     L --> R["residual = y − ŷ<br/>(how far each point is off)"]
> ```
>
> *How to read it:* the **residual** of a point is the vertical gap between its true value and the line. Least squares picks the line with the smallest total of squared residuals. With an intercept in the model, the residuals add up to exactly zero.

**Words you'll meet on this page**

| Word | What it means here |
|---|---|
| regression | predicting a continuous number |
| least squares | choosing parameters to minimise squared error |
| residual | `y − ŷ`: the error on one example |
| MSE / RMSE / MAE | mean squared / root mean squared / mean absolute error |
| `R²` | fraction of variance explained compared with predicting the mean |
| extrapolation | predicting outside the range seen in training |
| collinearity | features that nearly copy each other |

### 1. What is it?
Supervised learning where the target `y` is a **continuous number**: price, demand, temperature, latency.

### 2. Why does it exist?
Many business questions are quantities, not categories. Regression predicts the quantity (and, ideally, how uncertain it is).

### 3. Detailed explanation
- **Linear regression:** `ŷ = w·x + b`. Least squares has the closed form `w = (XᵀX)⁻¹Xᵀy`; in practice use a least-squares solver (`lstsq`) rather than inverting (1.14).
- **Assumptions behind least squares:** the relationship is linear in the features, the errors are independent with constant variance, and there is no extreme collinearity. Under Gaussian noise, MSE is the maximum-likelihood loss (1.35).
- **Beyond linear:** add non-linear features (polynomial terms), or use more flexible models (trees, neural networks).
- **Evaluation:** MSE, RMSE, MAE and `R² = 1 − SSE/SST`, the share of variance explained relative to the "predict the mean" baseline. **`R² ≤ 0` means no better than predicting the mean.**
- **Residuals:** with an intercept their mean is exactly zero. Look for structure in the residuals (curvature, uneven spread).
- **Extrapolation is dangerous:** a fitted line knows nothing about regions it has not seen.
- **Counts and bounded targets** (counts, rates) often need different losses or link functions; not covered here.

### 4. How does it work?
Features → weighted sum → compare with the target through a loss → solve (closed form) or optimise (gradient descent, 2.19).

### 5. Simple example
Drawing the best straight line through a scatter plot to predict a child's height from age.

**By hand, one feature.** Points `(1, 3), (2, 5), (3, 7.2), (4, 8.8)`.
- Mean `x̄ = 2.5`, mean `ȳ = 6.0`.
- Slope `w = Σ(x − x̄)(y − ȳ) / Σ(x − x̄)² = (−1.5·−3 + −0.5·−1 + 0.5·1.2 + 1.5·2.8) / (2.25 + 0.25 + 0.25 + 2.25) = 9.8/5 = 1.96`.
- Intercept `b = ȳ − w·x̄ = 6 − 1.96·2.5 = 1.1`.

The line is `ŷ = 1.96x + 1.1`. Predicting x = 5 gives 10.9.

### 6. Technical example
Predict next week's demand from price, promotions and seasonality; predict query latency from payload size and index state.

### 7. Code
**① By hand (plain Python).** The formulas above.

```python
xs = [1, 2, 3, 4]
ys = [3, 5, 7.2, 8.8]
mx, my = sum(xs) / len(xs), sum(ys) / len(ys)
w = sum((x - mx) * (y - my) for x, y in zip(xs, ys)) / sum((x - mx) ** 2 for x in xs)
b = my - w * mx
print("slope:", round(w, 3), " intercept:", round(b, 3))
residuals = [y - (w * x + b) for x, y in zip(xs, ys)]
print("residuals:", [round(r, 3) for r in residuals], " sum:", round(sum(residuals), 10))
print("prediction at x = 5:", round(w * 5 + b, 2))
```

```text
slope: 1.96  intercept: 1.1
residuals: [-0.06, -0.02, 0.22, -0.14]  sum: 0.0
prediction at x = 5: 10.9
```

**② With NumPy.** Least squares with `lstsq`, then `R²` against the mean baseline.

```python
import numpy as np

rng = np.random.default_rng(0)
X = rng.normal(0, 1, (300, 2))
y = 2 * X[:, 0] - X[:, 1] + 0.5 + rng.normal(0, 0.5, 300)            # true: 2*x1 - x2 + 0.5
Xtr, ytr, Xte, yte = X[:200], y[:200], X[200:], y[200:]

A = np.column_stack([Xtr, np.ones(len(Xtr))])                          # add a column of ones for the intercept
coef, *_ = np.linalg.lstsq(A, ytr, rcond=None)
pred = np.column_stack([Xte, np.ones(len(Xte))]) @ coef
mse = np.mean((yte - pred) ** 2)
baseline = np.mean((yte - ytr.mean()) ** 2)
print("coefficients:", coef.round(2), "(true: 2, -1, intercept 0.5)")
print("test MSE:", round(float(mse), 3), "  mean-baseline MSE:", round(float(baseline), 3), "  R²:", round(float(1 - mse / baseline), 3))
```

```text
coefficients: [ 2.01 -0.98  0.48] (true: 2, -1, intercept 0.5)
test MSE: 0.134   mean-baseline MSE: 5.691   R²: 0.976
```

**③ With scikit-learn.**

```python
import numpy as np
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.metrics import r2_score

rng = np.random.default_rng(0)
X = rng.normal(0, 1, (300, 2))
y = 2 * X[:, 0] - X[:, 1] + 0.5 + rng.normal(0, 0.5, 300)
m = LinearRegression().fit(X[:200], y[:200])
print("coefficients:", m.coef_.round(2), " intercept:", round(float(m.intercept_), 2))
print("test R²:", round(r2_score(y[200:], m.predict(X[200:])), 3))
print("ridge (alpha=10) coefficients are slightly shrunk:", Ridge(alpha=10).fit(X[:200], y[:200]).coef_.round(2))
```

```text
coefficients: [ 2.01 -0.98]  intercept: 0.48
test R²: 0.976
ridge (alpha=10) coefficients are slightly shrunk: [ 1.91 -0.92]
```

### 9. Enterprise use case
Forecasting, pricing, capacity planning and risk scores, typically paired with prediction intervals and monitoring.

### 10. AI engineering connection
Reward models output scalar scores; latency and cost predictors for routing; embedding-quality calibration; scalar heads in neural networks.

### 11. Advantages
Interpretable (the coefficients), fast, a strong baseline, and convex (1.45).

### 12. Limitations
Linear structure; sensitive to outliers (MSE) and collinearity; no uncertainty unless modelled.

### 13. Trade-offs
Simple models extrapolate smoothly but underfit; flexible models fit better but overfit (2.26–2.30).

### 14. Common mistakes
Reading coefficients as causal effects; extrapolating; ignoring scaling when regularising; evaluating `R²` on training data only; using regression for a ranking problem.

### 15. Performance / cost
The closed form costs `O(nd² + d³)`; for large `n` or `d` use SGD (2.20).

### 16. Security
Features that proxy protected attributes give discriminatory predictions; inspect coefficients and slices.

</details>

### 17. Interview explanation
"Regression predicts a continuous value. Linear regression minimises squared error, which is maximum likelihood under Gaussian noise, and I solve it with a least-squares solver rather than inverting a matrix. I compare against a mean baseline with R² and check the residuals for structure."

### 18. Rapid-fire answer
Predict a number; least squares = MLE under Gaussian noise; `R²` compares with the mean baseline.

### 20. Hands-on exercise
**Goal:** see under- and over-fitting with polynomial regression.

1. Make 30 noisy points from a sine curve and split them 20 train / 10 validation.
2. Fit polynomials of degree 1, 3, 5 and 9 (`np.polyfit`).
3. Print the training and validation MSE for each. Which degree is best?

<details>
<summary>Show a solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)
x = np.sort(rng.uniform(0, 1, 30))
y = np.sin(2 * np.pi * x) + rng.normal(0, 0.2, 30)
idx = rng.permutation(30)
tr, va = idx[:20], idx[20:]
for degree in (1, 3, 5, 9):
    coefs = np.polyfit(x[tr], y[tr], degree)
    err = lambda i: np.mean((np.polyval(coefs, x[i]) - y[i]) ** 2)
    print(f"degree {degree}: train MSE {err(tr):.3f}   validation MSE {err(va):.3f}")
```

```text
degree 1: train MSE 0.214   validation MSE 0.238
degree 3: train MSE 0.027   validation MSE 0.033
degree 5: train MSE 0.022   validation MSE 0.046
degree 9: train MSE 0.017   validation MSE 0.065
```

Low degrees underfit (both errors high); a very high degree makes the training error tiny while the validation error stops improving or worsens (see 2.26–2.27).
