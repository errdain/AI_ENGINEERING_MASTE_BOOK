# 2.47 Feature scaling and normalisation

**Metadata** — Tier: 2 · Phase: 1 · Priority: P0 · Difficulty: 1/5 · Interview: High · Hands-on: Very high
Prerequisites: 2.7, 1.30, 1.31 · Leads to: 2.25 Learning rate, 2.16 Clustering, 2.32 Regularisation, Tier 3 Normalisation layers

> **In plain words**
> **Feature scaling** puts all numeric features on a **comparable ruler** before the model sees them: one in dollars (thousands) and one in years (tens) would otherwise be treated unfairly. The most common recipe, **standardisation**, subtracts the average and divides by the spread.
> It matters for anything based on **distances**, **gradient descent** or **penalties**; it doesn't matter for **trees**. And always **measure with the training set's ruler only**, then reuse that ruler on test and production data.

**Words you'll meet on this page**

| Word | What it means here |
|---|---|
| standardisation | `(x − μ)/σ`: mean 0, std 1 |
| min–max scaling | `(x − min)/(max − min)`: into [0, 1] |
| robust scaling | `(x − median)/IQR`: resists outliers |
| log transform | tames heavy right skew |
| skewness | asymmetry of a distribution |
| condition number | how stretched the loss valley is (1.45) |
| training/serving skew | scaler differs between training and production |

### 1. What is it?
Rescaling numeric features to comparable ranges: **standardisation** `(x − μ)/σ`, **min–max** `(x − min)/(max − min)`, **robust scaling** `(x − median)/IQR`, plus transformations such as `log` for skew.

### 2. Why does it exist?
Features on very different scales distort distances, the conditioning of gradient descent, and penalties.

### 3. Detailed explanation
- **When it matters:** gradient-based training (conditioning, the learning-rate limit), distance-based methods (k-means, k-NN), regularised models (penalties depend on coefficient size), PCA. **When it doesn't:** ordinary least squares *predictions* (the coefficients rescale; the predictions are identical), and tree-based models (their splits depend on order only).
- **Effect on optimisation:** with two features on scales 1 and 100, the largest stable learning rate shrinks by a factor of hundreds (2.25) and gradient descent takes ages; after standardisation it converges in a handful of epochs.
- **Outlier behaviour:** with one extreme value (10,000 among data around 50 ± 10), min–max scaling squashes all ordinary points into a tiny interval; standardisation is also affected; robust scaling keeps the bulk usable.
- **Skew:** log-normal data is strongly skewed; after a `log` it is nearly symmetric. Use `log1p` when zeros are possible.
- **Fit on training data only** (2.33) and apply the same parameters to validation, test and production; do not re-fit at inference. Save the fitted scaler together with the model.
- **Constant features** have zero variance: guard the division.
- **Min–max with unseen extremes** produces values outside [0, 1] in production; decide whether to clip.
- **"Normalisation" has other meanings:** L2-normalising each *example* (unit vectors for cosine similarity, 1.17), batch or layer normalisation of *activations* inside networks (Tier 3), and database normalisation. This concept covers feature scaling.
- **Categorical features** are encoded, not scaled (2.48, 2.49).

### 4. How does it work?
Compute the statistics on the training set → transform every split with those statistics → store the parameters with the model.

### 5. Simple example
Converting inches, kilometres and dollars into comparable units before measuring distances.

**By hand.** Ages `[20, 30, 40]` and salaries `[30000, 60000, 90000]`. The distance between the first two people is `√(10² + 30000²) ≈ 30000`: age is invisible. After standardising each feature (age: mean 30, std 8.16 → `[−1.22, 0, 1.22]`; salary: mean 60000, std 24495 → `[−1.22, 0, 1.22]`) both features contribute equally.

### 6. Technical example
Standardise numeric inputs before a logistic regression with an L2 penalty; log-transform price; use robust scaling for sensor data with spikes.

### 7. Code
**① By hand (plain Python).** Three scalers on data with an outlier.

```python
data = [48, 50, 52, 49, 51, 10000]                       # five ordinary values and one outlier
def stdev(xs):
    m = sum(xs) / len(xs)
    return (sum((x - m) ** 2 for x in xs) / len(xs)) ** 0.5
mean, sd = sum(data) / len(data), stdev(data)
lo, hi = min(data), max(data)
sorted_d = sorted(data)
median = (sorted_d[2] + sorted_d[3]) / 2
iqr = sorted_d[4] - sorted_d[1]                          # a rough interquartile range for 6 values
ordinary = data[:5]
print("standard scaling:", [round((x - mean) / sd, 3) for x in ordinary])
print("min-max scaling :", [round((x - lo) / (hi - lo), 5) for x in ordinary], "<- everything squashed together")
print("robust scaling  :", [round((x - median) / iqr, 2) for x in ordinary], "<- the bulk stays usable")
```

```text
standard scaling: [-0.448, -0.447, -0.447, -0.447, -0.447]
min-max scaling : [0.0, 0.0002, 0.0004, 0.0001, 0.0003] <- everything squashed together
robust scaling  : [-0.83, -0.17, 0.5, -0.5, 0.17] <- the bulk stays usable
```

**② With NumPy.** Scaling rescues gradient descent.

```python
import numpy as np

rng = np.random.default_rng(0)
X = np.column_stack([rng.normal(0, 1, 300), rng.normal(0, 100, 300)])         # scales 1 and 100
y = X @ np.array([2.0, 0.03]) + rng.normal(0, 0.1, 300)

def epochs_to_loss(X, y, lr, target=0.02, max_epochs=400):
    w = np.zeros(2)
    for epoch in range(1, max_epochs + 1):
        w -= lr * (2 / len(X)) * X.T @ (X @ w - y)
        if np.mean((X @ w - y) ** 2) < target:
            return epoch
    return None

lam = np.linalg.eigvalsh(2 * X.T @ X / len(X)).max()
print("raw features    : epochs to reach loss 0.02 ->", epochs_to_loss(X, y, 0.9 * 2 / lam), "(None = not reached in 400)")
Z = (X - X.mean(axis=0)) / X.std(axis=0)
lam_z = np.linalg.eigvalsh(2 * Z.T @ Z / len(Z)).max()
print("standardised    : epochs to reach loss 0.02 ->", epochs_to_loss(Z, y - y.mean(), 0.9 * 2 / lam_z))
```

```text
raw features    : epochs to reach loss 0.02 -> None (None = not reached in 400)
standardised    : epochs to reach loss 0.02 -> 16
```

**③ With scikit-learn.** The scalers, skew, and OLS invariance.

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import MinMaxScaler, RobustScaler, StandardScaler
from scipy.stats import skew

rng = np.random.default_rng(0)
x = np.append(rng.normal(50, 10, 200), 10000).reshape(-1, 1)                 # 200 ordinary values + 1 outlier
for name, sc in (("standard", StandardScaler()), ("min-max", MinMaxScaler()), ("robust", RobustScaler())):
    z = sc.fit_transform(x)[:-1, 0]
    print(f"{name:<9} spread of the ordinary points after scaling: {z.std():.4f}")

lognormal = rng.lognormal(0, 1.2, 5000)
print("skewness raw:", round(float(skew(lognormal)), 2), "  after log:", round(float(skew(np.log(lognormal))), 2))

X = rng.normal(0, 1, (200, 2)) * [1, 100]; y = X @ [2.0, 0.03] + rng.normal(0, 1, 200)
a, b = LinearRegression().fit(X, y).predict(X), LinearRegression().fit(StandardScaler().fit_transform(X), y).predict(StandardScaler().fit_transform(X))
print("ordinary least squares predictions identical with or without scaling:", np.allclose(a, b))
```

```text
standard  spread of the ordinary points after scaling: 0.0137
min-max   spread of the ordinary points after scaling: 0.0010
robust    spread of the ordinary points after scaling: 0.7296
skewness raw: 4.78   after log: 0.03
ordinary least squares predictions identical with or without scaling: True
```

### 9. Enterprise use case
Feature-store transformations are versioned; training and serving share the same scaler artefact.

### 10. AI engineering connection
Embedding normalisation for cosine search; input standardisation for small models; understanding why LayerNorm exists in Transformers (Tier 3).

### 11. Advantages
Faster, more stable training; fair distance and penalty behaviour.

### 12. Limitations
Sensitive to outliers (standard, min–max); changes the interpretation of coefficients; must be applied consistently.

### 13. Trade-offs
Standardisation (assumes outliers are rare) versus robust scaling (resists outliers, ignores tail scale) versus min–max (bounded but fragile).

### 14. Common mistakes
Fitting on all data; re-fitting at inference; scaling categorical codes; forgetting to scale a newly added feature; min–max with outliers.

### 15. Performance / cost
`O(nd)` to fit; negligible.

### 16. Security
Scaler statistics are derived from data and can leak aggregate information if shared.

</details>

### 17. Interview explanation
"I scale features when the algorithm depends on distances, gradient conditioning or penalty size. Standardisation is the default, robust scaling when outliers exist, log transforms for heavy skew; I fit the scaler on the training set only and ship it with the model. Trees and plain least squares don't need it."

### 18. Rapid-fire answer
Standardise, min–max or robust (plus log for skew); fit on train only; matters for gradient descent, distances and penalties; not for trees or OLS predictions.

### 20. Hands-on exercise
**Goal:** see scaling change k-means results.

1. Two features: one informative (two groups at 0 and 5 with spread 1) and one pure noise with a huge scale (std 1,000).
2. Cluster with k-means (`k = 2`) with and without standardising.
3. Compare the agreement with the true groups.

<details>
<summary>Show a solution</summary>

```python
import numpy as np
from sklearn.cluster import KMeans

rng = np.random.default_rng(0)
truth = np.repeat([0, 1], 200)
X = np.column_stack([rng.normal(0, 1, 400) + 5 * truth, rng.normal(0, 1000, 400)])
def agreement(labels):
    return max(np.mean(labels == truth), np.mean(labels != truth))

raw = KMeans(2, n_init=10, random_state=0).fit_predict(X)
Z = (X - X.mean(axis=0)) / X.std(axis=0)
scaled = KMeans(2, n_init=10, random_state=0).fit_predict(Z)
print("agreement, raw features   :", round(float(agreement(raw)), 3), "(the noisy huge-scale feature decides)")
print("agreement, standardised   :", round(float(agreement(scaled)), 3))
```

```text
agreement, raw features   : 0.502 (the noisy huge-scale feature decides)
agreement, standardised   : 0.993
```
