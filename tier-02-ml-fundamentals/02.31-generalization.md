# 2.31 Generalisation

**Metadata** — Tier: 2 · Phase: 1 · Priority: P0 · Difficulty: 2/5 · Interview: Very high · Hands-on: High

> **In plain words**
> **Generalisation** is a model's ability to **do well on new data it has never seen**. It is the whole point: training data is only a means to an end; value comes from predictions on future cases.
> The **generalisation gap** is test error minus training error. A small gap on top of a good score means the model learned the pattern, not just the examples. Like understanding the subject versus remembering the practice questions.

**You need first:** 2.13 Test set, 2.27 Overfitting, 2.30 Bias–variance.

> *How to read it:* a flexible model can score 100% on the training set even when the labels are random noise, but on new data it stays at chance. A high training score only counts as learning if the new-data score is also high.

### 1. What is it?
A model's ability to **perform well on new, unseen data** from the same (or the intended) distribution. The **generalisation gap** is test error minus training error.

### 2. Why does it matter?
Training data is a means, not the goal. Value comes only from predictions on future cases.

### 3. Detailed explanation
- **Estimating it:** a held-out test set (2.13), cross-validation (2.44), or monitoring in production.
- **The gap shrinks with data:** with more training examples the training and test scores come closer together.
- **The memorisation test:** with *random labels*, a 1-nearest-neighbour classifier reaches 100% training accuracy but only chance-level accuracy on new data. High capacity can always fit the training set; it only generalises if the data contains learnable structure.
- **What drives generalisation:** quantity and diversity of data, suitable capacity (2.30), regularisation (2.32), inductive bias (2.28), the noise level, and how well the training and deployment distributions agree (2.34).
- **Generalisation is relative to a distribution.** A model may generalise in-distribution and fail out-of-distribution (new customers, a new language, a new time period). State which one you measured.
- **Theory (brief):** statistical learning theory bounds the gap using capacity measures (VC dimension, Rademacher complexity) and `1/√n`. These bounds are often loose for deep networks, so practice relies on held-out evaluation. (REVIEW_REQUIRED: keep theoretical claims minimal until cited.)
- **Leakage and heavy tuning inflate apparent generalisation** (2.12, 2.33).
- **LLMs:** generalisation means handling new tasks and prompts; contamination of benchmarks can fake it (2.13).

### 4. How does it work?
Train on one sample, evaluate on independent data under the intended conditions, and report the metric with its uncertainty and the conditions of the test.

### 5. Simple example
Understanding the subject versus remembering the practice questions.

**With numbers.** In the second code example below, a model trained on only 20 examples scores about 21 points better on its training data than on new data; with 100 examples the gap is about 3 points; with 1,000 it is about zero.

### 6. Technical example
A fraud model trained on 2023 transactions and tested on 2024 transactions: the forward-in-time test is the relevant generalisation test.

### 7. Code
**① By hand (plain Python).** Random labels: a nearest-neighbour "model" memorises them.

```python
import random

random.seed(0)
def make(n):
    return [((random.random(), random.random()), random.randint(0, 1)) for _ in range(n)]       # labels are pure noise

train, test = make(200), make(200)
def nearest_label(p):
    return min(train, key=lambda t: (t[0][0] - p[0]) ** 2 + (t[0][1] - p[1]) ** 2)[1]

print("training accuracy:", sum(nearest_label(p) == y for p, y in train) / len(train), "(it memorised)")
print("new-data accuracy:", sum(nearest_label(p) == y for p, y in test) / len(test), "(chance: there was nothing to learn)")
```

```text
training accuracy: 1.0 (it memorised)
new-data accuracy: 0.565 (chance: there was nothing to learn)
```

**② With NumPy and scikit-learn.** The gap shrinks as the training set grows.

```python
import numpy as np
from sklearn.linear_model import LogisticRegression

def gap(n, seeds=20):
    gaps = []
    for s in range(seeds):
        rng = np.random.default_rng(s)
        y = np.arange(n + 2000) % 2
        X = rng.normal(0, 1, (n + 2000, 5)) + 0.7 * y[:, None]
        m = LogisticRegression(C=1e6, max_iter=2000).fit(X[:n], y[:n])
        gaps.append(m.score(X[:n], y[:n]) - m.score(X[n:], y[n:]))
    return float(np.mean(gaps))

for n in (20, 100, 1000):
    print(f"n = {n:>4}: average train - test accuracy gap = {100 * gap(n):.1f} points")
```

```text
n =   20: average train - test accuracy gap = 21.5 points
n =  100: average train - test accuracy gap = 3.3 points
n = 1000: average train - test accuracy gap = -0.1 points
```

**③ With scikit-learn.** Capacity decides what can be memorised.

```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier

rng = np.random.default_rng(0)
X, y = rng.normal(0, 1, (400, 5)), rng.integers(0, 2, 400)         # random labels
Xtr, ytr, Xte, yte = X[:200], y[:200], X[200:], y[200:]
for name, model in (("1-nearest-neighbour (high capacity)", KNeighborsClassifier(1)), ("logistic regression (low capacity)", LogisticRegression())):
    model.fit(Xtr, ytr)
    print(f"{name:<38} train {model.score(Xtr, ytr):.2f}   new data {model.score(Xte, yte):.2f}")
```

```text
1-nearest-neighbour (high capacity)    train 1.00   new data 0.52
logistic regression (low capacity)     train 0.65   new data 0.54
```

### 9. Enterprise use case
Go/no-go criteria are stated in terms of held-out performance under production-like conditions, not training metrics.

### 10. AI engineering connection
Held-out prompts, unseen documents for RAG, new domains for fine-tuned models, and out-of-distribution tests (Tier 30).

### 11. Advantages
It is the only thing that matters for deployed value.

### 12. Limitations
It can only be estimated, never observed in advance, and depends on how "new" is defined.

### 13. Trade-offs
Better in-distribution generalisation may cost robustness elsewhere; larger models need more data and compute.

### 14. Common mistakes
Evaluating on near-duplicates of training data; equating a small gap with good performance; ignoring the target distribution; reporting one split's result as certain.

### 15. Performance / cost
More diverse data and evaluation cost more but cut risk.

### 16. Security
Poor generalisation is exploitable by adversarial inputs and distribution manipulation.

### 17. Interview explanation
"Generalisation is how well the model does on unseen data from the distribution I care about; the generalisation gap is the difference between test and training error. I estimate it with a clean held-out set or cross-validation, watch how the gap shrinks with data, and remember that fitting random labels perfectly shows capacity is not the same as understanding."

### 18. Rapid-fire answer
Performance on unseen data; gap = test − train error; estimate on independent data matching deployment.

### 20. Hands-on exercise
**Goal:** compare memorising capacity across models on random labels.

1. Use 200 random-label examples with 5 features.
2. Fit 1-NN, a depth-3 decision tree and logistic regression.
3. Print the training accuracy for each. Which memorise?

<details>
<summary>Show a solution</summary>

```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier

rng = np.random.default_rng(0)
X, y = rng.normal(0, 1, (200, 5)), rng.integers(0, 2, 200)
for name, m in (("1-NN", KNeighborsClassifier(1)), ("tree depth 3", DecisionTreeClassifier(max_depth=3, random_state=0)),
                ("unlimited tree", DecisionTreeClassifier(random_state=0)), ("logistic regression", LogisticRegression())):
    print(f"{name:<20} training accuracy on random labels: {m.fit(X, y).score(X, y):.2f}")
```

```text
1-NN                 training accuracy on random labels: 1.00
tree depth 3         training accuracy on random labels: 0.62
unlimited tree       training accuracy on random labels: 1.00
logistic regression  training accuracy on random labels: 0.61
```

The models that can memorise (1-NN, unlimited tree) reach 100% on pure noise; a low-capacity model cannot.
