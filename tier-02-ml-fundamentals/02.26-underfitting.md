# 2.26 Underfitting

**Metadata** — Tier: 2 · Phase: 1 · Priority: P0 · Difficulty: 1/5 · Interview: High · Hands-on: High
Prerequisites: 2.15, 2.17 · Leads to: 2.27 Overfitting, 2.28 Bias, 2.30 Bias–variance trade-off

### 1. What is it?
A model that is **too simple (or too constrained, or trained too little) to capture the real pattern**, so it performs poorly on both the training data and new data.

### 2. Why does it exist?
Recognizing underfitting tells you to add capacity, features or training time, and not to waste effort on regularization or more data.

### 3. Detailed explanation
- **Signature:** high training error *and* similar high validation error (small gap). More data will not fix it; the model cannot represent the pattern.
- **Causes:** model class too simple (a line for a sine wave), too few or uninformative features (2.7), too strong regularization (2.32), too few epochs or too small learning rate (2.25), poor optimization.
- **Demonstration (polynomial fits to noisy `sin(πx)`, 30 training points, 500 validation points; noise MSE floor 0.04):**
  | degree | train MSE | validation MSE |
  |---|---|---|
  | 0 (constant) | 0.501 | 0.532 |
  | 1 | 0.205 | 0.273 |
  | 3 | 0.028 | 0.051 |
  Degrees 0 and 1 are underfit: both errors are far above the noise floor.
- **Underfitting is high bias** (2.28): systematic error that persists however much data you collect.
- **Baselines (2.46) expose it:** if your model barely beats the majority/mean baseline, suspect underfitting (or a missing signal).
- **Remedies:** richer model (more layers/units, nonlinear features, interactions), better features, less regularization, longer or better-tuned optimization, check for bugs (e.g., unscaled inputs, wrong labels).

### 4. How does it work?
Compare training error with a reference (noise level, human performance, strong baseline). A large training error means the model has not learned what the data allows.

### 5. Simple example
Describing a mountain range with a single straight line.

### 6. Technical example
A linear classifier on XOR-like data scores about 45%, no matter how many examples you add (2.1).

### 7. Code
```python
import mlkit as M
x, y = M.make_sine(30, 0.2, seed=1); xv, yv = M.make_sine(500, 0.2, seed=101)
for d in (0, 1, 3):
    r = M.fit_poly_train_val(d, x, y, xv, yv); print(d, round(r.train_mse, 3), round(r.val_mse, 3))
```

### 8. Input → Process → Output
`model too simple → can't fit pattern → high train and validation error`

### 9. Enterprise use case
Model reviews check train-vs-validation error first: a low-capacity model that fails both signals a modelling problem, not a data-volume problem.

### 10. AI engineering connection
A too-small LLM, too-aggressive quantization, too-short fine-tune or a frozen backbone with a tiny head can underfit the target task; evaluation on the training set reveals it.

### 11. Advantages
Simple models are cheap, stable and interpretable.

### 12. Limitations
Cannot capture complex relationships; limited ceiling.

### 13. Trade-offs
Moving away from underfitting adds capacity, which risks overfitting (2.27, 2.30).

### 14. Common mistakes
Collecting more data to fix underfitting; blaming the data when the optimizer never converged; over-regularizing; not checking training error.

### 15. Performance / cost
Underfit models are cheap to train and serve but waste the business value of the data.

### 16. Security
A model that underfits subgroups can be systematically unfair to them even if overall metrics look fine; check slices.

### 17. Interview explanation
"Underfitting means the model is too simple or under-trained, so both training and validation error are high. I confirm it by comparing training error with a baseline or a noise floor, and fix it with a richer model, better features, less regularization or more optimization, not by collecting more data."

### 18. Rapid-fire
Underfit = high train and validation error (high bias); fix capacity/features/training, not data volume.

### 19. Interview questions
- Basic: How do you recognize underfitting?
- Intermediate: Why won't more data fix underfitting?
- Advanced: Distinguish underfitting from a missing-signal problem.
- Scenario: Training accuracy is 62% and validation 61% on a task where humans get 95%. Next steps?
