# 2.4 Semi-supervised learning

**Metadata** — Tier: 2 · Phase: 1 · Priority: P1 · Difficulty: 2/5 · Interview: Medium · Hands-on: Medium
Prerequisites: 2.2, 2.3 · Leads to: pseudo-labeling in modern pipelines, LLM-generated labels (Tier 10)

### 1. What is it?
Learning from a **small labeled set plus a large unlabeled set** by letting the unlabeled data shape the model.

### 2. Why does it exist?
Labels are expensive; unlabeled data is plentiful. Semi-supervised methods trade a little modelling assumption for a lot of free signal.

### 3. Detailed explanation
- **Self-training / pseudo-labeling:** train on labeled data → predict unlabeled data → add *confident* predictions as pseudo-labels → retrain.
- **Consistency regularization:** predictions should not change under small input perturbations.
- **Assumptions:** the cluster/smoothness assumption (points in the same dense region share labels) and a reasonably good initial model. If the assumptions fail, unlabeled data can hurt.
- **Confirmation bias:** wrong pseudo-labels reinforce themselves. Use high thresholds, limited rounds, and a clean validation set (never pseudo-labeled).
- **Demonstration (only 10 labeled points, 800 unlabeled, 400 held-out):** labeled-only 96.0% → self-training 97.25%, using 714 pseudo-labels that were 98.3% correct. The gain is modest and depends on well-separated classes.
- LLM-generated labels used for training smaller models are a modern form of pseudo-labeling (their errors propagate).

### 4. How does it work?
Loop: fit → score unlabeled → keep predictions above a confidence threshold → augment training set → refit; stop when no change.

### 5. Simple example
A student learns from a few worked examples, then practises on unmarked problems she's sure about and learns from her own solutions.

### 6. Technical example
Medical imaging with a few expert-labeled scans and many unlabeled ones; text classification with a small seed set.

### 8. Input → Process → Output
`few labeled + many unlabeled → pseudo-label confident cases → retrain → better model`

### 9. Enterprise use case
Reduces annotation spend: label a seed set, use the model to pre-label, humans verify the uncertain items (active learning loops).

### 10. AI engineering connection
Synthetic/LLM-generated training data, distillation on unlabeled corpora, bootstrapping evaluation sets.

### 11. Advantages
Cuts labeling cost; uses abundant data.

### 12. Limitations
Can amplify mistakes; sensitive to threshold and class imbalance; gains vanish if the initial model is poor.

### 13. Trade-offs
Low threshold = more data, more noise; high threshold = cleaner but little new information.

### 14. Common mistakes
Evaluating on pseudo-labeled data; no confidence threshold; ignoring class imbalance (the majority class dominates pseudo-labels).

### 15. Performance / cost
Repeated retraining multiplies training cost by the number of rounds.

### 16. Security
Adversaries can plant unlabeled data to steer pseudo-labels; control the unlabeled source.

### 17. Interview explanation
"Semi-supervised learning uses a few labels plus lots of unlabeled data, for example self-training: predict, keep the confident predictions as pseudo-labels, retrain. It helps when classes are well separated, and it can backfire through confirmation bias, so I keep a clean validation set."

### 18. Rapid-fire
Few labels + many unlabeled; self-training with confident pseudo-labels; risk = confirmation bias.
