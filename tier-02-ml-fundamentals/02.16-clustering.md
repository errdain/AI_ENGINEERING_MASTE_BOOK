### 1. What is it?
Unsupervised grouping of samples so that items in a group are more similar to each other than to items in other groups.

### 2. Why does it exist?
To discover segments, compress data into prototypes, organize documents and spot outliers when no labels exist.

### 3. Detailed explanation
- **k-means** (worked example, `mlkit.KMeans`): choose `k` centers; assign each point to the nearest center; move each center to the mean of its points; repeat until stable. It minimizes **inertia** = within-cluster sum of squared distances.
- **Initialization matters.** k-means finds a local optimum (1.47). On 5 well-separated blobs, 20 runs with a single random initialization gave inertia between 1,005 (the best solution) and 4,412; with best-of-10 initializations every run gave 1,005.
- **Scaling matters.** Distance-based methods are dominated by the largest-scale feature. With one feature expressed in huge units, cluster agreement with the true grouping falls to 77.7%; after standardizing (2.47) it returns to 98%.
- **Choosing `k`:** inertia always decreases with `k`, so use the elbow, silhouette score (`(b−a)/max(a,b)`; 0.75 at `k=2`, 0.53 at `k=3`, 0.29 at `k=4` on two true blobs; our implementation matches scikit-learn), stability across seeds, or the downstream objective.
- **Assumptions:** k-means prefers roughly spherical, similarly sized clusters; other algorithms (hierarchical, density-based, Gaussian mixtures) relax this.
- **Clusters are not categories.** They reflect the features and metric you chose.
- **Embeddings:** clustering text embeddings (cosine/L2 on normalized vectors, 1.17) organizes corpora; high dimension weakens distance contrast (1.16).

### 4. How does it work?
Standardize → pick algorithm and `k` → run several initializations → evaluate (silhouette, stability, usefulness) → name and validate clusters with a human.

### 7. Code
```python
import mlkit as M
from lab_02_models_and_training import make_blobs_multi, silhouette
X, _ = make_blobs_multi(500, 5, radius=7.0, seed=1)
print(sorted({round(M.KMeans(5, n_init=1, seed=s).fit(X).inertia_) for s in range(20)})[:3])   # many local optima
km = M.KMeans(5, n_init=10, seed=0).fit(X); print(round(km.inertia_), silhouette(X, km.labels_))
```

### 8. Input → Process → Output
`X → scale → assign/update loop → centers + labels → validate`

### 9. Enterprise use case
Customer segmentation, ticket topic discovery, log pattern grouping; results feed product decisions and need business review.

### 10. AI engineering connection
Embedding clustering for corpus organization and dataset curation, deduplication, and community detection for graph-based retrieval.

### 11. Advantages
No labels needed; simple and fast; produces interpretable prototypes.

### 12. Limitations
Sensitive to scale, initialization and `k`; no ground truth; assumes cluster shape.

### 13. Trade-offs
More clusters = tighter groups but less interpretable and less stable.

### 14. Common mistakes
Not scaling; trusting one run; picking `k` by minimum inertia; treating clusters as ground truth labels; clustering in raw high-dimensional space.

### 15. Performance / cost
`O(n·k·d)` per iteration; use mini-batch k-means or approximate methods for millions of points.

### 16. Security
Clusters on personal data can expose or create sensitive groupings; review before use in decisions.

### 17. Interview explanation
"Clustering groups similar items without labels. With k-means I standardize features, run several initializations since it finds local optima, and choose k using silhouette and stability rather than inertia alone. I treat the clusters as hypotheses to validate, not truth."

### 18. Rapid-fire
k-means minimizes within-cluster squared distance; scale features, use multiple inits, choose k by silhouette/stability.
