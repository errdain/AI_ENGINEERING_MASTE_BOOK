> **In plain words**
> In this concept, **variance** means **how much the model changes its predictions when you train it on a different sample of data** from the same source.
> A high-variance model is jumpy: show it slightly different training data and it gives noticeably different answers, because it is chasing the quirks of the particular sample. Like ten archers with the same average aim but widely scattered shots.
> It is the mechanism behind overfitting.

**You need first:** 2.27 Overfitting and 1.30 Variance (the plain spread of numbers).

> *How to read it:* we imagine redrawing the training set many times and retraining. The *spread of the predictions* at a fixed input is the variance. It is not the spread of the data, nor of the label noise: same formula as 1.30, different random variable.

### 1. What is it?
**Model variance:** how much the learned predictions would change if the model were trained on a *different training sample* from the same distribution.

### 2. Why does it matter?
High variance is the mechanism behind overfitting: the model chases the idiosyncrasies of the particular training set.

### 3. Detailed explanation
- **Terminology:** this is the variance (1.30) of the *prediction* `f̂(x)` over random training sets: `Var_D[f̂(x)]`. It is not the variance of the data or of the label noise.
- **It grows with model flexibility.** For least squares with a fixed design, theory says variance ≈ `σ²·p/n` for `p` parameters and `n` examples. More parameters, more variance.
- **It shrinks with data**, roughly proportionally to `1/n`.
- **With random (rather than fixed) training inputs,** extra variance appears from *which* `x` values happened to be sampled. Clean teaching experiments fix the design; real data has both sources.
- **Reducing variance:** more data, a simpler model, regularisation (2.32), bagging and ensembling (averaging models trained on resamples), dropout, early stopping, feature selection.
- **Diagnosis:** a large spread of cross-validation scores across folds, a big train–validation gap, predictions that change after small data changes (2.44).
- **Variance of evaluation** (the noise in your metric on a finite test set) is a different thing from model variance; both matter for decisions (2.13).

### 4. How does it work?
Train the same procedure on many resampled datasets and measure the spread of the predictions at fixed inputs.

### 5. Simple example
Ten archers with the same average aim but widely scattered shots.

**With numbers.** Fit a line and a degree-9 polynomial to 30 noisy points, 200 times with fresh noise. Averaged over the input range, the line's predictions have a spread (standard deviation) of about 0.05; the degree-9 curve's is roughly twice that, and much more near the edges. More flexibility, more variance.

### 6. Technical example
A decision tree grown until every leaf is pure: tiny changes in the training data change its splits and predictions a lot.

### 7. Code
**① By hand (plain Python).** A flexible model changes its mind; a rigid one doesn't. Compare "predict the mean" with "copy the nearest training point".

```python
import random, statistics

def prediction(kind, seed):
    rng = random.Random(seed)
    xs = [rng.uniform(0, 1) for _ in range(10)]
    ys = [x + rng.gauss(0, 0.3) for x in xs]                    # y = x + noise
    if kind == "mean":
        return sum(ys) / len(ys)                                # rigid: ignores x
    nearest = min(range(10), key=lambda i: abs(xs[i] - 0.5))
    return ys[nearest]                                          # flexible: copies the closest example

for kind in ("mean", "nearest"):
    preds = [prediction(kind, s) for s in range(500)]
    print(f"{kind:>7} model at x = 0.5: prediction spread (std) over 500 training sets = {statistics.pstdev(preds):.3f}")
```

```text
   mean model at x = 0.5: prediction spread (std) over 500 training sets = 0.137
nearest model at x = 0.5: prediction spread (std) over 500 training sets = 0.293
```

**② With NumPy.** Variance by simulation: grows with flexibility, shrinks with data.

```python
import numpy as np

f = lambda x: np.sin(np.pi * x)
grid = np.linspace(-1, 1, 100)
rng = np.random.default_rng(0)

def variance(degree, n):
    xs = np.linspace(-1, 1, n)
    preds = np.array([np.polyval(np.polyfit(xs, f(xs) + rng.normal(0, 0.2, n), degree), grid) for _ in range(300)])
    return preds.var(axis=0).mean()

print("flexibility (n = 30):", {d: round(float(variance(d, 30)), 4) for d in (1, 3, 9)})
print("more data (degree 3):", {n: round(float(variance(3, n)), 5) for n in (15, 30, 120, 480)})
print("theory sigma²·p/n for degree 3, n = 30:", round(0.04 * 4 / 30, 4))
```

```text
flexibility (n = 30): {1: 0.0028, 3: 0.0048, 9: 0.012}
more data (degree 3): {15: 0.0092, 30: 0.00522, 120: 0.00134, 480: 0.00033}
theory sigma²·p/n for degree 3, n = 30: 0.0053
```

**③ With scikit-learn.** Bagging reduces variance by averaging.

```python
import numpy as np
from sklearn.ensemble import BaggingRegressor
from sklearn.tree import DecisionTreeRegressor

f = lambda x: np.sin(np.pi * x)
rng = np.random.default_rng(0)
x0 = np.array([[0.3]])
single, bagged = [], []
for _ in range(100):
    X = rng.uniform(-1, 1, (60, 1))
    y = f(X[:, 0]) + rng.normal(0, 0.3, 60)
    single.append(DecisionTreeRegressor().fit(X, y).predict(x0)[0])
    bagged.append(BaggingRegressor(DecisionTreeRegressor(), n_estimators=30, random_state=0).fit(X, y).predict(x0)[0])
print("variance of one deep tree   :", round(float(np.var(single)), 4))
print("variance of 30 bagged trees :", round(float(np.var(bagged)), 4))
```

```text
variance of one deep tree   : 0.0873
variance of 30 bagged trees : 0.0465
```

### 9. Enterprise use case
Stability tests retrain on resampled data to quantify prediction churn, important for models whose outputs drive customer-facing decisions.

### 10. AI engineering connection
Seed-to-seed variance in fine-tuning, variance of LLM-judge scores, and prompt sensitivity: report mean ± std over seeds (1.31).

### 11. Advantages
(Of understanding it) it explains why ensembles and regularisation help.

### 12. Limitations
Hard to measure without resampling; must not be confused with the variance of the data.

### 13. Trade-offs
Lower variance through simplicity increases bias (2.30).

### 14. Common mistakes
Calling "variance" the spread of the data; trusting a single training run; ignoring fold-to-fold spread; assuming larger models always have higher variance (not always).

### 15. Performance / cost
Measuring variance needs multiple trainings, so it is often approximated by cross-validation folds or seeds.

### 16. Security
High-variance models are more susceptible to data poisoning and membership inference.

</details>

### 17. Interview explanation
"Model variance is how much predictions change across different training samples. Flexible models have high variance, which shows up as overfitting and unstable cross-validation scores. It shrinks roughly like one over n with more data and falls with regularisation or ensembling, at the cost of some bias."

### 18. Rapid-fire answer
Model variance = spread of predictions across training sets; it grows with flexibility and shrinks roughly like `1/n` with data.

### 20. Hands-on exercise
**Goal:** estimate variance by bootstrap on one dataset.

1. You have only **one** dataset of 60 noisy points.
2. Resample it with replacement 200 times (a bootstrap), fit a degree-9 polynomial to each, and record the prediction near the edge of the data, at `x = 0.95`.
3. Compare the spread with the same for a degree-1 fit.

<details>
<summary>Show a solution</summary>

```python
import numpy as np
import warnings

warnings.simplefilter("ignore")
rng = np.random.default_rng(0)
x = rng.uniform(-1, 1, 60)
y = np.sin(np.pi * x) + rng.normal(0, 0.3, 60)             # the ONE dataset we have
for degree in (1, 9):
    preds = []
    for _ in range(200):
        idx = rng.integers(0, 60, 60)                       # bootstrap resample
        preds.append(np.polyval(np.polyfit(x[idx], y[idx], degree), 0.95))
    print(f"degree {degree}: bootstrap std of the prediction at x = 0.95 is {np.std(preds):.3f}")
```

```text
degree 1: bootstrap std of the prediction at x = 0.95 is 0.142
degree 9: bootstrap std of the prediction at x = 0.95 is 0.899
```

The more flexible model's prediction is much less stable across resamples, especially near the edge of the data where a flexible curve has the least support.
