### 1. WHAT IS IT?

A model is calibrated if its stated confidence matches its actual accuracy: among predictions made with 80% confidence, about 80% are correct.

### 2. WHY DOES IT EXIST?

Confidence drives decisions (answer, abstain, escalate to a human). An overconfident model makes those decisions wrong even when its accuracy is fine.

### 3. DETAILED EXPLANATION

- **Reliability diagram**: bin predictions by confidence; plot accuracy per bin against confidence; the diagonal is perfect (Figure 3).
- **ECE** = sum over bins (n_b/N) * |acc_b - conf_b|. Hand check: confidences (0.9, 0.9, 0.6) with outcomes (1, 1, 0): bin 0.9 has gap 0.1 (weight 2/3), bin 0.6 has gap 0.6 (weight 1/3), ECE = 0.0667 + 0.2 = 0.2667.
- ECE depends on the number of bins and on sample size (few items per bin is noisy); also report NLL or Brier score (Brier = mean squared error of probabilities).
- **Temperature scaling**: divide logits by T fitted on validation data; T>1 softens an overconfident model; argmax (hence accuracy) is unchanged.
- Modern LLMs: pretrained models are often reasonably calibrated on token probabilities, while post-training and verbalised confidence can be miscalibrated (REVIEW_REQUIRED; empirical, model-dependent).
- Calibration is not accuracy: a model can be calibrated and weak, or accurate and overconfident.
- Calibrate **per distribution**: shift breaks calibration (""[15.17 Distribution-shift evaluation](15.17-distribution-shift-evaluation.md)"").

### 4. HOW DOES IT WORK?

Collect confidence and correctness on held-out data, bin, compute ECE, plot; if miscalibrated, fit T on a separate validation split and re-measure on test.

### 5. SIMPLE EXAMPLE

A forecaster who says '70% chance of rain' on 100 days should see rain on about 70 of them.

### 6. TECHNICAL EXAMPLE

Toy 3-class model with logits scaled by 3 (overconfident): ECE is large; fitting T by grid search lands at about 2.0 and ECE falls from about 0.115 to about 0.004 while accuracy is unchanged (test `test_overconfident_model_and_temperature_scaling`).

### 7. CODE

```python
# run inside lab/
from metrics import softmax, ece, fit_temperature
from toy import make_classifier_logits
logits, y = make_classifier_logits(4000, signal=1.5, sharpen=3.0, seed=1)
p = softmax(logits)
print("ECE before:", round(ece(p.max(1), p.argmax(1) == y), 3))
T = fit_temperature(logits, y)
p2 = softmax(logits, T)
print("T =", T, " ECE after:", round(ece(p2.max(1), p2.argmax(1) == y), 3))
```

### 8. INPUT → PROCESS → OUTPUT

```
logits -> softmax -> confidence + correctness -> bins -> reliability diagram, ECE -> (fit T) -> recalibrated confidence
```

### 9. ENTERPRISE USE CASE

Triage systems route low-confidence cases to humans; calibration decides how many cases that is, so it directly sets staffing cost.

### 10. AI ENGINEERING CONNECTION

Calibration underlies abstention ('I don't know'), selective answering in RAG and uncertainty-aware hallucination control ([15.13 Hallucination](15.13-hallucination.md)).

### 11. ADVANTAGES

- Makes confidence actionable.
- Cheap post-hoc fix (temperature scaling).

### 12. LIMITATIONS

- ECE is binning-dependent; accuracy-only top-label view; calibration does not survive shift; free-text confidence is hard to define.

### 13. TRADE-OFFS

- More bins give resolution vs noise; calibrate on validation vs risk of overfitting it.

### 14. COMMON MISTAKES

- Fitting T on the test set.
- Reporting ECE with n too small.
- Thinking calibrated means accurate.

### 15. PERFORMANCE / COST CONSIDERATIONS

Cheap: forward pass plus a 1-D fit.

### 16. SECURITY CONSIDERATIONS

Attackers can craft inputs that receive high confidence; confidence is not a security control.

### 17. INTERVIEW EXPLANATION

Calibration means confidence equals empirical accuracy. I check it with a reliability diagram and ECE, fix overconfidence with temperature scaling fitted on validation data, and re-check under distribution shift because calibration is distribution-specific.

### 18. RAPID-FIRE ANSWER

Confidence should equal accuracy; ECE measures the gap; temperature scaling is the cheap fix.
