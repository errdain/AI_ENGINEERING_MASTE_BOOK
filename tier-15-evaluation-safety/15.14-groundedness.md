### 1. WHAT IS IT?

Groundedness (faithfulness) is the degree to which an answer is supported by the provided context or retrieved documents.

### 2. WHY DOES IT EXIST?

In RAG and summarisation the right answer is 'what the sources say'. Groundedness separates 'faithful to context' from 'true in the world' and from 'helpful'.

### 3. DETAILED EXPLANATION

- Check each claim against the context: entailed, contradicted, or not stated.
- Metrics: fraction of supported claims; citation precision (cited passage supports the claim) and citation recall (claims that have support are cited).
- Methods: NLI-style entailment models, LLM judges (""[15.28 LLM-as-judge concepts and limitations](15.28-llm-as-judge-concepts-and-limitations.md)"") with their biases, human review.
- A grounded answer can be factually wrong if the source is wrong; an ungrounded answer can be true (and still a failure of a context-only task).
- Also test the opposite: when context lacks the answer, does the model abstain?

### 4. HOW DOES IT WORK?

Split answer into claims -> align each to context spans -> label entailed/contradicted/unstated -> aggregate; separately check citations point to the supporting span.

### 5. SIMPLE EXAMPLE

An open-book exam: marks are for using the book correctly, not for answers from memory.

### 6. TECHNICAL EXAMPLE

Policy bot answers 'refunds within 30 days' but the retrieved policy says 14 days: contradicted claim, groundedness failure even though 30 days is plausible.

### 7. CODE

```python
# run inside lab/ -- toy lexical groundedness: share of answer content words found in the context
def grounded_share(answer, context):
    stop = {"the", "a", "is", "are", "of", "to", "in", "and", "within"}
    ctx = set(context.lower().replace(".", "").split())
    words = [w for w in answer.lower().replace(".", "").split() if w not in stop]
    return sum(w in ctx for w in words) / len(words)
ctx = "Refunds are accepted within 14 days of purchase."
print(grounded_share("Refunds accepted within 14 days", ctx), grounded_share("Refunds accepted within 30 days", ctx))
```

### 8. INPUT → PROCESS → OUTPUT

```
answer + context -> claims -> entailed / contradicted / unstated -> groundedness score + citation checks
```

### 9. ENTERPRISE USE CASE

Enterprise RAG assistants gate on groundedness and require citations that users can open.

### 10. AI ENGINEERING CONNECTION

Core RAG quality metric; also used for summarisation and tool-result faithfulness.

### 11. ADVANTAGES

- Directly actionable; checkable without world knowledge.

### 12. LIMITATIONS

- Lexical overlap is a weak proxy (toy example); NLI/judges err; context may be wrong.

### 13. TRADE-OFFS

- Strict grounding reduces helpfulness (more abstentions).

### 14. COMMON MISTAKES

- Using word overlap as the final metric.
- Not testing unanswerable questions.

### 15. PERFORMANCE / COST CONSIDERATIONS

Claim-by-claim verification costs extra model calls.

### 16. SECURITY CONSIDERATIONS

Retrieved documents can contain injected instructions; groundedness does not detect that (Tier 32).

### 17. INTERVIEW EXPLANATION

Groundedness asks whether each claim is supported by the provided context. I decompose answers, label each claim entailed/contradicted/unstated, add citation precision/recall and test abstention on unanswerable questions; it differs from factuality, which concerns the world.

### 18. RAPID-FIRE ANSWER

Supported by the given context, claim by claim, plus citations and abstention.
