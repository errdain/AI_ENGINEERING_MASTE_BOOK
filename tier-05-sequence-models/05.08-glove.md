# 5.8 GloVe

> **In plain words**
> **GloVe** (Global Vectors) learns embeddings in a different way from Word2Vec. First it **counts, over the whole corpus, how often every pair of words occurs together** (a big table). Then it finds vectors whose **dot product matches the logarithm of those counts**. Word2Vec learns from one window at a time; GloVe uses the global statistics directly. In practice both give similar embeddings.

**You need first:** 5.4 Word embeddings, 1.19 Matrix factorization.

> **Figure 5.8-1 — from counts to vectors**
>
> ```mermaid
> flowchart LR
>     T["corpus"] --> X["co-occurrence matrix X<br/>X[i][j] = how often j is near i"]
>     X --> L["log X"]
>     L --> F["find vectors with<br/>wᵢ · w̃ⱼ + bᵢ + b̃ⱼ ≈ log Xᵢⱼ"]
>     F --> E["embeddings"]
> ```
>
> *How to read it:* the table of counts is built once. Training then adjusts small vectors so that their dot products reproduce the log-counts, weighting frequent pairs more but not too much (a cap on the weight function).

**Words you'll meet on this page**

| Word | What it means here |
|---|---|
| co-occurrence matrix `X` | `X_ij` = how often word `j` appears near word `i` |
| `w_i`, `w̃_j` | the two vectors for a word (centre / context) |
| `b_i`, `b̃_j` | scalar biases |
| weighting function `f` | down-weights very frequent and ignores unseen pairs |
| weighted least squares | squared error multiplied by a weight |
| `x_max` | the count above which the weight stops growing |
| global statistics | counts over the entire corpus |

### 1. What is it?
An embedding method (Pennington, Socher & Manning, 2014) that minimizes `J = Σ_{i,j} f(X_ij)·(w_i·w̃_j + b_i + b̃_j − log X_ij)²`.

### 2. Why does it exist?
Word2Vec uses only local windows and learns online; matrix methods (LSA) use global counts but weight them poorly. GloVe combines the efficiency of count statistics with the good geometry of predictive training.

### 3. Detailed explanation
- **Motivation: ratios of probabilities.** For words `i = ice`, `j = steam`, and probe `k`: `P(k | ice)/P(k | steam)` is large for `k = solid`, small for `k = gas`, near 1 for `k = water` (related to both) or `k = fashion` (related to neither). GloVe wants vector differences to encode such ratios, which leads to the log-linear form above.
- **Weighting.** `f(x) = (x/x_max)^α` for `x < x_max`, else 1 (typically `x_max = 100`, `α = 0.75`); `f(0) = 0`, so pairs that never co-occur cost nothing.
- **Training.** Only the non-zero entries of `X` are used, with SGD/AdaGrad. Cost scales with the number of non-zero pairs, not with `V²`.
- **Final embedding.** `w_i + w̃_i` (the sum of the two vectors).
- **Distance weighting.** Counts are often weighted by `1/distance` so nearby words count more.
- **Versus Word2Vec.** Similar quality in practice; GloVe is deterministic given the counts; Word2Vec needs no big matrix in memory.
- **Versus LSA.** LSA factorizes (transformed) counts with an SVD (code in 5.4 ②); GloVe's weighting and log make rare and frequent pairs balance better.
- **Limits.** Static; whole-corpus counts must be built first; no subword information.
- **Pre-trained GloVe** vectors (50–300 d, trained on Wikipedia/Common Crawl/Twitter) are widely used as initialization.

### 4. How does it work?
Count co-occurrences, initialize vectors, minimize the weighted squared difference between `w_i·w̃_j + biases` and `log X_ij`.

### 5. Simple example
A seating chart reconstructed from a table of "how many times these two people sat together": find 2-D positions such that closeness reflects the log of the counts.

**By hand.** `X_ij = 100` gives target `log 100 = 4.6`; `X_ij = 10` gives 2.3. A model prediction of 3.0 for the first pair has squared error `(3.0 − 4.6)² = 2.6`, weighted by `f(100) = 1`.

### 6. Technical example
`glove.6B.100d.txt` provides 100-dimensional vectors for 400,000 words trained on 6 billion tokens (REVIEW_REQUIRED: quoted figures).

### 7. Code
**① By hand (plain Python).** Build the co-occurrence table and the weighting function.

```python
sentences = [s.split() for s in ("the cat chased the mouse", "the dog chased the cat", "the cat liked the fish")]
vocab = sorted({w for s in sentences for w in s}); idx = {w: i for i, w in enumerate(vocab)}
X = [[0.0] * len(vocab) for _ in vocab]
for s in sentences:
    for i, w in enumerate(s):
        for j in range(max(0, i - 2), min(len(s), i + 3)):
            if j != i:
                X[idx[w]][idx[s[j]]] += 1.0 / abs(i - j)             # nearer words count more
print("X[cat][chased] =", X[idx["cat"]][idx["chased"]], "   X[cat][fish] =", X[idx["cat"]][idx["fish"]], "   X[cat][mouse] =", X[idx["cat"]][idx["mouse"]])
f = lambda x, xmax=100, alpha=0.75: (x / xmax) ** alpha if x < xmax else 1.0
print("weights f(0), f(1), f(10), f(100), f(1000):", [round(f(x), 3) for x in (0, 1, 10, 100, 1000)])
```

```text
X[cat][chased] = 1.5    X[cat][fish] = 0.0    X[cat][mouse] = 0.0
weights f(0), f(1), f(10), f(100), f(1000): [0.0, 0.032, 0.178, 1.0, 1.0]
```

**② With NumPy.** Train GloVe with gradient descent on the non-zero entries.

```python
import numpy as np

sentences = [s.split() for s in ("the cat chased the mouse", "the dog chased the cat", "the cat liked the fish", "the dog liked the bone",
                                  "a red car was here", "a blue car was here", "a red ball was here", "a blue ball was here") * 4]
vocab = sorted({w for s in sentences for w in s}); idx = {w: i for i, w in enumerate(vocab)}; V = len(vocab)
X = np.zeros((V, V))
for s in sentences:
    for i, w in enumerate(s):
        for j in range(max(0, i - 2), min(len(s), i + 3)):
            if j != i:
                X[idx[w], idx[s[j]]] += 1.0 / abs(i - j)
rows, cols = np.nonzero(X)
rng = np.random.default_rng(0); d = 6
W, Wc, b, bc = rng.normal(0, 0.1, (V, d)), rng.normal(0, 0.1, (V, d)), np.zeros(V), np.zeros(V)
fw = lambda x: np.minimum((x / 20) ** 0.75, 1.0)
lr = 0.05
for epoch in range(300):
    err = (W[rows] * Wc[cols]).sum(1) + b[rows] + bc[cols] - np.log(X[rows, cols])
    g = fw(X[rows, cols]) * err
    np.add.at(W, rows, -lr * g[:, None] * Wc[cols]); np.add.at(Wc, cols, -lr * g[:, None] * W[rows])
    np.add.at(b, rows, -lr * g); np.add.at(bc, cols, -lr * g)
    if epoch in (0, 299):
        print(f"epoch {epoch + 1:>3}: weighted squared error {np.sum(fw(X[rows, cols]) * err ** 2):.2f}")
E = W + Wc; E = E / np.linalg.norm(E, axis=1, keepdims=True)
sim = lambda a, c: float(E[idx[a]] @ E[idx[c]])
print(f"cat ~ dog {sim('cat', 'dog'):.2f}   red ~ blue {sim('red', 'blue'):.2f}   cat ~ red {sim('cat', 'red'):.2f}")
```

```text
epoch   1: weighted squared error 89.64
epoch 300: weighted squared error 0.01
cat ~ dog 0.68   red ~ blue 0.89   cat ~ red 0.34
```

**③ With PyTorch.** The same loss with autograd.

```python
import numpy as np
import torch

sentences = [s.split() for s in ("the cat chased the mouse", "the dog chased the cat", "the cat liked the fish", "the dog liked the bone",
                                  "a red car was here", "a blue car was here", "a red ball was here", "a blue ball was here") * 4]
vocab = sorted({w for s in sentences for w in s}); idx = {w: i for i, w in enumerate(vocab)}; V = len(vocab)
X = np.zeros((V, V))
for s in sentences:
    for i, w in enumerate(s):
        for j in range(max(0, i - 2), min(len(s), i + 3)):
            if j != i:
                X[idx[w], idx[s[j]]] += 1.0 / abs(i - j)
rows, cols = np.nonzero(X); x = torch.tensor(X[rows, cols], dtype=torch.float32)
rows, cols = torch.tensor(rows), torch.tensor(cols)
torch.manual_seed(0)
W, Wc = torch.nn.Embedding(V, 6), torch.nn.Embedding(V, 6); b, bc = torch.nn.Embedding(V, 1), torch.nn.Embedding(V, 1)
for m in (b, bc):
    torch.nn.init.zeros_(m.weight)
for m in (W, Wc):
    torch.nn.init.normal_(m.weight, 0, 0.1)
params = [p for m in (W, Wc, b, bc) for p in m.parameters()]
opt = torch.optim.Adam(params, lr=0.01)
weight = torch.clamp((x / 20) ** 0.75, max=1.0)
for epoch in range(300):
    pred = (W(rows) * Wc(cols)).sum(1) + b(rows).squeeze(1) + bc(cols).squeeze(1)
    loss = (weight * (pred - torch.log(x)) ** 2).sum()
    opt.zero_grad(); loss.backward(); opt.step()
E = torch.nn.functional.normalize((W.weight + Wc.weight).detach(), dim=1)
print(f"final weighted squared error {loss.item():.3f}")
print("cat ~ dog:", round((E[idx['cat']] @ E[idx['dog']]).item(), 2), "   cat ~ red:", round((E[idx['cat']] @ E[idx['red']]).item(), 2))
```

```text
final weighted squared error 0.008
cat ~ dog: 0.91    cat ~ red: 0.0
```

### 9. Enterprise use case
Cheap pre-trained word vectors for classical NLP models and quick similarity features.

### 10. AI engineering connection
Initialization for small models; historical bridge between count-based and neural representations.

### 11. Advantages
Uses global statistics; stable; strong pre-trained vectors available.

### 12. Limitations
Static; needs the co-occurrence table; no subwords.

### 13. Trade-offs
Memory for the matrix versus streaming training of Word2Vec.

### 14. Common mistakes
Forgetting the weighting function (frequent words dominate); using only one of the two vectors; mismatched vocabularies.

### 15. Performance / cost
Cost ∝ number of non-zero co-occurrences.

### 16. Security
As other embeddings.

### 17. Interview explanation
"GloVe builds a global word-word co-occurrence matrix and trains vectors so that dot products plus biases approximate the log counts, using a weighted least-squares loss with a capped weight function. It is count-based like LSA but trained like a predictive model, and performs similarly to Word2Vec."

### 18. Rapid-fire answer
Fit `w_i·w̃_j + b_i + b̃_j ≈ log X_ij` with weights `f(X_ij)`; global counts; final vector = sum of the two; similar quality to Word2Vec.
