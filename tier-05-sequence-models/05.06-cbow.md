# 5.6 CBOW (continuous bag of words)

**Metadata** — Tier: 5 · Phase: 1 · Priority: P1 · Difficulty: 2/5 · Interview: Medium · Hands-on: Medium
Prerequisites: 5.5 Word2Vec · Leads to: 5.7 Skip-gram

> **In plain words**
> **CBOW** is one of the two Word2Vec games. You hide the **middle word** of a small window and guess it from the **average of its neighbours**: from "the ___ sat on" guess "cat". "Bag of words" means the neighbours' order is ignored; they are just averaged. It is faster than skip-gram and works well for frequent words.

**You need first:** 5.5 Word2Vec.

> **Figure 5.6-1 — CBOW**
>
> ```mermaid
> flowchart LR
>     W1["the"] --> A["average of the<br/>context vectors"]
>     W2["sat"] --> A
>     W3["on"] --> A
>     W4["the"] --> A
>     A --> P["predict the centre word:<br/>cat"]
> ```
>
> *How to read it:* the context words on both sides each look up an embedding; the embeddings are averaged into one vector; that vector is scored against every candidate centre word. One training example per centre word, not one per (centre, context) pair, so CBOW does about `1/window` as many updates as skip-gram.

| Word | What it means here |
|---|---|
| CBOW | predict the centre word from the average of its context |
| context window | words within `w` positions on each side |

| centre word | the word being predicted |

| frequent word | CBOW is strongest on these |

### 1. What is it?
Word2Vec variant with input = context words and output = centre word: `h = mean(E[context])`, score each word `w` by `h · u_w`.

### 2. Why does it exist?
Averaging the whole context into one vector makes each training step cheap and smooths noise. For large corpora and frequent words it trains faster than skip-gram.

### 3. Detailed explanation
- **Model.** Input embeddings `E` (`V × d`), output vectors `U` (`V × d`). `h = (1/|C|) Σ_{c∈C} E[c]`; loss = negative sampling or softmax for the true centre word.
- **Order is ignored** inside the window. "dog bites man" and "man bites dog" give the same context average for the middle word. Recurrent models (5.10) fix this.
- **Gradient sharing.** The gradient on `h` is split equally across all context words, so each gets `1/|C|` of it (a reason CBOW often needs a larger learning rate than skip-gram, as in `code/seqmodels.py`).
- **Versus skip-gram (5.7):** CBOW is faster and good for frequent words; skip-gram is slower but better for rare words and small data.
- **Window size.** Wider windows capture topical similarity; narrower ones capture syntactic similarity.
- **Output.** The input matrix `E` is the embedding table.
- **Relation to BERT.** Masked language modelling predicts a hidden word from its context, but with a deep, order-aware network (Tier 8).
- **Implementation detail.** Context words near the sentence boundaries have fewer neighbours, so the average is over fewer vectors.

### 4. How does it work?
Pick a centre word; look up and average its context embeddings; score the true centre against sampled negatives; update.

### 5. Simple example
A fill-in-the-blank quiz: "the ___ sat on the mat". The surrounding words suggest the answer; you do not care which neighbour came first.

**By hand.** Context vectors `[1, 0]`, `[0, 1]`, `[1, 1]`, `[0, 0]` average to `[0.5, 0.5]`; the word whose output vector points most in that direction is predicted.

### 6. Technical example
`gensim.models.Word2Vec(sentences, sg=0)` trains CBOW (`sg=1` is skip-gram).

### 7. Code
**① By hand (plain Python).** CBOW training examples: (context list, centre).

```python
sentence = "the cat sat on the mat".split()
window = 2
examples = []
for i, centre in enumerate(sentence):
    context = [sentence[j] for j in range(max(0, i - window), min(len(sentence), i + window + 1)) if j != i]
    examples.append((context, centre))
for context, centre in examples[:3]:
    print(context, "->", centre)
print("CBOW examples:", len(examples), "   skip-gram pairs for the same text:", sum(len(c) for c, _ in examples))
```

```text
['cat', 'sat'] -> the
['the', 'sat', 'on'] -> cat
['the', 'cat', 'on', 'the'] -> sat
CBOW examples: 6    skip-gram pairs for the same text: 18
```

**② With NumPy.** CBOW with a full softmax on a tiny corpus.

```python
import numpy as np

data = [s.split() for s in ("the cat chased the mouse", "the dog chased the cat", "the cat liked the fish", "the dog liked the bone") * 5]
vocab = sorted({w for s in data for w in s}); idx = {w: i for i, w in enumerate(vocab)}; V = len(vocab)
examples = []
for s in data:
    ids = [idx[w] for w in s]
    for i, c in enumerate(ids):
        ctx = [ids[j] for j in range(max(0, i - 2), min(len(ids), i + 3)) if j != i]
        examples.append((ctx, c))
rng = np.random.default_rng(0)
E, U = rng.normal(0, 0.1, (V, 6)), rng.normal(0, 0.1, (V, 6))
softmax = lambda z: np.exp(z - z.max()) / np.exp(z - z.max()).sum()
for epoch in range(200):
    loss = 0.0
    for ctx, c in examples:
        h = E[ctx].mean(0); p = softmax(U @ h); loss -= np.log(p[c])
        dz = p.copy(); dz[c] -= 1
        dh = U.T @ dz; U -= 0.1 * np.outer(dz, h); E[ctx] -= 0.1 * dh / len(ctx)
    if epoch in (0, 199):
        print(f"epoch {epoch + 1:>3}: average loss per example {loss / len(examples):.3f}")
h = E[[idx["the"], idx["chased"], idx["the"], idx["mouse"]]].mean(0)
print("context [the, chased, the, mouse] -> predicted centre:", vocab[int(np.argmax(U @ h))])
```

```text
epoch   1: average loss per example 2.058
epoch 200: average loss per example 0.326
context [the, chased, the, mouse] -> predicted centre: dog
```

**③ With PyTorch.** CBOW as an `nn.Module` using `nn.EmbeddingBag` (mean of embeddings).

```python
import torch

class CBOW(torch.nn.Module):
    def __init__(self, V, d):
        super().__init__()
        self.emb = torch.nn.EmbeddingBag(V, d, mode="mean")             # averages the context vectors
        self.out = torch.nn.Linear(d, V)
    def forward(self, context):
        return self.out(self.emb(context))

data = [s.split() for s in ("the cat chased the mouse", "the dog chased the cat", "the cat liked the fish", "the dog liked the bone") * 5]
vocab = sorted({w for s in data for w in s}); idx = {w: i for i, w in enumerate(vocab)}; V = len(vocab)
X, y = [], []
for s in data:
    ids = [idx[w] for w in s]
    for i, c in enumerate(ids):
        ctx = [ids[j] for j in range(max(0, i - 2), min(len(ids), i + 3)) if j != i]
        ctx = (ctx + [ctx[0]] * 4)[:4]                                   # pad to 4 by repeating the first (keeps the demo simple)
        X.append(ctx); y.append(c)
X, y = torch.tensor(X), torch.tensor(y)
torch.manual_seed(0); model = CBOW(V, 6); opt = torch.optim.Adam(model.parameters(), lr=0.05)
for epoch in range(100):
    loss = torch.nn.functional.cross_entropy(model(X), y); opt.zero_grad(); loss.backward(); opt.step()
print(f"final loss {loss.item():.3f}   training accuracy {(model(X).argmax(1) == y).float().mean().item():.2f}")
```

```text
final loss 0.280   training accuracy 0.80
```

Fast domain embeddings for large internal text collections.

### 10. AI engineering connection
Predicting a word from surrounding context foreshadows masked language modelling (BERT).

### 11. Advantages
Fast; good for frequent words; smooth.

### 12. Limitations
Ignores word order; weaker for rare words than skip-gram.

### 13. Trade-offs
Speed versus rare-word quality.

### 14. Common mistakes
Using the same learning rate as skip-gram; ignoring boundary effects; calling it a sequence model (it is not).

### 15. Performance / cost
One update per centre word.

As Word2Vec.

### 17. Interview explanation
"CBOW predicts the centre word from the average of its context embeddings. Averaging makes it fast and good for frequent words but throws away word order; skip-gram does the reverse, predicting context from the centre, which is slower but better for rare words."

Predict centre from the mean of context embeddings; fast; ignores order; skip-gram is the mirror image.

### 20. Hands-on exercise
**Goal:** order-blindness.

1. Compute the CBOW context average for `["dog", "bites"]` and `["bites", "dog"]` with random embeddings.
2. Are they equal?

<details>
<summary>Show a solution</summary>

```python
import numpy as np

rng = np.random.default_rng(0)
E = {w: rng.normal(size=4) for w in ("dog", "bites", "man")}
a = np.mean([E["dog"], E["bites"]], axis=0)
b = np.mean([E["bites"], E["dog"]], axis=0)
print("same average for either order:", np.allclose(a, b))
```

```text
same average for either order: True
```
