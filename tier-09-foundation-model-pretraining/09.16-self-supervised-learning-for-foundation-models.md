### 1. WHAT IS IT?

*Self-supervised learning* (SSL) manufactures the supervision signal from the data itself: hide part of the input and predict it. No human labels are needed, so the dataset can be as large as the internet.

### 2. WHY DOES IT EXIST?

Labels are expensive and task-specific; raw text is abundant. Predicting hidden parts of text forces the model to learn grammar, facts, code patterns and reasoning regularities *as a side effect*, giving a general-purpose starting point.

### 3. DETAILED EXPLANATION

SSL turns an unlabeled corpus into a supervised problem: `(visible context) -> (hidden target)`. Three common ways to hide: the **future** (next-token, [9.17](09.17-next-token-prediction.md)), **random positions** (masked LM, [9.18](09.18-masked-language-modeling.md)) and **spans** (denoising, [9.19](09.19-pretraining-objectives.md)). The same idea works for images (masked patches) and audio. The choice of what to hide determines the model family and what it is good at.

*Figure 10 — Three self-supervised setups side by side: which positions may be read (blue) and which receive a loss (red-outlined rows). All three create labels from the text itself.*

### 4. HOW DOES IT WORK?

1. Take raw text and tokenize. 2. Cut windows of `ctx` tokens. 3. Choose what to hide (the next token, random tokens, a span). 4. The model predicts it from visible context. 5. Cross-entropy against the hidden truth is the loss. 6. Backprop and update.

### 5. SIMPLE EXAMPLE

A fill-in-the-blank workbook generated automatically from any book: the answer key is the book itself.

### 6. TECHNICAL EXAMPLE

In the lab, `get_batch` slices windows `x = data[i:i+ctx]` and targets `y = data[i+1:i+1+ctx]`: the labels are the same stream shifted by one, so no annotation exists anywhere in the pipeline.

### 7. CODE

```python
# Run from lab/: self-supervision in one call — inputs and labels both come from the same token stream.
import numpy as np
from pretrain import get_batch

stream = np.arange(1000, dtype=np.uint16)            # a stand-in token stream
x, y = get_batch(stream, ctx=8, bs=2, seed=0, step=0)
print(x[0].tolist()); print(y[0].tolist())            # y is x shifted by one position
assert (y[:, :-1] == x[:, 1:]).all()
```

Source: [`lab/pretrain.py`](lab/pretrain.py) (`get_batch`).

### 8. INPUT → PROCESS → OUTPUT

```
unlabeled text -> tokens -> (context, hidden target) pairs made automatically -> loss -> weights
```

### 9. ENTERPRISE USE CASE

Enterprises have lots of unlabeled internal text and few labels. SSL-style continued pretraining ([9.30](09.30-domain-adaptive-pretraining.md)) exploits that, as do embedding models trained with contrastive self-supervision (Tier 6 and Tier 20).

### 10. AI ENGINEERING CONNECTION

Every LLM, embedding model and vision-language model starts with an SSL stage. Fine-tuning ([Tier 10](../tier-10-fine-tuning-alignment/README.md)) is *supervised* on top of it; RAG relies on SSL-trained embedding and generator models.

### 11. ADVANTAGES

- Unlimited, label-free data; scales with compute.
- Representations transfer to many downstream tasks.

### 12. LIMITATIONS

- The objective is a proxy: low loss does not guarantee helpfulness, truthfulness or safety.
- Learns biases and errors present in the data.

### 13. TRADE-OFFS

Causal objectives give natural generation but see only left context; masked objectives give bidirectional context but weaker generation and sparser loss signal ([9.18](09.18-masked-language-modeling.md)).

### 14. COMMON MISTAKES

- Thinking "no labels" means "no data quality problem".
- Comparing losses between different objectives or tokenizers.
- Expecting a base model to follow instructions without alignment.

### 15. PERFORMANCE / COST CONSIDERATIONS

SSL is data-efficient per token (every position of a causal model yields a gradient) but compute-heavy overall; cost scales with `6ND` ([9.15](09.15-compute-budgets.md)).

### 16. SECURITY CONSIDERATIONS

Because the corpus is the teacher, poisoned or private text becomes behaviour or memory. Data provenance and scrubbing ([9.9](09.09-data-provenance.md), [9.10](09.10-data-licensing.md)) are the controls.

### 17. INTERVIEW EXPLANATION

"Self-supervised learning builds the labels from the data itself — hide something and predict it. For LLMs the hidden thing is the next token, so any text corpus becomes a training set, every position gives a gradient, and the model picks up grammar, facts and code as a by-product. The catch is the objective is only a proxy for what we actually want."

### 18. RAPID-FIRE ANSWER
